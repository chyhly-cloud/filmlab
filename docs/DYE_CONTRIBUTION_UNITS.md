## 原始链式乘积与单位

基准红层曝光对三染料的局部导数为：

```
∂(C,M,Y)/∂q_R = [.6815840063, −.1223113839, −.0772585101]
```

C/M/Y是模型染料谱的系数（染料当量单位），不是染料浓度或光子能量。
指数扫描路径b*对三染料的局部导数为：

```
∂b*/∂(C,M,Y) = [8.22782761, 32.97649363, −24.43609659]
```

逐项乘积得到：

|链式路径|乘积|单位|
|---|---:|---|
|红层有效曝光→青染料→扫描b*|+5.6079557067|b* / log10(H_R)|
|红层有效曝光→品红染料→扫描b*|−4.0334005709|b* / log10(H_R)|
|红层有效曝光→黄染料→扫描b*|+1.8878964142|b* / log10(H_R)|

复算直接使用完整3×3 `J_Lab,dye * J_dye,q`，而非相乘不同样本的中位数。
该q0指数链式总和与完整链直接差分的最大Lab误差1.65e-9；paper_only为5.08e-9。

**5.61和3.46不是每EV，也不是灯外围实际增加了多少色差。**
b*正方向为黄，不是单独的红色指标；红橙方向必须同时看a*和b*。

## 有限染料分解：总变化固定，路径分配不唯一

对固定静态扫描函数F(C,M,Y)及两染料端点，
先改C再改M与先改M再改C，总变化始终为F(end)−F(start)，
但每次改变量分到哪条染料路径可以不同。
这即使在光滑、每个输入都单调的函数中也成立，不需要使用反常曲线或裁切反例。

最小可嵌入三染料的例子：

```
F(C,M,Y) = C*M + Y
start = [1,1,1], end = [2,2,2]
```

在整个正值盒子中∂F/∂C=M>0、∂F/∂M=C>0、∂F/∂Y=1>0。
总变化为4，但：

- C→M→Y路径分配为[1,2,1]；
- M→C→Y路径分配为[2,1,1]；
- 全六种顺序的Shapley平均为[1.5,1.5,1]。

第二个相同单调函数的端点[1,2,1]→[2,1,.5]模拟正负变化共存：
总变化−.5；C先为[2,−2,−.5]，M先为[1,−1,−.5]，Shapley为[1.5,−1.5,−.5]。
这不是FilmLab实验结果，只是分配可变而总和不变的数学反例。

### 不要求可微的有限界限

对实际端点的8个染料组合值V(S)，定义

```
m_i(S) = V(S∪{i}) − V(S), i不在S中
```

每个染料有4个上下文边际值。任何坐标顺序对该染料的分配都等于其中一个；
Shapley是这些边际的非负加权平均，所以严格满足

```
min_S m_i(S) ≤ Shapley_i ≤ max_S m_i(S)
Σ_i Shapley_i = V({C,M,Y}) − V(∅)
```

这个界限不需要扫描曲线光滑，存在LUT或裁切也能用。
工具保存两个反例的8角点、六路径、Shapley与每染料边际范围，并用测试检查效率/界限。
可用相同方法给实际局部的有限分配报告范围，避免把某一坐标顺序当成唯一贡献。

若F在整个端点盒子内二阶连续，换序引起的两染料边际差还可写为混合导数的矩形积分，
其绝对值≤sup|∂²F/∂d_i∂d_j|·|Δd_iΔd_j|。
但实际插值/裁切并非处处C²，不能未经检查直接套用这个光滑Hessian界限。

### 解释边界

局部链式Jacobian在指定模型、指定点、可导条件下有明确含义；
有限Shapley对**指定8角点和权重**也唯一确定。
不唯一的是“有限变化按哪种路径或分配规则归属”的物理解释，
不是说Shapley的数学定义不唯一。

混合染料角点是诊断性干预，未必能由真实显影历史产生；
平均这些顺序不能证明真实化学先后、抑制剂释放量或可归属的光子数量。
真实模型曝光路径上的积分分解需要指定并验证相应的连续耦合路径，不能从两个端点自行推断。

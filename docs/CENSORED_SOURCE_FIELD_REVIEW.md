# 逐单元失测源场：独立审查

2026-10-21 UTC。只读检查 `censored_source_field.py` 与首轮两灯 JSON/NPZ；未修改主程序、生产文件或拟合参数。
本审查区分实现是否满足声明的约束、最终照片是否改善，以及数学源场是否真实三个问题。

## 新实验的判别范围

此前五空间模板只有4维，解析界只限制线性红层返回的far/near比，不直接约束完整非线性Lab。
本轮固定同一112谱共同witness与总幅度，开放严格删失支持内88/34个单元，确实检验了此前未覆盖的空间方向。
若完整前向下降，则不能再把旧有限模板失败称为所有空间源场均无作用；但此结果不修改旧解析界，也不证明返回核或后端正确。

## 实现与约束

- 同一固定SPD产生每个源单元的直接/返回曝光，二者不独立调色。
- 幅度变量是原profile的无量纲倍率；总和固定88/34，SPD本身已包含约696.8/477.0的引擎Y系数。
  固定SPD下，总倍率固定意味着相对输入积分固定；不能把88/34或三层曝光之和称为SI辐射能量。
- 每单元相机代理下界保持，终点最大摄像机代理deficit约3.3e−16/0，属于舍入。
- 总和变化近灯1.6e−13、中灯5.7e−14；单元basis重放误差约1.4e−12/9.1e−13，完整Lab重放约5.7e−14。
- `linear_proposal`对零和增量、逐单元下界与信赖域加硬约束；它没有将总和作为带任意权重的软残差。
- 线性方案必须经完整非线性训练MSE下降与实际/预测下降比≥0.1验收；留出不参与选步。
  近灯后两轮整步被拒绝、半步被接受；中灯第三轮同样拒整步、接受半步。

近灯首轮QP报告`Iteration limit reached`，但可行性和完整非线性下降检查通过，实际/预测下降比约0.970。
它可以作为可行下降步，不能描述为QP收敛或达到局部/全局最优。
初始信赖域是总倍率的四分之一（22/8.5），并非每个单元原幅度的25%，允许大幅重排。
实际下降比检验控制了本次线性外推；它不赋予剧烈源场物理真实性。

## 源场集中与辨识性

| 项目 | 近灯：初始→终点 | 中灯：初始→终点 |
|---|---:|---:|
| 有效单元数 `(sum s)^2/sum(s²)` | 77.90→9.42 | 32.38→2.17 |
| 峰/均倍率 | 1.80→19.01 | 1.59→19.63 |
| 最大单元占总输入 | 2.05%→21.61% | 4.69%→57.75% |
| 贴住相机代理下界的单元 | 0→75/88 | 0→30/34 |
| 相对初始源场L1变化 | 1.758 | 1.739 |
| 加权质心 `(native y,x)` | (101.682,101.226)→(103.944,104.564) | (104.723,104.867)→(103.254,102.804) |

相机下界总量只占固定总量的1.92%/2.39%，其余近98%可重分配。
强约束满足并没有防止大部分能量集中到少量单元；缺乏源几何或镜头独立测量时，这些结果只能称源场witness。
集中本身不是不物理的证明：未分辨的小发光结构确实可能比饱和足迹窄，不能仅凭有效单元数小而否决。
当前不足的是实际灯具在这些位置具有该空间能量分配的独立支持，以及局部颜色验收未通过。
不据尖峰解恢复灯具形状，不以相机代理下界成立认证实际SPD或绝对辐射，也不据此拟合材料/扫描。

## 合成已知源场核查的实际含义

目标是冻结模型自身产生的已知微扰场，验证同SPD算子与有限非线性下降，不是真实800T材料或实灯实验。
近灯训练MSE从7.41e−5降至2.49e−7，中灯8.30e−5降至1.45e−7，完整变化与线性预测吻合。
但已知源场的相对L1误差仅近灯0.03348→0.03142、中灯0.02994→0.02271。
输出误差下降数百倍并不等于源场恢复达到相同精度；不能把这个检查称为实际空间辐射准确恢复。

## 一次空间对调检查的解释规则

可以固定原SPD、总量、初值、数值协议和同一目标，将原groups 1/3用于拟合、0/2用于报告，
比较两次源场的L1距离、质心/二阶矩、能量集中度和双向预测；不从方向中择优或平均后推广。
这是一项预声明的同图空间再拟合敏感性检查，不是新的外部盲测，也不是完整交叉验证：
固定SPD及既有背景本身已经使用过原训练区最终RGB。
必须在元数据中明确`fit_groups`，保存原groups标签，避免将未改变硬编码残差的运行误称对调。
即使两个方向稳定，也不能证明实灯源场真实；若大幅移动或改变尖峰分配，则应降低对该输入形状的可信度。

本轮首轮结果支持：未知源场形状对完整模型有可观察影响，但自由源场主要获得训练收益，尚未解决真实橙红过渡。
三步有限结果不证明任意真实源场无解，也不把残差归因给某一材料、显影或扫描环节。

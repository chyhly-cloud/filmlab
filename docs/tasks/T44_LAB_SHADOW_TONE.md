# T44：冲印店的暗部传递——逐通道黑位的实测（Claude；研究代际）

## 0. 摘要

- **T40 的"Dn 0.15–0.4 处真实是模型 1.3–3.7 倍"大部分不是传递关系，是逐帧定光。**
  - 每帧每通道的定光 δ 只用中间调（对齐输出 0.05–0.6）来定，与暗部无关。δ 跨帧离散 σ 0.09–0.14（logE），中位 +0.05 / +0.035 / +0.014（R/G/B），按帧自助 95% 区间都含 0。所以没有可实现的系统偏移，属于逐帧定光（T08：不可预测）。
  - 相纸代理在暗部的 log 斜率约 3–3.5，中间调约 1.5–2。所以同一个 δ 在暗部被放大约一倍。T40 按固定定光看到的倍数，是这一放大与真正传递项的叠加（第 2.3 节分解表）。
  - 扣掉 δ 后，跨帧一致的传递项集中在**片基附近**：Dn < 0.05 处，真实比模型亮 R ×1.66、G ×1.18、B ×0.84（B 帧间 σ 0.39，不确定）。到 Dn 0.25 以上，R 回到 ×1.03。
- **结构：逐通道的输出黑位，一个通道一个参数。** 真实 = β + (1 − β)·N(xe − δ)，N 是现有的数字相纸输出（已含 OUTPUT_BLACK 0.002）。β 就是这家冲印店文件的黑位比相纸代理高出的量。
  - 共同 β：**R 0.0030（95% 0.0015–0.0045），G 0.0015（0–0.0030），B 0.0015（0–0.0055）**。
  - 留一帧时 β 范围：R 0.0025–0.0040，G 0.0010–0.0025，B 0.0010–0.0025。
  - 逐帧 β 离散大（R 四分位 0.0010–0.0050）。β 与整帧平均亮度无正相关（Spearman −0.28 / −0.29 / −0.12，p 0.31 / 0.26 / 0.67），所以不是拍摄端的眩光。
  - 对照两种钳位结构（每通道同样一个参数）：相纸曝光钳位（以定光为锚）、底片密度钳位（以片基为锚，即"扫描黑点在片基"）。黑位结构在三个通道上暗部代价都最低（相对无结构：0.555 / 0.848 / 0.924，钳位 0.63–0.99），留一偏差 R 从 −0.179 降到 +0.027。
- **物理来源**：Frontier 的输出是逐通道灰平衡 LUT，暗部侧参考点映射到一个设定的目标黑（Fuji US6668096B1 的结构），不是相纸 Dmax。实测量就是这个目标黑的逐通道值：R 抬得最多，所以片基附近偏品红（实测 G/R 0.61）。它不是任意曲线，只是把现有的 OUTPUT_BLACK（中性 0.002）换成这家店逐通道实测的值。
- **实现**：修正标志 `lab_shadow`，`engine.LAB_SHADOW_BLACK = (0.0030, 0.0015, 0.0015)`，在最终输出上做 β + (1 − β)·out。代际 `t44_base` = t31_base + lab_shadow。现有 15 个代际 × 2 像素尺度逐位不变；t31_base 新渲与 T41 缓存逐位相同。

- **目视（本人）**：暗部从近乎纯黑抬到很深的暗红褐 / 品红。暗处层次略多，灯、光晕、中间调不变，整体不输 t31。但它不会出现真实那种蓝紫夜空，在两张 EPFL 夜景上仍明显比真实黑。**建议**：数据上可以作为新基准（全图 ΔE 留出 −0.21，其余不变或改善）；黑的色调比较主观，需要用户看整图后确认。

## 1. 目标

- EPFL 同场景对照里最显眼的差别是暗部：真实的夜空和暗部是抬起的深蓝或紫，模型接近纯黑。
- T40 已排除场景、镜头眩光、片基 / Dmin 和扫描黑位，定位到冲印店的暗部影调。
- 本任务：
  - 实测冲印店暗部的传递关系，分清传递本身（跨帧一致）与逐帧定光；
  - 对照扫描仪的物理结构；
  - 在 t31_base 的输出级按实测加入，并评估。
- 规则：胶片部分不动。冲印店项必须是输出级可测量的属性，不用经验调色补胶片的问题。

## 2. 实测

### 2.1 数据与方法（`scratchpad/t44/`：`trace.sh`、`cells.py`、`common.py`、`prof2.py`）

- 帧：T40 的 18 帧已确认配对（夜景 8、暖光灯箱 4、白光灯箱 4、色卡 R1-20-21、楔 R1-17-18）。
  - 用 t31_base 重新生成 trace（`t32_epfl_trace.py`，楔帧用手工几何）。
  - 24 px 格子中位；去掉画外，以及灯芯 24 px 以内的格子；共 18 942 格。
- 自变量：模型的归一化底片密度 Dn_c（片基 = 0）。t31_base 的相纸曝光为 xe_c = K_c − off_c − Dn_c（固定光号 + T07 颜色偏移）。
- 逐通道输出函数 N(xe)：中性相纸曲线 + OUTPUT_BLACK 的逐通道形式（T42 per_channel 的公式）。它与 t31 的实际输出相差中位 1–4%，来自相纸染料的跨通道项，暗部近中性处更小。
- **定光与传递的分离**：
  - 每帧每通道的 δ 只由中间调格拟合：对齐输出 0.05–0.6，即 xe − δ ∈ [−0.21, 0.25]，迭代 3 次，soft_l1；
  - 中间调格少于 40 的通道不参与，包括 R1-05-6 全部、R1-03-4 与 R1-06-7 的 R、B；
  - 暗部格（xe − δ > 0.25，即对齐输出 < 0.05）只用来定传递结构。
- 结构（每通道一个参数）：
  - S1 黑位：β + (1 − β)·N(xe − δ)；
  - S3x 相纸曝光钳位（以定光为锚）：N(smin(xe − δ, x_bp))；
  - S3d 底片密度钳位（以片基为锚）：N(K − off − smax(Dn, Dn_bp) − δ)，平滑宽度 0.03。
- 跨帧一致性：逐帧最优参数的离散；共同参数按帧自助 2000 次；留一帧（用其余帧定参数，被留帧只用自己的 δ，报告暗部误差）。
- 先试过的全联合优化（`joint.py`）太慢，已停止，改用等价的参数网格剖面（`prof.py`、`prof2.py`）。`a1.py`–`a3.py` 是早期探索：δ 用全部格子拟合时会吸收暗部，夜景帧尤其如此，不作结论。

## 3. 物理来源

- **Frontier 一类扫描仪的暗部链**（Fuji US6668096B1，见 docs/EPFL_HIGHLIGHT_VALIDATION.md 的摘录；本次 Google Patents 返回 503，未能重新取原文，按仓库已有摘录）：
  1. CCD 读透射率。薄负片（片基附近）透射最大，扫描仪按片基设置增益 / 积分时间，使其接近满量程。这一段测量信噪比最好，不会造成抬升。
  2. 由本帧密度直方图求暗部侧（最低密度）与高光侧参考点，建立**逐通道**灰平衡 LUT（每通道偏移 + 斜率）。
  3. 输出转换（显示 / 文件用的 LUT）把暗部侧映射到一个目标黑。这个目标是设置值，不是相纸的物理 Dmax。
- **实测形状对应第 3 步的目标黑**：
  - 加性、逐通道、跨帧一致（与场景亮度无关），且只在输出 < 0.02 处可见。这正是"输出 = 黑位 + (1 − 黑位)·LUT"的形状。
  - 以片基为锚的密度钳位（"扫描黑点在片基"）与以定光为锚的相纸钳位都更差（2.4 节）。实测的不是硬的黑点截断，而是抬起的黑位。
  - 模型里已有这个量：`scanning.paper.OUTPUT_BLACK = 0.002`（中性，此前由混合冲印店扫描调参）。本修正把它换成这家店的逐通道实测值。等效输出黑位 b' = 1 − (1 − β)(1 − 0.002) = **0.0050 / 0.0035 / 0.0035**。
  - R 黑位最高，所以片基附近偏品红：实测 G/R 0.61，t44 为 0.77，t31 为 1.05。
- **不是什么**：
  - 不是任意曲线：每通道一个数，对应一个已有的输出量。
  - 不是拍摄端眩光：与场景亮度不相关；T40 中楔背景在空间上平坦。
  - 不是胶片 Dmin：t31 的片基已在相纸曲线顶端。
  - 不是逐帧定光：定光已逐帧扣掉；δ 不显著偏离 0，不实现。
- **US6668096B1 的灰平衡斜率（受限的通道反差）**这次没有单独拟合：只用偏移 + 黑位即可解释暗部，加斜率会与 δ 混在一起。

## 4. 实现

- `filmlab/engine.py`：
  - `LAB_SHADOW_BLACK = (0.0030, 0.0015, 0.0015)`（注释写明实测方法、区间与留一范围）；

  - `Scanner(..., shadow_black=None)`；

  - 先裁切再抬黑：在裁切前抬黑，会让色域外的负值被抬后又截成 0，同一像素在 t31 / t44 间不再是仿射关系（测试 `test_output_is_per_channel_affine_of_t31` 抓到过）。

  - β_R = R 通道暗部（对齐输出 < 0.05）在逐帧中间调定光之后，跨 15 帧共同的线性黑位抬升；
  - β_G、β_B 同理（17、15 帧）。
  - 没有其他自由参数。
- **逐位核对**（`bitwise.py`，同 T43）：
  - 合成灯光图在 15 个现有代际 × 2 像素尺度上，git HEAD 与改动后 30 组输出逐位相同；

## 5. 评估（脚本同 T41 / T43，只改代际名；8 夜景，STOPS=0，cos⁴）

### 5.1 暗背景判据的口径

- T35 的问题：黑位抬高后，绝对阈值（背景 < 0.02）会筛掉一部分灯，光晕统计比较的就不是同一组灯。
- 本修正是逐通道仿射。中位与单调映射可交换，所以阈值换成 β + (1 − β)·0.02（逐通道）时，选出的灯与未抬升时相同。"超出背景"的剖面只差因子 (1 − β) ≈ 0.997。
- 实现：`tools/eval/t19_halo_stats.dark_bg_max(文件名)`，环境变量 `BG_LIFT="子串:βR,βG,βB"` 只作用于文件名含该子串的模型渲染，参考扫描不受影响。默认仍为 0.02，旧结果不变。`t24_dist_colour.py`、`t27_size_halo.py` 与 scratchpad 的 `m1.py` 改用它。
- 两种口径都报告：绝对阈值（`t44_base`）与相对阈值（`t44rel`，同一渲染）。β 小，两者几乎相同。60–150 µm 灯数为 149/181（t31）、149/178（t44 绝对）、149/179（t44 相对）。

## 7. 结论

1. **暗部差别的主体是逐帧定光，不是传递关系。** 在中间调扣掉逐帧定光后，跨帧一致的传递项只剩片基附近的抬升（R ×1.66、G ×1.18，B 不确定）。T40 的 1.3–3.7 倍是逐帧定光被相纸代理较陡的暗部斜率放大的结果。逐帧定光的均值不显著偏离 0，不实现。
2. **传递项的结构是逐通道输出黑位**：每通道一个参数，跨帧一致（R 区间 0.0015–0.0045，留一 0.0025–0.0040），优于两种钳位结构，与场景亮度无关。物理上对应 Frontier 输出 LUT 的目标黑（逐通道），即现有 OUTPUT_BLACK 的逐通道实测值：等效 0.0050 / 0.0035 / 0.0035。
3. **t44_base = t31_base + lab_shadow。** EPFL 全图 ΔE00 10.64 → 10.33（留出 10.43），红带 0.252 → 0.246，灯旁持平，T19 RMS 三档改善，光晕与红环不变。片基附近颜色 G/R 1.05 → 0.77（真实 0.61）。
4. **蓝紫夜空没有解决**：R1-05-6 的天空蓝来自这一帧的负片 / 光源（各帧片基平均 B/G 1.04，不偏蓝），R1-03-4 的天空是逐帧提亮的中间调。
5. **建议**：数据上 t44_base 可以成为新基准（只加一个有测量依据的输出量，指标不变或改善）。黑的色调需要用户看整图确认；如果用户认为暖品红的黑不如 t31 的纯黑，保留为研究代际。
6. **下一步**：
   - 夜空的蓝：查夜景天空区在 S1（光源 / 天空光谱）与负片蓝层上的值，看真实的 B 从何而来；
   - 楔帧背景仍暗一半，且 δ ≈ 0，单帧原因待定；
   - G、B 在 Dn 0.25–0.4 剩约 ×1.2（帧间 σ 内）：可在同店新数据上检验灰平衡 LUT 的通道斜率（US6668096B1 的受限斜率）。

## 8. 局限

- 自变量是模型的 Dn，不是真实负片的密度。模型负片在暗部的误差（S1 光源、天空光谱）会进入离散，这是逐帧 β 离散大的一个原因。
- 只有 EPFL 一家冲印店、一次拍摄。8 个评估场景都在 18 帧测量集中；留出版只是留一帧，不是独立数据。
- 中间调不足的帧（R1-05-6 全部，R1-03-4、R1-06-7 的 R、B）不参与 β 的估计。
- 暗部格没有剔除光晕外圈与灯旁杂光，只去掉灯芯 24 px 内的格子。
- G、B 的 β 区间下沿为 0，只是弱证据；B 的帧间离散很大。

## 负责人结论

审核范围：逐帧定光与暗部传递的分解、三种结构的对比、留一检验、`scanner.py` / `engine.py` 差异、暗背景判据的处理、460 项测试（通过）、逐位核对、整图与 EPFL 四景三列对照。

1. **任务前提被修正，接受。** T40 测到的"暗部是模型的 1.3–3.7 倍"，大部分来自逐帧定光：同一偏移在相纸代理曲线最陡的暗部被放大约一倍。跨帧一致的只有片基附近的逐通道黑位抬升，R 最多，所以片基偏品红（真实 G/R 0.61，t31 1.05，t44 0.77）。
2. **这是现有量的实测替换，不是新的经验项。** 原来的 `OUTPUT_BLACK` 是中性 0.002，现在改为这家冲印店实测的逐通道值；结构符合 Frontier 设定目标黑点的方式。R 的证据扎实，G、B 弱。
3. **数据支持采用。** 留出帧全图 ΔE 10.64 → 10.43；灯旁、红带、光晕、T19 不变或略好；灯的选择经单调映射保持一致。
4. **夜空的深蓝没有出来**：那是这一帧负片或光源的颜色，不是冲印店黑位。楔帧背景仍只有真实的一半，原因未明。
5. **是否换基准，等用户目视确认。** 变化只在暗部：从近纯黑变成很深的红褐 / 品红，暗部细节稍多，灯、光晕、中间调不变。用户认可，就以 t44_base 为新基准；否则保留为研究代际。

# T36：按层项的绿层 w 与哑光压片板的漫反射（Claude；研究代际）

## 0. 摘要

- **A. 绿层 w**：按 T11 同一方法单独算出绿层 w_G = **0.676**（红层 0.765，蓝层按定义 0）。它只比红层的 w 小 0.09，绿层核总量只增加 **5.6%**（t34_phys 0.0997 → 0.1053，为 t31_base 的 0.35 → 0.37 倍）。
  - 绿层光晕被压到约 0.35 倍，主要来自已有的物理：绿光到片基的整层密度 D_G = 1.115（要整层斜穿红感层及其中的青成色剂遮罩），以及返回斜光程 g_G < 1。只看下行斜程的均匀深度部分就已 ×0.57。
  - 逐深度精确积分检查（同一叠层、逐波长）给出的绿层 A(θ) 介于 w=0.765 与 w=0.676 之间，更接近 0.765。所以"w 近似使绿层过暗"的假设**不成立**。
  - 成片上 t36_phys 与 t34_phys 几乎相同。**EPFL 光源旁 ΔE00 16.11 → 16.07**，远没回到 t31_base 的 15.52。其余测量变化都在 ±0.01 内。
- **B. 压片板**：原实现（T15）把压片板当**镜面**：透出片基的光以同一角度返回，落在 2·t·tanθ。改成**朗伯漫反射**版本：
  - 下行横移 t·tanθ 与回程横移 t·tanθ′ 按随机方位做矢量和；
  - 回程角分布由光学扩展量守恒推出；
  - 板与片基之间多次反射按几何级数计入。
  - 能量与解析值、径向分布与蒙特卡洛逐档一致（±0.002）。
  - 这仍是 halo_plate 项，新标志 `halo_plate_lambert` 只在 t36_base 启用。
- **压片板扫描**（ρ = 0 / 0.03 / 0.05 / 0.08，另做 0.3 诊断）：**暗缝没有被填上**。
  - 板反射光只加在红层：灯芯旁 25–100 µm 的 R 增加 0.01–0.04，G 反而下降 0.01–0.03（输出端串扰，推断）。Y(50 µm) 不升反降。
  - 真实与模型在暗缝处的差别主要在 **G（亮度）**：60–150 µm 灯 50 µm 处 G 真实 0.90、模型 0.66–0.71；R 是 0.91 对 0.85–0.88。
  - 片基返回光在这个模型里只能加红，填不了"白—橙"的过渡。ρ = 0.3 也一样。
- 外圈 700–1500 µm 没有被抬高（板反射光只落在 2·t·tanθc ≈ 234 µm 以内）。
  - T19 0–60 µm 档 RMS(Δr) 0.054 → 0.045（ρ=0.05），150–400 µm 档 0.053 → 0.060。
  - EPFL 光源旁 16.07 → 16.11 / 16.14 / 16.18（ρ = 0.03 / 0.05 / 0.08），全图不变。
- **选定 ρ = 0.05**：0.03–0.08 之间各项差别都小，取哑光黑漆、黑色阳极氧化的中间值。
  - 候选代际 `t36_base` = t36_phys + halo_plate（朗伯，ρ = 0.05）。
  - 它物理上更完整，但不改善 EPFL，也不解决暗缝。**不建议据此替换 t31_base**。

## 1. 目标

1. T34 末尾负责人结论：t34_phys 光源旁变差（+0.59），可能是按层项对绿层沿用红层 w（T11 近似）导致光晕过红。按同一方法逐层算 w，检验这一点。
2. 裁切对照中模型是"白芯—暗缝—红环"，真实是连续的橙色辉光。检查压片板项（halo_plate）的实现，用物理取值评估它能否填暗缝。

规则：只纠正已有项的近似与取值。不动定光、灯亮度先验、遮罩放置、蓝层映射、m（= 4）。现有代际逐位不变。

## 2. A：按层的 w

### 2.1 定义与推导

T11 的按层深度斜程衰减（u = 1/cosθ − 1，D 为该层波段到片基的整层密度，即 `film.oblique_densities`）：

    A(θ) = w · 10^(−D·u) + (1 − w) · (1 − 10^(−D·u)) / (D·u·ln10)

w 的定义是：该层波段内，散射发生在该感光层**之上**的比例。用 `emulsion_stack` 同一设定：
- 每层吸收 A_c(λ) = 0.15·S_c/max S_c；
- 散射消光 turb = 0.15·(550/λ)³，各层相同；
- 黄滤光层只吸收、不散射；
- 某层被散射（而非吸收）的比例 sc(a) = (1 − 10^(−a))·turb/a，a = 该层总消光；
- 按该层感光度 S_c(λ) 加权。

| 层 | 之上 | 之上的散射 above(λ) | 本层内的散射 inside(λ) | w |
|---|---|---|---|---|
| 红 | 蓝层、黄滤光层、绿层 | sc(a_B) + 10^(−a_B−A_Y)·sc(a_G) | 10^(−a_B−A_Y−a_G)·sc(a_R) | **0.7651**（= scatter_above_red，不变） |
| 绿 | 蓝层、黄滤光层 | sc(a_B) | 10^(−a_B−A_Y)·sc(a_G) | **0.6764** |
| 蓝 | 无 | 0 | sc(a_B) | **0**（即 T03 均匀深度平均） |

    w_c = Σλ S_c·above / Σλ S_c·(above + inside)

绿层波段内的平均量（S_G 加权）：
- turb 0.160、a_B 0.165、A_Y 0.189、a_G 0.256；
- 蓝层散射 0.304，绿层内散射 0.146 → w_G = 0.304 / 0.450 = 0.676。

绿层之上虽然只有一层，但该层与绿层的散射消光相同，且绿光在蓝层几乎不被吸收（a_B 中吸收只占 0.005），所以蓝层散射的绿光比绿层自己还多。w_G 因此只比 w_R 小一点。

## 4. B：压片板项的实现核对与漫反射版本

### 4.1 原实现（T15，`halation_kernel(plate=ρ)`）

- θ < θc 时：refl(θ) = R(θ) + (1 − R)²·ρ / (1 − ρ·R)。
  - 片基背面菲涅耳反射 R，加上透出 → 压片板 → 透回 → 背面与板之间多次往返的几何级数。
  - 对**镜面**板，能量守恒是对的。
- 返回光**以同一角度 θ**、落在**同一半径 2·t·tanθ**；斜光程 A(θ)、g(θ) 都按 θ 计。
- 结论：这是**镜面**处理。哑光黑压片板是漫反射，回程角与入射角无关，落点也不在 2·t·tanθ。

### 4.2 朗伯版本（`film._plate_lambert_kernel`，`halation_kernel(..., plate_diffuse=True)`）

1. **下行**：以 θ 到达片基背面的光，权重 w(θ) = cos^m 角分布 × A(θ)（与主核相同），透出 1 − R(θ)，横移 a = t·tanθ。只计 θ < θc。
2. **压片板**：漫反射率 ρ，朗伯（出射强度 ∝ cosθ_a）。
   - 回到片基背面时按空气 → 片基的菲涅耳透入，其余被背面反射回板，再漫反射……
   - 透入片基的比例 = ρ·T_d / (1 − ρ·R_d)。R_d 是朗伯入射的半球反射率：n = 1.5 时 R_d = 0.092、T_d = 0.908，片基侧积分与空气侧独立积分一致。
   - 空气隙忽略：压片板压紧，隙 ≪ t；在隙里往返只改变方向分布，不产生横移。
3. **回程角分布**：由光学扩展量守恒 n²·cosθ′·dΩ′ = cosθ_a·dΩ_a，透入片基的光在 θ′ ∈ [0, θc] 内按 p(θ′) ∝ (1 − R(θ′))·2n²·sinθ′·cosθ′ 分布，∫p = T_d。回程横移 b = t·tanθ′，方位与下行无关。返回乳剂时各层吸收按 θ′ 的斜光程 g_c(θ′)（halo_return）。
4. **落点** |a + b|，相对方位均匀。实现上用细网格（步长 t/130）上两段环分布的二维卷积求径向分布，再按解析总量栅格化到画面像素。
5. **能量**（不重新归一，吸收的就是损失）：

       E_plate = Σ_{θ<θc} w(θ)·(1 − R(θ)) · ρ·T_d / (1 − ρ·R_d) · ⟨g(θ′)⟩_p

   菲涅耳部分 R(θ) 仍按镜面留在主核的 2·t·tanθ 处。

核验（`kchk.py`；130 µm 片基，cos^4，不含斜程项）：
- cos^4 下 77% 的光以 θ < 42° 到达背面：5.8% 被背面反射，71.2% 透出，全反射 23.0%。
- 核增量与解析值一致（ρ = 0.05：+0.0325 对 0.0325）；镜面版 +0.0333。
- 径向能量分布（每 25 µm 一档）与 400 万次蒙特卡洛逐档差 ≤ 0.002。中位落点 85 µm（镜面版约 115 µm）。全部能量在 2·t·tanθc = 234 µm 以内。
- 面密度（×10⁻⁶ /µm²，r = 0 / 50 / 100 / 150 / 200 µm）：

| | 0 | 50 | 100 | 150 | 200 |
|---|---|---|---|---|---|
| 主核 | 0.40 | 0.41 | 0.31 | 0.24 | 0.30 |
| 朗伯 ρ=0.05 | 0.97 | 0.78 | 0.41 | 0.12 | 0.01 |
| 镜面 ρ=0.05 | 0.46 | 0.48 | 0.33 | 0.19 | 0.09 |

  朗伯板的返回光集中在灯芯正下方到 100 µm 内，在曝光空间正好落在"暗缝"处。

实现与标志：
- `halation_kernel` 新增 `plate_diffuse=False`，经 `multi_bounce_kernel`、`layer_halation_kernel`、`halation` 传递。
- `engine` 只在同时含 `"halo_plate"` 与 `"halo_plate_lambert"` 时用朗伯版本，反射率取 `engine.PLATE_REFLECTANCE_LAMBERT`（默认 0.05）。T15 的镜面研究项与 `PLATE_REFLECTANCE = 0.2` 不变。
- 灰卡定光用同一核：3200K 灰卡彩度 0.212，不变。
- 多次反射外环沿用"n 倍片基厚度"的近似，每环同一 ρ。

### 5.7 选定值

**ρ = 0.05**。理由：
- 物理：哑光黑漆、黑色阳极氧化的漫反射率约 0.03–0.08，0.05 居中。

候选代际 `t36_base` = t36_phys + halo_plate（朗伯，`PLATE_REFLECTANCE_LAMBERT` = 0.05）。

## 7. 结论

1. **A**：按层的 w 已实现为 halo_layered 的修正（w_G = 0.676，w_B = 0）。量很小：绿层核 +5.6%，EPFL 光源旁 16.11 → 16.07，其余测量不变。T34 负责人结论中"绿层沿用红层 w 使光晕过红、光源旁变差"的推断**不成立**。绿层光晕偏弱主要来自绿光到片基的整层密度（含红层里的青成色剂遮罩）与返回斜光程，这些是已有物理。
2. **B**：原压片板实现是镜面的。已给出并实现朗伯漫反射版本（能量、径向分布都核对过）。在物理取值 0.03–0.08 下，它让灯芯旁 25–100 µm 的 R 略升、G 略降，**不能填补暗缝**。真实暗缝处缺的是 G（白色的近场光），片基返回光在这个模型里只加红。EPFL 光源旁再变差 0.04–0.11。
3. **选定 ρ = 0.05**，候选代际 `t36_base`。物理上它比 t36_phys 完整（真实相机都有压片板），但不改善 EPFL，也不解决暗缝。建议作为研究代际保留，不替换 t31_base。
4. t34/t36 光源旁 +0.55 的来源仍未找到，建议下一步：
   - 在 EPFL 上对三项逐项消融（只加下行斜程 / 只加按层 / 只加返回），看 +0.55 由哪一项带来；
   - 用 `t31_epfl_lamps.py` 逐灯核对颜色与亮度，区分"更红"与"更暗"。
5. 暗缝（缺白色近场光）不属于片基光晕。应在乳剂正面散射（`emulsion_scatter` 只有 σ = 4 µm）、拍摄端眩光（T20）或高光扫描映射（T13）里找。

## 8. 局限

- 真实 800T 与带碳对照是不同场景、不同灯的总体，没有估计抽样误差。暗缝处的"白色光晕部分"有一部分可能来自两组灯本身的差别。
- 中位剖面上看不到"缝"。负责人定义的暗缝量（min R(50–200)/R(25)）实际度量的是下降快慢；逐灯"再升起"比例被邻近光源干扰。裁切中的暗缝在中位统计里表现为 G 与 Y 在 25–100 µm 下降过快。
- 压片板提高灯芯边缘亮度，会让少量像素越过灯芯阈值（0.93），灯芯半径与分档随之改变。外圈个别档的跳动来自这一点。
- 两分量 A(θ) 公式本身对红层多算衰减（60° 时 0.36 对精确 0.42），对蓝层少算。本任务按要求只改 w，没有改公式。改用精确深度积分会让红层光晕增强，是另一项已有近似的修正，未评估。
- 朗伯板忽略空气隙。板的真实散射可能不是严格朗伯，也可能有纹理或局部镜面成分。多次反射外环用"n 倍片基厚度"近似。
- G 在灯芯旁随红层曝光增加而下降，推断来自输出端的通道串扰，未逐级追踪。

## 负责人结论（Fable 审核）

审核范围：报告数值、`film.py`/`engine.py` 差异、414 项测试（通过）、现有代际逐位不变的前后对比、`$SP/t36/full` 8 张整图与灯区裁切。

1. **两个假设都被否定，这是本任务的结果，不是失败。**
   - A：绿层 w 按同一方法独立算出 0.676，与沿用的 0.765 差别小；精确逐深度积分还落在二者之间。t34_phys 灯旁色差变差（+0.59）**不是**绿层 w 近似造成的，这条线索关闭。
   - B：压片板原实现是镜面处理，改为朗伯漫反射在物理上更对（能量、径向分布均与蒙特卡洛一致），但无论 ρ 取 0.03–0.08 还是诊断用的 0.3，都填不了白芯与红环之间的暗缝。
2. **暗缝的真正性质已经定位：是颜色，不是红光缺口。**
   - 60–150 µm 灯在 50 µm 处：R 真实 0.91、模型 0.85–0.88，差别小；G 真实 0.90、模型 0.66–0.71，差别大。
   - 真实 800T 比带碳对照在 25–50 µm 多出近乎白色的光（R +0.098，G +0.103）。片基返回光在这个模型里只进红层，所以任何片基项都补不了这一段。
   - 这与"红晕比灯色扩散强 1.2/1.7 倍"是同一问题：缺的是灯色（近白）的近场扩散，在绿、蓝层同样存在。候选来源依次为乳剂正面散射的近场、拍摄端眩光（T20）、高光扫描映射（T13）。
3. **基准不变，仍为 t31_base。** t36_phys、t36_base 保留为研究代际：EPFL 灯旁 16.07 / 16.14 对基准 15.52，没有改善；T19 0–60 µm 档略好、150–400 µm 档略差。
4. **保留的实现**：`scatter_above_layers`、朗伯压片板核与 `halo_plate_lambert` 标志，默认关闭、现有代际逐位不变。以后若压片板项重新启用，应以朗伯版本为准，`PLATE_REFLECTANCE_LAMBERT = 0.05` 为哑光黑的物理中值。
5. **下一步**（取代原计划的"再调红层"）：
   - 先解决灯绝对亮度的不确定（约 5 档）：用灯未裁切的公开夜景 HDR 数据把 U[6,8] 档先验换成测量（T37 调研进行中）。近场的白色扩散量直接随灯亮度走，先验不定，近场项的任何拟合都没有意义。
   - 然后对近场白色扩散逐项消融（正面散射 / 眩光 / 扫描映射），用 EPFL 逐灯核对"更红"还是"更暗"。
   - T35（灰阶扫描调子）在其后。

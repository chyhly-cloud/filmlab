# T33：蓝层映射的物理约束与 DIR 层间抑制量定标（Claude）

## 0. 摘要

- **A（蓝层映射）：任务前提不成立，没有新代际。**
  - 现行 `blue_xyz`（T16）在 XYZ 里做非负拟合。对全部 27 款人造光源成员，拟合结果都是只有 Z 的系数为正，X、Y 系数为 0，即蓝层曝光 = k·Z。
    - 它已经是"只由短波积分器决定"的映射。
    - 方案 2（只用 Z，保白点）、方案 3 的 XYZ 版（X 系数 = 0）与现状逐位相同。
  - 方案 1（只用 sRGB B）与方案 3 的 sRGB 版（R 系数 = 0）都更差：
    - sRGB B 不是非负的短波积分器，真实颜色上可以为负。
    - T16 灯边测试（sRGB B = −0.09）在多数光源类下又得到 0 蓝层曝光，T16 的黄色硬边会回来。
    - 高压钠灯类的训练集误差从 0.053 升到 0.325。
  - 对按光谱构造的发光饱和色，现行映射在模型的相机假设（相机 = CIE 观察者）下是对的：
    - 红 LED、红霓虹、琥珀 LED、低压钠的蓝层曝光为 3200K 中灰的 6e−4…3e−3，即 ≈ 0；
    - 高压钠 0.30（真值 0.30），绿 LED / 绿霓虹 0.22 / 0.36（真值 0.10 / 0.26），蓝 LED 38（真值 30）。
  - T32 里"线性映射给饱和红 B/R 0.2–0.7"不是映射外推出来的，来源是输入：
    - EPFL 的 G81 把红灯箱解码成线性 sRGB (1, 0.07, 0.042)；
    - 对 > 600 nm 的光，CIE 观察者给出的是 (1, −0.07, −0.01)，Z ≈ 0。
  - 按胶片自己的参照（3200K 中灰，线性 sRGB B = 0.060，不是日光中灰的 0.184）：
    - 这块红的 Z 是中灰的 0.81，sRGB B 是中灰的 0.68；
    - 所以蓝层曝光接近中灰水平，是输入的短波信号本身决定的。
  - T32 的反事实"蓝层不高于相机 B"把 RAW B 和日光中灰比，在胶片单位下多压了约 0.5 log。按 3200K 中灰换算后：
    - +2…+3 档 B/G：默认定光 2.26 → 1.18，O1 定光 2.37 → 1.77；
    - 真实 0.58，仍差很远。
  - G81 原始通道里，这个红灯箱是 [1, 0.195, 0.103]：
    - 实测 Bayer 相机（Nikon D5100）对 630 nm 红 LED 只有 [1, 0.05, 0.005]；
    - 所以灯箱很可能真有短波光，或者 G81 的蓝通道在红区漏光更多。
  - 没有 G81 的光谱感光度，RGB 分不开这两种情况。这是输入端的相机同色异谱，不是胶片物理，不在本任务的修正范围内。
- **B（DIR 定标）：色相方向不一致，与灰楔也略冲突，按规则不实现。** 只给诊断整图。
  - 减小 `dir_amount` 后，模型偏饱和的通道向真实靠近：
    - 红的 G：log10(模型/真实) −0.045 → −0.008（dir 0.5）；
    - 青的 R：−0.116 → −0.026；
    - 蓝的 R：−0.229 → −0.154；
    - 品红的 G（1 帧）：−0.33 → −0.06。
  - 另一些通道反而远离：
    - 红的 B：+0.21 → +0.25；
    - 黄的 B：+0.09 → +0.18；
    - 绿的 R（3 帧）：+0.06 → +0.12。
  - 灰阶楔三通道斜率按构造几乎不随 dir 变（中性灰阶由 `_intrinsic_curve` 固定），dir 越小绿通道越陡：
    - 模型 0.81 / 0.62 / 0.67 → 0.82 / 0.65 / 0.68（dir 0.5）；
    - 真实 0.55 / 0.53 / 0.56。
    - 灰楔的反差差距与 DIR 无关。
  - 8 夜景 ΔE00：全图 10.64 → 10.53，光源旁 15.52 → 15.12（dir 0.5）。
    - 主要来自 R1-02-3（15.09 → 12.91）；
    - R1-00-1、R1-04-5、R1-03-4（全图）变差 0.3–0.4。
  - 专利口径的"分色 / 中性 gamma"在 dir 0.5 时为 0.99 / 1.04 / 1.06，低于 Kodak US 6,210,870 的 C-41 民用片范围（1.15–1.64）。
- 代码只加了一个默认关闭的机制：
  - `materials.DIR_AMOUNT`，以及 `generation.DIR_AMOUNT`（代际 → 覆盖）；
  - 现在没有任何代际使用它，现有代际逐位不变（n29240 t31_base 新渲与 T31 缓存最大差 0）。

## 1. 目标与方法

- 目标：
  - (A) 检查人造光源下蓝层的 RGB → 曝光映射对发光饱和色的外推，按物理约束给候选；
  - (B) 在 (A) 之后，用 EPFL 单光源控制帧定标 DIR 层间抑制量（`Emulsion.dir_amount`，彩色 1.0，未定标）。
- 规则：只校正真实存在的物理量；不加经验调色；不动定光方式、光晕核、灯亮度先验、遮罩放置。
- 基准：`t31_base`。
- 数据：
  - EPFL 8 夜景 R1-00-1…R1-07-8；
  - 控制帧（与 T32 同一组 12 帧）：背光色卡 R1-20-21（−1 档）、灯箱 / 灯管帧 R1-21-22…R1-35-36；
  - 灰阶楔 R1-17-18。
- 工具（`tools/eval/`）：

| 工具 | 内容 |
|---|---|
| `t33_blue_map.py` | A：现状与各方案的蓝层系数、训练反射率误差、发光饱和色、T32 红像素与 T16 灯边（第 2.1–2.3 节表） |
| `t33_camera_red.py` | A：colour 自带的两台实测相机（Nikon D5100、Sigma SD Merrill）看发光饱和色（第 2.4 节） |
| `t33_raw_blue.py` | A：G81 原始通道与解码 sRGB 在红像素上的比较（第 2.4 节） |
| `t33_red_classes.py` | A：EPFL 红像素的光源类权重与各类映射给出的三层曝光（第 2.3 节） |
| `t33_blue_cf.py` | A：S1 反事实（只诊断）：红物体蓝层 = 相机 sRGB B，分别以 3200K 中灰 / 日光中灰为参照（第 2.3 节） |
| `t33_dir_sweep.py` | B：从存档的 S1 logH 重新显影 + 扫描（t32_rescan，dir 1.0 与完整渲染最大差 7e−8），扫描 dir_amount；输出控制帧单通道传递、灰阶楔斜率、夜景 ΔE00 与红像素 |

- 训练反射率误差用独立随机种子的 2000 条（同 T16）。
- ΔE00 与红像素的口径同 T32：
  - ΔE00 在真实扫描几何里计算，与 `accept_t02.scene_job` 同法；
  - 红像素：RAW G/R < 0.3、B/R < 0.5，距灯芯 > 0.5 mm，光晕份额 < 0.2。

## 2. A：蓝层映射

### 2.1 现状的系数

`t31_base` 的人造光源走 `linear_wp_bxyz`：
- 红、绿层在 sRGB 里做非负拟合；
- 蓝层在 XYZ 里做非负拟合，再按列缩放保白点。

- 在模型的输入表示（线性 sRGB，按 CIE 观察者理解）里，唯一非负的短波积分器就是 Z，现状已经只用 Z。

### 2.3 那么饱和红的蓝层曝光从哪里来

T32 +2…+3 档红像素的 RAW 中位是线性 sRGB (0.983, 0.069, 0.041)，B/R 0.042，B 是日光中灰的 0.22。

胶片的参照是 3200K 中灰。它在 RAW 日光白平衡下的线性 sRGB 是 (0.309, 0.159, 0.060)，Z 0.082；日光中灰是 0.184 / 0.200。

| RAW 档 | Z / Z(3200K 中灰) | sRGB B / B(3200K 中灰) | Z 的组成 R / G / B | cur 蓝层：白炽 / 荧光 / LED / 金卤 |
|---|---|---|---|---|
| 0…+1 | 0.42 | 0.43 | 0.16 / 0.12 / 0.72 | 0.39 / 0.40 / 0.30 / 0.50 |
| +1…+2 | 0.77 | 0.72 | 0.17 / 0.18 / 0.64 | 0.73 / 0.74 / 0.56 / 0.92 |
| +2…+3 | 0.81 | 0.68 | **0.29** / 0.12 / 0.59 | 0.76 / 0.78 / 0.58 / 0.96 |

（蓝层曝光以 3200K 中灰为 1。）

- 这些像素的光源类权重中位：白炽 0.34、荧光 0.28、LED 0.20、金卤 0.12，日光与钠灯 ≈ 0（`t33_red_classes.py`）。
- 所以蓝层 ≈ 中灰的 0.6–1.0：输入的 Z（或 B）本身就在中灰的 0.7–0.8，各类的 k 只带来 ±0.2 log。
- 唯一与"发光饱和色"有关的量，是 Z 里来自 sRGB R 的那 29%：
  - 对真实的 > 600 nm 光，这一项会被负的 sRGB G、B 抵消；
  - 但 G81 解码出的 G、B 是正的，所以没有抵消。

S1 反事实（`t33_blue_cf.py`，只诊断，不进入渲染）：红物体蓝层不高于"相机 sRGB B"。

| 参照 | +2…+3 档 B/G 默认 / O1 | +1…+2 档 B/G 默认 / O1 | 全图 / 光源旁 ΔE00 |
|---|---|---|---|
| t31_base | 2.26 / 2.37 | 1.20 / 1.52 | 10.64 / 15.52 |
| 相对 3200K 中灰（胶片单位，正确） | **1.18 / 1.77** | 1.05 / 1.44 | 10.63 / 15.48 |
| 相对日光中灰（T32 s1b 的写法） | 0.17 / 0.68 | 0.66 / 0.90 | 10.63 / 15.80 |
| 真实 | **0.58** | 0.48 | — |

- 即使把蓝层压到相机 sRGB B 的水平（比现状低约 0.15 log），O1 定光下 B/G 仍是 1.77，真实 0.58。
- T32 的 0.68 来自把日光中灰当作胶片的中灰，多压了 log(0.184/0.060) ≈ 0.49。
- 撤回 T32 第 2.1 节"S1：红物体蓝层曝光不高于相机 B → B/G 0.68"的读法。按正确单位，这个机制只解释了约一半的 log 差距（默认定光）。

## 3. B：DIR 层间抑制量

### 3.1 作用方式（`chemistry.develop_image`，C-41 彩色显影）

1. 抑制强度 `inhib = e.dir_amount`（彩色显影；显影液的 acutance 为 0）。
2. 层间矩阵 `_dir_matrix(a)`：行 = 释放抑制剂的层，列 = 受抑制的层，顺序 R G B：

   ```
   A = a × [[0.15, 0.80, 0.45],
            [0.60, 0.15, 0.60],
            [0.45, 0.80, 0.15]]
   ```

   - 绿层受抑制最强（0.8）；
   - R↔B 不相邻，×0.75；
   - 对角 0.15 是同层（边缘效应）。
   - 相对强度按 Kodak US 6,210,870 的 C-41 民用负片"分色 gamma / 中性 gamma"标定，没有 500T 自己的测量。
3. 每层的显影比例 `first = S(logH)/halide_cap`（halide_cap = 1.4·Dmax），用 σ = 12 µm 高斯模拟抑制剂扩散。
4. 每层的有效曝光 = `logH_j − Σ_i first_i·A_ij`（logH 单位），再查"无抑制的内在曲线" C。
5. C 由 `_intrinsic_curve` 反推：中性曝光（三层同 logH）被抑制后正好回到厂商曲线 S。所以：
   - 中性灰阶的密度按构造不随 `dir_amount` 变；
   - 只有彩色曝光（层间显影比例不同）和边缘处受影响：低曝光层被高曝光层多抑制，于是增饱和。

所以 `dir_amount` 只是整个矩阵的标量缩放。改它不改中性反差（第 3.2 节灰楔）。

| 红（B） | 14 | +0.206 | +0.223 | +0.251 | +0.278 | +0.294 | **更远** |
| 黄（B） | 13 | +0.087 | +0.163 | +0.179 | +0.226 | +0.264 | **更远** |

### 3.3 结论

- 不存在一个 `dir_amount` 能同时让各色相更接近真实：
  - 模型偏饱和的通道（红 G、青 R、蓝 R、品红 G）支持 0.25–0.5；
  - 暖色的 B 与绿的 R 在现状已经偏高，减小 dir 会更远。
- 灰楔对 DIR 不敏感，方向略反。
- 按任务规则不实现。没有新代际 `t33_dir`，`generation.DIR_AMOUNT` 为空。
- 冲突的通道恰好是 S1 最不可靠的：
  - 暖色的 B 与第 2 节的相机同色异谱是同一个问题；
  - 红 G、绿 R 都落在 570–600 nm，500T 绿层在 580 nm 的感光是红层的 6.6 倍（T32 第 8 节）。
  - 所以"实际 / 预测"的偏差有多少属于 DIR、多少属于 S1，用成片分不开。
- 单一标量也表达不了观测到的模式：真实像是 R→G、G/B→R 的抑制比模型弱，而 R/G→B（对黄层）的抑制比模型强。
  - 这需要矩阵各项的形状，而不是缩放。
  - 矩阵形状来自 C-41 民用片专利，500T 没有独立测量，成片配对也不足以把 9 项分开定标。
- 诊断整图（**不是候选**）：`$SP/t33/full_b/01_n29240.jpg … 08_n33920.jpg`，① t31_base ② dir 0.5（同 t19_model 的渲染流程）。

## 4. 哪些是物理约束、哪些是数据定标

- 物理约束（不拟合）：
  - 蓝层曝光由非负的短波积分器决定（XYZ 里的非负组合，T16）。本任务确认它已只用 Z。
  - 中性灰阶的显影结果不随 DIR 强度变（内在曲线的构造）。
- 用数据定标的已有物理量：`dir_amount`（DIR 层间抑制量）。本任务的结论是用现有 EPFL 数据定不出一个一致的值，不改。
- 不在范围内：
  - 相机光谱感光度（G81，S0 输入端）；
  - DIR 矩阵各项的形状；
  - 500T 的分色 gamma。

## 5. 局限

- 发光饱和色的"真值"用的是构造光谱：高斯 LED、Ne 主要谱线、汞氩加 Zn₂SiO₄:Mn 绿粉近似。真实灯具不同，但量级结论（> 585 nm 的光对蓝层 ≈ 0）不受影响。
- 红灯箱的光谱未知。第 2.4 节只能界定"真有短波光"和"G81 蓝通道漏光"两种可能，不能裁定。colour 里只有两台实测相机，其中 Sigma 是 Foveon，不代表 Bayer。
- 单通道传递检验的横轴是模型的 S1 logH：真实的"实际 / 预测"包含 S1 误差（T32 第 8 节）。品红只有 1 帧，绿只有 3 帧，蓝 / 青的高彩度档只有 1–2 帧。
- 灯箱、色卡帧的胶片曝光未知（色卡用 −1 档）。品红灯管帧的配对仍待确认。
- 夜景全图 ΔE 的改善主要来自 R1-02-3。T32 记录这一帧的真实冲印比 `lab_measured` 预测的暗（O1 光号 +0.13…+0.15），因此可能部分是定光而不是 DIR。

## 负责人结论（Fable 审核）

- A 的前提（蓝层映射带 R、G 正系数）不成立：blue_xyz 已经只用 Z，对窄带红光给 ≈0。红灯箱的洋红来自输入本身——EPFL 的 G81 相机对饱和红给出 G 0.195、B 0.103（Bayer 相机约 B 0.005），而引擎假设相机等于 CIE 观察者。没有该相机的光谱感光度，这是三通道输入的同色异谱极限，如实保留。T32 的 B/G 反事实读法已更正（真实 0.58，默认定光下 1.18，不是 2.26）。
- B：单一标量 dir_amount 表达不了真实的层间抑制模式（R→G、G/B→R 比模型弱，R/G→B 比模型强），且方向冲突的通道正是 S1 最不可靠的波段；灰楔斜率与 DIR 无关。不实现，保留 DIR_AMOUNT 覆盖钩子（默认空）。
- 两个独立的遗留：(1) 灰阶楔上模型的输出斜率 0.81/0.62/0.67 对真实 0.55/0.53/0.56，模型整体反差偏陡且红通道更陡——这是冲印店扫描的影调（可像 T07 那样实测），影响所有场景与光晕的观感；(2) 红晕相对灯色扩散光偏强约 2 倍（T31）。

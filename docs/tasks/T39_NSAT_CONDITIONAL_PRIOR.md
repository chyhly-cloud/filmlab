# T39：截断灯亮度按"块外背景 × 三通道饱和比例"条件化（Claude；研究代际）

## 0. 摘要

- **做法**：
  - 逐通道饱和带进 stops 重建。新观测量 nsat3 = 块内三通道都饱和的比例，nch = 平均饱和通道数，在相机原始 RGB（白平衡前）上判定。
  - HDRI 假想 RAW 也改为在相机通道上截断。主矩阵用我们 n29240 的 Nikon；对照矩阵为 Sony n33920、Fuji n30464。
  - 条件表 = bg 5 档 × nsat3 3 档 × 类 × 尺寸档。新模式 `measured_cond2`，代际 `t39_base`。
  - 另做 `t39_corr`：同一张图、同一条件格内的分位按实测帧内组内相关抽样（ρ = 0.42）。
- **nsat3 是最强的预测量**：
  - 全部块 ρ = +0.82；灯具 0–60 / 60–150 / ≥150 µm 为 +0.74 / +0.87 / +0.73；24 张 HDRI 各自 +0.45…+0.87。
  - 换相机矩阵：nsat3 分档变化 5–17%，ρ 变化 ≤ 0.04。
  - 留出集（4 张）：
    - 预测中位与实测的 ρ：只用 bg 0.52，只用 nsat3 0.79，bg × nsat3 **0.81**；
    - 中位绝对误差：0.45 / 0.29 / **0.29** 档；
    - PIT 的 KS：0.026 / 0.040 / 0.039。
- **但按用户的三条判据，t39 都没有达到 t31**：
  1. **裸灯**（灯具类、nsat3 ≥ 0.5、暗背景，8 个场景中 146 块）：
     - 块 flux 中位：t31 **6.17** 档，t39 **2.12** 档（t39_corr 3.02）；
     - 60–150 µm 裸灯的光晕部分 / 真实（100–400 µm）：t31 **1.3–2.2**，t39 **0.18–0.49**（t39_corr 0.19–0.52）；
     - 测得的裸灯亮度（HDRI 中 nsat3 ≥ 0.5 的块，中位 1.9 / 2.9 / 3.7 档）在现有光晕链下给出的光晕不到真实的一半。**裸灯输给 t31。**
  2. **亮面**（nsat3 < 0.05，897 块）：
     - flux 6.66 → 0.43 档；
     - 60–150 µm 光晕部分 / 真实：0.66–0.97 → 0.09–0.27。**比 t31 小（满足）。**
  3. **相同的灯**：
     - 招牌那对（nsat3 0.55 / 0.52，同一格）：t31 5.52 / 6.02，t39 3.32 / 5.99，t39_corr 3.95 / 6.39；
     - 桥上灯排 47 盏的 flux 标准差：t31 0.70，t37 1.43，t38 1.27，t39 1.29，t39_corr 1.00 档；
     - HDRI 里"看起来相同"的灯 |Δflux| 中位 0.19 档；模型独立抽样 0.43 档，t39_corr 0.36 档。**仍明显宽于实测。**
- **多种子**（每个代际 3 个种子）：
  - EPFL 红带 RMS 的种子间范围：t37 0.164–0.252，t38 0.142–0.203，t39 0.148–0.176。**T38 报告的 0.252 → 0.203 在噪声内。**
  - t39 灯旁 ΔE00 三个种子 14.27–14.36，t37 14.36–14.83、t38 14.42–14.81。改善（约 0.3）略大于噪声；t31_base 为 15.52。
- **结论：不建议 t39_base 成为基准，基准仍为 t31_base。**
  - 在现有光晕链下，测得的裸灯亮度给出的光晕约为真实的 0.4 倍，目视上多数路灯仍失去光晕（整图与 t37 / t38 相似）。
  - 条件化本身是成立的测量结果（nsat3 能区分裸灯与亮面），保留为研究模式。
  - 主要矛盾已从"灯有多亮"移到"在测得的亮度下光晕链给出的光晕偏弱约 2 倍"，见第 7 节。

## 1. 目标与审核意见

T38 审核：
- 放弃 nsat3 的理由不成立。逐通道饱和在 RAW 中可得，只是没有传进 stops 重建。
- "相同的灯一弱一强"的根因是条件分布太宽。

本任务：
- A 把逐通道饱和带进重建并统一口径；
- B 二维条件表与留出检验；
- C 新模式与代际；
- D 相同灯一致性，必要时做帧内相关抽样；
- E 多种子噪声；
- F 评估与整图；
- G 本文档。

补充判据（用户目视认为 t31_base 最好）：
1. 裸灯的光晕回到 t31 水平并接近真实；
2. 亮面的光晕小于 t31；
3. 相同的灯亮度相同。

否则不换基准。

## 2. 逐通道饱和的口径（A）

### 2.1 RAW 侧（`filmlab/rawio.py: load_raw`、`_block_obs`）

- 只在 `measured_cond2` / `measured_cond2_corr` 下计算，其余模式不经过这里。
- 判据与当前截断判定相同：
  - channel_max（t31 系列的判定）：相机原始 RGB（postprocess raw、user_wb = 1）的每个通道 ≥ 0.97 × 该通道最大值；
  - sensor：`sensor_saturation(per_channel=True)` 的传感元饱和堆积。
- 每像素得到三通道饱和标志，按 step 下采样为三个比例（任一通道 / 三通道全部 / 饱和通道数）。块的观测量：
  - nsat3 = Σ f_all / Σ f_any；
  - nch = Σ f_nch / Σ f_any；
  - 块内没有任何通道饱和时都记为 0。
- **为什么不用 `sensor_saturation`**（审核建议用它）：
  - 在 n27416（Canon CR2）上，它判不出绿通道饱和。两个绿 CFA 通道的最大值是孤立的离群码值（16383 / 15862），饱和堆积在 15330 附近，落在它"最高 3% 量程"的搜索窗之外。结果整张图三通道全饱和比例为 0。
  - channel_max 的逐通道判定给出 0.26%，与其他场景两者一致的情况相符：

    | 场景 | sensor 全饱和比例 | channel_max 全饱和比例 |
    |---|---|---|
    | n29240 | 0.064% | 0.064% |
    | n40481 | 0.28% | 0.28% |
    | n40825 | 0.17% | 0.19% |
    | city_40095 | 0.081% | 0.083% |
    | n20595 | 0.032% | 0.033% |
    | city_61360 | 0.038% | 0.057% |
  - n33920（Sony 霓虹）两种判定都是绿通道从不饱和（红、蓝霓虹），nsat3 = 0 是真实情况。
  - 所以用"与截断判定同一判据"，并且不改 `sensor_saturation` 本身（next_sensor 等代际依赖它）。

### 2.2 HDRI 假想 RAW 侧（`tools/eval/t39_hdri_obs.py`）

- 透视渲染、锚、块划分同 T38。截断改在相机通道上：cam = M_cam · XYZ，XYZ 由 HDRI 的线性 Rec.709 换算，三个相机通道在同一满阱电平 S 处截断。

## 4. 实现（C）

- **`_block_obs(..., sat=None)`**：给出 sat = (f_any, f_all, f_nch) 时另返回 nsat3、nch。HDRI 与 RAW 用同一函数。
- **load_raw**：`measured_cond2(_corr)` 下按截断判定同一判据取逐通道饱和，下采样后传给 `reconstruct_highlights(..., sat=...)`。
- **`HIGHLIGHT_RECON = "measured_cond2"`**：与 measured 系列同一随机数、分类、尺寸档、反解、穹顶 0.7。
  - flux = `_cond2_flux(类, r_um, obs, u)`，查 bg 档 × nsat3 档；
  - bg 缺失时用 `flux_ns`；没有逐通道信息时 nsat3 = 0。
- **`"measured_cond2_corr"`**（t39_corr）：
  - u' = Φ(√ρ·z_格 + √(1−ρ)·Φ⁻¹(u))，ρ = `MEASURED_COND2_ICC`（灯具 / 大面积 0.42、细线 0.46，均为测得的组内相关）；
  - z_格 由本帧随机数种子与格编号确定，不消耗每块的随机数；边缘分布不变。
- **`rawio.SEED_OFFSET`**（默认 0，逐位不变）：多种子评估用。`t19_model.py`、`t15_eval.py` 增加环境变量 SEED。
- **代际**：`t39_base` = t31_base + measured_cond2；`t39_corr` = t31_base + measured_cond2_corr。截断判定仍为 channel_max。
- **测试**：
  - 新增 `tests/test_t39_nsat.py`（8 项）：表形状、nsat3/nch 观测量、每块 flux = 条件分位且随 nsat3 单调、无逐通道信息时 nsat3 = 0、与 measured 同一随机数与分类、SEED_OFFSET 默认与 prior 模式忽略 sat、corr 模式（确定性、ρ → 1 共享、ρ = 0 不变、边缘均匀）、代际；
  - `tests/test_t31_mask.py` 加入 t39_base、t39_corr。
  
  全部 **435 项通过**。
- **逐位核对**：
  - 改动前（T38 提交 4f40054）与改动后，current、next、next_lab_halo_meas、t22_bxyz、t28_skirt、t30_stops、t31_base、t36_base、t37_base、t38_base 在 n29240、city_61360 上的 load_raw 输出 20 组哈希相同；
  - t38_base 成片与 T38 缓存最大差 0。

## 6. 意外

1. `sensor_saturation` 对离群码值敏感：Canon n27416 两个绿通道的最大值都是孤立码值，饱和堆积不在它的搜索窗里，三通道全饱和被判成 0。改用与截断判定同一判据的逐通道比较后，结果与它在其他场景一致。没有修改它本身。
2. nsat3 的预测力（ρ 0.82）远强于 bg（−0.47），二者组合只比只用 nsat3 好一点。T38 放弃它是错的，这一点审核意见正确。
3. 条件化后，裸灯的测得亮度只有约 2–4 档：HDRI 中 nsat3 ≥ 0.5 的块，中位 1.9 / 2.9 / 3.7 档，95% 分位 3.8 / 5.6 / 7.5 档。比 U[6,8] 低 2–4 档。
4. **在现有光晕链下，这样的裸灯光晕只有真实的约 0.4 倍**。t31 的 U[6,8] 是 1.3–2.2 倍。也就是说，若测量正确，要让裸灯的光晕接近真实，光晕链在这个亮度下需要强约 2 倍；反过来，t31 的"目视最好"靠的是比测量亮 3–4 档的灯来补偿偏弱的光晕链。
5. T38 文档里 t37 → t38 的几项差别（红带 0.252 → 0.203 等）在多种子下都落在噪声内。

## 负责人结论

审核范围：nsat3 口径与相机矩阵敏感性、条件表与留出检验、裸灯类单独统计、多种子噪声、`rawio.py` 差异、435 项测试（通过）、逐位核对、`$SP/t39/full` 整图与灯区裁切。

1. **不换基准，t31_base 定为灯亮度的正式取值。** 按事先定的三条判据，只有"亮面光晕比 t31 小"成立。裸灯的光晕只有真实的 0.2–0.5 倍，明显输给 t31。招牌那对相同的灯，t39 下仍是 3.3 对 6.0 档。用户目视也认为 t31 最好。灯亮度这条线到此结束，不再派后续任务比较灯亮度。
2. **STOPS_PRIOR = U[6,8] 档的性质要写清楚。** 它是目视锚定的**有效亮度**，不是灯的物理亮度。HDRI 实测的裸灯 flux 约 2–4 档，比它低 3–4 档。多出来的这几档补偿的是光晕链里一个尚未找到的不足：在实测亮度下，链条只给出真实光晕的约 0.4 倍。
3. **保留为研究成果的结论：**
   - nsat3（三通道都饱和的比例）是区分裸灯与亮面最强的观测量，留出集 ρ 0.81。
   - 多种子重复表明，T38 文档里 t37→t38 的几项差别都在噪声内。
   - measured 系列整体相对 t31 的光晕强度与 EPFL 灯旁改善超出噪声。
   - `measured_cond2` 与 `lamp_flux_cond2.json` 保留。以后如果光晕链补足了，可以用它在物理亮度下重新评估。
4. **下一步不再动灯亮度，在 t31 上做：**
   - T35，灰阶扫描调子；
   - 灯芯与红环之间缺的那段近似白色的近场辉光，按 T36 的顺序消融：乳剂正面散射、拍摄端眩光、扫描映射。
   - EPFL 包围曝光（`tools/eval/epfl_night_brackets.json`）可以独立核对"光晕链偏弱约 2.5 倍"是否成立，放到近场辉光那一步一并处理。

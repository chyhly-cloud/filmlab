# T37：被裁切灯的亮度先验换成测量（Claude；研究代际）

## 0. 摘要

- **测量**：24 张 Poly Haven 夜景 HDRI（CC0，灯未裁切，官方 8k .hdr）上取 384 张假想照片（36×24 mm、35 mm 焦距，每张 HDRI 偏航 8 × 俯仰 2）。
  - 假想裁切电平由我们自己 25 张有裁切灯的夜景 RAW 实测锚定：**帧内亮度 Y 的第 90 百分位 → 裁切电平 = 3.71 档**（中值 → 裁切 5.63 档）。
  - 块的划分与分类（膨胀一圈、HIGHLIGHT_PRIOR 面积阈、`_line_like`）、flux 定义都与 rawio 相同。
  - 锚的独立核对：HDRI 假想照片的裁切面积占比中位 2.9e-3，我们的 RAW 为 2.7e-3。
- **结果：测得的截断块亮度比 U[6,8] 低 4–6 档。** 灯具类块的 flux（截断区平均 / 裁切电平）：

  | 尺寸档（截断面积等效半径） | 中位 [四分位] | 5–95% | 现在 t31_base（8 个夜景，同一批块） |
  |---|---|---|---|
  | 0–60 µm | **0.44** [0.16, 1.02] | 0.03–2.73 | 6.48 [6.01, 7.11] |
  | 60–150 µm | **1.30** [0.57, 2.76] | 0.18–5.16 | 5.42 [4.97, 5.80] |
  | ≥150 µm | **2.29** [1.05, 4.62] | 0.34–7.24 | 4.91 [4.39, 5.30] |
  | 细线（全部） | 0.40 [0.19, 0.79] | 0.06–1.85 | 2.4–3.0（各场景中位） |
  | 大面积（全部） | 4.09 [2.30, 7.07] | 0.74–8.90 | 3.0–3.5（2 块） |

  - U[6,8] 给出的 flux 落在测得分布的第 100 / 95 / 77 百分位（三个尺寸档）。
  - 截断块大多数是"刚过裁切"的亮面、橱窗、小灯，flux 不到 1 档。少数裸灯 flux 5–10 档，峰值 10–15 档。上一任调研说"≥8 档很常见"，看的是最亮几盏灯的**峰值**，不是每块的 flux。
  - SID 的同机长短曝光配对（真实相机分辨率）给出同样的结论：按同一锚，招牌 / 灯箱 flux 0.1–3 档，大面积招牌 2.1–2.7 档。裸灯芯在短曝光中也裁切，只能给下界 ≥ 2–5 档。
  - 稳健性：锚 ±1 档时各档中位变化 0.07–0.4 档；改用中值锚低 0.1–0.3 档；16k 原生与 8k 中位差 ≤ 0.08 档。穹顶指数实测中位 0.70（16k）/ 0.75（8k），与 rawio 的 0.7 一致，**不修正**。
- **实现**：`rawio.HIGHLIGHT_RECON = "measured"`。每块按类与尺寸档，从实测分布抽一个 flux（每块一次随机数，与 "stops" 同一随机数序列），再反解穹顶档数。新代际 `t37_base` = t31_base + measured。现有代际逐位不变；全部 420 项测试通过。
- **评估（对 t31_base）**：

  | 指标 | 真实 | t31_base | t37_base |
  |---|---|---|---|
  | 光晕部分 60–150 µm 灯，强度 RMS（全部 / −61360） | | 0.135 / 0.112 | **0.081 / 0.085** |
  | 同上，形状 RMS | | **0.080 / 0.095** | 0.123 / 0.136 |
  | 同上，绝对 / 真实（100–500 µm） | 1 | 1.57–2.05 | 0.40–0.63 |
  | 扩散 : 红晕 @200 µm（0–60 / 60–150，−61360） | 3.15 / 1.18 | 1.95 / 0.60 | 2.99 / 1.80 |
  | T19 RMS(Δr) 0–60 / 60–150 / 150–400 | | **0.053** / 0.091 / **0.051** | 0.077 / **0.083** / 0.064 |
  | EPFL 红带 RMS / 灯旁 ΔE00 / 全图 ΔE00 | | 0.252 / 15.52 / 10.64 | 0.252 / **14.83** / **10.60** |

  光晕从"比真实强 1.6–2 倍"变成"比真实弱约一半"。EPFL 灯旁色差是到目前为止最好的。T19 的 0–60 µm 档变差，60–150 µm 档变好。
- **建议**：t37_base 作为灯亮度这一项的新研究基准，替换 t31_base。理由：
  - 它是测量，不是目视锚定，并且把约 5 档的不确定缩到约 ±0.3 档（锚与分辨率）。
  - EPFL（独立同场景对照）改善。
  - 用户目视选过的"河边灯排红晕不连成带"自然出现。
  
  代价：在测得的亮度下，片基光晕总体偏弱（中等灯 0.4–0.6 倍、40–60 µm 灯几乎没有光晕部分）。按规则不调核、不压先验，这是交给下一步的结构性问题（第 7 节）。

## 1. 目标

T30 的 `STOPS_PRIOR = U[6, 8]` 是锚定在目视认可场景的先验，不是测量。它决定截断灯高出裁切多少，是光晕外观最大的不确定来源（约 5 档）。T36 已表明，灯旁"白芯—暗缝—红环"缺的灯色近场扩散量直接随灯亮度走。

本任务**只把这个已有物理量（截断块高出截断电平的档数 / flux）换成测得的分布**，不加参数、不动核、不动定光。现有代际逐位不变。

  - 帧内亮度 P90 × 2^3.71 = 假想裁切电平 C。
- 每块记录（只在 Y > C 的像素内积分）：
  - **flux** = log2(Σw·Y / (Σw·C))，即 rawio STOPS_LOG 的 flux；

## 4. 实现（`filmlab/rawio.py`、`filmlab/generation.py`）

- `HIGHLIGHT_RECON = "measured"`：
  - 截断判定、块划分与分类、颜色、穹顶形状与 "stops" 相同。
  - 每块 `u = rng.uniform()` 只抽一次。它与 "stops" 的 `rng.uniform(lo, hi)` 用的是同一个随机数，同一块在两种模式下处在各自分布的同一分位。
  - flux = `MEASURED_FLUX[类][尺寸档]` 在 u 处的分位，21 点线性插值。
  - 尺寸档按截断子像素面积的等效半径 √(Σf/π) × 36000/长边（µm）分为 [0, 60)、[60, 150)、[150, ∞)。
  - `_measured_stops` 二分反解穹顶档数 s，使块内 f 加权的 2^(s·dome) 平均 = 2^flux，下限 0.05 档。
  - 不用 MAX_STOPS = 8 截顶：那是 T30 先验的一部分。反解只设安全上限 `MEASURED_MAX_STOPS = 24`；8 个夜景 1826 块中最大 s = 12.1，16 块 > 8。
  - `source_stops` 平移照旧作用于 s（≠ 0 时仍按 `_shift_stops` 截顶）。
- 分位表 `MEASURED_FLUX`（灯具 / 细线 / 大面积 × 3 档 × 21 分位）由 `tools/eval/t37_summary.py` 生成，直接写在 rawio 里。
- 代际 `t37_base` = t31_base + "measured"：定光、光晕链、遮罩、取色、光圈范围全同 t31_base；评估时 FWD = 4，同 t31_base。
- 测试：新增 `tests/test_t37_measured.py`（6 项）：
  - 分位表形状与单调；
  - 每块 STOPS_LOG 的 flux 等于该块随机数处的分位；
  - 与 stops 同一随机数序列、同一分类，与 L_clip 无关；
  - 反解器（单像素块 s = flux、单调）；
  - stops / prior 不受 MEASURED_DOME 影响；
  - 代际设置。
  
  `tests/test_t31_mask.py` 的遮罩代际列表加入 t37_base。全部 **420 项通过**。
- 逐位核对：
  - 改动前（git stash）与改动后，`current`、`next`、`next_lab_halo_meas`、`t22_bxyz`、`t28_skirt`、`t30_stops`、`t31_base`、`t36_base` 在 n29240、city_61360 上的 load_raw 输出 16 组哈希相同；

## 6. 意外

1. **方向与预期相反**。上一任调研（只看最亮几盏灯的峰值）和 T36 负责人都预期测量会比 U[6, 8] 更亮。按每块 flux 测量，绝大多数截断块只比裁切高不到 1–2 档，U[6, 8] 落在分布的第 77–100 百分位。
   - 原因：rawio 每块抽一次，被裁切的块主要是亮面、橱窗、远处小灯，不是裸灯泡。
   - 我们的 RAW 与 HDRI 假想照片的裁切面积占比一致（2.7e-3 对 2.9e-3），说明这不是锚定错误。
2. **锚 ±1 档几乎不影响每块的 flux 分布**（中位变 ≤ 0.4 档）。裁切电平决定**有多少块**被裁切，而不是被裁切的块平均高出多少。这与 T27 "RAW 裙边在场景间一致"的观察相符。
3. **官方 8k = 16k 的 2×2 盒式平均**，逐档统计完全相同。16k 原生只多出更暗的小块。
4. 穹顶指数 0.7 被测量证实（0.70–0.75），没有需要修正的地方。
5. 16k 的 Poly Haven 路径是 `hdr/16k%2B/`（文件 API 给出），第一次按 `hdr/16k/` 拼 URL 得到 404，已改正后重跑。
6. 用 t37 亮度，60–150 µm 灯的光晕部分只有真实的 0.4–0.6 倍。T26 / T28 / T30 选 cos^4、判断"中等灯需要 −2 档"等结论，都是在 U[6, 8] 的亮度下得到的；在测得的亮度下它们需要重新审视（见第 7 节）。

## 7. 局限与下一步

- **类内随机**：rawio 只知道块的类与尺寸，同一尺寸档里的亮面和裸灯泡按同一分布抽样。块的颜色、裙边等 RAW 里已有的信息没有用来区分（T28 的裙边法可以作为条件变量）。所以同一盏灯在不同代际会抽到不同的分位。
- **HDRI 与真实相机**：
  - HDRI 是全景拼接，镜头眩光与真实相机不同；
  - 8k 像素比评估像素粗 1.2–1.7 倍（35 / 50 mm）；
  - 16k 对照表明对 flux 影响 < 0.1 档，但对"块数"影响大，小块在 HDRI 中被少计。
- 场景偏向欧洲街道、广场。没有霓虹密集的亚洲街景，只有 shanghai_bund 一张。招牌 / 大面积只有 245 块（23 张），细线 ≥150 µm 只有 23 块（已并档）。
- 锚 3.71 档来自 25 张 RAW（标准差 1.1 档）；敏感性见 3.2。
- 尺寸换算按 35 mm 焦距与 36 mm 长边；长焦（78–315 mm）RAW 中同一盏灯的 µm 半径更大，会分到更大的档。
- **结构性问题（不在本任务内调整）**：灯亮度定下来后，60–150 µm 灯的片基光晕偏弱约一半，40–60 µm 灯几乎没有；0–60 µm 档红环不足（T19 Δr 10/11）；暗缝处 G 仍缺。下一步按 T36 的顺序：
  1. 近场白色扩散逐项消融（乳剂正面散射 / 拍摄端眩光 / 扫描映射）；
  2. 在 t37 亮度下重新检查核的角分布与总量（T26 的 cos^4、T34 的三项），它们当初是在偏亮 4–6 档的灯下评估的。

## 负责人结论（Fable 审核）

审核范围：测量表与锚的推导、`rawio.py` 差异、420 项测试（通过）、现有代际逐位不变的核对、`$SP/t37/full` 8 张整图与灯区裁切。

1. **测量成立，而且推翻了两个先验。** U[6,8] 档（T30，目视锚定）落在实测分布的第 77–100 百分位；T37 前的调研只看最亮几盏灯的峰值，预期会更亮，也错了。按块计的 flux 中位只有 0.4 / 1.3 / 2.3 档（三个尺寸档）。锚 ±1 档、8k 对 16k、焦距 35/50 mm 都只动 ≤0.4 档，远小于与 U[6,8] 的 4–6 档差距。穹顶指数 0.7 被测量证实。
2. **但这个分布不能直接当作每盏灯的先验。** 它混合了裸灯泡和刚过裁切的亮面、橱窗，而 rawio 只按类与尺寸抽样。裁切对照里两盏完全相同的招牌灯，一盏几乎无光晕、一盏红环很强，就是同一尺寸档内随机抽到了不同分位。同一盏灯在不同代际还会变。这不是物理，是信息没用上。
3. **因此 t37_base 暂不作基准，基准仍为 t31_base**；t37 的测量表、锚和 measured 模式全部保留，作为 T38 的基础。T38 的任务是把先验改成**条件分布**：在 HDRI 假想照片里逐块同时记录 RAW 中也能算出的观测量（块周围环带的背景亮度比、紧贴块外的裙边、饱和通道数等），用它们区分"裸灯"和"亮面"，再按条件分布抽样。预计裸灯（暗背景、高对比）的 flux 回到 5–10 档，亮面回到 1 档以内，相同的灯得到相同的亮度。
4. 在 t37 亮度下，60–150 µm 灯的片基光晕只有真实的 0.4–0.6 倍、小灯扩散:红晕比反而与真实一致（2.99 对 3.15）。这些数字要等 T38 把裸灯亮度条件化之后再解释；T26 / T28 / T30 关于核的结论（cos^4、"中等灯 −2 档"）也要在那之后重审。
5. 下载总量 4.1 GB 超过了我给的 3 GB，但同时占用 <1 GB、用后已删，不追究；T38 重下时沿用逐张下载即删的做法。

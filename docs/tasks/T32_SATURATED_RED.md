# T32：饱和红为什么在真实冲扫里偏橙——逐级定位（Claude）

## 0. 摘要

- 任务前提：EPFL 夜景里 RAW G/R ≈ 0.07 的亮红像素，真实冲扫 G/R 0.36–0.39，模型 0.12–0.14。按级拆开后，这个差距**不来自一个地方，也不来自红层肩部**。
- **最大的一项是这一帧的定光**（S4c，操作员变量）。+2…+3 档的红像素有 662/833 个来自 R1-03-4 的一个红灯箱。冲印店把这一帧印得比 `lab_measured` 预测的亮约 0.2 logE，也更偏蓝/绿。
  - 每帧只拟合三个印放光号（O1，只用非红区域，诊断用），模型 G/R 就从 0.12 升到 0.29（真实 0.36）。
  - 红灯箱的 R 在真实里接近纸白（0.74），被压住；G 还在线性段继续上升，所以 G/R 跟着升高。
- **定光对齐后，模型仍然比真实更饱和**：G/R 低 0.05–0.3，B/G 高 3–4 倍。后者就是"洋红 vs 橙"的观感来源。拆成三项：
  1. **S1 曝光映射给饱和红过多的蓝层曝光**。红灯箱在胶片蓝层的曝光 ≈ 中灰水平（RAW B 只有中灰的 0.22）。按 500T 感光度光谱计算，波长 > 600 nm 的红光对蓝层的曝光 ≈ 0（B/R < 10⁻⁴），而线性 RGB→层曝光映射给出 B/R 0.2–0.7。把红物体的蓝层曝光压到相机 B 的水平后，+2…+3 档 B/G 从 2.3 降到 0.7（O1 定光；真实 0.58）。
     - 这是"洋红"而不是"橙"的主因，但它是统计拟合的映射，不是数据手册物理量，所以只报告。
  2. **模型的跨通道增饱和比真实整条链强**。在单一光源的控制帧（背光色卡 + 灯箱）上做"单通道传递"检验：
     - 真实冲扫的饱和红 G 与"同一帧中性像素在同一绿层曝光下的输出"一致（实际/预测中位 1.0–1.2）；
     - 模型只有 0.80（彩度 0.5–0.8）。
     - 模型内部按级关掉跨通道项，主要来自 DIR 的层间抑制（红层显影抑制绿层，方向是物理的）。蓝、青物体的 R 同样被模型压到 0.5–0.8，真实 ≈ 1.0。
     - 500T 的层间强度沿用 C-41 民用片的专利数据，没有独立的 500T 测量；也不能排除 S1 低估了红物体的绿层曝光。所以只报告。
  3. **已有物理量取值不对：5219 的分层曲线与染料光谱**。模型的 500T（spektrafilm 解混 + 截断染料谱）在 ECN-2 下的 Status M：
     - 中间调红层比 Kodak 数据手册高 0.07–0.10 D；
     - 红层反差高 8%（R/G 0.92，数据手册 0.84）；
     - 成片中性灰阶红通道比绿通道陡 8%（真实灰阶楔 R/G 1.04）。
     - 青染料在绿区的副吸收只有数据手册的 1/3（扫描绿通道 0.04，Kodak 0.11）。
     - 换成 Kodak 数据手册的染料光谱 + 按 Kodak Status M 重新解混的曲线（已有修订 `kodak_raw`），作为候选 **`t32_k5219`**（默认关闭）：
       - 红像素 G/R（+2…+3 档）：默认定光 0.12 → 0.16，O1 定光 0.29 → 0.37（真实 0.36）；
       - 控制帧的红 G 实际/预测：0.80 → 0.87；
       - 8 夜景全图 ΔE00 10.64 → 10.76（变差），光源旁 15.52 → 15.39（改善）；
       - 蓝色物体更饱和（变差）。
       - 结果好坏参半，与 next_k5219 冻结时的判断一致；是否采用交负责人决定。
- 其他各级的结论：
  - **红层肩部 / D-max 不是来源**：这些像素的红层曝光只在中灰 +0.4 logH，Kodak 的肩部在 +2 logH 以上。只把红层曲线改成数据手册值，G/R +0.03（O1 下 +0.06），来自中间调的密度与反差，不是肩部。
  - **扫描通道光谱不是来源**：加宽绿通道（σ 16 → 35 nm）反而更红（0.12 → 0.07）。印放矩阵 P 把窄带串扰换算回印放密度，青染料的"绿漏"在 Dn 上只剩 0.009。
  - **冲印店的处理没有可见的饱和度压缩**：灰阶楔、色卡灰阶每通道单调；饱和红、蓝、青的主通道与单通道传递一致（1.0 ± 0.2）。所有饱和色在真实里都比模型淡，但相对于真实自己的中性传递并没有被压。差别在模型一侧。

## 1. 目标与方法

目标：定位"饱和红 → 橙"发生在哪一级，每级给数据；只有已有物理量取值不对才做候选（默认关闭）。不加经验调色，不动定光方式、光晕核与灯亮度先验。

基准：`t31_base`。

数据：
- EPFL 8 夜景 R1-00-1…R1-07-8（同一 RAW、同一 Frontier 冲印店扫描）；
- 控制帧（单一光源、有大块饱和色）：背光色卡 R1-20-21、钨丝灯箱 R1-30-31 / 27-28、白光灯管灯箱 R1-31-32 / 32-33 / 26-27…、品红灯管 R1-21-22 / 23-24 / 25-26（配对待确认，只作参考）；
- 灰阶楔 R1-17-18（手工几何）。

工具（`tools/eval/`）：

| 工具 | 内容 |
|---|---|
| `t32_epfl_trace.py` | 数码几何下保存逐级中间量：测光后 RAW、三层 logH（含光晕）、光晕份额、三层染料量、Dn、成片、真实扫描（反向配准）、定光参数。`EV` 只用于图卡帧的诊断性曝光偏移 |
| `t32_eval_trace.py`、`t32_red_cands.py` | 红像素按 RAW R 档统计；默认定光与 O1 定光 |
| `t32_o1.py` | O1：每帧三个印放光号，拟合非红区域 24 px 格子的 log RGB，soft-L1 |
| `t32_rescan.py`、`t32_counterfactuals.py` | 从存档 logH 重新显影 + 扫描（t31_base 逐像素复现，最大差 6e−8），各级反事实 |
| `t32_chain.py` | 模型链跨通道项的分解 |
| `t32_hue_ci.py`、`t32_hue_cands.py` | 单通道传递检验 |
| `t32_chart.py`、`t32_chart_patches.py` | 色卡逐块 |
| `t32_wedge.py` | 灰阶楔 |
| `t32_film_checks.py`、`t32_gamma_chain.py`、`t32_scan_checks.py` | 与 Kodak 5219 数据手册对照（`KODAK5219_RAW` 指向数据手册数字化目录） |

红像素：
- RAW 测光后线性 G/R < 0.3、B/R < 0.5，三通道 > 0；
- 距传感器饱和灯芯 > 0.5 mm，模型光晕份额 < 0.2；
- 5×5 平滑后腐蚀 2 像素；
- 亮度档 = log2(RAW R / 0.184)。

单通道传递检验：
- 每帧取"胶片中性"像素：三层 logH（相对本帧白的色度）极差 < 0.05；
- 对每个通道 c 建立 logH_c → 输出_c 的单调传递 F_c，真实、模型各一条；
- 对彩色像素按其三层 logH 预测输出；实际 / 预测 = 跨通道作用。
- 若整条链是"每通道一条单调曲线"，比值为 1。
- 真实的比值另含 S1 误差（横轴用的是模型的 logH）。

## 3. 第 2 步：胶片级（S2）

### 3.1 红层上限与肩部：与 Kodak 5219 数据手册比

中性灰阶，Status M（Kodak 数据手册的 Status M 响应）：

| logH | 模型 ECN-2 R G B | Kodak 5219 R G B | 模型 C-41（τ 1.18）R G B |
|---|---|---|---|
| −1.00 | 0.48 0.93 1.18 | 0.43 0.86 1.10 | 0.58 1.10 1.33 |
| −0.84（中灰） | 0.57 1.04 1.29 | 0.51 0.95 1.18 | 0.69 1.23 1.47 |
| 0.00 | 0.98 1.48 1.77 | 0.90 1.41 1.64 | 1.12 1.71 2.01 |
| +1.00 | 1.47 2.02 2.35 | 1.38 1.97 2.18 | 1.66 2.33 2.67 |
| +2.00 | 1.88 2.48 2.82 | 1.77 2.44 2.64 | 2.06 2.79 3.15 |
| +2.41 | 1.96 2.58 2.92 | （数据手册到此为止，仍在上升） | 2.14 2.88 3.24 |
| +4.00 | 2.04 2.68 3.01 | — | 2.20 2.96 3.32 |

结论：
- 模型红层的上限（ECN-2 Status M 约 2.04，C-41 约 2.20）在任务给的 2.0–2.4 范围内。数据手册范围内没有比 Kodak 更早的肩部。
- 夜景饱和红的红层曝光在 −0.43 logH（中灰 +0.41），离肩部（> +2）很远：真实 G/R 0.36 对应的红层密度没有到 D-max。
- 模型与 Kodak 的差别在中间调：
  - 红层净密度高 10–20%；
  - 反差斜率 R/G 0.92，Kodak 0.84（中灰 −0.3…+0.9 logH）；
  - 蓝层也高（B/G 1.08，Kodak 0.98），即 CRITERIA "FilmLab 的 5219 数据合成的 Status M 与 Kodak 实测不一致"。
- 只把红层曲线逐点缩放到 Kodak（数据范围外沿用端点比）：+2…+3 档 G/R 0.12 → 0.15（O1：0.29 → 0.35）；ΔE 全图 −0.10、光源旁 −0.13。
  - 这是中间调密度 / 反差的作用，与肩部、上限无关；
  - 只改一层不是一致的修正，见第 7 节候选。

### 3.2 DIR 层间效应的方向

红物体（红层 +k 档、曝光 G/R 0.1、B/R 0.05；C-41），三层染料量：

| 红层 | 有层间 C M Y | 只同层 C M Y | 绿层若在中性灰阶 |
|---|---|---|---|
| +2 档 | 1.01 0.21 0.11 | 0.84 0.29 0.17 | 0.29 |
| +4 档 | 1.36 0.47 0.35 | 1.17 0.57 0.48 | 0.57 |
| +8 档 | 1.90 1.02 1.08 | 1.80 1.11 1.21 | 1.11 |

- 方向是物理的：红层显影放出的抑制剂让绿层（品红）密度降低约 0.08 D，成片 G 更暗，红更饱和。层间效应本来就是增饱和。
- 所以模型的层间效应只会让红更深，不会让它变橙。
- 量级：去掉层间项，+2…+3 档 G/R 0.12 → 0.29（O1：0.29 → 0.55，越过真实的 0.36）。
- 控制帧上，模型的红 G 实际 / 预测 0.80，无层间 1.14，真实 1.19（第 6 节）。真实整条链没有可见的"R 抑制 G"。
- 但不能据此改层间强度：
  - 模型的 DIR 矩阵按 Kodak US 6,210,870 的 C-41 民用负片（分色 / 中性 γ 比）标定，没有 500T 自己的测量；
  - 第 2.1 节的 S1 绿层反事实（×1.5）有同样的效果，两者用成片无法分开。

## 4. 第 3 步：扫描级（S3 染料 → S4a/b 扫描通道）

单位染料（叠在片基上）在扫描通道（Frontier 估计：650 / 540 / 450 nm，σ 14 / 16 / 14）上的相对密度：

| 染料光谱 | 青：G/R | 青：550/650 nm | 品红：R/G | 黄：G/B |
|---|---|---|---|---|
| 模型（spektrafilm 截断谱，C-41 平移后） | 0.040 | 0.037 | 0.070 | 0.042 |
| 模型档案（ECN-2） | 0.042 | 0.038 | 0.064 | 0.048 |
| Kodak 5219 数据手册（带符号） | **0.114** | **0.141** | 0.084 | **0.138** |

- Status M 积分给出同样的比例（青 G/R 0.042 对 0.123–0.128）。
- 模型的青染料在绿区的副吸收只有数据手册的 1/3，黄染料在绿区也是 1/3。
- 扫描链中，印放矩阵 P（窄带 → 印放密度，按 Portra 800 染料拟合）的第 1 行是 [0.81 −0.03 0.03]：纯青的 Dn_G/Dn_R 只剩 0.009。所以换成 Kodak 青染料后，Dn_G 只多 (0.114−0.04)·0.91 ≈ 0.07·D_R。
- 完整的 Kodak 染料（候选 t32_k5219，完整重渲）：+2…+3 档 G/R 0.12 → 0.16（O1 0.29 → 0.37）。控制帧红 G 实际 / 预测 0.80 → 0.87，其中染料串扰约占一半，另一半来自曲线（中性反差）。
- 扫描通道带宽是估计值（厂商未公开）：绿通道加宽到 35 nm 后 G/R 0.12 → 0.07，方向相反，因为 P 重新拟合后补偿了。现有数据不支持"扫描仪通道串扰让红变橙"。

## 5. 第 4 步：冲印店处理（S4c/S4e）

- `lab_measured`（T07）只是逐帧的通道光号偏移（密度域常数），没有饱和度矩阵或色域映射，所以不存在"超出拟合范围"的饱和度处理。它与真实的差别是逐帧定光：
  - R1-03-4 的 O1 光号与预测差 0.16–0.31 logE；
  - 只这一项就让 +2…+3 档 G/R 0.12 → 0.29。
- 灰阶楔 R1-17-18（14 条，手工几何）：
  - 真实三通道各自单调；
  - 中间段 log 输出 / logH 斜率 R G B：真实 0.55 / 0.53 / 0.56（通道间相差 4%）；
  - 模型 0.81 / 0.62 / 0.67，红通道比绿通道陡 30%。模型的灰阶楔 G/R 1.05–1.86（偏青绿），真实 0.95–1.16。
- 色卡灰阶（R1-20-21，曝光 −1 档以匹配真实亮度）：真实与模型每通道都单调。

真实是否对饱和色做了通道之外的处理：单通道传递检验（第 6 节）中，真实饱和红的 G、饱和蓝 / 青的 R 与本帧中性传递的预测一致（中位 1.0–1.2）。没有观察到饱和度压缩或色域映射。

唯一系统性偏离的是暖色的 B：真实红 / 黄的 B 只有预测的 0.15–0.6，更饱和、更"橙"而不是更淡。这与 S1 的蓝层曝光偏高（第 2.1 节）一致，也可能有真实层间效应的份，无法区分。

因此不能、也不需要实测为一个饱和度映射。冲印店在这一项上的作用只有逐帧定光。

### 7.1 "饱和红 → 橙"按级的贡献（+2…+3 档，G/R；真实 0.36，t31_base 0.12）

|---|---|---|---|
| S4c 定光 | 冲印店对这一帧印得更亮、偏蓝绿（R1-03-4 光号 −0.16 −0.20 −0.31） | **+0.17**（0.12 → 0.29） | 操作员变量；不动定光方式，只报告 |

## 8. 局限

- 主要症状（+2…+3 档）80% 的像素来自 R1-03-4 一个红灯箱；其他场景的饱和红很少（R1-00-1 71 像素，R1-02-3 102 像素）。
- O1 定光只是诊断：3 个参数拟合到非红区域，可能吸收与饱和度无关的偏差，不进入任何渲染。
- 单通道传递检验的横轴是模型的 S1 曝光：
  - 真实的"实际 / 预测"包含 S1 误差；
  - 夜景混合光源下"中性"像素不可靠，所以只用单光源控制帧；
  - 灯箱、色卡帧的胶片曝光未知（色卡用了 −1 档，只为不截断）；
  - 品红灯管帧配对待确认。
- 红色光谱的绿层曝光对 570–600 nm 极敏感：500T 绿层在 580 nm 的感光比红层高 6.6 倍（以中灰归一），600 nm 已降到 0.04。相机 G/R 0.07 可对应胶片 0.01–0.5。S1 的绿、蓝层曝光对饱和红都不可靠，需要光源光谱或分光测量。
- 层间效应强度、扫描通道光谱、数字相纸都是估计或代理，成片配对无法单独辨识。要分开胶片与扫描，需要同一负片的密度读数（解冻条件同 next_k5219）。
- Kodak 5219 是 ECN-2 数据，C-41 下沿用同一动力学（CRITERIA 已核对表示无关），未独立验证。

## 负责人结论（Fable 审核）

- T31 的头条数字（真实 0.39 对模型 0.14）主要是 R1-03-4 这一帧冲印店定光偏亮偏青造成的（操作员变量），不是"冲扫把饱和色压淡"。真实冲扫对饱和色是每通道单调映射，没有饱和度压缩。撤回 T31 结论第 (3) 条的表述。
- 真正站得住的两个发现：
  1. **模型对所有饱和色都比真实更饱和**（单光源控制帧：红物体的绿通道实际/预测真实 1.19、模型 0.80；去掉层间抑制后 1.14）。与色相无关，指向 DIR 层间抑制偏强（`dir_amount` 未定标），或 S1 曝光映射低估了饱和色的相邻层曝光；成片上分不开。
  2. **S1 给饱和红的蓝层曝光接近中灰**（RAW 蓝只有中灰的 0.22；> 600 nm 的光对蓝层 B/R < 1e-4，线性映射却给 0.2–0.7），所以红灯箱是洋红不是橙。这是统计映射对发光饱和色的外推，不是胶片物理。
- `t32_k5219`（Kodak 数据手册染料光谱与分层曲线）方向对但只补一部分，全图变差、光源旁改善，与 next_k5219 冻结时相同，不并入基准，保留为研究代际。
- 下一步 T33：(a) 蓝层映射对发光饱和色的物理约束（短波只来自相机蓝通道）；(b) 在 (a) 之后用 EPFL 控制帧定标 DIR 层间抑制量。

# 任务 T05：冲印店固定光号偏差的纠正（执行：Codex；规格与验收：Claude）

## 背景

T04（`docs/tasks/T04_ACCEPTANCE.md`）测得：
- 每帧只给 3 个印放光号（O1），全图误差就从 11.63 降到 6.00。定光是最大的单项误差。
- O1 的偏移 x 有**固定成分**：红通道在训练集 11 帧中有 10 帧为负，中位数 −0.121。这是模型某一环节相对这家冲印店的系统偏差，不是逐帧差异。
- 逐帧校色力度 k 无法识别，所以本任务**不碰逐帧部分**，只纠正固定部分。

冲印店给每种胶片设一套固定的通道平衡（印放光号基准），这是真实存在的物理量。本任务用 T04 已实测的光号，把这个现有量纠正到这家冲印店，**不新增系数，也不做新的拟合**。

## 纠正量（已在规格中固定，不得重新估计）

Δ 取训练集 `accept_calibration.TRAIN` 11 帧的 O1 偏移 x 的中位数，数据来自 `tools/eval/t04_result.json` 的 `frames[场景]["x"]`：

    ΔK = −0.11437142396955352
    ΔR = −0.12100152025600766
    ΔB = −0.008793146365340334

单位与 O1 相同（`oracle_timing.py` 的 `fit(1)`）：自动定光算出 `PrintTiming` 之后，

    K ← K + ΔK                         （三个通道加同一个 ΔK；s、x_knee、x_white 不变）
    M ← (off + (ΔR, 0, ΔB), r)          （M 为 None 时 off = 0、r = 1）

即把 O1 中"所有帧共有的那一份"固定施加到每一帧。留出集的光号不参与 Δ 的计算。

## 实现要求

1. 新增修正标志 `"lab_balance"`（写入 `Params.corrections` 的说明注释），以及可选代际 `next_balance` = next + `"lab_balance"`。
2. Δ 作为模块常数写入代码，三个数值逐位等于上面的值，并在注释里写明来源：T04 训练集中位数、提交号。
3. **只作用于逐帧自动定光（`timing="frame"`）**，其余定光方式和物理参考配方不受影响，所以 3200K 灰卡结果不变。
4. 标志未开启时逐位不变：`current`、`next`、`legacy` 及所有现有配方的输出不变。
5. 不得改动其他常数；不得按 ΔE 调整 Δ；不得增加逐帧或按场景的规则。

## 测试（随实现提交，只用合成数据）

- 标志关闭时与现行逐位相同；
- 开启时 `PrintTiming` 的 K 与 M 偏移恰好变化 Δ（误差 < 1e-12）；
- 非 `frame` 定光不受影响；
- 默认代际不受影响（合成输入逐位回归）。

## 停止规则

- 若 O1 的 x 与 `PrintTiming` 的 K / M 无法按上式一一对应（单位或施加位置不一致）：停止并报告，不改定义。
- 若"只作用于 frame 定光"无法在不改动其他路径的情况下实现：停止并报告。

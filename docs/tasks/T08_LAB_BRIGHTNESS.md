# T08：冲印店逐帧亮度调整的实测（Claude 执行）——不成立

背景：用户目视判断 next_lab 整体比 next 更接近真实扫描（2026-10-31）。next_lab 不做逐帧亮度调整，失败帧（R1-02-3 过曝、R1-06-7 与 R1-03-4 过暗）都与亮度有关。

方法：做法与 T07 颜色相同，先测量、后判定。
- 纵轴：O1 的亮度偏移 x_K，相对固定光号；基础配置为 `fixed_exposure,plain`。
- 横轴：模型底片绿通道相对档案中灰的水平，主估计量为整帧算术平均密度。
- 回归：在训练集上拟合 x_K = a − k·水平，到留出集上检验预测。
- 数据：`tools/eval/t07_lab_colour.py` 增加 `level` 字段后重跑；颜色部分与此前完全一致。

| 估计量 | 训练相关 | 留出预测相关 | 留出 RMSE：模型 / 常数 |
|---|---:|---:|---|
| mean（主估计量） | +0.83 | −0.03 | 0.172 / 0.110 |
| latd | +0.90 | −0.24 | 0.186 / 0.110 |
| bright | +0.58 | −0.05 | 0.169 / 0.110 |

**判定：不成立。** 训练集上的关系（底片越厚，冲印店印得越暗）在留出集上没有预测力，误差还大于常数预测。

不符合这一关系的留出帧：
- 夜景 R1-01-2：底片很薄（水平 −0.39），冲印店没有提亮；
- 色卡 R1-20-21：底片很薄（−0.37，黑背景占大半），冲印店反而压暗；
- 黄昏 R1-03-4：被提亮（−0.20）。

结论：逐帧亮度由数据中没有记录的量决定，即摄影师实际给的曝光与操作员的判断，在现有数据里无法从底片预测。
next_lab 保持不变，不加亮度模型；评估中用 K 预言机把这部分分离出去（`tools/eval/k_oracle.py`）。

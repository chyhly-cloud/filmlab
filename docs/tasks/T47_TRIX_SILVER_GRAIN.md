# T47：Kodak Tri-X 400 的显式银粒——晶体、银量、覆盖力与 Schmidt 显微颗粒（Claude；研究代际）

## 0. 链条：从卤化银晶体到最终颗粒

```
 ① 卤化银晶体（三维、传统乳剂）
    3 个亚群（快 / 中 / 慢；T46 通用结构 λ_k、σ_ln），ECD 对数正态，9 档
    尺寸 a_k = (λ_k a0^β / (φ·H_s))^(1/(1+β))，φ = η_3D × D55 三波段光子数，H_s = 0.8/EI       ← η_3D 是标定量 ①
    每亚群涂布银量 coat_k（g Ag/m²）→ 每 µm² 晶体数 n = coat / m，m = 3.72e-12 g/µm³ × a^1.5  ← 由 D-76 曲线定
    位置：在连续坐标中泊松撒点（Thomas 团簇作为对照）
        │
 ② 曝光：有效光子数 ~ 泊松(φ·a·(a/a0)^β·H)，≥ 4 个可显影；灰雾 1 − exp(−a/a_f)     （T46 通用常数，不改）
        │  —— 哪些晶体显影，到这里定
 ③ 显影：显影晶体在原位长成银丝团（质量守恒）
        丝的总长 ℓ = V_Ag / (π w²/4)，V_Ag = m / 10.49 g/cm³；4 根丝从晶体内的显影中心出发，
        在半径 R = √(spread·a/π) 的丝团内随机游走；投影 = 不透明细丝的并集（每颗形状都不同）
        │
 ④ 光学：每个微元 T = exp(−Σ τ_i)，τ_i = −ln(1 − g·c_i)，c_i = 第 i 颗银丝团的投影覆盖率
        g = 1（镜面收集）或 1/Q（漫射收集，Callier Q = 1.4）
        │
 ⑤ 积分：显微镜 → 微元透射率 ⊛ 显微 PSF（标定量 ②）→ 0.25 µm 像素 → 方孔平均透射率 → −log10
        扫描 → 微元透射率 → 像素平均透射率 → 扫描仪 PSF（透射率域，T45）→ −log10 → 冲印店链条
```

- **平均密度的闭式解**（泊松布尔模型）：E[T] = exp(−Σ n_kq p_kq g A_kq)，A = 单颗银丝团的投影不透明面积（∫(1 − T_grain)），D = −log10 E[T]。渲染器把每颗银丝团重采样到任意微元间距时按面积精确守恒 ∫(1 − T)，所以任何像素尺寸下宏观密度都等于这个闭式解（测试）。
- **银量守恒**：每颗显影晶体的银 = 晶体体积 × 3.72e-12 g/µm³；显影银 = Σ 数量 × 每颗银；覆盖力 = 密度 / 显影银；涂布银 × 覆盖力 = 全部显影时的密度上限。
- **不在输出端加噪声**：颗粒只来自一颗颗晶体的位置、尺寸、是否显影和银丝团的形状；均值与颗粒由同一个晶体模型给出。

## 1. 摘要

- **几何检验（零成本）**：Schmidt 的 D-76 原液 20 °C 9 min 曲线与 Kodak F-4017 第 8 页 D-76（漫射视觉密度）在净 D 0.10 处对齐后，19 级残差 |ΔD| ≤ 0.059（按 9 min 时间插值）；按同一估计器的平均斜率匹配到 9.3 min 也是 ≤ 0.059。Kodak 曲线在相同 ΔlogE 处到净 D 1.60，没有在 1.0–1.1 处趋平。结论：**高曝光处的密度增长是真实的银效应，Codex 原型 1.02 的上限是模型的问题；Schmidt 的曲线与 Kodak 的漫射曲线同一几何**（若是镜面，同一银会高出 Q ≈ 1.3–1.5 倍，到 2.0–2.4）。
- **平均密度由同一个银粒模型给出，过门槛**：晶体数、每颗晶体的银、银丝团的投影不透明面积、漫射 / 镜面收集几何 → 19 级净 D 最大残差 **0.089**（门槛 0.10，事先写定）。涂布银 **3.87 g/m²**，漫射覆盖力 **0.63 密度/(g/m²)**（镜面 0.88），全部显影时净 D 上限 **2.42（漫射）/ 3.39（镜面）**；第 19 级 1.576 时显影银 2.88 g/m²（74%）。残差为 S 形（6–7 级 −0.09，11 级 +0.07），Schmidt 与 Kodak 之间在同一段也有 +0.06 的鼓包。
- **四孔径（Schmidt 估计器，同一窗口：方孔 ⊛ 显微 PSF，0.25 µm 像素，相邻单元差 ÷ √2）**：实测 0.0780 / 0.0488 / 0.0272 / 0.0210；闭式解 0.0783 / 0.0489 / 0.0266 / 0.0215（+0.4% / +0.2% / −2.2% / +2.2%）；显式银粒模拟 0.0780 / 0.0500 / 0.0268 / 0.0209（4 个 375 µm 视场平均，+0.1% / +2.5% / −1.3% / −0.3%；视场间标准差 1–4%）。全部在 ±15% 内。标定量两个：三维晶体的有效量子效率 η_3D（→ 晶体尺寸，由 20/25 µm 平台定）与显微镜 PSF σ = 1.10 µm（由 Schmidt 两参数式的 a_k 定，落在 Schmidt 自述"约 1.5 µm 分辨率"的两种读法 0.52–1.5 µm 之间）。
- **偏度**：5 µm 单元密度的偏度：模型 **+0.15**；同一平均密度、同一平台的两个对照场——"少而不透明"（τ = 30 的 0.5 µm 圆盘）+0.19，"多而淡"（τ = 0.05、面积 ×20）+0.02。模型落在"少而不透明"一侧：每颗银丝团中心近乎不透明（快亚群 80% 覆盖），颗粒是一颗颗暗点叠加，不是平滑的弱起伏。Schmidt 没有公布偏度，这是预测。
- **团聚**：不需要。泊松撒点 + PSF 1.10 µm 给出 a_k = 25.9 µm²（实测 25.9）。PSF 取 1.5 µm（Schmidt 自己的模拟值）时泊松已给 a_k = 45.5，团簇只会让它更大；只有 PSF 取 FWHM 读法（σ 0.64 µm）时才要 Thomas 团簇，而且要每团 55–75 颗晶体、平台多 35–66%，没有独立证据支持。团聚与 PSF 在现有数据上不可区分，按奥卡姆不加。
- **FX39 留出：未通过**。只改显影工艺参数（显影阈值光子数 r 4 → 3.3，使模型复现 FX39 自己的曲线，最大残差 0.085），同一总密度下的颗粒预测为 D-76 的 **1.00 倍**；实测 1.34（平台）/ 1.39（25 µm）。"哪些晶体显影"在同一密度下几乎不改变颗粒；缺的物理量是**显影液决定的银粒形态**（D-76 含 100 g/L 亚硫酸钠，是溶剂型显影液；FX39 低亚硫酸盐、非溶剂型〔T50 更正：FX39 的配方从未公开，这一说法没有可靠出处〕）——丝团面积 ×2 给 1.27 倍，丝径 ×2 给 0.69 倍，方向与量级都可能，但没有独立数据能定，不调。
- **Kodak 48 µm 官方值（独立检查）**：模型 14.6，官方 17（0.86 倍）。Kodak 在净漫射 1.0、Schmidt 在净 0.682、仪器也不同。
- **实现**：`grain.py` 新增显式银粒路径（`SilverSpec`、`render_silver`、`apply_silver` 及闭式解 `silver_density` / `silver_covariance` / `window_variance`），对所有黑白片通用；`materials.trix_film()`（特性曲线由晶体模型算出，光谱感光度取 F-4017）、`materials.silver_spec`；代际 **t47_bw = t46_base + grain_t47**；配方 `kodak_trix_400`。现有代际逐位不变（81 组：18 个现有代际 × 2 像素尺度 × 颗粒 0 / 1，加 t45_base / t46_base 上 5 种胶片的颗粒，与 git HEAD 逐位相同），彩色片在 t47_bw 下与 t46_base 逐位相同。新增测试 21 项，全部 506 项通过。
- **建议**：**t47_bw 可以作为黑白片颗粒的研究基准候选，取代 t46 的黑白路径**，但限定在 D-76 类溶剂显影：平均密度与颗粒由同一个晶体模型给出（银量、覆盖力、上限都在物理范围内），四孔径与 Kodak 48 µm 都对得上，颗粒方向与常识一致，彩色片与现有代际逐位不变。不能作为"任意显影液"的基准：FX39 留出没过，显影液对银粒形态的影响没有建模。是否定为基准由用户看整图后决定。

- **Kodak 曲线在相同 ΔlogE 处同样到 1.5–1.6**（9 min 1.600，9.3 min 1.636），不在 1.0–1.1 处趋平；12 min 曲线在最高曝光处还在上升（净 2.40）。所以第 19 级 1.576 是真实的银效应，模型的密度上限必须高于它——这直接否定了 Codex 原型 1.02 的上限。

## 5. 颗粒：与 Schmidt 同一估计器

### 5.1 估计器与窗口

- 渲染：0.25 µm 像素（Schmidt 的 RAW 像素）、微元 0.125 µm，392 µm 见方渲染后取中央 375 µm（1500 像素，Schmidt 的视场）；晶体在连续坐标中显式撒下（27 个尺寸档中只有慢亚群最小的一档 ECD 0.09 µm 按 0.25 µm 格计数，其余都是显式银丝团）；微元透射率 ⊛ 高斯 PSF → 像素平均 → 20 / 39 / 80 / 101 像素的方孔（即实读边长 4.92 / 9.87 / 19.95 / 25.19 µm）→ 单元密度 = −log10(单元平均透射率) → 水平与垂直相邻单元差的 RMS ÷ √2。所有孔径都是整数像素，窗口 = 方孔 ⊛ 像素 ⊛ PSF，不需要 Codex 提到的非整数像素修正。
- 闭式解：泊松布尔模型的透射率协方差 Cov_T(r) = E[T]² (exp(Σ_j λ_j g² γ_j(r)) − 1)（γ_j 为第 j 档银丝团不透明投影的形状平均自相关），与窗口的自相关积分，相邻差估计器 = 方差 − 相邻单元协方差；透射率 → 密度按 1/(E[T] ln10) 线性化。在 Codex 交接包的单半径圆盘条件上与其闭式解一致到 1%（测试）。
- 视场密度：Schmidt 选的是密度计总 D ≈ 1 的灰阶（净 0.682，漫射）；模型在同一净漫射密度的曝光下渲染。
- 显微镜的收集几何（**假设漫射**）。依据：两种口径各自标定后，四孔径都能对上（标定量吸收了差别），但独立的 Kodak 48 µm 官方值区分得开：漫射口径（晶体 0.63 µm）预测 14.6（官方 17），镜面口径要把晶体缩到 0.45 µm 才能对上平台，预测 9.4（0.55 倍），漫射口径更一致（第 5.6 节）。

### 5.4 团聚判定（a_k）

Schmidt 两参数式 σ²A(a) = c²·a/(a + a_k) 拟合实测四点：a_k = 25.9 µm²（结构边长 5.1 µm；他表中写 5.7 µm）。模型用同一式拟合自己的四点：

| 情形 | PSF σ µm | 模型 a_k µm² | 平台 σ²A | 结论 |
|---|---|---|---|---|
| 泊松 | 0.52（"1.5 µm" 按 Rayleigh 距离） | 9.9 | 0.308 | a_k 太小 |
| 泊松 | 0.64（按 FWHM） | 12.3 | 0.304 | a_k 太小 |
| 泊松 | 1.00 | 22.3 | 0.291 | 接近 |
| **泊松** | **1.10（标定）** | **25.9** | 0.287 | **= 实测** |
| 泊松 | 1.50（Schmidt 自己模拟用的 σ） | 45.5 | 0.272 | a_k 太大，团簇只会更大 |
| Thomas σ_c 2 / 3 / 5 µm | 0.64 | = 25.9（闭式近似） | 0.476 / 0.414 / 0.388（+66 / +44 / +35%） | 要每团 75 / 56 / 60 颗晶体（团中心每 0.36–0.48 µm² 一个） |

- 结论的前提是 PSF：现有数据里团聚与 PSF 不可区分（两者都只把相关长度拉长）。要区分需要 Schmidt 显微镜的实测 PSF（拍一个刃边或亚分辨率点），或者在同一张片上换物镜重拍。

### 5.5 FX39 留出检验

- FX39：1+12、24 °C、10 min、EI 400、γ 0.59；D-76：原液、20 °C、9 min、EI 400、γ 0.56。实测颗粒倍数：平台（Schmidt 表）17.4 / 13.0 = **1.34**；25 µm（Codex 读图）约 **1.39**。
- 预测方法：胶片（晶体、涂布银）不变，只改显影工艺参数。可由 FX39 自己的曲线独立定的工艺参数只有"显影强度"——这里用显影阈值光子数 r（越强的显影，越小的潜影也能显影）：r = 3.3 时模型复现 FX39 曲线，最大残差 0.085、RMS 0.051（D-76 为 r = 4）。温度高 4 °C、稀释 1+12、时间长 1 min 的净效果都在这一个数里；模型的斜率 0.640 → 0.654（Schmidt 的 γ 0.56 → 0.59，比例相近）。
- **预测：同一总密度（≈1）下颗粒为 D-76 的 1.00 倍**（5–25 µm 都是 0.998）。实测 1.34–1.39，**留出检验未通过**。
- 原因：同一总密度下，显影更强只是让略少的大晶体（更低的曝光）加上略多的中晶体显影，"哪些晶体显影"对颗粒几乎无影响。温度与 γ 的差别本身在模型里不产生颗粒差别。
- 缺的物理量是**显影后银粒的形态**，它由显影液化学决定：D-76 含 100 g/L 亚硫酸钠，是溶剂型显影液（溶解卤化银、物理显影成分使银更致密、更细）；FX39 是低亚硫酸盐的高锐度显影液〔T50 更正：FX39 配方从未公开（Crawley 卖给 Paterson），成分没有可靠出处；T50 改用“显影晶体成团”表达显影液效应，见 docs/tasks/T50_BW_DEVELOPERS.md〕。灵敏度：丝团面积 ×2 → 1.27 倍；丝径 ×2（更致密）→ 0.69 倍。也就是说 FX39 的银丝团只要比 D-76 的伸展约 2.5 倍就能解释 1.34——方向合理，但没有独立数据（两种显影液下同一晶体的电镜形态或覆盖力）能定它，**按规则不调**。Schmidt 表中 FX39 的结构尺度 6.2 µm 也大于 D-76 的 5.7 µm，与"更大的银粒"一致。

## 6. 显式银粒渲染（`filmlab/grain.py`）

- **晶体**：每档（亚群 × 9 个尺寸档）每像素的显影晶体数 ~ Poisson(n·p(H)·像素面积)（泊松撒点的显影稀疏化，与"先撒全部晶体、再逐颗按显影概率判定"同分布；晶体的位置在像素内均匀连续）。Thomas 团簇（`cluster_mu`、`cluster_um`）时逐颗撒团中心与晶体、在各自所在像素的曝光下逐颗显影。
- **银丝团**：每档 6 个随机形状（参考栅格 0.01 µm，4 根丝从晶体投影内的显影中心出发、方向扩散、碰丝团边界折回；总丝长由银质量守恒定）。按面积精确重采样到微元网格（4×4 个亚格相位），所以任意采样间距下单颗银粒的 ∫(1 − T) 都等于参考栅格上的不透明面积（测试），宏观密度与扫描间距无关（测试：8.69 / 6.35 / 2.0 µm 像素都等于闭式解）。
- **透射率**：微元 τ 相加、T = exp(−Στ)、在透射率域平均到像素；显微镜视场在微元上做 PSF。整帧扫描的 PSF 仍由扫描仪在像素透射率上做（T45 `scan_psf`，4.9 µm），两者是同一个线性运算。
- **位置分辨率分级**（计算量）：丝团直径 ≥ 1.5 个微元的档显式（连续位置 + 形状）；更小的档按粗格（像素 / 4）计数，粗格内每颗的覆盖率 = A/δ_B²，保持单颗 ∫(1 − T) 精确，所以平均透射率仍精确等于闭式解。整帧（8.69 µm 像素）：微元 0.54 µm，快亚群 9 档中 8 档与中亚群最大 2 档显式，其余按 2.17 µm 粗格计数；显微视场（0.25 µm 像素）：微元 0.125 µm，27 档中 26 档显式。
- **分块与确定性**：晶体按像素行用独立种子生成（显式档与计数档各一条流），相邻块的边缘行重新生成同一批晶体，跨块的银丝团在两边一致；分块大小与进程数不改变结果（测试逐位相同）。
- **冲印店定光（预扫）**：T47 路径在底片状态里另存显影化学给出的无颗粒银密度（`prescan_silver`），`timing = frame` 时自动定光用它（同样经扫描 PSF）：冲印店按低分辨率预扫的直方图定光，颗粒在预扫里平均掉。只在 T47 路径生效，其他代际、彩色片不受影响（逐位核对）。
- **计算量**：整帧（4144 × 2760，8.69 µm 像素，微元 0.54 µm）4 进程 260–320 s（不含颗粒的同一帧约 90–105 s）；显式银粒约 1.5e9 颗/帧（快亚群），中、慢亚群按粗格计数。显微视场（375 µm，0.25 µm 像素，全部显式）每个约 40 s。内存峰值约 3.5 GB（主进程）。
- **与引擎的衔接**（`apply_silver`）：显影化学（`chemistry.run`，含推拉、边缘效应）给出的银密度 d 由同一晶体模型的曲线反求每像素有效曝光 H_eff，在 H_eff 下渲染；Tri-X 的 S_nom 就是这条模型曲线，所以标准冲洗下 H_eff = H。其他黑白片（`bw_pan` 等）用同一组常数、由自己的特性曲线定涂布银量；曲线最低处与模型灰雾之差作为不渲染的中性灰雾（Tri-X 为 0）。

## 10. 局限

1. **只有一个颗粒密度点**：四孔径都在总 D ≈ 1；颗粒随密度的变化（第 5.7 节）、暗部与高光的颗粒都是预测。没有 Schmidt 的 RAW，也没有他显微镜的实测 PSF——PSF 是标定量，团聚的判定以它为前提。
2. **标定量吸收了什么**：η_3D 把三维晶体缩小到 T46 预测的 0.6 倍（ECD 0.63 µm）；它与银丝团形态（面积比 4、丝径 0.04 µm，都是先验）是简并的——丝团更大、晶体更小也能给出同一平台。密度审计（涂布银 3.87 g/m²、覆盖力 0.63）与 Kodak 48 µm（0.86 倍）是对这一组合的旁证，不是唯一解。
3. **银丝团形态没有 Tri-X 的电镜数据**：随机游走丝团是有文献依据的定性形态（化学显影的银丝从显影中心长出、伸出晶体轮廓），面积比与丝径是量级先验；最小的晶体（ECD < 0.15 µm）的丝短到只剩端帽，投影面积比同体积的实心银球大 1.3–1.8 倍（它们对颗粒几乎没有贡献，对高曝光的密度由涂布银量吸收）。
4. **FX39 留出未通过**：模型里显影液只改变"哪些晶体显影"，不改变银粒形态；显影液对银粒形态的影响需要独立测量。
5. **收集几何是假设**：Schmidt 的显微镜按漫射，依据是与 Kodak 48 µm 的一致性；Callier Q = 1.4 取文献中值，只影响镜面密度的报告，不影响漫射口径下的结果。
6. **乳剂结构沿用 T46**：3 个亚群的相对感光度与 σ_ln 取自 5219（T 颗粒彩色乳剂）；曲线残差的 S 形（−0.09 / +0.07）来自快 → 中亚群的交接，在门槛内但已接近；没有加亚群。
7. **撒点是泊松**：厚乳剂里 3D 硬球堆积的投影仍是亚泊松（结构因子 < 1，T45 对 5219 定的 S0 = 0）；对 Tri-X 没有数据，取泊松；亚泊松会降低高显影比例处的颗粒。
8. **整帧的分级**：8.69 µm 像素下中、慢亚群的大部分尺寸档按 2.17 µm 粗格计数（平均透射率精确，粗格内位置不分辨）；显微视场全部显式。扫描像素与扫描仪 PSF（4.9 µm）下两者不可见，但这是计算上的近似。
9. **扫描后**：输出仍经 T44/T46 的冲印店链条；冲印店扫描后的空间处理（T46 第 7 节）没有建模。

## 负责人结论

审核范围：Codex 交接包（codex/t47-trix@3f3bc80）与本任务的数据对照、几何检验、19 级密度审计、四孔径颗粒表、偏度与团聚判定、FX39 留出检验、标定量清单、引擎改动、506 项测试（通过）、81 组逐位核对、三场景整图、颗粒开 / 关对照、诊断局部与灰阶楔图。

1. **几何问题已经解决。** Schmidt 的曲线与 Kodak 官方漫射曲线在 19 级内相差不超过 0.059 D，高曝光段都到约 1.6。Codex 原型的 1.02 上限是模型的限制，不是测量几何造成的；Schmidt 用的也是漫射密度。
2. **密度过了门槛，而且是由银粒得出的。** 最大误差 0.089 D，小于 0.10。密度由晶体数 × 每晶体银量 × 显影银团的遮光面积得出，涂布银量 3.87 g/m²，覆盖力 0.63（漫射），都在合理范围。没有为了凑曲线增加亚群。
3. **四孔径全部在 ±15% 以内，但独立性有限。** 三个标定量里，有两个用掉了四个孔径中的两个：量子效率由 20/25 µm 定，显微镜 PSF 由结构尺度定。所以真正的独立检验只有 5、10 µm 两点。
   - 拿 Kodak 官方 48 µm 颗粒度 17 做"独立检验"要打折扣。Codex 已经指出，这个值是在另一种显影液 HC-110 下测的，与 D-76 不可互换。0.86 倍只能说明量级一致。
4. **FX39 留出检验没通过，按实情记录。** 模型里显影液只决定哪些晶体显影，不决定显影银的形态。溶解性显影液（D-76）与非溶解性显影液（FX39）对银丝形态的影响缺少独立数据，不去拟合是对的。所以 t47_bw 只适用于 D-76 一类的溶解性显影。
5. **通用性方面需要补一步。** 三维晶体的量子效率乘了 6.61，这个量目前只在 t47_bw 路径里生效。T46 的留一检验原本就显示 Tri-X、Plus-X 偏粗 1.3–1.5 倍，方向与此一致。但要保持"对所有胶片通用"，下一步必须用这个新常数重跑 T46 全部黑白片的留一检验，确认它不是只对 Tri-X 成立的单片拟合。
6. **引擎改动可以接受。** 冲印店自动曝光改为在无颗粒密度上计算，相当于低分辨率预扫，只影响 T47 路径。
7. **目视。**
   - 整图上，T47 的颗粒在中间调最明显、深暗部最弱，这和 T46 正好相反，也符合黑白片的常识。高光不再溢出。
   - 在 8.69 µm/像素下，单颗银粒（约 1 µm）本来就看不见，100% 局部仍然像细噪点。这是像素尺寸所限，不是模型错了。灰阶楔图上半部分是 0.5 µm/像素下的显式银粒，能看到真正的银粒结构。
8. **结论**：t47_bw 作为黑白片（D-76 类）颗粒的候选基准，替换 T46 的黑白路径。正式采用要等两件事：用户对整图的目视确认，以及第 5 点的多片种重跑。彩色片的染料云另做一轮，不受本任务影响。

- **最弱的一片是 Pan F+（0.70）**：最慢的片（EI 40），推出的晶体最小（快亚群 ECD 0.34 µm）；T46 是 0.99。可能的原因是量子效率随尺寸的 β（T46 由以 T 颗粒彩色片为主的数据定）对很小的三维晶体偏强，或慢片的乳剂结构与 5219 不同；没有调。

### b.3 T 颗粒与三维晶体的差别

- **T46**：同一组常数下三维片偏粗（几何平均 1.24）、T 颗粒片偏细（0.80），差别被高估 1.56 倍。
- **T47"只修三维"的读法**（×6.61 只乘三维晶体，T 颗粒仍用 T46 的 η）：三维片对了，T 颗粒片反而偏粗 1.5–1.9 倍（几何平均 1.70），差别反向高估约 2 倍。所以 ×6.61 不是"三维晶体特有"的量。
- **T47b**：把 ×6.61 理解为显式银粒模型对 T46 η 的修正（T46 的 η 是在染料云 / κ 银量模型下定的，显式银丝团下每颗晶体的遮光与颗粒关系不同），对三维与 T 颗粒同样适用；三维与 T 颗粒的差别只来自已有的几何量（表面吸附系数 3 : 1、体积 a^1.5 : a·t）。结果：T 颗粒片几何平均 1.03（7 片，0.90–1.14），三维片 0.86（4 片，含 HC-110 的 3 片；同口径 D-76 的只有 Tri-X 标定与 Pan F）。**T 颗粒与三维的差别被修正到 ±20% 以内，不需要给 T 颗粒单独的量**（厚度 0.12 µm、两面吸附都是 T46 的原值）。
- 旁证：同一口径下 T 颗粒的颗粒比同感光度的三维片细，是因为同样的光子捕获面积下 T 颗粒体积小（a·t ≪ a^1.5），每颗显影银少、遮光弱，要更多晶体才达到同一密度——这是几何，不是参数。

### b.4 是否推广：推广

- 留一误差不比 T46 差（同口径判定 0.05 对 0.32，Schmidt 留出 0.10 对 0.19，RMS 相当 0.18 对 0.19），所以把 t47_bw 的显式银粒路径推广为全部黑白片的通用路径：
  - `grain.SilverSpec.thickness_um`（T 颗粒体积 a·t）、`grain.silver_structure(..., thickness_um, scale_tgrain=True)`（表面系数 1，同一 ×6.61）；
  - `materials.BW_SILVER_FILMS` + `materials.bw_silver_film(key)`：Tri-X 400、T-Max 100、T-Max 400、Plus-X 125（特性曲线都由晶体模型从各自的 D-76 曲线算出；`trix_film()` 是其中一项，输出逐位不变）；配方 `kodak_tmax_100`、`kodak_tmax_400`、`kodak_plusx_125`。没有档案的黑白片（`bw_pan` 等）仍按 T47 的通用推导（三维、EI 400、自己的曲线），行为不变。
- 限制：只对 D-76 类显影成立（FX39 留出仍未过）；Plus-X 没有 D-76 曲线（借 Tri-X 形状）；T-Max / Plus-X 的光谱感光度借 Tri-X（未数字化）；Pan F 偏细 0.70。

### T47b 负责人结论

1. **推广成立，但有一个解释上的选择需要写明。** ×6.61 这个效率修正，只按"三维晶体专用"来理解时，T 颗粒片偏粗 1.5–1.9 倍；理解成"对显式银粒模型的整体修正、各种晶体通用"时，T-Max 和 Delta 落在 0.90–1.14。报告给出的理由是：T46 的效率是在染料云模型下拟合的，所以这个修正针对的是模型本身。这个理由成立，而且需要的假设更少，接受。但这是看到结果之后做的选择，并非事先写定。
2. **真正能判定的数据很少。** 官方数值里用 D-76 测的只有 T-Max 100 和 T-Max 400 两种，预测是 1.00 和 1.11。Schmidt 的另外五种片是同一台仪器、同一显影液的留出检验，|log| 中位误差 0.10，比 T46 的 0.19 好。Pan F+ 偏细到 0.70，明显未命中，不调参是对的。
3. **新档案的假设**：
   - Plus-X 借用 Tri-X 的曲线形状；
   - T-Max 和 Plus-X 借用 Tri-X 的光谱感光度；
   - Delta 按 T 颗粒处理。
   这些档案只能作为候选使用。
4. **曝光指数需要核对。** 200% 图的标注里，T-Max 400 是 EI 640、T-Max 100 是 EI 200，与包装感光度 400 和 100 不同。如果这来自 Schmidt 在 D-76 下测得的有效感光度，需要在档案里注明；如果是推导误差，需要修正。
5. **结论**：显式银粒路径作为全部黑白片（D-76 类显影）的通用颗粒路径，取代 T46 的黑白路径，仍为候选，等待用户目视确认。仍然未解决的有两项：
   - 显影液对银形态的影响，FX39 的留出检验未通过；
   - 慢速细颗粒片，以 Pan F+ 为例。

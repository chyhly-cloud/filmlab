# T55：银盐颗粒独立为 silvergrain 项目（Claude；重构，物理与数值不变）

## 0. 摘要

- **起因**：用户的指示是"银盐颗粒这个是单独的一个项目，你要单独去做"。颗粒应该独立开发，不再挂在 CineStill 800T 管线上验证。负责人补充了一项新要求：将来要能给**任意照片**加这种颗粒，既要从成像物理出发，也要看起来对。
- **做了什么**：
  - 在仓库顶层建了独立包 `silvergrain/`，有自己的 `pyproject.toml`、中文 README、测试、检验与示例。包内**零 `import filmlab`**（有测试检查），可以原样移到独立仓库。
  - filmlab 反过来依赖它：`filmlab/grain.py` 成为薄接口，`materials.py` 的通用常数与黑白数据从 `silvergrain/data` 读。
- **数值没有动**：
  - filmlab 已有输出 **238 组与 HEAD 逐位相同**：沿用 T53 的 180 组与 HEAD 比较，另 58 组显式设定，方法同 T46 §8 / T51 / T53。
  - silvergrain 自己的检验复现了 T46 / T47 / T47b / T50 / T53 的数：T46 留一、T47 四孔径、T47b、T53 闭式与参考结果**逐位相同**；T50 的 D-76 表与数据库参数的预测与文档一致。
- **新功能**：`apply_to_image`。两种模式：
  - "grain"（默认）：保留照片影调，只加物理颗粒；
  - "full"：该片的影调加颗粒。
  - 输入可以是 8 / 16 位 sRGB 或线性浮点、彩色或单色、任意尺寸。
  - 曝光走黑白片自己的光谱感光度，与 filmlab 同一套 RGB → 光谱方法，可加 Wratten 滤镜；测光按 ISO 约定 18% 灰 = 10/EI。
  - 可选 T51 实测的冲印店扫描。
  - 大图的黑白颗粒有快速路径 `closed_form`：用闭式协方差合成对数正态场，二阶统计与显式渲染相同。
- **测试**：filmlab 580 项通过，即原 568 项加新 12 项（`tests/test_t55_silvergrain.py`）。silvergrain 27 项通过，另有 1 项 slow：T46 全网格留一，单独运行通过。
- **检验中的新发现**（只报告，库里的数没有改）：
  1. **冲印店扫描光学的实现**。T51 的 Noritsu 光学 σ = 0.35 像素是按连续传递函数定的。filmlab 引擎用离散 `gaussian_filter` 实现它，几乎是恒等（邻点权重 0.017）。
     - 按连续 MTF 实现时，Tri-X 的胶片侧比值从 1.02–1.13 变为 1.17–1.30（真实 / 模型）；
     - 颗粒谱 P(0.48)/P(0.11) 从 2.36 变为 0.99（真实 1.42）。
     - silvergrain 用连续 MTF。filmlab 是否修改，留给负责人决定（第 6 节）。
  2. **同码值的颗粒强度主要由影调决定**。silvergrain 的 full 模式是按该片平均反差的直线反转，grain 模式用照片自己的影调；两者的中间调斜率（码值 / 底片密度）都比 RPL 的平。
     - 码值 68–138 时为 124–231，RPL 为 275–302；
     - 所以同码值的颗粒是真实的 1/1.5–1/2.9。
     - 胶片侧（除去影调）一致：Tri-X 1.08–1.30；HP5+ 1.44–1.79，T51b 已知 HP5+ 偏细。
     - 手机尺寸上，Tri-X 为 0.94–1.32（full）。

## 2. 公共 API

- `films()` / `developers()` / `film(key)` / `developer(key)`。
- `derive(film, developer=None, grain_scale=1)` → `Emulsion`，包含 `spec`、`mean_density(H)`、`exposure_axis()`、`describe()`。
- `render(emulsion, exposure=H | density=d, px_um=… | format=…, seed, method="auto", psf_um=0)` → `RenderResult`，包含 `density`、`mean`、`fluctuation`、`exposure`、`method`、`base_density`。
- `granularity(emulsion, density, aperture_um=48, shape="circle", net=True)`：闭式 RMS。黑白返回标量，彩色返回每层。
- `apply_to_image(image, film, developer, grain_scale, format, output_px, mode, exposure_ev, metering, filter, filter_compensate, scanner, seed, method)` → `GrainImage`，包含 `linear`、`encoded`、`info`、`save()`。拆开的步骤是 `expose()` 与 `finish()`。

彩色片的 `Developer` 是冲洗工艺（C-41 / ECN-2 / E-6）。黑白片的显影液是 d76 / xtol / rodinal / fx39。推冲不列，因为 T50 结论 3 认定它不可用。

## 4. apply_to_image：物理定义

完整说明见 `silvergrain/README.md` 第 4 节与 `image.py` 模块说明。要点：

- **几何**：画幅长边对图像长边，µm/像素 = 画幅长边 × 1000 / 图像长边像素数，默认 35 mm。`output_px` 指在线性光里按面积缩小，即以输出像素为扫描孔径。
- **曝光**：
  - 把照片的线性值当作反射率，经 Jakob–Hanika 光谱上采样（与 `filmlab.spectral.spectral_response` 同一算法），在设计光源下照明（D55 / 3200 K），可加 Wratten 滤镜。
  - 按该片每层的光谱感光度积分：黑白用 T48 / T49b 的逐片全色光谱，彩色用三层光谱。
  - 18% 灰落在 H = 10/EI，再乘 2^EV。`metering="average"` 时以对数平均为中灰。
  - 带滤镜时默认按中性灰补偿，系数由模型算出（T49：与 Kodak 公布值 RMS 0.23 档）。
- **full**：
  - 负片：P = 0.18·10^((D − D_g)/γ̄)，γ̄ 为中灰 ±2 档的平均斜率；
  - 反转片：P = 10^−(D − D_min)。
  - 彩色片每层只在自己的通道里读，没有串色校正。
- **grain**（默认）。物理的部分：
  - 照片值 ↔ 底片密度的映射，就是该片特性曲线的反函数；
  - δ = D_px − D̄ 是显式银粒 / 染料云在该密度处的起伏，含空间结构与 −log⟨T⟩；
  - 输出 v' = v·10^(δ/γ_eff − b(H))：
    - 斜率取常数时，v·10^(δ/γ) 是反映射的精确形式，恒为正；一阶为 v·(1 + ln10·δ/γ)。
    - b(H) 是指数映射的二阶偏移，按同一曝光的全部像素算出、扣除（`image._exp_bias`）。
    - 输出平均 = 照片 × 10^(E[δ]/γ)，即只剩物理的 −log⟨T⟩。12 µm、18% 灰时：Tri-X k = 1 +1.1%，Rodinal +2.0%，k = 3 +8.8%，Portra ≈ 0。
    - 最初的实现用一阶形式，在 k ≥ 2 的整图上截断出黑点；只用指数形式又让 k = 3 的平均亮 29%。两者都是整图检查时发现的，现已改正。
  - γ_eff = max(γ, γ_速度点)：速度点以下胶片不记录可用影像，这是唯一的约定；
  - 黑白只作用于亮度，彩色每层进对应通道。
  - 假设照片线性值与景物亮度成正比。带 S 形曲线的相机 JPEG 中间调更陡，颗粒会被低估同样的倍数。
- **冲印店扫描**（可选）：
  - 光学用**连续**高斯 MTF（频域），孔径按画幅换算，亮度 USM，彩色另做色度降噪；
  - grain 模式只作用于颗粒部分：光学与孔径作用于 δ，USM 作用于编码后的差。

**读法**

- **胶片物理与 filmlab 一致**。扫描按同一离散实现时，Tri-X 的胶片侧 1.02–1.13，对 filmlab 的 0.98–1.12，剩下的差别来自两者的扫描影调形状。HP5+ 偏细约 1.35 倍，T51b 已经记录。
- **同码值的差距来自影调**。silvergrain 的直线反转（系统反差 1），以及照片自己的影调（场景线性 → sRGB），在暗部与中间调的斜率只有 RPL 的 0.45–0.77，所以在同一码值上颗粒弱 1.5–2.9 倍。码值 184 处斜率相当，比值为 0.94–1.10。
  - 这不是颗粒物理的问题，没有按观感去调。
  - 用户若在意，应给出"照片的影调相对景物的反差"这一物理量，或用 RPL 的影调。这一项留给负责人决定，不在本任务中引入。
- **谱形**：
  - 不经扫描时，20 µm 像素上是白的，符合物理。
  - 连续 MTF 的 Noritsu 在中频上升（0.30 周/像素 1.32，真实 1.15），在 0.48 回落（0.99，真实 1.42）。离散核在高频过冲（2.36）。
  - 真实谱还含扫描仪的白噪声底与 JPEG（T51 的 N 项），silvergrain 没有建模，因为它不属于颗粒。

彩色（Portra 400 / C-41，RPL Noritsu）：同码值 σ_48 真实 / silvergrain(full) 在码值 71–229 上为 3.71 → 0.55，同样由影调主导（silvergrain 的直线反转对 RPL 的数字相纸影调）。silvergrain 的彩色物理与 filmlab 逐位相同，T54 已给出胶片侧：亮部 0.98，暗部 1.3–2.2 未归因。记录值里没有彩色的斜率，所以这里不再分解。

## 6. 发现：filmlab 引擎的扫描光学几乎没有生效（只报告）

- **现象**：`engine._scan_psf` 对 T51 的冲印店参数执行 `gaussian_filter(T, (0.35, 0.35, 0))`。σ = 0.35 像素的离散高斯核，中心权 1、邻点 0.017，几乎是恒等，与 T51 按连续传递函数定的 σ_o = 7 µm 不一致。
  - USM 半径 0.68 像素也用离散核（邻点权 0.34），偏差较小。
- **影响**：
  - t51_bw 的 Noritsu 输出在高频偏强：谱形 0.48 周/像素处 2.36 倍，真实 1.42。这与 T51b / T52 记录的"模型像素级颗粒略强于真实"（Tri-X 0.77–0.95）方向一致。
  - 改为连续 MTF 后，Tri-X 胶片侧的真实 / 模型从约 1.05 升到约 1.2。

## 负责人结论

审核范围：包结构（零 filmlab 依赖）、公开接口、颗粒自身数据的验证报告（T46 留一、T47 Schmidt 四孔径、T47b 官方值、T50 显影液、T53 粗细）、filmlab 逐位核对 238 组、580 + 27 项测试（通过）、三张照片 × 12 种设置的整图与 100% 对照、24 MP 用时与内存。

1. **银盐颗粒成为独立项目 `silvergrain/` 采用。** 物理与数值未变：所有验证数字与 T46–T53 文档相同；filmlab 改为调用它，现有代际逐位相同。以后颗粒的工作只在这个包里、只用颗粒自身的数据（官方颗粒度、Schmidt 实测、真实扫描的测量）检验，不再对照 800T 链路。
2. **任意照片加颗粒（apply_to_image）可用**：画幅定 µm/像素，胶片自身光谱感光与 EI 定曝光，"只加颗粒"模式保留原图影调和颜色；24 MP 快速路径约 2–3 分钟（彩色约 5 分钟），峰值内存 4–6 GB。
3. **审图发现、下一步（T55b）修正后再给用户看**：
   - "只加颗粒"模式把局部斜率取自"照片 = 场景线性的 sRGB 编码"，中间调比真实冲印店的影调平（每单位密度 124–231 码值 vs RPL 实测 275–302），颗粒比真实扫描弱 1.5–2.9 倍。改为用实测的冲印店影调（底片密度 ↔ 输出码值，T51b / T54 的配准，属冲印店属性，同 T44）。
   - "完整胶片"模式的直线反转扫描使黑白片整体发白，同样改用实测冲印店影调。
   - 黑白胶片颗粒加在彩色照片上时，高 k 出现带色的亮点；黑白银盐颗粒只改变亮度，应保持色度。

## T55b：冲印店实测影调、完整胶片模式、黑白颗粒的中性密度（Claude）

### b.0 摘要

- **冲印店影调改用实测**：`silvergrain/data/lab_tone.json`（`lab="rpl_noritsu"`，默认），即 RPL Noritsu 的输出码值 ↔ 底片密度。
  - 来自 T51b（黑白 14 帧）与 T54（彩色 31 帧，每通道）的扫描 ↔ 翻拍配准，只存测量、来源与帧间分散。
  - 生成脚本：`tools/export_silvergrain_labtone.py`。
- **grain 模式**：照片码值 → 影调的反函数 → 底片密度 → 该片在那里的颗粒 → 同一影调回到码值。
  - 同码值的颗粒从 T55 的"真实的 1/1.5–1/2.9"变为约 1/1.2（Tri-X）。
  - 剩下的 1.2 倍就是扫描光学实现之差（连续 MTF 对 filmlab 的离散核，T55 第 6 节）：按离散核为 1.04–1.10，与 filmlab 的 0.90–1.03 一致。
- **full 模式**：同一影调，加冲印店自动定光（无颗粒密度的整帧平均 → 中灰码值；彩色每通道）。黑白不再发白。
- **黑白颗粒在彩色照片上 = 中性密度**：三通道乘同一透射率因子；最亮只能到片基（输出 1.0），三通道一起限制。
  - 实测色比变化 ≤ 4.4e-16，没有任何像素被推过 1，没有带色的亮点。
  - HDR 输入按显示的样子先截到 1（否则中性限制会压暗过曝的天空）。
- **filmlab 未改动**：逐位核对沿用 T55 的结论（238 组相同）。T55b 只改 silvergrain 与 tools 下的导出脚本。

### b.1 冲印店实测影调（`data/lab_tone.json`）

- **做法**：
  - 每帧取 (底片密度, 码值) 的分档中位（T51b / T54 已存）。冲印店逐帧定光只平移密度轴，所以每帧取锚点 D_118（码值 118 = sRGB 中灰处的密度），写成 u = D − D_118。
  - 帧间合并在**码值域**做：每帧用三次拟合，即 T51b / T54 求真实斜率的同一拟合，只取实测范围内斜率为正的一段，两端各去 4 码值。每个码值上取各帧 du/dCode 的中位（≥ 4 帧），从 118 积分得到曲线。
  - 这样保留了颗粒所见的局部斜率。另一种做法是在 u 网格上直接取码值的中位，它会被各帧形状差压平 10–20%；初版用了这种做法，Tri-X 同码值比为 1.35–1.51，已弃用，作为对照仍存于 `u_grid_median`。
- **彩色**：翻拍密度按 T54 的 u_c（γ_翻拍 / γ_模型，每片每通道）换到模型染料当量，与 silvergrain 染料云路径同一单位。

**黑白斜率 dCode/dD**（帧间中位与四分位）：

|---|---|---|---|---|---|---|---|---|
| 斜率 | 206 | 267 | 296 | 299 | 292 | 274 | 229 | 148 |
| 四分位 | 191–217 | 250–303 | 271–327 | 272–328 | 264–317 | 244–287 | 203–244 | 103–167 |
| 帧数 | 11 | 14 | 14 | 14 | 14 | 14 | 14 | 10 |

T51b 记录的真实斜率在码值 68 / 99 / 138 / 184 处为 275 / 302 / 302 / 242，一致。

**彩色斜率 dCode/d(模型染料密度)**，码值 68 / 118 / 184：

- 彩色帧间分散大：5 种片的 u_c 换算各不相同，翻拍是相机 JPEG。
- 覆盖范围：黑白码值 16–216，R / G / B 分别为 34–234、18–230、8–234。范围外按端点斜率线性外推到 0 / 255。

### b.2 grain 模式（`image.lab_grain_exposure`、`finish_lab`）

- **映射**：照片码值 c → u = T⁻¹(c) → D = D_ref + u。D_ref 是该片在测光中灰（10/EI × 2^EV）的平均密度，照片中灰对齐它。
  - 由该片特性曲线的反函数得到 H，渲染颗粒，δ = D_px − D̄。
  - 输出码值为 T(u + δ)，即"这家冲印店在这个码值上的实测斜率 × 胶片在该密度处的颗粒"。
- **黑白**：
  - 用照片线性亮度 Y（BT.709）的码值。
  - 因子 k = Y'/Y 乘到三通道（中性密度）。亮的颗粒 = 该处底片密度低于平均（显影晶体少于平均）。
  - 正像最亮到片基：k ≤ 1 / 最亮的通道，三通道一起限制。
  - 全黑像素给中性的颗粒亮度。k = 3 时有 0.01–0.26% 的像素落到 0，日景的暗部最多；k = 1 时 ≤ 0.009%。这些是底片上几乎没有显影银的像素，正像为黑，中性。
- **彩色负片**：每通道各自的影调，每层颗粒进对应通道。**反转片**：v' = v·10^−δ。
- **平均**：影调曲率造成的二阶偏移，按同一 u 的系综扣除（`_mean_fix`），只剩物理的 −log⟨T⟩ 经影调的传递。
  - 18% 灰、12 µm 时：Tri-X k = 1 约 +1.2%，Rodinal +2.2%，k = 2 +4.4%，k = 3 +9%（整图的 `mean_rel_shift`）。
  - 冲印店影调比场景线性陡，所以比 T55 略大。
- 不再需要 T55 的速度点斜率约定：影调下端由实测曲线与外推给出。
- **对照**：`lab=None` 保留 T55 的做法。

### b.3 full 模式

- 光谱曝光 → 该片的特性曲线与颗粒 → 底片密度（可选扫描光学）→ 冲印店定光 → 影调 → 码值。
- `timing="auto"`（默认）：冲印店在无颗粒密度上定光（同 filmlab T47 的预扫），整帧平均密度 → 码值 118。彩色片每通道各自定光，即冲印店的自动色彩平衡。
- `timing="fixed"`：测光中灰 → 码值 118，曝光补偿可见。
- 反转片仍为透射率。
- **整图**：黑白人像不再发白，皮肤、头发、背景层次与普通冲印店扫描一致。Portra 400 的自动色彩平衡（灰世界）使人像皮肤略偏粉、日景天空略偏粉。这是"整帧每通道平均 → 中灰"这一定光规则的结果，没有另行调色。

|---|---|---|
| T55b | −0.87 | 0.86% |
| filmlab t51_bw 整帧（T52） | −0.30 | 0.34% |
| 真实均匀块 | −0.30 | 0.43% |
| T55c 修正后 | −0.27 | 0.36% |

**原因与修正**
- **黑点的来源**：不是影调外推，不是 _mean_fix，而是黑白颗粒的**中性限制**。T55b 把因子 k 压到 1 / 最亮通道，对有颜色的亮部（皮肤 R ≈ 0.9），亮的颗粒被整片砍掉，只剩暗的颗粒，看起来就是黑点。
- **修正（物理）**：保持亮度 Y' = Y·k（不超过影调的白）与色相；某个通道会超过正像的白时，只把色度向白收，即 `o = Y' + t·(rgb·k − Y')`，t 使最亮通道 = 1，同相纸上接近纸白时颜色变淡。不截断亮的颗粒，不逐通道截断。
- 冲印店 USM 也改为作用于亮度的变化，仍是中性的。
- **整图检查**（`view3/views.json`）：
  - 色度方向余弦 ≥ 1 − 7e-16（色相不变）；
  - 被推过 1 的像素为 0；
  - 色度向白收的像素：人像 12–16%、日景 6–8%、合成图 0.03–5%；
  - 黑像素在 k = 1 时 ≤ 0.001%，k = 3 时 0.06–0.32%，中性。
- 暗部头发区域的"黑点"观感在统计上不成立：照片暗部 20–70 档偏度 +0.17…+0.22（亮的尾巴），z < −3 为 0.02–0.05%。棕色头发上的中性亮度颗粒，暗的一半看起来像黑点，亮的一半像发白的点，两者对称。
- grain 模式与 full 模式在均匀块上的形状几乎相同，说明影调映射与平均修正没有引入形状偏差。
- 尾巴偏轻（峰度约 0）的原因：快速路径 closed_form 把像素透射率取为对数正态，密度因此是正态；显式渲染在 20 µm 时偏度略大（+0.2…+0.3）。真实的 +0.4、峰度 +0.7 可能含扫描仪 / JPEG 的非颗粒部分，这里没有调整。

## 负责人结论（T55b / T55c）

审核范围：实测冲印店影调（RPL 黑白 14 帧、彩色 31 帧的扫描 ↔ 底片翻拍配准）、"只加颗粒"与"完整胶片"两种模式、彩色照片上的黑白颗粒、颗粒分布形状与真实扫描（偏度、峰度、±3σ 尾部，含暗部）、Noritsu 光学按 silvergrain 自身实现重拟合与留出检验、611 项测试（通过）、三张照片的整图与标注位置的 100% 局部（中间调 + 暗部）。

1. **采用实测冲印店影调**（冲印店属性，同 T44），两种模式共用；完整胶片模式加冲印店自动定光。黑白人像不再发白。默认是一个一致的冲印店：RPL Noritsu 影调 + Noritsu 扫描（光学、孔径、亮度锐化）。
2. **"胡椒粒"已查明并修正**：原因是彩色照片上黑白颗粒的中性上限把亮颗粒截掉、只剩暗颗粒（170–220 码值偏度 −0.87 vs 真实 −0.30）。改为保持亮度与色相、超白时向白收色度（如相纸接近纸白），现为 −0.27；暗部偏度符号与真实一致（暗部亮尾、亮部暗尾）。真实扫描的尾部更重（峰度 +0.2 至 +1.2），可能含扫描仪 / JPEG 噪声，未加。
3. **Noritsu 光学 σ 取重拟合的 0.45 像素（9 µm）**：与 silvergrain 自己的实现一致（T51 的 0.35 是"先模糊后积分"下的值），直边 → 留出颗粒通过（0.0765）。T51 原值保留为 `optics_px_t51`。
4. **未解决**：同码值下 Tri-X 颗粒比真实弱 1.3–1.4 倍（手机尺寸 1.2），HP5+ 1.5（含已知偏细）。真实扫描的白噪声底占 40 µm 方差的 40–58%，可能解释这部分；区分需要片基 / 暗场的扫描仪噪声或同底片两种尺寸扫描。不按输出补。
5. **下一步**："只加颗粒"模式用黑白胶片时，底片密度应由胶片自身的光谱感光算出（`expose` 已有），而不是由照片的 BT.709 亮度码值反推——彩色照片里蓝色背景在 Y 上暗、在全色片上亮，两种模式因此颗粒不同。filmlab 引擎里 Noritsu 的离散核问题仍另行处理。

## T55d：grain 模式的黑白（及彩色）底片密度改为该片自己的光谱曝光（Claude）

### d.1 问题与定义

- **问题**：T55b/c 的 grain 模式由照片亮度（BT.709）的码值经冲印店影调反推底片密度，与该片实际受到的光谱曝光无关。
  - 蓝色背景在 Y 里暗，但全色片对蓝光的曝光更多，底片应更密，颗粒也不同；
  - 镜头滤镜在 grain 模式里也不起作用。
- **新定义**（`grain_density="film"`，默认；`image.py` 模块说明、README 第 4 节）：
  1. **底片**与 full 模式是同一张：`expose()` 的光谱曝光 H（RGB → 光谱 → 该片光谱感光度，可选 Wratten 滤镜；18% 灰 = 10/EI × 2^EV）→ 特性曲线 → D̄ 与逐像素 D_px，`δ = D_px − D̄`。
  2. **冲印店定光**与 full 模式同一约定（`lab_anchor`；默认整帧无颗粒平均密度 → 码值 118），得到锚点 m。这一点印成 `T(D̄ − m)`，颗粒让它变成 `T(D̄ − m + δ)`。
  3. **相对亮度因子** `f = lin(T(D̄ − m + δ)) / lin(T(D̄ − m))`（二阶平均偏移按同一 u 的系综扣除），乘到照片上：
     - 黑白为中性因子，用 T55c 的保色相方法；
     - 彩色负片为每层自己的 f_c 乘到对应通道；
     - 反转片 `f = 10^−δ`。
     - 照片的码值不再参与密度。
- **与 full 模式一致**：full 模式在同一点输出 `lin(T(D̄ − m + δ))`，相对其无颗粒值的起伏就是 f。所以两种模式同一像素的相对亮度起伏相同，区别只在底下的图：full 是这张底片的印片，grain 是照片本身。
- **彩色片**：存在同样的不一致（T55b/c 用照片每通道的码值，而不是该层由光谱感光度定的曝光），已按同一原理逐层改正。
- `grain_density="photo"` 保留 T55b/c 的做法，只为对照。

## T55e：颗粒"像噪点"——Noritsu HS-1800 的采样链（Claude）

### e.0 摘要

- **原因**：模型的扫描链不对，不是胶片。真实 RPL 扫描是 HS-1800 的线阵 CCD 在原生间距（645：56 mm / 4824 = 11.6 µm）上采样，冲印店软件再按 1.7253 倍缩小到 2048 × 2796（带抗混叠的双线性），最后在输出像素上做可分离的 3 抽头锐化。
  - T55c 的链在输出像素上做高斯模糊（σ 0.45 像素，Nyquist 处 MTF 0.37），再做径向 USM，把像素级的颗粒抹软。真实扫描没有可测的光学模糊。
  - 单像素的颗粒是"脆"的：原生采样的方盒孔径加上缩小时的混叠，使颗粒在输出像素上近乎独立；3 抽头锐化又让邻点相关为负（CCD 方向 −0.10）。
- **改动**（`image.py`、`data/scanners.json`）：底片渲染在 CCD 的原生网格上（像素孔径 = 原生像素），重采样到照片尺寸，再做 3 抽头锐化（kx 0.157 输送方向，ky 0.306 CCD 方向）。不加噪声，不加增益，不调色。
- **结果**：
  - 同码值 σ_48（真实 / silvergrain）：Tri-X full 1.13 / 1.11 / 1.12 / 1.01（T55d 1.42 / 1.40 / 1.42 / 1.29），grain 1.06 / 1.06 / 1.19 / 1.20（T55d 1.32 / 1.35 / 1.51 / 1.52）。
  - Tri-X 的谱 P(0.48)/P(0.11)：真实 1.42，模型 1.40（T55d 0.99）。
  - 留出检验通过（彩色训练 → 彩色留出 → 黑白）。
- **没解决**：
  - 峰度（真实块内 +0.15–0.37，模型 ≈ 0）；
  - 亮部偏度（真实 −0.25 至 −0.45，模型 −0.1）；
  - 同一码值上真实颗粒随底片密度增长（e.4）。

### e.1 证据：HS-1800 的采样

**冲印店规格**
- HS-1800 最大分辨率：135F 为 4492 × 6774，6×4.5 为 4824 × 3533（filmlab.com.my "Technical details"）。
- 线阵扫描，片带输送，同一镜头按片幅变焦；CCD "三色同时读取"（luckybox "Mini deep dive: the Noritsu HS-1800"）。
- 所以原生间距是：横跨片带的画面尺寸 / CCD 线数。

**缩小倍数的指纹**
- RPL 645 文件为 2048 × 2796 = 原生 4824 × 3533 ÷ 1.7253。
- 真实扫描每列与每行的颗粒方差（按块方差归一），都在 0.2747 周/像素（= 1 − 0.7253）有尖峰。53 帧都有，两个方向都有，深度 0.02–0.05。
- 不同重采样核在白噪声上的调制深度：

| 核 | 深度 |
|---|---|
| 按倍数拉宽的三角核（带抗混叠的双线性） | 0.03–0.05（经本链的模型场 0.05–0.07） |
| 面积平均 | 0.10–0.13 |
| 拉宽的三次核 | 约 0.02 |
| 不拉宽的线性或三次核 | 0.1–0.3 |

- 唯一给出这个深度的是三角核。

**锐化的形状**
- 真实 / 模型（不锐化）的 2D 颗粒谱比是菱形，四角（fx、fy 都高）最高；坐标轴端点只有约 1.2–1.4 倍，四角约 2.5–3 倍。
- 这是乘积形，来自可分离的核。径向的高斯 USM 给不出。
- 拟合一个对称 5 × 5 核，结果近似为 x、y 两个 3 抽头核的乘积：中心 1.48，x 邻点 −0.20，y 邻点 −0.28，对角 +0.06。

**各向异性**
- 真实的邻点相关，Tri-X 各帧中位：
  - x（片带输送方向）+0.09；
  - y（CCD 线阵方向）−0.10。
- 所有片种、所有帧上，y 都比 x 负。

**真实颗粒更"白"**
- 2D 中位谱在 0.25–0.5 周/像素仍高。

### e.2 模型

**`image.scan_grid(shape, px_um, format, scanner, gauge)`**
- 原生间距按片带取：135 为 5.34 µm，120 为 11.6 µm；`film_gauge` 参数可指定。
- 冲印店输出 = 按这张照片的像素数订的扫描，s = px_um / 原生间距。
- s > 4 时在 px/4 上渲染，原生网格最多 2600 万像素（内存）。
- CCD 方向取物理长度最接近横跨片带尺寸的那一边：35 mm 横幅为短边，RPL 645 竖幅为长边（竖直，与真实同）。

**`apply_to_image`**
- 曝光 H 插值到原生网格，在原生网格上渲染。
- `_to_output_grid` 在密度域把底片按三角核重采样到照片网格（`resample2`；冲印店软件在处理后的图像上缩放，影调对密度在小信号上近乎线性）。

**锐化：`_sharpen3`**
- `_software` 在编码后的亮度上做 `[−k, 1 + 2k, −k]`，x 与 y 各一遍。
- grain 模式作用于亮度变化（同 T55c/d）。

**参数（`scanners.json` noritsu_rpl）**

| 参数 | 值 | 来源 |
|---|---|---|
| 原生间距 | 135：24 mm / 4492；120：56 mm / 4824 | 规格表 |
| 像素孔径（填充） | 1（渲染像素就是孔径） | 线阵 CCD 的方形像素（假设，没有数据表）；谱形不需要更小的孔径 |
| 重采样核 | 拉宽三角核 | 方差调制的指纹 |
| 扫描光学 σ | 0 | 拟合：加 3 µm 时谱形 RMS 0.195 → 0.202，单调变差 |
| 输送方向拖影 | 0 | 与 kx 简并（0–0.6 线等价） |
| kx / ky | 0.157 / 0.306 | 彩色训练帧拟合 |

- T51 / T55c 的旧值存于 `t51` 字段。
- Frontier 不变（T51：高斯光学 + 方盒 + USM），因为没有原生采样的证据。

## 负责人结论（T55e）

1. **采用 Noritsu HS-1800 的实际采样链**：线阵 CCD 在自身细间距上采样（135：5.34 µm；120：11.6 µm，来自冲印店技术规格与拆解资料）→ 冲印店软件按比例缩小（带抗混叠的双线性 = 按缩放倍数拉伸的三角核）→ 按轴的 3 抽头锐化（kx 0.157、ky 0.306）；扫描光学 σ = 0。证据彼此独立：真实扫描每行、每列颗粒方差在 0.2747 周/像素（= 1 − 1/1.7253）的周期起伏（53 帧、两个方向都有）定了缩小核；二维谱比呈菱形定了按轴锐化；87 条直边检验通过。
2. **留出检验通过**：彩色三种片定参数，留出的彩色片（Portra 800、Ektar）0.198、跨片种黑白（Tri-X、HP5+）0.197，与训练 0.195 相同；旧链 0.647。
3. **"像噪点"的主因已修正**：旧默认在输出像素上做高斯模糊再径向锐化，像素级颗粒发糊。同码值颗粒比 Tri-X 由 1.3–1.5 降到 1.0–1.2；最高频段 1.40 对真实 1.42。负责人用真实扫描 3 倍对照目视确认颗粒变"脆"、接近真实。
4. **仍未解决**：中频（0.30 周/像素）偏强（1.42 vs 1.15）；真实像素值的峰度（+0.1 至 +0.2）与亮部偏度更强，线性扫描链给不出；颗粒随底片密度上升的幅度真实比模型大（Tri-X 同码值 EV 0 → +3：真实 7.6 → 12.3，模型 7.1 → 8.2），指向胶片的 σ–密度关系或逐帧定光，下一步查。HP5+ 仍偏细（已知）。
5. 24 MP 用时与内存上升（Portra 7.2 GB 峰值），原生网格上限 26 MP。filmlab 未改。

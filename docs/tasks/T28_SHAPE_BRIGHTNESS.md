# T28：光晕核形状 × 灯芯亮度的组合；按 RAW 裙边估计截断亮度（候选）（Claude）

## 0. 目标

- **A**：T26 定出光晕核散射角分布 cos^m 的形状（m 在 4–5 吻合），T27 发现中等灯（60–150 µm）偏强 1.6–3.3 倍、各场景亮度先验相差 4–4.5 档。
  把两者组合：m ∈ {4, 5} × 灯芯亮度 STOPS ∈ {0, −2}，用同一组测量比较，选出最接近真实的组合，并检验一个假设：
  "宽核把能量摊成低反差的雾，调暗后看不见；同样的能量集中在 150–300 µm 的窄环，反差高得多"。
- **B**：实现 T27 第 5 节的方向——每个截断块高出截断电平的档数改由同一张 RAW 的裙边与 PSF 推算，替代按 EXIF 的绝对亮度先验（默认关闭）。
- 只校正已有的物理量；不加经验调色；不动定光。现有代际逐位不变。

## 1. A 的方法

- 渲染：`t19_model.py`，代际 `t26_fwd` 配 `FWD`；STOPS=0 的 m=4/5 复用 T26 缓存，STOPS=−2 新渲。带 remjet 的对照没有光晕核，与 m 无关，复用 `t22_bxyz_0_remjet` / `t22_bxyz_-2_remjet`（T26 已核对逐像素相同）。
- 光晕部分：`t25_halo_part.py`（全部灯）与 `t27_size_halo.py` 的逐灯数据（按灯、去掉 city_61360）。光晕部分 = 除碳成片灯的中位 − 带碳成片灯的中位（总体对总体，同 T25–T27）。
- 小灯检查：800T 成片灯旁超出背景的线性 R，以及光晕部分，灯芯 < 40 / 40–60 / 0–60 µm，去掉 city_61360。
- T19：`t19_criteria.py`。
- 环的可见度（新，`tools/eval/t28_summary.py`）：每盏暗背景灯，150–300 µm 环（150–200、200–300 两档中位的平均）的 R 超出背景量 ÷ 同一盏灯 700–1000 µm 的 R 超出背景量。
  尾不足 0.003 时按 0.003 计。给出"逐灯比值的中位"与"环中位 ÷ 尾中位"两种汇总，以及环的 G/R 中位。只计两档都有像素的灯。
- 基准为 t22_bxyz（cos^1.5）。表中"m4_−2"即 cos^4、灯芯调暗 2 档。

### 2.5 选择与各组合输在哪里

**选 cos^4、调暗 2 档（FWD=4，STOPS=−2）**作为四个组合里最接近真实的一个，理由：
中等灯光晕部分的形状最好（全部灯形状 RMS 0.047，100–500 µm 归一形状为真实的 0.99–1.13 倍），强度 100–500 µm 为真实的 1.16–1.32 倍（去掉 city_61360：0.95–1.57 倍）；
成片 R 小灯与真实相差 ≤ 0.1 倍；中等灯环的 G/R 与真实相同（0.57），环/尾中位之比 9.3（真实 10.5）。

它输在：**小灯（< 40 µm）的红色光晕部分只剩真实的 0.42–0.56 倍**；T19 的 Δr 在 0–60 µm 档 10/11 环超出区间（基准 4/11）；150–400 µm 档 7/11。这正是用户否定"整体调暗"的那一类灯。

|---|---|
| 基准 cos^1.5，0 档 | 中等灯光晕强 1.7–7 倍，形状宽（700/峰 0.35，真实 0.11）；40–60 µm 小灯偏强 1.6–2.3 倍；中等灯环/尾低（4.1 对 10.5） |

| cos^4，0 档 | 中等灯强 1.7–2.8 倍（去掉 city_61360 到 3.5 倍）；40–60 µm 灯光晕强 1.4–2.2 倍；T19 Δr 8/5/6 |

## 3. B：按 RAW 裙边估计每块的档数（`rawio.HIGHLIGHT_RECON = "skirt"`，代际 `t28_skirt`）

### 3.1 实现

- `generation.py`：`t28_skirt` = `t26_fwd` 的修正集与定光 + `HIGHLIGHT_RECON["t28_skirt"] = "skirt"`；须配 `FWD`。
- `rawio.load_raw`：只在 skirt 模式下保留降噪前的下采样线性 RGB（`skirt_lin`），传给 `reconstruct_highlights`。其余模式不经过新代码，调用参数也不变。
- `rawio.skirt_psf`（每张图一次）：未截断的紧凑亮点——7×7 局部最大、峰值在截断电平（clip_frac > 0.9 像素的 Y 中位）的 0.1–0.9、离任何截断像素 > 20 px、
  14–17 px 背景 < 峰值 5%、4 px 内超过半峰的像素 ≤ 9、13 px 内没有更亮的像素。径向剖面 / 峰值 p(r)，r = 0…12 px（流水线像素，约 22.5 µm），逐点取中位。
  少于 8 个点，或 p(1..3) 的自助标准误 > 0.5 档 → 整张图回退原先验。
- `rawio._skirt_block_stops`（每块）：
  - 裙边：截断核（clip_frac > 0.25）外 Δ = 1、2、3 px、本身完全未截断、且最近的截断核属于本块的像素；背景 = 同样归属、12–16 px 处的中位。
  - 光源模型：以穹顶峰值像素为中心、半径 ρ 的均匀圆盘，经 p(r) 得到 G(y)。每个 Δ 由"中位((Y − 背景) / G)"给一个幅度 a，取几何平均；
    ρ 在 0…(√(Σf/π) + 1) 上搜索，选"预测值 a·G ≥ 截断电平的像素数"最接近"实测 f ≥ 0.5 的像素数"的那个。点源（ρ = 0）时即 s = log2(裙边 / (截断电平 × p(Δ)))。
  - 档数 s = log2(穹顶峰值处的预测光源部分 / (f·截断电平))，与原先验的档数同义（穹顶 lum = base·2^(s·dome)），限制在 [0.5, 8]；穹顶形状、颜色、只替换截断子像素这些都不变。
  - 不估计（用原先验）：大面积块（≥ 画面 0.5%）、背景 > 截断电平 25%、没有可用的裙边或背景像素。裙边不高于背景时取下限 0.5。
  - 原先验的随机数照常抽取，所以回退的块与 t26_fwd 逐位相同。`rawio.SKIRT_LOG`（默认 None）可记录每图的 PSF 与每块的估计。
- 合成检验（`tests/test_t28_skirt.py` 与 `scratchpad/t28/b/synth.py`）：已知 PSF（高斯 σ = 0.5–1.2 半尺寸像素 + 弱幂律尾）的点光源与圆盘，在半尺寸像素截断、2×2 平均：

| 合成光源 | 估计 − 真实 中位（档） | 四分位 |
|---|---|---|
| 点源，σ = 0.5 / 0.8 / 1.2 | +0.29 / +0.11 / −0.04 | 最宽 −0.31…+0.87 |

### 3.2 假设

1. 截断源与未截断亮点共用同一镜头 PSF，PSF 径向对称、全画面相同（不考虑像场边缘的彗差、渐晕与色差）。
2. 未截断亮点是近似点源。若它们有一定大小，p(r) 被估宽，裙边推出的档数偏低。
3. 截断源是均匀圆盘（含点源），中心在穹顶峰值；灯罩、反光碗等结构不在模型里。
4. 裙边 1–3 px 内只有本灯的光（没有被照亮的灯具、墙面、相邻的灯）。这一项在拥挤的灯群里不成立（见 4.2 的 no_bg）。
5. 截断电平按亮度 Y 取全图中位；不同颜色的灯在不同通道先截断，Y 截断电平随灯色变化。

## 6. 结论

1. **A**：四个组合里 cos^4、调暗 2 档最接近真实的中等灯光晕（形状 RMS 0.047，强度 1.16–1.32 倍，环颜色与真实相同）。
   代价是小灯（< 40 µm）红色光晕只剩真实的 0.42–0.56 倍、T19 的 Δr 在小灯档 10/11 环超出。**没有一个组合同时满足中等灯与小灯**：同一亮度偏移下，中等灯要 −2 档、小灯要 0 档。
2. **"宽核把能量摊成雾"只得到一半支持**：亮度不变时，宽核的中等灯环/尾确实偏低（4.1 对真实 10.5），窄核提高到 6.5–17.9；但宽核调暗 2 档后环/尾反而升到 8.4，并没有变成更低反差的雾。小灯在所有组合下环/尾都高于真实。
   调暗后真正下降的是环的 R 绝对量、红色程度（G/R 升高）与小灯的红色光晕部分。用户"红得不明显"的观察与这些一致，但按这组参考，调暗后的环颜色反而更接近真实 800T；两者不一致的原因本数据判断不了。
3. **B**：已实现 `HIGHLIGHT_RECON = "skirt"`（代际 t28_skirt，默认关闭），合成数据上能找回点源与圆盘的档数（中位偏差 −0.3…+0.6 档）。
   但在 8 个真实夜景里，**只有 city_61360 能从同一张 RAW 给出稳定的近场 PSF**；其余 7 个按规则回退原先验。放宽判据后各场景 PSF 相差 2 档以上（p(2)），块内 Δ 间离散 0.8–2.3 档。**PSF 估计不稳，按"同一张 RAW"的要求，这个方法在现有场景上基本不起作用。**
4. 若假设各镜头近场 PSF 相同（B'），裙边把长曝光组降 4–5.7 档、低先验组 −1.7…+1.9 档，中等灯光晕部分最接近真实；但它给小块的档数最低（多数场景 0.5–0.6 档），小灯的红晕更不足（0.37–0.42 倍），尺寸依赖的方向反而加重。这一假设没有独立依据（T27 远处 PSF 尾的绝对值就不确定约 5 档）。
5. 建议（供负责人决定）：形状定为 cos^4–cos^5 是稳的；亮度方面，"统一调暗"和"裙边按场景估"都会让小灯的红晕不足。下一步应查的是**光晕强度随灯芯大小的依赖**（T27 第 4.3 节：真实几乎不随灯芯大小变，模型 ≥ 40 µm 时随之增强），而不是继续调整体亮度。
   代码保留：`rawio.HIGHLIGHT_RECON = "skirt"` 与代际 `t28_skirt` 仅在显式选择时生效；`engine.HALO_FORWARD` 仍为 None。

## 7. 局限

- 真实 800T 与对照是不同场景、不同灯的总体；模型只有 8 个场景，去掉 city_61360 后中等灯约 140–150 盏，小灯 100–560 盏。没有估计抽样误差，表中 0.1–0.2 倍的差别不应过度解读。
- 环的可见度指标是本任务临时定义的，逐灯比值噪声很大；它只看 R，没有看人眼对"红"的感知（G/R 列只作参考）。
- B 的合成检验只覆盖径向对称的 PSF 与均匀圆盘；真实灯具（灯罩、反光、成簇）、PSF 随像场变化、按颜色不同的截断电平都没有检验。
- B' 用一个场景（佳能，招牌近景）的 PSF 代表其他相机与镜头，只能作为诊断。
- STOPS 只扫了 0 与 −2；中间值（−1）与 m = 4.5 没有渲染。

## 负责人结论（Fable 审核）

- 形状：cos^4–5 成立（与灯亮度无关的证据）。
- 强度：任何对"灯多亮"的整体调整都不能同时满足中等灯与小灯：中等灯需要调暗 2 档，小灯需要 0 档。按块估裙边（B）在 8 个场景里只有 1 个能测出稳定的 PSF，且会把小块压得更暗，方向相反；不采用，代码保留（默认关闭）。
- 真实 800T 里，光晕在距灯芯边缘固定距离上的强度几乎不随灯芯大小变（T27 §4.3）；模型里它随灯芯面积增长。这是现在最大的结构性差异，灯亮度先验与核参数都解释不了。
- 与成片阶段按阈值叠加（T29，DaVinci 方式）的结构对比：阈值叠加天然给出"光晕强度不随灯芯大小变"。这是否对应某个真实物理（例如大灯芯是漫射灯罩，亮度受材料限制，而不是按同一先验重建到截断电平的 2^6 倍），留待 T29 的目视与数据一起判断。
- 暂不改基准。

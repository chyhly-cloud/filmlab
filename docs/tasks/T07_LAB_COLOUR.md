# T07：冲印店颜色处理的实测与候选（Claude 执行）

## 测量（`tools/eval/t07_lab_colour.py`，结果 `t07_result.json`）

以固定光号（standard：800T 设计光源中灰印成中性）为参照，O1 拟合的颜色偏移就是冲印店对这一帧额外做的调整。

- 基础配置：`fixed_exposure,plain`，横轴为模型底片的偏色（相对档案中灰）。
- 估计量事先写定：主估计量是整帧算术平均密度；`latd`、`bright` 作为次要估计量报告。

主估计量，训练集 11 帧：

| 通道 | 校色力度 k | 截距 a | 训练相关 r | 留出预测相关 | 留出 RMSE 模型 / 常数 |
|---|---:|---:|---:|---:|---|
| 红 | 0.646 | −0.023 | −0.88 | +0.84 | 0.045 / 0.086 |
| 蓝 | 0.386 | +0.007 | −0.46 | +0.42 | 0.084 / 0.091 |

- 冲印店对红方向偏色约中和 65%，保留 35%，在留出集上成立。
- 蓝方向解释力弱：白光灯管帧冲印店多加约 +0.14 的蓝，但模型底片在蓝方向上与钨丝灯箱几乎相同。这是输入端缺蓝，不是冲印店行为。

## 候选 `fixed_exposure,plain,lab_colour`（`accept_variant.py`）

三项组成：
- 胶片与数码同一份曝光；
- 不套他店输出调整；
- 逐帧颜色偏移 a − k·偏色，参数照抄上表，只替换逐帧自动定光。

**原全图指标，判定条件事先写定（与 T05 相同）：通过**（`t07_accept_full.json`）。

| 留出集 | 变化 |
|---|---:|
| EPFL 全图平均 | **−1.679**（11.275 → 9.60） |
| 光源旁平均 | **−3.712** |
| 白光灯管 | −3.20 |
| 品红灯管 | −3.95 |
| 钨丝灯箱 | −2.35 |
| 黄昏 | −0.59 |
| 夜景 | +0.04 |
| 色卡 | +0.44 |

- 场景最大变差 +0.44；灰卡彩度 0.212。
- 训练集（样本内）−2.13；咖啡店 +3.02（只报告）。

实现修正：首次运行时我把颜色模型也套在了物理参考配方上，灰卡判为 3.46。改为只作用于逐帧自动定光后（与 T05 规格相同），场景结果不变，灰卡回到 0.212。

## 新数据独立验证（判定条件在运行前写定）

只用此前从未参与任何评估的 EPFL 帧（`tools/eval/t07_fresh.py`）：

- **判定帧（已确认配对）**：R1-17-18 灰阶楔、R1-29-30 空灯箱·钨丝、R1-34-35 空灯箱·白光灯管。
- **只报告（配对待确认）**：R1-22-23、R1-24-25 品红灯管。

**判定**：判定帧上候选相对 next 的全图 ΔE00 中位平均改善 ≥ 0.5，且任何一帧变差 ≤ 1.5。只看颜色的评估一并报告，不参与判定。

**修订（运行时、计算任何 ΔE 之前）**：R1-17-18 灰阶楔配准失败，画面几乎全是均匀色块，ORB 与 SIFT 都找不到足够的特征点。
处理：该帧记为无法评估，**不替换成其他帧**；判定改为在剩余两帧（R1-29-30、R1-34-35）上进行，条件不变。

**结果：无法进行。**

- 5 帧（R1-17-18、R1-29-30、R1-34-35、R1-22-23、R1-24-25）全部配准失败。它们都是空灯箱或测试卡，几乎全是均匀色块。
- 借用同组相邻帧的配准不可行：同组已配准帧之间的单应性角点相差 70–290 像素（拍摄间相机移动，或扫描裁切不同）。
- 灯泡系列（R1-08-9 … R1-16-17）在清单中配对依据不足，事先已排除。

结论：EPFL 现有数据无法为本候选提供独立验证。

另外两类数据的情况：
- 咖啡店属于他店，SillyStill 与 ref3 来自其他冲印店或其他数据。这些都不能检验"同一家冲印店的颜色行为"。
- 本候选的曝光常数针对 EPFL 这次拍摄，冲印店颜色参数针对这家冲印店。

要确认，需要同一家冲印店的新配对数据：新的一卷 CineStill 800T，同时拍数码 RAW，并在同一家 Frontier 冲扫。

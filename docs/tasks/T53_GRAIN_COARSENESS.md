# T53：颗粒粗细可调——同一胶片的颗粒尺寸 ×k（Claude；可选参数，默认关）

## 0. 摘要

- **问题**：用户认可了现在的黑白颗粒。T52 表明，真实扫描与模型的颗粒在原尺寸和手机尺寸上都一致，颗粒也按物理随显影液、画幅变化。用户要一个最后的控制量：**颗粒粗细可以调整**。它必须仍是银盐颗粒，对所有胶片通用（黑白银粒、彩色染料云）。
- **定义**（第 2 节）：颗粒粗细 **k**（`Params.grain_scale`，默认 1，范围 0.5–3）定义为**同一胶片的一个假想乳剂，每个线性颗粒尺寸都乘 k**。乘 k 的尺寸是：
  - 晶体 ECD（T 颗粒的投影面积 ×k²，厚度 0.12 µm 不变）；
  - 显影银丝团 / 染料云的大小；
  - 显影液成团半径 σ。
- **守恒量**：每个亚群全部显影时的**投影遮光截面** Σ n·g·A。它就是泊松布尔模型 E[T] = exp(−Σ n p g A) 的指数（染料是积分密度 Σ n·m）。也就是说，每颗显影晶体的投影足迹放大 k 倍、不透明度轮廓不变，每 µm² 的晶体数 n ∝ k⁻²。由此：
  - **特性曲线不变**：闭式解 D(H) 在三维晶体（Tri-X）和染料（Portra 400）上与 k = 1 相同到 1e-15。T 颗粒银（T-Max 400）的丝团要按新尺寸重新生成，所以差 ≤ 0.006 D。
  - **颗粒结构 ×k**：透射率协方差是 k = 1 的空间放大 Cov_k(r) = Cov_1(r/k)。闭式解 σ_k(d) = σ_1(d/k) 到 0.02%；Selwyn σ√A（96 µm）∝ k，误差 ≤ 1.7%。
  - **银量**：三维晶体每颗含银 ∝ k³。保持银量不变时，按模型自己的覆盖力 ∝ 1/√a（Farnell & Solman），密度会 ∝ 1/k，特性曲线不能不变；所以涂布银 **∝ k**（Tri-X k = 2：7.7 g/m²）。T 颗粒每颗含银 ∝ k²，涂布银**约不变**（0.92–1.00），即银量守恒。染料（彩色 T 颗粒）的染料量严格守恒。
  - **感光度：唯一的非物理假设**。真实的大晶体捕获更多光子，按本模型的光子捕获会快 k^(2(1+β)) = k^3.75 倍（k = 2 快 3.7 档）。这里每颗晶体在每个曝光下的有效光子数不变：η ×k⁻²，a0 ×k²，灰雾面积 ×k²。感光度由用户另设（EI）。
- **检验**（第 4 节；k ∈ {0.5, 1, 1.5, 2, 3}）：

| 闭式曲线 max \|ΔD\|（19 点） | ≤ 2e-16 | ≤ 1.4e-15 | ≤ 0.006 | ≤ 1e-15 |

## 1. 目标与规则

- 给用户一个颗粒粗细的旋钮。它必须是银盐颗粒的物理量，不是输出端噪声、不是调色，也不是新拟合的参数。
- 一个参数 k，对所有胶片通用：黑白显式银粒（T47 / T50）、彩色染料云与 κ 银量（T45 / T46）。
- 特性曲线不变（"同一胶片"），颗粒结构 ×k，Selwyn σ√A ∝ k。闭式解与显式模拟都要检验。
- 同时把"真实"的变粗方式（显影液、画幅）作为正式选项写清楚，作为对照。
- k = 1 与 HEAD 逐位相同，新选项默认关。
- 资源：单进程渲染（银粒 3 个工作进程，结果与进程数无关），`ulimit -v 9000000`，可续跑。

## 2. k 的定义与守恒量

### 2.1 定义

k 是同一胶片的一个假想乳剂：每个线性颗粒尺寸 ×k。

| 量 | 变化 | 理由 |
|---|---|---|
| 晶体 ECD（每亚群中位） | ×k（三维晶体体积 ×k³；T 颗粒投影面积 ×k²、厚度 0.12 µm 不变） | 定义 |
| 银丝团半径 R = √(spread·a/π) | ×k（spread 是比值，不变） | 显影银团的大小 |
| 银丝直径 w | 三维 ×k，T 颗粒不变（w ∝ 晶体平均厚度 v/a，见 2.4） | 丝团填充率不变 |
| 染料云扩散长度 L（T45 路径的整场 σ） | ×k | 染料云的大小 |
| 显影液成团半径 σ（T50） | ×k；每团晶体数 μ 不变 | 颗粒结构的大小 |
| 每 µm² 晶体数 n | ∝ k⁻²（由守恒量定，见 2.2） | — |
| 灰雾面积 a_f | ×k² | 每颗晶体的灰雾概率不变（2.5） |
| 有效量子效率 η、参考面积 a0 | η ×k⁻²，a0 ×k² | 每颗晶体的光子数不变（2.5，非物理假设） |
| 产量 CV、Callier Q、显影阈值 r、σ_ln、堆积 S0 | 不变 | 无量纲 |

### 2.2 守恒量：从 grain.py 的覆盖与覆盖力参数化推出

- **显式银粒**（T47）：
  - 平均透射率 E[T] = exp(−Σ_kq n_kq p_kq g A_kq)：A 是一颗丝团的投影不透明面积，g = 1/Q；
  - 覆盖力 CP = log10(e)·g·A / m（密度 / 每 g/m² 银），m = 每颗晶体含银。
  - 三维晶体放大 k：m ∝ k³。丝团几何放大 k 时 A ∝ k²，所以 **CP ∝ 1/k = 1/√a**。这正是 T47 引的 Farnell & Solman (1970) 的化学显影饱和覆盖力关系；模型按 k 自动给出，Tri-X 实测 0.627 → 0.314（k = 2）。
  - 因此"银量守恒"（n ∝ k⁻³）会让密度 ∝ 1/k：k = 2 时整条曲线减半，与"同一胶片、同一曲线"矛盾。
- **能同时满足"曲线不变"与"颗粒结构 ×k"的守恒量**，是每颗显影晶体的投影足迹放大 k 倍、不透明度轮廓不变，即 **n·A 守恒，n ∝ k⁻²**。此时：
  - p（显影概率）不变（2.5），n·A 不变 → **E[T] 不变，曲线不变**；
  - 协方差 Cov_T(r) = E[T]² (exp(Σ λ g² γ(r)) − 1) 中 λ = n p ∝ k⁻²，丝团自相关 γ_k(r) = k² γ_1(r/k)，所以 Σ λ γ_k(r) = Σ λ_1 γ_1(r/k)，**Cov_k(r) = Cov_1(r/k)**：纯空间放大。
  - 成团项（T50）：团中心密度 ρ = N/μ ∝ k⁻²，σ_e ∝ k，x = μS/(N 2πσ_e²) 不变 → 闭式解同样是放大；
  - 任意窗口 W_d 的方差 V_k(d) = V_1(d/k)，所以 σ√A 在 Selwyn 区 ∝ k，结构长度 ∝ k。
- 实现上，每个亚群按"全部显影时的投影遮光截面 Σ_q n_q A_q 不变"重定涂布银（`grain.scale_silver`）。三维晶体时它就是 n ∝ k⁻²（数值上 coat ×k 到 1e-9）；T 颗粒的丝团不是严格放大（2.4），这样定可以保持每亚群的 Dmax。
- **染料云 / κ 模型**（T45 / T46，`grain.scale_grain`）：
  - 每亚群全部显影的密度（`amount`）不变，n = amount / Σ w m，m = κ·v。
  - 投影足迹放大、不透明度不变要求 m ∝ k²：
    - T 颗粒 v = a·t ∝ k²，**自然成立**，染料量严格守恒（即负责人设想的"T 颗粒按面积 k⁻²"）；
    - 三维晶体 v ∝ k³，κ ×1/k。对银来说这就是覆盖力 ∝ 1/√a。三维 κ 模型只用在 T46 的通用黑白（`bw_film`）与 Kodachrome。
  - 方差 ∝ n·m² ∝ k² → σ(48 µm) ∝ k 严格；云 σ_k = √((ECD/4)² + L²) ∝ k 严格。

### 2.3 银量（报告）

| 片 | k = 0.5 | 1 | 1.5 | 2 | 3 |
|---|---|---|---|---|---|
| Tri-X 400（三维）涂布银 g/m² | 1.94 | 3.87 | 5.81 | 7.74 | 11.6 |
| Tri-X 覆盖力（漫射，密度/(g/m²)） | 1.26 | 0.63 | 0.42 | 0.31 | 0.21 |
| T-Max 400（T 颗粒）涂布银相对 k = 1 | 0.92 | 1 | 0.99 | 1.00 | 0.99 |

- Tri-X k = 3 的 11.6 g/m² 超出真实黑白负片的 3–8 g/m² 量级（T47 的范围）。所以 k = 3 是一个"假想乳剂"：用同一条曲线达到同样的 Dmax，粗三倍的三维晶体要涂更多银。这是覆盖力随晶体尺寸下降的物理结果，不是拟合。
- 真实的快速粗颗粒片也确实涂更多银。但本任务没有找到可引用的逐片银量数据，只作定性说明。

### 2.4 银丝团几何

- 丝团由 4 根丝在半径 R 的圆内随机游走生成（T47），丝长 = 含银体积 / 丝截面，填充率 ∝ L·w / R² ∝ (v/a) / w。
- 规则：**丝径 w ∝ 晶体平均厚度 v/a**，丝团填充率（不透明度轮廓）不变。
  - **三维**：v/a ∝ k，所以 w ×k，丝团就是 k = 1 的丝团整体放大。实现上丝团参考栅格同样 ×k（`SilverSpec.fine_um`，默认 0.01 µm），同一随机序列给出同一形状。检验：每档 A_k / (k² A_1) = 1.0000（9 档 × 3 亚群，全部）。
  - **T 颗粒**：v/a = t 不变，w 不变。丝长 ∝ k²、R ∝ k，填充率不变，但随机游走按新尺寸重新生成（步长 w/2 固定），所以只是统计上的放大：每档 A_k / (k² A_1) 为 0.84–1.07（k ≥ 1.5），k = 0.5 时最小的档到 1.72（丝团只剩几个参考格）。
  - 由此 T-Max 的闭式曲线差 ≤ 0.006 D、Selwyn / k 为 0.99–1.02。引擎里的平均密度不受影响：apply_silver 按缩放后档案自己的曲线反求有效曝光，每个像素的密度仍等于显影化学给出的 d。

### 2.5 感光度：唯一的非物理假设

- 本模型每颗晶体的有效光子数 λ = φ·a·(a/a0)^β·H（T46，β = 0.875）。a ×k² 而其他不变时，λ ×k^(2(1+β)) = k^3.75：k = 2 的乳剂快 13 倍（3.7 档），k = 0.5 慢 13 倍；特性曲线在 logH 上整体平移 3.75·log10 k。
- 真实的粗颗粒片确实更快，但用户另设 EI，所以这里保持每颗晶体在每个曝光下的光子数不变：η ×k⁻²、a0 ×k²（λ 严格不变）；灰雾面积 a_f ×k²（每颗晶体的灰雾概率不变，Dmin 不变）。检验：显影概率 p(H) 逐档与 k = 1 相同到 1e-12（测试）。
- 引擎里这一项其实不改变输出：颗粒步骤按缩放后档案自己的曲线，由显影化学给出的密度 d 反求有效曝光 H_eff。曲线整体平移只会让 H_eff 跟着平移，p(H_eff) 相同。保持 λ 不变是为了让档案自身的闭式曲线 D(H) 与 k = 1 相同、可直接比较。
- **这是 k 唯一不物理的地方**：k ≠ 1 的"同一胶片"在真实世界里会有不同的感光度，模型不给。

### 2.6 宏观密度与逐像素密度

- 底片的宏观密度（大孔径密度计）= −log10 E[T]，严格不变。扫描仪逐像素测透射率再取对数，−log10 T_px 的平均大于 −log10 E[T]（Jensen），差约为 ln10/2·σ²_D,px，随颗粒方差上升。
- 闭式预测（Tri-X，12 µm 方孔）：k = 0.5 / 1 / 1.5 / 2 / 3 为 0.0007 / 0.0025 / 0.0055 / 0.0095 / 0.0198 D。显式整帧像素渲染的逐像素平均：0.6923 / 0.6993 / 0.7100（k = 1 / 2 / 3，宏观 0.6900），即 +0.0023 / +0.0093 / +0.0200，**与预测一致**。
- 结果是 k 大时扫描出来的负片"略密"，正像略亮：k = 2 +1.7 码值，k = 3 +4.5（第 4.3 节）。冲印店定光按无颗粒的预扫密度（T47），不补偿这一项。真实的粗颗粒片在逐像素扫描下一样会这样：T52 里 Rodinal 比 D-76 亮 2.5 码值，110 比 35 mm（同为 Rodinal，EV −1）亮 5 码值。所以不在输出端修正。

## 3. 接口与"真实"的变粗方式

### 3.1 颗粒粗细

- `Params.grain_scale: float = 1.0`。
  - 范围 `grain.GRAIN_SCALE_RANGE = (0.5, 3.0)`，范围外或非数抛 `ValueError`。
  - 只在银盐颗粒路径上定义（修正 `grain_silver`，t45_base 及以后）。之前的代际用按感光度估算的统计颗粒，那不是银盐模型，设 k ≠ 1 抛 `ValueError`。
- 配方后缀（`recipes.recipe`）：`"<配方>+g<k>"`，例 `kodak_trix_400+g1.5`、`kodak_portra_400+g2`。后缀可按顺序叠加：`kodak_trix_400@rodinal+w25+g2`，`+w` 的含义与 T49 相同（滤镜系数按 `+` 之前的配方名查）。非数（`+gx`）与范围外（`+g4`）报错，未知后缀报错。
- 范围的理由：
  - k = 0.5 时 Tri-X 快亚群 ECD 0.31 µm、银丝 0.02 µm，仍在渲染的显式档内；
  - k = 3 时涂布银已到 11.6 g/m²（2.3 节），在 12 µm 像素上原尺寸 σ_px 63 码值，8 位截断开始明显（4.3 节）。

### 3.2 "真实"的变粗方式（对照）

- **显影液**（T50，已有）：`kodak_trix_400@rodinal`、`@xtol`、`@fx39`。Rodinal 在 35 mm 上 ≈ k 1.4（4.4 节）。
- **画幅 / 放大倍率**：`Params.film_format`（`engine.FILM_FORMATS`，默认 None = 用 `frame_width_mm`）。
  - 可选 "35mm" 36×24、"half" 24×18、"110" 17×13、"126" 26.5×26.5、"aps_c" 25.1×16.7、"645" 56×41.5、"6x6" 56×56、"6x7" 69.5×56、"6x9" 84×56、"4x5" 121×97（名义画面尺寸）。也可用配方后缀 `+fhalf`、`+f110`。
  - 设定时画面长边 = 画幅长边（取代 `frame_width_mm`），输入图像按长边对长边放在画面上。长宽比不同时，相当于画面里最大的同长宽比裁切；要对应整幅画面，先用 `engine.crop_to_format(img, fmt)` 居中裁切。
  - 冲印店空间传递（T51）的传感器孔径按画幅长边 / 36 mm 换算，即 T52 3.1 节的假设：冲印店对各画幅输出与 35 mm 相近的像素数。RPL 的 645 中等尺寸 2796 像素正是这样：12 µm × 56/36 = 18.7 µm，实测约 20 µm。
  - `film_format = "35mm"` 与默认逐位相同（逐位核对）。
  - 半格 ≈ k 1.5、110 ≈ k 2.1（4.4 节）：画幅的效果就是放大倍率，即每个输出像素对应的胶片面积。

### 4.4 锚：k 的"意思"（只报告，不拟合）

- 在 4.3 节的曲线 σ_px(k)（Tri-X / D-76，35 mm，EV 0）上，按 log–log 插值求与"真实"变粗方式相同 σ_px 的 k：

| 真实的变粗方式 | 量（T52 / 本任务，同一代码） | 相当的 k |
|---|---|---|
| Tri-X Rodinal 对 D-76，原尺寸 12 µm/像素 | σ_px 33.4（D-76 24.1） | **1.41** |
| 同上，手机尺寸 | 9.41（D-76 6.53） | 1.44 |
| 半格 / 35 mm，手机尺寸（T52 的 Tri-X Rodinal 对：13.94 / 9.41 = ×1.48） | ×1.48 | **1.48** |
| 半格 / 35 mm，手机尺寸（本任务 Tri-X D-76 半格：9.89 / 6.53 = ×1.52） | ×1.52 | 1.51 |
| 110 / 35 mm，手机尺寸（T52 Rodinal，EV −1：×2.09） | ×2.09 | **2.13** |

- 画幅：半格 k ≈ 1.5、110 k ≈ 2.1，正是两种画幅相对 35 mm 的放大倍率 36/24、36/17。原因是画幅放大后，"每个输出像素的胶片面积"缩小 1/k²，与颗粒放大 k 对 σ_px 的作用相同（Selwyn）。两者的区别是：画幅同时放大景物锐度的损失（镜头、乳剂散射在输出上变宽），k 只放大颗粒。
- Rodinal ≈ k 1.4：Rodinal 的显影晶体成团（T50，μ 2、σ 1 µm）让颗粒 ×1.4。成团只放大团内结构，k 放大全部结构。两者的颗粒谱形不同，所以原尺寸（1.41）与手机尺寸（1.44）给出的 k 略有不同。
- 给用户的读法：**k 1.4 ≈ 35 mm 换 Rodinal；k 1.5 ≈ 半格；k 2 ≈ 介于半格与 110 之间；k 2.1 ≈ 110；k 3 已超出这些真实组合**（T52 的最粗 110 + Rodinal 在手机尺寸 σ_px 16.8（EV −1），本任务 k = 3 的 D-76 为 15.9（EV −1））。

## 7. 局限

1. **感光度不随 k**（2.5 节）：这是唯一的非物理假设。真实的 ×k 乳剂会快约 k^3.75 倍（按本模型的光子捕获）；k 只改变颗粒，不改变感光度与曲线。
2. **三维晶体的银量 ∝ k**：k = 3 的 Tri-X 要 11.6 g/m²，超出真实黑白片的量级。"同一曲线"只能由更多的银达到（覆盖力 ∝ 1/√a），所以 k 较大时是一个假想乳剂。
3. **T 颗粒不是严格放大**：丝径不变、丝团重新生成，曲线差 ≤ 0.006 D、Selwyn / k 为 0.99–1.02；k = 0.5 时最小的丝团只剩几个参考格。
4. **三维染料（κ ×1/k）**：只用于 T46 的通用黑白与 Kodachrome，是"投影足迹不透明度不变"的同一规则，没有染料云的独立数据。
5. **逐像素取对数的平均偏差**（2.6 节）：k = 3 平均码值 +4.5（EV 0）、+7.3（EV −1）。它是物理的（真实粗颗粒的扫描也有），但用户可能把它看成"影调略亮"。
6. **锚依赖 T52 的条件**：Noritsu、12 µm/像素、同一输出像素数的画幅假设；Rodinal 的 k 在原尺寸与手机尺寸上差 2%（谱形不同）。
7. **渲染器的两处细像素近似**（不影响整帧，4.2 节）：显式银粒按行分块时的块边界丢失（像素 < 丝团时）；染料路径涂布堆积按 2 的幂次块计数。都是已有的。
8. 整帧像素 12 µm 远大于颗粒结构（1–7 µm），所以"颗粒结构 ×k"在输出像素上主要表现为 σ ×k；要在像素上看到颗粒形状变大，需要更细的扫描（或更大的 k）。

## 负责人结论

审核范围：k 的定义与守恒量、闭式与逐颗模拟的验证（k = 0.5–3）、全链路颗粒随 k 的标度、与显影液 / 画幅的对应（只报告不拟合）、568 项测试（通过）、180 + 58 组逐位核对、手机尺寸整图对照。

1. **颗粒粗细 k 采用。** k 是"同一胶片、所有颗粒线尺度 ×k 的假想乳剂"：晶体、银团 / 染料云、显影簇聚半径一起放大；守恒每个亚群显影后的投影光学截面，所以特性曲线不变（闭式最大 0.006 D，模拟 −0.003 至 +0.008 D），颗粒场就是 k = 1 的场放大 k 倍（σ√A ÷ k = 0.98–1.02，相关长度 ×1.46 / 1.95 / 2.88）。全链路输出颗粒 ∝ k^0.98–1.04。
2. **偏离原设计、负责人接受**：三维晶体不守恒银量而守恒投影截面——按模型自身的覆盖力关系，守恒银量会让曲线按 1/k 变，违反"曲线不变"这一首要要求。代价是 k = 2、3 时 Tri-X 涂银量 7.7、11.6 g/m²，超出真实黑白片范围；T 颗粒与彩色片基本守恒质量。所以 k ≥ 2 是假想乳剂，文档已写明。感光度不随 k 变是唯一有意的非物理假设。
3. **高 k 时整体略亮**（k = 3 约 +4.5 码值）：扫描像素平均透射率再取对数，颗粒方差越大越亮，预测与渲染一致；这是物理效应，不修正（T52 的 Rodinal、110 帧同样如此）。
4. **k 的含义**（35 mm Tri-X / D-76）：Rodinal ≈ k 1.4，半格 ≈ k 1.5，110 ≈ k 2.1；k = 3 粗于模型中任何真实组合。
5. 真实世界的做法也成为正式选项：`Params.film_format`（`+fhalf` 等）、显影液（`@rodinal`）。配方后缀 `+g<k>`，范围 0.5–3。默认关，k = 1 与 HEAD 逐位相同。
6. 已知渲染器限制（亚微米像素下块边界丢失约 5% 银团，12 µm 整帧不受影响）另列任务，不在本次修。

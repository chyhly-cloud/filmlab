# T54：彩色颗粒的量级——EPFL 800T 的"2.7 倍"拆成哪几项（Claude；只测量，库代码未改）

## 0. 摘要

- **问题**：EPFL CineStill 800T 的 Frontier 扫描（未压缩 TIFF，6.6 µm/像素）在中间调的亮度颗粒约为模型的 2.7 倍（σ = 2.5 像素高通，约 10 对 3.4–3.9 码值，T51 第 7.3 节）。黑白在 RPL Noritsu 上同码值已经一致（T51b）。本任务用 T51b 的方法把彩色的比值拆成几项，每一项对应一个已有的物理量，再看哪一项可以按独立证据修正。
- **分解**（第 2 节）：同一输出码值上
  - 总比 = **影调斜率**（dCode/dlogE，真实 / 模型）× **底片位置**（真实块在胶片曲线上的位置让模型自己的噪声等效曝光变多少）× **胶片侧**（同一曝光下的噪声等效曝光 NEE = σ / (dCode/dlogE)，真实 / 模型）；
  - 亮度另有 **通道相关项**：每通道颗粒相同时，通道间相关（颜色换算的交叉项、色度降噪）让亮度颗粒多出的倍数；
  - 扫描仪通道看染料密度起伏的倍数（第 3 节）单独由光谱算。
  - 真实斜率不用包围档的码值（冲印店逐帧定光，T51b 已说明不可用）：RPL 由扫描 ↔ 底片翻拍配准（每通道 dCode/dD）× 相邻包围档翻拍的 dD/dEV 得到 dCode/dEV，翻拍密度的单位在乘积里抵消；EPFL 由扫描 ↔ 同场景数码 RAW 配准（RAW 线性值就是场景曝光）。

- **结论（第 7 节归因表）**：
  1. **影调斜率（候选 a）不是来源。** 两家冲印店在中间调的宏观影调都**不比**模型陡：EPFL 0.82–1.03（与 T35 的灰阶楔 0.85 一致），RPL 暗部 0.66–0.84、亮部约 1。T44 的"暗部偏陡"是逐帧定光，扣掉后不剩。
  2. **颜色换算（候选 b）不是来源。** 真实与模型的亮度通道相关项之比为 0.95–1.17。模型里换掉颜色换算的三个开关（paper_channel、去掉输出饱和度矩阵、Kodak 原始 5219 染料谱），中间调的亮度预测颗粒只变 ×0.85–1.08（第 4 节）。在固定定光的均匀灰上，t51_base 的 R–B 相关本来就是正的（0.3–0.7）；T46 的负相关是暗夜空工作点上的。
  3. **扫描仪看染料密度的方式（候选 c）不是来源。** 仓库的 Frontier LED 对 Status M（ISO 5-3）的本层倍数为 1.02–1.04，Noritsu LED 为 0.92–1.18；即使是落在染料峰值上的单色通道，上限也只有 R 1.32–1.41、G 1.14–1.18、B 1.13–1.16。而且这一项同时放大信号与颗粒，冲印店按档案拉齐反差后在 NEE 里抵消（第 3 节）。染料像的 Callier 系数接近 1（无可引用的数值，第 3.3 节）。
  4. **测量本身（候选 d）不是 EPFL 的来源。** 无纹理的白场比值最高（3.0），噪声卡 2.6，与夜景（2.3）同一量级。
  5. **剩下的是"胶片侧"：在同一（会话测光推算的）曝光下，EPFL 底片的噪声等效曝光是模型的 2.0–2.8 倍**；模型自己的 800T 胶片侧在 Status M 下与 Kodak 5219 一致到 0.9–1.26 倍。同一方法在 RPL 上，Portra 400 / 160 / 800 / Ektar 的**亮部**胶片侧为 0.98–1.07，即模型正确；RPL 的**暗部**胶片侧为 1.1–1.6，未归因。
- **采用**：**无。** 没有一项既对应已有物理量、又有与颗粒差距无关的独立证据、且量级够：斜率、颜色换算、扫描仪光谱都已被测量排除；剩下的胶片侧 2.5 倍只出现在 EPFL 这一家冲印店的 CineStill 800T（C-41 冲 ECN-2 乳剂），它可能是 800T 在 C-41 下的真实颗粒、EPFL 实际曝光比会话常数假设的更薄（落在趾部），或二者兼有——两者都没有独立数据可定，按规则不拟合颗粒增益。库代码未改，现有代际自然逐位不变；没有出图（规则：只有采用时才出前后对照）。
- **文件**：`tools/eval/t54_model.py`、`t54_real.py`、`t54_epfl_tone.py`、`t54_compare.py`、`t54_summary.py`；测量在 `tools/eval/t54/`（只存 URL 与测量）。全部 568 项测试通过。

## 1. 目标与规则

- 用 T51b 的分解找出 EPFL 彩色 2.7 倍的来源：RPL 彩色（Noritsu，Portra 400 为主，其余片顺带）与 EPFL 800T（Frontier）两套真实扫描，每通道与亮度；再由公开的染料光谱与仓库建模的扫描仪通道算"扫描仪 vs Status M"一项。
- 只有当某一项是已有物理量的修正、且证据独立于颗粒差距本身（例：数据表给的扫描仪通道带宽；由底片照片测得的影调斜率）时，才默认关地实现为新的研究代际，并在留出帧 / 留出片上检验。**不对输出拟合颗粒增益。**
- 第一性原理；不加输出端噪声、不调色、无自由增益。第三方图像只存 URL 与测量，下载在 scratchpad，用完删除。资源：单进程、`ulimit -v 9000000`、可续跑。

## 2. 方法

### 2.1 颗粒量（`tools/eval/t54_real.py: grain_stats`；真实与模型同一代码）

- 8 位码值的 R、G、B 与 BT.601 亮度 Y（编码域，冲印店软件与 T51 的亮度）。均匀块 32 × 32 像素，去一次平面，T45 平坦判据对 Y 与三个通道都要通过，码值 12–250。
- 每块每通道：σ_px（去平面后的标准差）、σ_hp（减 σ = 1 像素高斯）、**σ_hp25**（减 σ = 2.5 像素高斯，即 T51 第 7.3 节"10 对 3.4–3.9"的量）、**σ_48**（约 48 µm 盒平均，按面积律换到 42.5 µm 等面积方孔）、48 µm 盒级通道相关。8 位量化方差已扣。
- 模型（`t54_model.py uniform`）：均匀 18% 灰 × 2^EV（EV −5 … +3），t51_base，固定定光（timing = "gray"），颗粒开，512 × 512；800T 用 Frontier 实测空间传递（6.6 µm/像素），RPL 各片用 `Params.scan_spatial = "noritsu_rpl"`（20 µm/像素，645）。同一点另算颗粒关的 dCode/dlogE（EV ± 0.1 有限差分）与 8 位码值对三层染料量的局部雅可比 J（第 4 节）。

### 2.2 分解

- 同码值的总比 r = σ_真实(c) / σ_模型(c)。σ = (dCode/dlogE) × NEE，NEE 是噪声等效曝光（logE），是胶片在该曝光处的性质（冲印店的影调是逐点的，在 NEE 里约掉）。所以
  - r = [S_真实(c) / S_模型(c)] × [NEE_模型(E_真实) / NEE_模型(E_模型(c))] × [NEE_真实(E_真实) / NEE_模型(E_真实)]
  - 第一项 **影调斜率**；第二项 **底片位置**——真实块在胶片曲线上的曝光 E_真实 与模型在同码值处的曝光不同（冲印店把薄底片印亮），模型自己的 NEE 因此变多少；第三项 **胶片侧**——同一曝光下真实与模型的 NEE 之比，是唯一与冲印店无关的一项。
- **真实块的曝光**：
  - RPL：块所在帧的影调曲线（扫描 ↔ 翻拍）给出翻拍密度 D_c，按 u_c = γ_翻拍 / γ_模型（直线段每 EV 的密度增量之比；Portra 400：R 0.74、G 1.13、B 1.41）换到模型染料量，再在模型自己的曲线上找同一净密度的 EV（未曝光处为 0，与翻拍"减片基"同一零点）。亮度的位置按 G。
  - EPFL：块在 RAW 上的平均线性值 × 会话测光常数（`rawio.SESSION_LOG_SCALE`，胶片输入 = RAW × 10^0.613，与渲染 EPFL 时同一假设），18% 灰 = 0 档，与模型均匀灰同一轴。
- **真实斜率**：
  - RPL（`t54_real.py`）：扫描与同一底片的灯箱翻拍（Neg Sequence，Nikon D5300）配准（亮度边缘 FFT 互相关，比例 0.32–0.33），每通道 D_c = −log10(T_c / T_片基,c)，片基（含橙色遮罩）取上沿片边未曝光带较亮的一半；在 D 上分档取扫描码值中位 → 局部回归 dCode_c/dD_c。相邻包围档的翻拍互相配准（同一场景）→ 每通道 dD_c/dEV（在 D 上分档的中位差）。相关 < 0.45 或平移 > 30 像素的档对不用（Portra 400：5/5 对可用；Portra 160 3/6、800 4/5、Ektar 3/6）。**dCode/dEV = dCode/dD × dD/dEV，翻拍相机的光谱、白平衡与影调曲线都在乘积里抵消。**
  - EPFL（`t54_epfl_tone.py`）：扫描与同场景数码 RAW（Panasonic G81）缩小后 ORB + RANSAC 单应配准（R1-00-1 内点 403/461；噪声卡 43/58；楔 15/20，弱；白场无特征，无法配准），两者平滑到约 100 µm，按 log10 RAW_c 分档取扫描码值中位 → 局部回归 dCode_c/dlogE。截断与暗噪声处不用。
- **亮度的通道相关项**：f = (σ_Y / σ_Y,独立)_真实 / (σ_Y / σ_Y,独立)_模型，σ_Y,独立 = √Σ w_c² σ_c²。每通道颗粒固定时，它就是通道间相关让亮度颗粒多出的倍数（颜色换算的交叉项、色度降噪都通过相关起作用）。
- 汇总脚本 `t54_summary.py` → `tools/eval/t54/summary.json`（每帧每档的各项与四分位）。

### 3.2 每层染料起伏在两种仪器下的倍数

- 在模型自己的中灰底片上（显影后的染料量 + 片基 + 遮罩的光谱透射率 T），仪器 j 对第 c 层单位染料量的局部导数 J_jc = Σ_λ S_j T E_c / Σ_λ S_j T。本层项之比（扫描仪 / Status M），EV −2 / 0 / +2 的范围：

| 片 | Status M 本层 J（模型染料单位，R / G / B） | Frontier / M | Noritsu / M | 单色通道在染料峰值的上限 |
|---|---|---|---|---|
| 800T（仓库染料谱） | 0.91 / 1.25 / 1.06 | 1.02–1.03 / 1.02 / 1.03 | 1.13–1.14 / 0.97 / 1.07–1.09 | 1.32（695 nm）/ 1.14 / 1.16 |
| 800T（Kodak 原始 5219 染料谱） | 0.77 / 0.87 / 0.87 | 1.02 / 1.01–1.02 / 1.02 | 1.12 / 0.94 / 1.05–1.06 | — |
| Portra 400 | 1.00 / 1.13 / 1.04 | 1.02–1.03 / 1.03–1.04 / 1.02 | 1.15–1.16 / 1.01–1.04 / 1.06 | 1.41 / 1.18 / 1.13 |
| Portra 160 / 800 / Ektar 100 / Pro 400H | 0.99–1.02 / 1.08–1.20 / 1.02–1.08 | 1.02–1.03 / 1.01–1.04 / 1.02–1.03 | 1.14–1.18 / 0.92–1.04 / 1.05–1.08 | — |

- 结论：
  - 建模的扫描仪通道看到的染料起伏与 Status M 相差 ≤ 4%（Frontier）或 ≤ 18%（Noritsu 的 R）。上限（假想的单色通道正好在染料峰值）亮度约 ×1.15–1.2，到不了 2.7。
  - 更重要的是，这一项**同时放大染料信号与染料颗粒**：扫描密度的反差与颗粒乘同一个倍数。冲印店按胶片档案把反差拉齐（`conversion.film_profile` 的 gain；真实冲印店同样按自己的档案 / 自动定光），所以在同码值的比较里它在 NEE 中抵消。只有冲印店不拉齐反差时才会以 ×1.0–1.2 留下。
  - 模型的 800T 胶片侧在 Status M 下与 Kodak 一致：中灰处（R / G / B 净密度 0.32 / 0.48 / 0.85）模型 σ48 × J_M = 9.3 / 12.1 / 18.6（×10⁻³），Kodak H-1-5219 同净密度约 8.9 / 9.6 / 20.5，比 1.05 / 1.26 / 0.91。模型的颗粒 σ 是按"染料量单位 = Status M 密度"定标的（T45 / T46），J_M 不是 1 的部分同时作用在模型的特性曲线上，NEE 不受影响。

### 3.3 Callier 系数（染料像）

- Callier Q = 定向光下的密度 / 漫射光下的密度；它来自乳剂对光的散射，没有散射时与照明的准直程度无关；文献对染料片的描述是定向与漫射两种图像的整体反差"大致相同"（[Callier effect](https://en.wikipedia.org/wiki/Callier_effect)）。染料云是分子吸收体，在折射率匹配的明胶里几乎不散射，所以 Q 接近 1。
- **没有找到给出染料负片 Q 数值的可引用一手来源**（Tuttle 1926、Streiffert 1947 "Callier Q of various motion picture emulsions" 未能取得）。即使取 Q = 1.1，按 3.2 节的同样理由（信号与颗粒同乘）在 NEE 里抵消，不能解释 2.7 倍。

|---|---|---|---|---|
| **t51_base** | 2.78 | 1 | 1.19 / 1.15 / 1.07 | 0.49 / 0.74 / 0.57 |

| 去掉输出饱和度矩阵（output_conditioning = None） | 2.75 | 0.99 | 1.01 / 1.05 / 1.03 | 0.17 / 0.51 / −0.05 |
| 两者 | 2.98 | 1.07 | 1.04 / 1.03 / 1.01 | 0.29 / 0.39 / 0.11 |
| Kodak 原始 5219 染料谱（t32_k5219 的修订） | 2.35 | 0.85 | 1.18 / 1.32 / 1.05 | 0.60 / 0.81 / 0.59 |

- EV −2 时同样在 0.89–1.07 之间。**模型的颜色换算怎么改，亮度颗粒都只变 ±15%。** 原因：亮度 = 三通道的加权和，交叉项把别层的颗粒加进来，也把别层的信号加进同一方向；蓝层（颗粒最粗）在亮度方差里占 32–38%（EV 0 / −2），没有哪种合理的换算能把它放大 2.7 倍而不同时破坏颜色。
- 在固定定光的均匀灰上，t51_base 的 R–B 相关是正的（0.29–0.68，EV −3 … +2），来自输出饱和度矩阵 R 行的 +0.274·B（去掉后 R–B ≈ 0）。T46 第 7.3 节的负相关是 R1-05-6 暗夜空（逐帧定光、强偏色）这一工作点上的，不是普遍的。
- 真实与模型的**通道相关项**（亮度，第 2.2 节）：EPFL 0.95–1.12（4 帧 × 4 档），RPL 1.02–1.17（5 种片 × 6–7 帧 × 4 档）。RPL 的 48 µm 通道相关真实为 0.8–0.95、模型 0.55–0.82（Noritsu 没有色度降噪，真实多出的相关是什么不在本任务定位），但它给亮度带来的也只有 ×1.04–1.11。

- **EPFL 的胶片侧 2.5 倍可能对应的已有物理量**（都没有独立证据，所以都没有修正）：
  1. **C-41 冲洗 ECN-2 乳剂（CineStill 的做法）的颗粒**。模型的 C-41 只改变显影程度与产量（T46：≤ +15%）；Kodak 只公布 ECN-2 的 RMS 颗粒度，CineStill 不公布。RPL 的 Portra（为 C-41 设计）在亮部胶片侧 ≈ 1，说明 C-41 本身与模型的颗粒链没有系统矛盾；剩下的是"ECN-2 乳剂在 C-41 里"这一组合，没有数据。
  2. **EPFL 底片的实际曝光比会话常数假设的更薄**（`rawio.SESSION_LOG_SCALE` 是按输出亮度在 11 帧上定的，冲印店的逐帧定光会掩盖胶片曝光的误差）。RPL 显示真实趾部比模型长、薄底片上真实 NEE 增长更快；若 EPFL 的块实际在 −2 … −3 档，"位置"一项可贡献 1.5–2 倍。反证：R1-00-1 的真实影调在码值 50–180 上斜率近乎恒定，不像深趾部。
  3. 两者兼有。
- **RPL 暗部的 1.3–2.2**：随输出码值而不随底片密度变化（5.3 节）。候选：暗部景物（深色印花裙、头发）的残余纹理；Noritsu 对暗部的处理；趾部 γ 的估计误差（翻拍 JPEG 在低密度处的非线性）。黑白 T51b 在同一场景同一码值上没有这一项，所以纹理是可能性较小的一个。

## 8. 是否修正

- 规则要求：修正必须是已有物理量的修正，证据独立于颗粒差距本身，且在留出帧 / 片上检验。逐项：
  - **扫描仪通道带宽**：建模通道与 Status M 只差 2–18%，且在 NEE 中抵消；没有冲印店扫描仪的通道光谱数据表。**不修正。**
  - **影调斜率**：真实比模型平或相同，修正方向会让颗粒更少；而且它是冲印店逐帧的操作（T35 已有 lab_contrast 研究代际）。**不修正。**
  - **颜色换算**：改变亮度颗粒 ≤ ±15%，真实与模型的通道相关项相同到 ±10%。**不修正。**
  - **胶片趾部**（RPL 翻拍的包围显示真实趾部更长）：它是特性曲线（spektrafilm 的数字化数据表曲线）的修正，证据独立于颗粒。但只有一个场景、相机 JPEG 翻拍、片基的 R 在相机肩部；且它解释的只是 RPL 薄底片帧里的一部分，对 EPFL 不适用（EPFL 的块不在趾部）。**不修正，列为下一步。**
  - **EPFL 胶片侧 2.5 倍**：唯一能"补上"的办法是放大 800T 的颗粒（或 C-41 的产量随机），这正是按输出拟合颗粒增益。**不做。**
- 所以**没有新代际**，库代码未改，现有代际逐位不变（未改 `filmlab/`）。按任务规则不出前后对照图。

## 9. 局限

- **EPFL 的胶片曝光不可直接测**：没有底片翻拍，块的曝光来自会话测光常数（对输出亮度拟合的常数，不是胶片相机的实测曝光）。胶片侧与底片位置两项在 EPFL 上因此不能完全分开（第 7 节第 2 条）。
- **翻拍的影调**：RPL 的翻拍是 Nikon D5300 的 sRGB JPEG，按 sRGB 解码当线性。dCode/dEV 的乘积里相机影调抵消，但"同底片密度"的定位用 u_c 换算，在趾部（D < 0.15）不可靠；Portra 160 / Ektar 的包围配准只有 3/6 对可用。
- **配准**：EPFL 楔（15 个内点）与白场（无特征）的影调斜率不可用；只有 R1-00-1 与噪声卡可信。
- **扫描仪通道**：Frontier / Noritsu 的真实通道光谱没有找到；只算了仓库的建模通道与理论上限。Status M 表是书中图的数字化（第三方）。
- **Callier**：没有染料负片 Q 的数值来源。
- 模型参照是均匀灰（单一光源、固定定光、512 × 512）；真实是各帧的均匀块。RPL 只有一个场景、一家冲印店；EPFL 只有一卷、一家冲印店。
- RPL 彩色是 4:2:0 JPEG：亮度不受影响，通道相关在 48 µm 上略受影响（第 4 节的通道相关项只作上限）。

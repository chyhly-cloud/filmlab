# T31：光晕的颜色——真实光晕里的"绿"从哪里来（Claude）

## 0. 摘要

- 任务前提是"真实片基光晕部分 G/R 0.37–0.46，模型 0.13–0.19"。**这个前提本身量不准**：
  - "800T − 对照"的颜色取决于估计量。60–150 µm 灯芯、150 µm 处，用逐灯 G/R 中位得 0.37；用通道中位相减只得 0.06。
  - 两组参考是不同场景、不同灯，对照组的灯偏青绿。相减时，800T 灯旁那部分"灯色光"（含蓝、含绿）的量与颜色都扣不准。
- 片基光晕本身不可能含蓝（黄滤光层 + 遮罩，公式与光子输运都给 B/G ≤ 0.003）。用蓝作示踪，先扣掉"灯色光"再看：
  - 真实 800T 的片基光晕 G/R ≈ 0.05–0.19，与物理和模型（0.06–0.16）同一量级；
  - 这个方法在模型上（有配对真值）验证过：R 的分摊误差 < 15%，G/R 误差 ±0.1–0.25。
- 真实灯旁看起来橙，主要是**红色片基光晕 + 量相当的灯色光**叠在一起：
  - 在 0–60 µm 灯、200 µm 处，真实"灯色光 : 片基光晕"的 R 之比约 3 : 1；模型（去掉 city_61360）约 1.7 : 1。
  - 模型的片基光晕相对灯色光偏强约 2 倍，与 T25/T30 的"光晕偏强 1.7–2.4 倍"一致。
  - EPFL 配对（同一场景）里，真实灯旁 100–400 µm 近中性（逐灯 G/R ≈ 1.0）；模型从 200 µm 起偏红（0.84 → 0.52）。
- 胶片光学内部没有找到绿的来源：
  - 遮罩按层结构放置：更红（×0.69）；
  - 返回斜光程：更红（45° ×0.69）；
  - 散射按重新分配而不是消光处理（光子输运）：不更绿（0.03–0.077 对公式 0.072）；
  - 灰雾扣除：最多 ×1.4；
  - 光源类型：光晕/灯芯 G/R 恒为 0.105–0.14。
- **扫描/印放阶段有一项真实差异**：真实冲扫把亮的饱和红（RAW G/R 0.07）印成 G/R 0.39，模型印成 0.14（EPFL，1589 像素，6 场景）。它不只作用于光晕，对普通红色物体同样存在。
  - 已有物理量（Kodak 原始青染料的绿区吸收）只能把光晕成片 G/R 提高 +0.02–0.04；
  - 其余来源（胶片肩部 / 扫描通道 / 冲印店处理）分不开，只报告，不加。
- 唯一"已有物理量放错"的一项：遮罩放置（绿光 1.5 次 → 按层结构 2 次）。实现为候选 `t31_mask`（默认关闭），方向是**更红**：
  - 光晕源 G/R 0.105 → 0.072（3200K）；
  - 成片光晕部分 G/R 0.11–0.16 → 0.05–0.07；
  - T19 几乎不变。
  - 它是物理上更对的放置，但不解决"看起来橙"。

## 1. 目标与方法

目标：查明真实 800T 灯旁的绿来自哪里，逐项定量；只有"已有物理量算错或放错"才实现为候选（默认关闭）。规则：不加经验调色，不动定光、灯亮度先验和核（FWD = 4）。

数据：
- 真实 800T 参考集 43 张；带 remjet 的 500T 对照集 25 张；
- 模型 8 个夜景，t30_base 及其带碳版：
  - `scratchpad/t30/cache` 的 t30_stops_f + FWD=4；
  - 已核对：与 t30_base 新渲逐位相同，n29240 最大差 0。
- EPFL 配对 8 夜景（R1-00-1…R1-07-8），同一 RAW、同一冲印店扫描。

测量：
- 第 1 步：`tools/eval/t31_lamps.py`，与 `t29_measure` 同一算法，逐灯保存，另记灯型（灯芯边缘 25–75 µm 环 B/G）。
- 第 2 步：`tools/eval/t31_epfl_render.py` + `t31_epfl_lamps.py`：
  - 传感器饱和灯芯为灯；
  - 背景取该灯 1.5–2.5 mm 环的中位；
  - 只取暗背景灯（真实背景 < 0.02），且真实扫描灯芯也截断（min 通道 ≥ 0.9）。
- 第 3、4 步：`tools/eval/t31_halo_source.py`（曝光空间，以中灰各层曝光为单位）、`t31_mc.py`（独立光子输运）。

### 2.2 估计量问题（任务前提的出处）

60–150 µm 灯、150 µm 处：

| | 逐灯 G/R 中位 | 中位比 | R 中位 |
|---|---|---|---|
| 真实 800T | 0.65 | 0.55 | 0.429 |
| 真实对照 | 1.12 | 1.38 | 0.159 |

- 任务前提的 0.37 = (0.43·0.65 − 0.16·1.12)/0.27，用的是"逐灯比值的中位 × R 中位"；
- 用同一口径（通道中位）相减，得 (0.429·0.55 − 0.159·1.38)/0.27 = **0.06**。

逐灯比值的中位与比值的中位之差，在这两组分布很偏的数据里可达 0.3。不同场景之间相减，颜色对估计量和对照的灯色构成都很敏感。在模型自己身上也能看到：灯芯 150–400 µm、去掉 city_61360 后，只是两组灯的构成略有不同，"光晕部分" G/R 就成了负数（第 6.2 节）。

### 2.3 蓝示踪：先扣掉灯色光

依据：
- 片基光晕不可能含蓝。下行要穿过黄滤光层（1.5 D）、遮罩（450 nm 0.78 D）和蓝感层，返回又要再穿一遍。
- 公式（第 4 节）与独立的光子输运（第 5.2 节）都给光晕源 B/G ≤ 0.003；
- 扫描把纯红印出的 B/R 约 0.06（第 5.5 节），量级小。

所以灯旁超出背景的蓝几乎全部来自"灯色光"：镜头、乳剂正面、扫描的散射，颜色同灯。

做法：
- 灯色取同一组灯 100 µm 处超出背景的颜色；
- 灯色光的 R = B ÷ (B/R)_灯；
- 剩下的就是片基光晕。

## 4. 第 3 步：遮罩的放置是否符合 Vision3 层结构

### 4.1 `base_density` 是什么

- 来源：spektrafilm 档案的 `base_density`，即 Kodak 5219 数据表的**最低密度光谱曲线**（漫射光谱密度，含片基、未反应的有色成色剂、灰雾、残留染色）。
  - 与 Kodak 原始数字化 `dye_density_min` 逐点相同（Status M 积分 0.166 / 0.553 / 0.829 两者一致）。
  - 不是 Status M 读数。
- 与 Kodak 特性曲线最低点（Status M D-min，R/G/B 0.19 / 0.585 / 0.84）相差 0.01–0.03。特性曲线起点 log H −2.38 处仍有少量曝光，差值合理。
- 遮罩 = `base_density − min`：
  - 最小值 0.083 在 780 nm；
  - 遮罩在 450 / 500 / 550 / 580 / 600 / 650 nm 为 0.78 / 0.64 / 0.44 / 0.44 / 0.22 / 0.07；
  - 换成 Status M：R 0.08、G 0.47、B 0.75。
- 片基平坦部分：
  - 640–780 nm 拟合 D-min = 0.069·青染料 + 0.064。透明片基约 0.064（含两个空气界面的菲涅耳损失），扣的 0.083 多了约 0.02；
  - 所以 550 nm 的遮罩若有偏差，是**偏小 0.02**（改正后更红）。
- 灰雾：D-min 里包含冲洗时才生成的灰雾染料，拍摄时并不存在。
  - 青色灰雾按红区形状约 0.07，在 550 nm 只贡献 0.003。
  - 品红灰雾无法从光谱分出。设 0.05 / 0.10，光晕源 G/R ×1.17 / ×1.38（物理放置下 0.072 → 0.084 / 0.099）。
- 550 nm 0.44（Status M G 0.47）对一张遮罩负片是正常的量级。没有发现算错。

### 4.2 放置

模型现在的放置（`emulsion_stack`）：
- 直接曝光：红层上方 mask/2；
- 到达片基：mask；
- 返回：绿层前 mask/2，蓝层前 mask；红层返回不计遮罩。

绿光共经过遮罩 1.5 次；红层下行有 mask/2、返回为 0，前后不对称。它不对应任何一种几何。

按层结构：
- 吸收绿（及蓝绿）的遮罩是青成色剂的有色成色剂，在红感层（Mc）；
- 黄色遮罩是品红成色剂的，在绿感层（Mm，只吸收蓝）。
- 返回光先整层穿过红感层才到绿感层：绿光经过 Mc 共 2 次；红层下行、返回各经过 Mc/2。
- 光谱分界取 480 nm（`film.MASK_SPLIT_NM`）。它只影响蓝区，蓝层光晕本来 ≈ 0。

### 5.3 c. 片基荧光

三醋酸纤维素片基只在紫外激发下有弱的蓝色荧光。镜头玻璃挡掉大部分紫外，灯的紫外份额也小，可忽略。只作记录。

### 5.4 d. 乳剂正面的反射

- 模型里没有乳剂正面反射这一项：
  - `film.py` / `engine.py` 中，光晕链只有片基背面反射（菲涅耳 + 全反射）、多次往返（乳剂/空气界面的全反射，`multi_bounce_kernel`）和可选的压片板反射。
  - 带 remjet 的渲染（`materials.emulsion("kodak_vision3_500t")`）只是 `halation = 0` → `self.halo = None`，关掉的是整条片基反射链（含多次往返），**没有别的正面反射项可关**。
- 物理上，空气/明胶界面的法向反射约 4.4%（n = 1.53）。这部分光**离开胶片射向镜头**，只有经镜头后组再反射回来（多层镀膜 0.3–0.5%/面，未镀膜约 4%）才会再曝光：
  - 约为灯光的 2×10⁻⁴–2×10⁻³，散成毫米级的鬼影/眩光，颜色同灯；
  - 量级远小于片基光晕（红光到达片基的约 30% × 散射 0.6 × 全反射份额约 0.5 ≈ 10%，集中在 0.5 mm 内）。
- 它在两种胶片里都有，所以不在"800T − 对照"里。
- 数码相机的传感器叠层（微透镜 + 保护玻璃）反射比乳剂更强，同一机制已经以更大的量包含在 RAW 里（T27：RAW 的正面中性光是真实对照的 1.0–1.4 倍）。模型不缺这一项，若有偏差，也是偏多。

## 7. 局限

- 真实 800T 与对照是不同场景、不同灯、不同镜头与冲印店。"800T − 对照"的颜色对估计量（逐灯比值中位与通道中位）和灯色构成都敏感，60–150 µm 档相差 0.06 对 0.37。本文不再把它当作片基光晕颜色的测量。
- 蓝示踪假设灯色光的颜色等于 100 µm 处的颜色。那里接近截断、本身含少量光晕，在模型上验证的 G/R 误差为 ±0.1–0.25，只能说"同一量级"，不能给出 0.1 与 0.2 的区别。
- EPFL 只有一家冲印店、一批校园 LED 灯，可用的灯集中在 2 个场景。"真实 − 模型带碳"依赖模型带碳版的灯色光正确，而它在 3 个场景里比真实还亮。
- 5.5 节"红层 +3 档以上 ×3–4"只来自一个场景（R1-03-4 的红灯箱）；按输入分档的 1–3 档有 6 个场景。
- 光子输运用的层厚（6 µm）、g 与散射强度都是假设值，只用来判断方向（散射按输运处理是否会更绿），不是定标。
- 品红灰雾无法从 D-min 光谱中分出，0.05–0.10 只是敏感度。
- 遮罩的 480 nm 分界是近似，只影响蓝层（≈ 0）。

## 负责人结论（Fable 审核）

- 我给的前提"真实片基光晕 G/R 0.37–0.46"是估计方法造成的，撤回。用蓝通道作示踪（片基光晕不含蓝）得到的真实片基光晕 G/R 0.05–0.19，与模型 0.06–0.16 一致：**片基光晕的颜色物理是对的。**
- 真实 800T 灯旁看起来偏橙，来自三件事：(1) 灯色扩散光与红晕的比例——真实 3.1:1 / 1.2:1，模型 1.7:1 / 0.56:1，即红晕相对偏强约 2 倍（与 T25/T30 一致）；(2) 参考集以白光灯为主；(3) **真实冲扫把饱和的亮红印成橙**（RAW G/R 0.07 的红色物体，真实扫描 0.39，模型 0.14），这一项模型没有，影响所有亮红物体，不只是光晕。
- 遮罩按层结构放置是对已有物理量的纠正（原放置不对应任何真实层序），采纳为基准 `t31_base`（光晕 G/R ×0.7，强度 ×0.85；目视变化很小）。
- 下一步：(a) 在 EPFL 配对数据上查"饱和红印成橙"发生在胶片肩部、扫描还是冲印店处理；(b) 把无自由参数的斜光程/分层项（T03/T11）纳入后重新定 m，并核对红晕相对灯色扩散的 2 倍偏强。

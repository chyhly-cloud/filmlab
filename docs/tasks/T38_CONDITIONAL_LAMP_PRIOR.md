# T38：截断灯亮度改为按观测量条件化的实测分布（Claude；研究代际）

## 0. 摘要

- **问题**（T37 负责人结论）：T37 的实测分布按"类 × 尺寸档"无条件抽样，裸灯与刚过裁切的亮面混在一起。裁切对照里两盏相同的招牌灯，一盏 flux 2 档、一盏 6 档。
- **做法**：把 24 张 HDRI 渲染成"假想 RAW"：
  - 透视投影，1600×1067 像素（22.5 µm），35 / 50 mm；
  - 三通道各自截断，截断子样本比例就是 clip_frac；
  - 锚与 T37 相同（帧内 P90 × 2^3.71）。
  
  然后用与 rawio 完全相同的块划分、分类，以及新的 `rawio._block_obs`，逐块算 RAW 里也能算的观测量，并记录真实 flux。共 42655 块。
- **相关**（Spearman，与 flux；灯具 0–60 / 60–150 / ≥150 µm）：

  | 观测量 | 全部 | 灯具 0–60 | 60–150 | ≥150 | 结论 |
  |---|---|---|---|---|---|
  | **bg**（块外环带背景 / base） | **−0.45** | −0.50 | −0.31 | −0.05 | 24 张 HDRI 内全部为负；8k / 16k 相同；RAW 与 HDRI 分布一致 → **选用** |
  | skirt（紧贴块外 1–2 像素） | −0.42 | −0.60 | −0.34 | **+0.15** | 留出集上更强，但随 HDRI 相机眩光变号：2 张 HDRI 内为正，≥150 µm 为正 → 不用 |
  | slope（1–3 倍半径衰减） | +0.12 | +0.02 | +0.18 | +0.30 | 弱 |
  | fmean（块内 clip_frac 均值） | +0.27 | +0.03 | +0.33 | +0.43 | 我们的 RAW 在 step = 1 时恒为 1，不稳健 |
  | compact（紧凑度） | +0.11 | +0.15 | +0.40 | +0.39 | 弱 |
  | nsat3（三通道都截断的比例） | +0.70 | +0.66 | +0.75 | +0.68 | 最强，但依赖假想传感器的通道截断（Rec.709 而非相机原始通道），RAW 中不可用 → 只作参考 |
  | 边缘颜色 log2(R/G) / log2(B/G) | −0.06 / +0.06 | | | | 无 |

- **条件表**：bg 按全部块的分位分 5 档，再乘以 类 × 尺寸档，每格 21 分位，每格 ≥ 60 块（不足并入相邻档）。灯具 0–60 µm 的 flux 中位从最暗背景到最亮背景依次为 0.98 / 0.64 / 0.50 / 0.35 / 0.15 档。
- **留出集**：训练 20 张，留出 street_lamp、hansaplatz、shanghai_bund、zwinger_night，共 10703 块。
  - 预测中位与实测的 ρ：0.38 → **0.48**；PIT 的 KS：0.069 → **0.035**；中位绝对误差：0.38 → 0.38 档。
  - 每张留出 HDRI 的 ρ 都升高。
- **但"相同的灯得到相同亮度"没有解决**：
  - 招牌那对灯的观测量几乎相同（bg −6.53 / −6.43），t38 抽到 1.92 / 5.17 档；
  - 河边桥上灯排的 flux 标准差 1.43 → 1.27 档。
  
  HDRI 本身给出原因：
  - 同一假想照片里"看起来相同"的灯（尺寸、bg、skirt、边缘颜色都相近）|Δflux| 中位只有 **0.23** 档（90% 1.00）；
  - 模型对同样的配对各自独立抽样，得到 **0.56** 档（90% 2.93）；
  - 条件化后的剩余分散在同一照片的同类灯之间是**相关**的（帧内 ICC 0.23–0.40），而"每块独立一个随机数"的规定把它当成了独立。
- **评估**（t31_base / t37_base / t38_base）：
  - EPFL 红带 0.252 / 0.252 / **0.203**，灯旁 15.52 / 14.83 / **14.81**，全图 10.64 / 10.60 / 10.59；
  - 光晕部分强度 RMS 0.135 / 0.081 / 0.090，形状 RMS 0.080 / 0.123 / **0.069**；
  - T19 RMS(Δr)：0–60 µm 0.053 / 0.077 / 0.070，60–150 µm 0.091 / 0.083 / 0.118，150–400 µm 0.051 / 0.064 / **0.047**。
  
  t38 与 t37 的差别与"每块随机数不同"引起的抽样噪声同一量级（第 5 节）。
- **建议**：**t38_base 暂不作基准**，保留为研究代际。
  - 条件化本身成立：bg 是稳健的预测量，留出集上校准更好。
  - 但它没有达到本任务的目标（相同的灯相同亮度）。
  - 下一步应在同一张图内对"看起来相同"的块共享随机数，相关程度用上面测得的帧内相关定量（第 7 节）。

## 1. 目标

T37 用实测的 flux 分布替换了 U[6,8]，但每块只按 类 × 尺寸档 抽样。本任务在 HDRI 假想照片里逐块记录 RAW 中也能用同一代码算出的观测量，检验它们能否预测 flux，再按条件分布抽样。目标：相同的灯得到相同的亮度，裸灯回到高 flux，亮面回到 1 档以内。

规则同 T37：只改这一个物理量的估计；不调核、不动定光；现有代际逐位不变；第三方照片只存 URL 与测量。

## 2. 数据与观测量

### 2.1 HDRI 假想 RAW（`tools/eval/t38_hdri_obs.py`；`tools/eval/t37_hdr2y.c` 增加 rgb 输出模式）

- 同 T37 的 24 张 Poly Haven 8k .hdr。逐张下载 → 解码 RGB（400 MB）→ 删除 .hdr → 测量 → 删除 RGB。
  - 另用 street_lamp、hansaplatz 的 16k 做分辨率对照。
  - 全部 HDRI 已删除。
- 每张 HDRI 32 帧：35 / 50 mm × 偏航 8 × 俯仰 0 / +20°。
  - 成像 1600×1067 像素，与 t19_model 相同的 22.5 µm/像素。
  - 每像素 3×3 子样本，最近邻取 HDRI 像素。
- **传感器截断**：线性 Rec.709 三通道各自在 S 处截断；子样本任一通道 > S 即为截断。
  - clip_frac = 截断子样本比例；
  - 观测图 = 截断后的子样本平均，即 RAW 看到的值。
- **截断电平 S**：先取 S0 = 帧内 P90 × 2^3.71，再按本帧灯具块 base 中位修正一次，使灯具块 base 中位 = P90 × 2^3.71。这与 T37 锚在我们 RAW 上的定义（灯具块 base 中位）一致。
- **块与真实 flux**：与 rawio 同一划分（clip_frac > 0.25 膨胀一圈连通）、同一分类、同一 base（块内观测 Y 的第 90 百分位）。
  - flux = log2(Σ f·L / (Σ f·base))，L 为像素内截断子样本的真实 Y 平均。
  - 带颜色的块（只一个通道截断）的截断子样本 Y 可以低于 base，所以 flux 可略小于 0；rawio 中按 0 处理。
- **与 T37 的差别**：T37 在等距柱状图上按 Y > C 判截断。这里按通道截断、在成像分辨率下划块，更接近 RAW，但块的总体不同。
  - 无条件灯具中位：T37 0.44 / 1.30 / 2.29 档，本任务 0.41 / 0.78 / 1.72 档。
  - t38 的无条件回退表（`flux_all`）用本任务的总体。

### 2.2 观测量（`filmlab/rawio.py: _block_obs`；HDRI 与 rawio 调用同一函数）

只用 RAW 里也有的量：截断后的亮度 Y、clip_frac、块标记。

- **bg**：块外环带（距膨胀块边 max(r,2) 到 max(3r,4) 像素，不含任何截断块）的 Y 中位 / base，单位为档。r 是截断面积的等效半径（像素）。
- **skirt**：紧贴块外 1–2 像素（不含截断块）的 Y 均值 / base，单位为档。
- **slope**：距块边 [1, 1+R] 与 (1+R, 1+2R] 两环的 Y 中位之比，单位为档，R = max(r, 1)。
- **fmean**：块内 clip_frac > 0 像素的 clip_frac 均值。
- **compact**：截断核面积 / 外接圆面积。
- 只在 HDRI 中有、作参考：nsat3（三通道都截断的截断子样本比例）、块外 1–3 像素的边缘颜色。

## 4. 实现

- `rawio._block_obs(Y, lab, k, sl, clip_frac, base)`：六个观测量，在 HDRI 与 rawio 中是同一函数。
- `HIGHLIGHT_RECON = "measured_cond"`：
  - 与 "measured" 相同：同一随机数 u、同一分类与尺寸档、同一反解、同一穹顶 0.7；
  - 只把 flux 换成 `_cond_flux(cls, r_um, obs, u)`；bg 缺失（环带内全是截断块）时用 `flux_all`。
- 条件表存为 `filmlab/data/lamp_flux_cond.json`（由 `t38_summary.py` 生成），在 rawio 导入时读取。
- 诊断：STOPS_LOG 每块增加块中心 cy / cx（所有模式，不影响输出）；measured_cond 模式下再记录 obs。
- 代际 `t38_base` = t31_base + measured_cond，其余同 t31_base。
- 测试：
  - 新增 `tests/test_t38_cond.py`（7 项）：表形状与单调、bg 观测量（暗 / 亮背景）、每块 flux 等于条件分位、与 measured 同一随机数与分类、条件改变分布 / 缺失回退、其他模式不受影响、代际；
  - `tests/test_t31_mask.py` 加入 t38_base。
  
  全部 **427 项通过**。
- 逐位核对：
  - 改动前（T37 提交 1d619a0，git stash）与改动后，current、next、next_lab_halo_meas、t22_bxyz、t28_skirt、t30_stops、t31_base、t36_base、t37_base 在 n29240、city_61360 上的 load_raw 输出 18 组哈希相同；
  - t37_base 的 n29240 成片与 T37 缓存最大差 0。

## 5. 评估（8 夜景，STOPS = 0，cos^4；t38_base 带碳对照重新渲染；t31 / t37 复用 T37 缓存）

**t38 与 t37 用的是同一个 u，只是表不同。每块 flux 仍是随机的，所以下面的差别包含抽样噪声，没有做多种子重复。**

## 6. 意外

1. 相关最强的观测量（nsat3 / base_rel，ρ 0.6–0.75）恰恰在 RAW 里不可用：判定后只保留"任一通道截断"，而且假想传感器的通道截断与真实相机原始通道不同。
2. skirt 对小块是强的负预测量（亮面的周围连续），对大块和有眩光的场景变成正的（亮灯的眩光 / 雾气光晕抬高裙边）。它的符号取决于拍摄相机的眩光，所以不能从 HDRI 搬到用户 RAW。
3. 暗背景并不等于高 flux。HDRI 里最暗背景档的小块中位只有约 1 档：夜景中暗背景前的截断块大多是远处的小灯或窗，像素平均后只刚过裁切。
4. 条件化后，"看起来相同"的灯在真实场景里差 0.23 档，模型独立抽样差 0.56 档。问题不在条件表，而在"每块独立随机"。
5. EPFL 红带 0.252 → 0.203 是本任务最大的单项变化，但 t37 → t38 只改变了每块的分位映射。在 EPFL 少量灯的场景里，这一改善与抽样噪声分不开，没有多种子估计。

## 7. 局限与下一步

- **假想 RAW**：
  - 通道截断用 Rec.709，不是相机原始通道；
  - 子样本取最近邻 HDRI 像素，8k 像素 26.8 µm（35 mm）比成像像素 22.5 µm 略粗；
  - 没有噪声、去马赛克和降噪。观测量 bg 用的是中位，对这些不敏感，skirt 敏感。
- 锚、HDRI 场景构成的局限同 T37。大面积 158 块，条件表基本不起作用。
- **下一步（建议 T39）**：保持条件表不变，把"每块一个独立随机数"改为同一张图内对观测量相近的块共享随机数。
  - 共享程度直接用本任务测得的量：相近配对 |Δflux| 0.23 档、帧内 ICC 0.23–0.40。
  - 例如按（尺寸档、bg 档、边缘颜色）在一张图内分组，组内 u 相同或按测得 ICC 相关。
  - 这仍是"同一物理量的测得统计"，没有新自由参数，并直接针对"两盏相同的招牌灯一弱一强"。
  - 若在 rawio 中保留逐通道饱和信息，再评估 nsat3 / base_rel。

## 负责人结论（Fable 审核）

审核范围：观测量相关表、留出集检验、`rawio._block_obs` 与 "measured_cond" 分支、427 项测试（通过）、逐位核对、`$SP/t38/full` 8 张整图与灯区裁切。

1. **按块外背景条件化成立但不够。** 留出集上预测相关 0.38 → 0.48，PIT 的 KS 0.069 → 0.035，亮面回到 1 档以内；但最暗背景档里裸灯仍只有 1.0 / 1.25 / 1.7 档中位，≥5 档的块只占 0.1 / 2 / 10%。招牌那对相同的灯仍是 1.92 对 5.17 档。t38_base 不作基准，基准仍为 t31_base。
2. **最强的观测量被放弃的理由不成立。** 三通道是否都饱和（nsat3）与 flux 的相关 0.66–0.75，是所有观测量里最强、且在三个尺寸档都稳定的。报告说 RAW 里算不出来，但 `rawio.sensor_saturation(per_channel=True)` 已经按传感元逐通道判定饱和（sat3），只是没有传进 stops 重建那一路。这是代码路径问题，不是物理限制。裸灯三通道全饱和、刚过裁切的亮面常只有一两个通道饱和，这正是区分二者的物理信息。
3. **"相同的灯一弱一强"的根因是条件分布太宽，不是随机数独立。** 同一照片里相近配对 |Δflux| 实测 0.23 档，模型独立抽样 0.56 档；条件分布窄下来，这个差自然缩小。帧内相关抽样（ICC 0.23–0.40）可以作为之后的补充，但先把信息用足。
4. **评估的灯选择已核对**：真实扫描与模型成片用同一规则在输出域选灯芯（三通道 ≥0.93），不存在"真实灯更亮"的选择偏差。
5. **T39**：把逐通道饱和带进 stops 重建，条件表改为 背景 × nsat3（× 类 × 尺寸档），同样留出 4 张检验；再看相同灯的一致性与评估表。EPFL 红带 0.252 → 0.203 这类差别要用多种子重复才能和抽样噪声分开，T39 一并做。

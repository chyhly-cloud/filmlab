# 任务 T03：光晕核的斜程衰减（执行：Codex；规格与验收：Claude）

## 背景

红带诊断（`docs/RED_BAND_DIAGNOSIS.md`）：真实扫描的红带位于离灯芯约 150–400 µm（与片基全反射几何一致），约 400–500 µm 外即消失；
现行光晕核把 42% 的能量放在 400 µm 以外，模拟红晕延伸到 1 mm 以上。原因是 `film.halation_kernel` 对所有入射角使用同一个（垂直方向的）
乳剂透射率，遗漏了斜射光在乳剂中更长的路程。诊断中的近似补丁使 4 个场景中 3 个的红带形状更接近真实。

本任务把这一物理遗漏正式实现为**可选修正**。**没有任何自由参数，不做拟合**。

## 物理定义（必须按此实现）

对每个感光层 c，到达片基的垂直方向乳剂密度：

    D_c = −log10( Σ_λ T_down(λ)·S_c(λ) / Σ_λ S_c(λ) )

`T_down` 来自 `film.emulsion_stack`，`S_c = 10^log_sensitivity`（与 `film.bounce_retention` 的加权方式相同）。

散射发生在乳剂各深度且均匀分布时，斜射光相对垂直方向的额外透射按深度平均为：

    u = 1/cosθ − 1
    A_c(θ) = (1 − 10^(−D_c·u)) / (D_c·u·ln10)        （u → 0 时 A_c → 1）

光晕核的角度权重由 `Fresnel(θ)·sinθ·cos^m θ` 变为 `Fresnel(θ)·sinθ·cos^m θ·A_c(θ)`：
- 角分布的归一化保持现状（先对 `sinθ·cos^m θ` 归一），乘 `A_c` 之后**不再重新归一**，被吸收的能量就是损失；
- 垂直方向的衰减已在 `halation_response` 中，`A_c` 只计额外的斜程部分，不得重复计算。

由此光晕核变为**逐层**（R、G、B 三个核）。多次反射外环（`multi_bounce_kernel`）的每一环使用同一个 `A_c(θ)`。

## 实现要求

1. 新增修正标志 `"halo_oblique"`（加入 `Params.corrections` 的说明注释），以及可选代际 `next_oblique` = next + `"halo_oblique"`。
2. 画面光晕（`film.halation`）与定光中灰的光晕总量（`engine._halo_total_multi`、`_halo_total`，用于 `gray_halo` 一致性）
   必须使用同一套逐层核。3200K 灰卡在物理参考中仍须印成中性。
3. 当 `D_c = 0` 或标志未开启时，核必须与现行实现逐位一致。
4. `current`、`next`、`legacy` 及所有现有配方的输出逐位不变。
5. 不得引入任何倍数、缩放系数或可调参数；不得改动 `diffuse_fraction`、`forward`、片基厚度、`HALATION_MEASURED` 等现有值。

## 测试（随实现提交）

- `D_c = 0` 时与现行核逐位相同；
- 逐层核的能量随 `D_c` 单调下降；红层核在 700 µm 以外的能量占比低于 5%（现行约 14%）；
- 开启修正后，3200K 灰卡在物理参考中的彩度 < 0.5；
- 默认代际未受影响（合成输入逐位回归）。

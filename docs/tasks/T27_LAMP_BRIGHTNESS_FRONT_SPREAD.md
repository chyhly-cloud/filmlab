# T27：截断灯芯的亮度与灯外中性光——两个靠前问题的分级诊断（Claude）

## 0. 目标

T26 负责人结论列出两个不在光晕核里的问题，本任务只诊断、分阶段定量，不改基准（代际 t22_bxyz、STOPS=0、HALO_FORWARD=None 均未动）。

- **A**：光晕强度随灯芯大小的偏差方向相反（60–150 µm 偏强约 1.7 倍，0–60 µm 偏弱 4.5–5.5 倍）。假设：截断灯芯亮度先验与尺寸无关，裸露发光体的小灯被低估。
- **B**：模型带 remjet（无片基光晕）时，灯外 100–300 µm 的中性光是真实带碳对照的 2–3 倍。中性光在哪一级产生？

## 1. 截断高光现在怎样赋亮度（`rawio.reconstruct_highlights`，t22_bxyz 用 `HIGHLIGHT_RECON="prior"`、`CLIP_DETECT="channel_max"`、`RECON_COLOUR="ring"`、`APERTURE_RANGE=None`）

1. 截断判定：相机原始 RGB 里任一通道 ≥ 该通道全图最大值的 97%；下采样到 1600 像素后得到每像素的截断子像素比例 `clip_frac`。
2. 截断块：`dilate(clip_frac > 0.25)` 的连通块，逐块处理。
3. 颜色：块外 pad 环内最亮 30% 像素的中位颜色，按亮度归一。
4. 亮度：**每块独立随机，与面积无关**（只按面积占比和形状分三类）：
   - 灯具（面积 < 画面 0.5%）：L 在 2e3–3e4 cd/m² 内对数均匀取值，档数 = clip(log2(L / L_clip), 0.05, 8)；
   - 大面积（天空、亮窗）：1e3–1e4 cd/m²；
   - 细线（宽 ≤ 2 px、长宽比 ≥ 4）：`LINE_PRIOR` 1e2–2e3 cd/m²；
   - 没有 EXIF 光圈（L_clip = None，t22_bxyz 不用 APERTURE_RANGE）：档数直接在 2–5（细线 0.5–2.5）内均匀取值。
   - L_clip = 120·N²/(t·S)（EXIF）。**档数随场景的 L_clip 变化很大**，与灯本身无关；上限 MAX_STOPS = 8。
5. 形状：穹顶 lum = base·2^(stops·(d/d_max)^0.7)，base = 块内 Y 的 90 百分位（≈ 截断电平），边缘连续；只替换像素中被截断的那部分 f = clip_frac。块外像素不改动。

8 个场景的先验档数（"灯具"类）与实际重建出的块光通量（块内 Σ重建 / Σ截断电平，穹顶使平均低于 2^stops）：

| 场景 | L_clip cd/m² | 先验档数 | 重建/截断（块半径 ≤3 / 3–7 px） |
|---|---|---|---|
| n29240 | 19.2 | 6.7–10.6 → 多数取上限 8 | +6.0 / +5.5 档 |
| n40825 | 48 | 5.4–9.3 | +6.0 / +4.1 |
| n40481 | 14.1 | 7.1–11 → 多数取 8 | 无暗背景块 |
| city_40095 | 3.24 | 9.3–13.2 → 全部取 8 | +6.1 / +5.8 |
| city_61360 | 1200 | 0.7–4.6 | +1.5 / +1.2 |
| n27416 / n20595 / n33920 | 无光圈 | 2–5（均匀） | +1.5 / +1.4；+2.0 / +1.1；— |

即：8 个场景按 EXIF 分成两组，"长曝光组"（n29240、n40825、n40481、city_40095）的灯被重建到截断电平的约 2^6 倍，"低先验组"（city_61360、n27416、n20595、n33920）只有约 2^1.5 倍。

## 2. RAW 裙边（`tools/eval/t27_raw_skirt.py`）

- 小核的裙边**更低、更陡**，不是更高、更缓。在每个有足够样本的场景里都如此。
- 近场上限：一个只占 1–2 个半尺寸像素的截断核，紧邻像素只有截断电平的 0.16–0.35。若它是未分辨的点光源，紧邻像素至少得到峰值像素的约 2–5%（f/8–f/10 的衍射加像素孔径，这是假设），所以峰值像素若不截断最多是截断电平的约 3–17 倍，总光通量最多比"截断电平 × 截断面积"高约 1–5 档。**"比先验高两个数量级"在这几个场景的小核上被排除**；长曝光组（第 1 节）小块被重建到约 +6 档，已在这个上限之上。

## 3. 重建光通量与裙边是否一致（`t27_stage_trace.py flux`，流水线 1600 像素尺度）

同一镜头的远处裙边 ≈ 真实光通量 × PSF 尾 T(ρ)。在块中心外 ρ = 6–12 px（约 135–270 µm）取环中位：

- **场景内、不同大小的块**：裙边 / 重建光通量（"隐含 T"）在 ≤1.5、1.5–3、3–5 px 三档之间相差不到 2–3 倍，且没有"小块偏高"的一致趋势（city_40095：5.0e-5 / 2.0e-5 / 4.0e-5；n29240：2.0e-5 / 2.3e-5 / 3.6e-5；city_61360：1.0e-3 / 3.4e-4 / 4.5e-4，只有这个场景最小档偏高约 2–3 倍，即最小的块相对低估约 1–1.5 档）。**裙边不支持"小核光源相对亮两个数量级"。**
- **不同场景**：裙边 / 截断电平下光通量在所有场景都是同一量级（ρ=6 处 6e-4–3.5e-3），而先验给的重建 / 截断在两组场景间差约 4.5 档（+1.2…+2 对 +4…+6）。
- 用未截断的紧凑亮点直接测 T(ρ)（只有 city_61360 的 34 个和 city_40095 的 6 个可用，几何平均 T(6) ≈ 6.6e-4）推算真实光通量 / 截断光通量：

| 场景 | 重建/截断 | 裙边推算/截断（块 ≤3 / 3–7 px） |
|---|---|---|
| city_40095 | +6.1 / +5.8 | +1.5 / +1.2 |
| n29240 | +6.0 / +5.5 | +1.7 / +1.2 |
| n40825 | +6.0 / +4.1 | +1.8 / +0.3 |
| city_61360 | +1.5 / +1.2 | +1.1 / +0.7 |
| n27416 | +1.5 / +1.4 | +3.0 / +1.4 |
| n20595 | +2.0 / +1.1 | +2.0 / +0.4 |

- 按这个 T，低先验组与裙边一致（差 ≤ 1.5 档），长曝光组被**高估约 4–4.5 档**。
- **但 T 的绝对值不可靠**：参考亮点少，且多半不是理想点源（会把 T 估高、把推算光通量估低）；按教科书式的镜头眩光尾（约 2% 光通量按 r⁻² 分布到 5 mm，ρ=8 处约 7e-6/像素）则 T 要低约 40 倍（5.4 档），结论反过来变成"长曝光组大致对、低先验组低估约 5 档"。
- 不依赖 T 绝对值的结论只有两条：(1) 同一场景内裙边与块大小的关系和"亮度与尺寸无关"的先验一致；(2) 两组场景的"重建/截断"差约 4–4.5 档，而用同一个 T 推算的"裙边/截断"两组重叠（长曝光组 +0.3…+1.8，低先验组 +0.4…+3.0），没有系统差别；若各镜头的 PSF 尾在 3 倍以内相同，则先验在场景之间的差别（来自 EXIF 的 L_clip、MAX_STOPS 截顶、缺光圈时的 2–5 档）不被 RAW 支持。

## 5. 候选修正（未实现）及其影响估计

裙边**不支持**"小核光源更亮"，按任务规则不实现开关。可以考虑的方向是"按裙边推算每块的光通量，替代 EXIF 绝对亮度先验"：

- 做法：每块 F = 裙边(ρ) / T(ρ)，ρ = 6–12 px；在块内仍用穹顶分布，总量取 F。
- 依赖的假设：镜头 PSF 尾 T(ρ) 已知且在画面内一致。8 个场景里只有 2 个能从未截断亮点测 T，而测得值与典型眩光尾差约 40 倍，**绝对亮度因此不确定约 5 档**；只有场景之间的相对关系（第 3 节）比较可靠。证据不足以定标，不建议现在实现。

## 6. 问题 B：带 remjet 时灯外中性光在哪一级产生（`tools/eval/t27_stage_trace.py`）

### 6.1 方法

同一 RAW、同一流程（与 t19_model.py 缓存逐像素相同），带 remjet 渲染（Vision3 500T，无光晕核）。各级都换成**红层等效曝光**（同一逐点曝光映射 `Engine._expose_mixed`），以"白阈值曝光"（成片 R 达到 0.93 时的红层总曝光，每场景由像素关系求得）为单位，按成片灯芯（同 t24）测超出背景的剖面：

- raw：不降噪、不重建的 RAW 线性；pre：降噪后、重建前；direct：重建后（= 测光后的输入）的直接曝光；scattered：乳剂散射后；total：加光晕后（带碳时 = scattered）；成片→曝光：成片 R 经同一曲线换回曝光。

### 6.3 逐项

- **RAW 本身（数码镜头/传感器眩光）**：中性光在 raw 级就已完整存在，150 / 300 µm 处为白阈值的 0.16 / 0.08。后面各级与它相差 ≤ 0.01。**来源是输入。**
- **降噪**：pre 与 raw 相同（±0.01）。
- **截断高光重建**：direct 与 pre 相同（±0.007）。重建只改写有截断子像素的像素，不把亮度摊到边界外。
- **乳剂散射**：σ = 4 µm 在 22.5 µm/像素时为 0.18 像素，`film.emulsion_scatter` 在 < 0.3 像素时直接跳过；scattered 与 direct 逐像素相同。
- **扫描**：扫描（`scanning/optics.measure`、`conversion`、数字相纸）全部逐点，没有模糊、锐化或眩光项；成片换回曝光与 total 一致（差 ≤ 0.015）。显影里的 DIR 抑制剂扩散（12 µm × (1+2·acutance)）是边缘效应，只会压暗灯旁，不产生中性光。
- **与真实对照比**：按模型自己的成片曲线把真实对照的成片 R 换回曝光，模型 RAW 的中性光在 150–300 µm 处是真实的 **1.0–1.4 倍**（60–150 档 150 µm：0.154 对 0.121；300 µm：0.085 对 0.071；0–60 档 150 µm：0.179 对 0.178，300 µm：0.110 对 0.080），即最多多约 0.5 档。成片里放大到 1.3–3 倍，是因为白阈值以下 2–3 档处胶片+扫描的局部斜率很陡（成片 R 对曝光的对数斜率约 2.5）。

### 6.4 结论（B）

模型带 remjet 时灯外的中性光**全部来自输入 RAW**（数码相机的镜头/传感器眩光，以及灯周围的真实景物），降噪、截断重建、乳剂散射、扫描都没有加入可测的中性光。曝光量上它只比真实对照多约 1.0–1.4 倍，成片上的 2–3 倍主要由白阈值附近陡的影调响应放大。"超出对照的部分"有两种可能，本数据分不开：(a) 数码镜头与传感器（盖玻璃、滤光片反射）的眩光确实比胶片相机镜头大；(b) 模型胶片+扫描在白阈值以下 1–3 档的影调与真实对照的冲扫不同（对照是不同冲洗店、不同扫描）。

## 7. 总结论

1. **A 的"方向相反"主要是统计口径造成的。** 模型 0–60 µm 的 2591 盏灯里 1924 盏来自 city_61360（Reno 拱门的跑马灯泡，先验只给 0.7–4.6 档，RAW 裙边也很小）。按图计或去掉这一个场景后，两档的偏差方向相同：
   - 按图计：两档都只偏强 1.0–1.2 倍；
   - 按灯计、去掉 city_61360：100–300 µm 处 0–60 µm 偏强 1.25–1.65 倍，60–150 µm 偏强 1.3–3.3 倍。
2. **RAW 裙边不支持"小核光源更亮"。** 小核裙边更低、更陡；同一场景内裙边/重建光通量与核大小无关；近场上限排除了小核"高两个数量级"。
3. RAW 裙边指出的是**场景之间**的问题：先验按 EXIF 截断亮度换算，使长曝光组被重建到截断电平的约 2^6 倍，其余组约 2^1.5 倍；而按同一 PSF 尾推算的裙边/截断在两组间没有系统差别。哪一组偏、偏多少，取决于镜头 PSF 尾的绝对值，现有数据定不到 ±3 档以内。
4. 仍然存在的尺寸相关差异：真实光晕部分几乎不随灯芯大小变；模型（去掉 city_61360）< 40 µm 与真实一致，≥ 40 µm 偏强 1.6–3.3 倍。RAW 证据不支持把它归因于亮度先验随尺寸的错误，也可能是灯的构成不同。
5. **B：灯外中性光在输入 RAW 里就有**，后面各级没有加入；曝光上比真实对照多 1.0–1.4 倍，成片上被影调放大到 2–3 倍。
6. 没有实现开关；代码与现有代际输出未改动。

## 8. 局限

- 模型只有 8 个场景，且一个场景占了小灯的四分之三；按图计时模型只有 7–8 个点，真实 22–32 个。真实 800T 与对照是不同场景、不同灯的总体。
- PSF 尾 T(ρ) 的绝对值只来自 2 个场景的 40 个未截断亮点，且多半不是理想点源；第 3、5 节的"推算光通量"只有方向意义。
- 近场上限依赖"紧邻像素至少得到峰值的 2–5%"这一假设（衍射 + 像素孔径），未对每台相机实测。
- 第 6 节把真实对照换算成曝光时用的是模型自己的成片曲线；若真实冲扫的影调不同，"1.0–1.4 倍"会变。
- 截断判定在渲染中用 channel_max（t22_bxyz），裙边测量用传感器饱和；两者在这 8 个场景都有真实饱和，但块的边界不完全相同。
- 第 5 节的影响估计用"长曝光组整体 −4 档"近似按块推算，不是该候选的实际渲染。

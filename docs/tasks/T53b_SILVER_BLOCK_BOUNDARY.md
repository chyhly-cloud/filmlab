# T53b：显式银粒分块渲染的块边界丢粒（Claude；渲染器修正，待负责人决定）

## 0. 摘要

- **问题**（T53 第 4.2 节发现）：`render_silver` 按 16 像素行分块（`_render_rows`）。块上下的边缘行用同一个逐行种子重新生成晶体，跨块的银丝团本应在两块里都计入。但 `_stamp_entries` 会丢掉丝团窗口越出缓冲区的晶体。缓冲区纵向只留白 `M`（约半个最大丝团），所以中心在块外约一个微元以上、足迹仍伸进块内首末行的晶体整颗被丢掉。
- **修正**：缓冲区纵向留白改为 `2M`（横向仍为 `M`：晶体只在视场内的像素列生成，横向从不越界）。丝团窗口高 ≤ 2M − 2，所以足迹与块内任一行重叠的晶体都能整颗放进缓冲区，丢掉的只有足迹完全在块外的晶体。实现只改了 `grain.py` 的缓冲区尺寸与偏移（`MY = 2M`），随机数流不变。
- **结果**：
  - 按 16 行分块与整块一次渲染**逐位相同**（640 × 640、0.5 µm 像素、`sub = 4`；Tri-X D-76 k = 1 / 2、Tri-X Rodinal（成团）、T-Max 400，各 2 个种子）。块内行位置剖面平坦，没有 16 行周期的密度起伏。修正前视场平均低 0.26–0.32%（k = 1）、1.45%（k = 2）。块首末行（第 0、15 行）低 2–2.5%（k = 1）、8–9%（k = 2）。这里的密度是 −log10（该行平均透射率），含灰雾。
  - 整块一次渲染（`h ≤ rows_per_task` 或 `psf_um > 0`）与 HEAD 逐位相同。T47 的显微视场、T53 第 4.2 节的显式检验都不变。
- **输出比特的变化**（第 3 节；HEAD = 538e39f，git worktree）：
  - **不变**：颗粒关、所有彩色片（染料云路径不经 `render_silver`）、非 `grain_t47` 代际、187.5 µm 的小缩略图；10.4 µm 上 k = 1 的黑白片除 t47_bw T-Max 400（浮点差 ≤ 0.1 码值）外全部不变。
  - **改变**：所有在细像素（≤ 4.7 µm）上渲染的黑白颗粒；k ≥ 2 时在整帧像素上也变；`render_silver` 层面半格（7.92 µm）的 T-Max 400 k = 1 只在块首末行变（视场 ΔD +5.5e-6）。
  - **整帧**（3032 × 2020 合成图，第 3.3 节）：t51_bw 的 Tri-X、Tri-X Rodinal、HP5+、T-Max 400、Tri-X 半格，t50_bw 的 Tri-X，全部与 HEAD **逐位相同**。只有 `+g2` / `+g3` 改变：8 位码值改变的像素 0.16% / 0.48%，整帧平均 +0.0008 / +0.004 码值，单像素最大 4.3 / 30 码值。
- **建议**：采用。修正后分块不再影响结果（与 T47 文档"分块大小与进程数不改变结果"的设计一致），且只有本来丢了晶体的地方改变比特。整帧（12 µm、半格 7.9 µm）的 k = 1 输出逐位不变；变化只出现在 k ≥ 2 的整帧（极小）和细像素（≤ 4.7 µm）的分块渲染上。T50 的单元测试视场（2 µm 像素）受影响，但测试的容差（平均 ±3%、方差 ±12%）远大于修正量，T50 测试通过。

## 1. 原因

`_render_rows` 的缓冲区（显式档，微元网格）尺寸为 `(nr·sub + 2M) × (w·sub + 2M)`，块内区域在 `[M, M + nr·sub)`。
`M = max(−oy, oy + hh) + 1`，取各档丝团窗口（左上角偏移 `oy`、边长 `hh`）的最大值，即约半个最大丝团。

`_stamp_entries` 只保留整颗窗口在缓冲区内的晶体：`cy + oy + M ≥ 0`。块上方边缘行生成的晶体，中心 `cy < 0`（相对块内首行）：

- 足迹伸进块内的条件：`cy + oy + hh ≥ 1`，即 `cy ≥ 1 − (oy + hh)`；对最大丝团（`oy + hh = M − 1`）为 `cy ≥ 2 − M`；
- 被保留的条件：`cy ≥ −M − oy`；对最大丝团（`−oy = M − 1`）为 `cy ≥ −1`。

所以中心在块外 2 … M − 2 个微元、足迹伸进块内的晶体全部丢失（块下方对称）。像素大于丝团时（引擎 12 µm，`sub = 16`，微元 0.74 µm，`M = 4`）落在这一带、且窗口最外一行有非零覆盖的晶体很少，大多数情形比特不变（第 3 节）。

修正：纵向留白 `MY = 2M`。窗口高 `hh = (−oy) + (oy + hh) ≤ 2(M − 1)`，于是任何与块内行重叠的晶体满足 `cy + oy + MY ≥ 1 − hh + 2M ≥ 3 > 0`，下方同理。
新保留的晶体只往它覆盖的微元里加 τ。`bincount` 对每个微元按晶体生成顺序累加，其余微元的加法序列不变，所以这些微元逐位不变。随机数的抽取与是否保留无关，也不变。

`margin_rows = ceil(M / sub + 4σ_团 / px) + 1` 已覆盖所有足迹能伸进块内的行，不用改。

## 3. 输出比特的变化（HEAD 538e39f 与修正后）

做法同 T51 / T53 第 6 节：同一张合成灯光图（横向 −6 … +4 EV 的对数斜坡、冷暖渐变、四盏 +6 … +9 EV 的灯、一块 −7 EV 的暗区）。HEAD 放在 git worktree 里，修正后的代码在本仓库，各渲染一次，逐位比较线性 sRGB 输出（`tools/eval/t53b_bitwise.py`、`t53b_bitcmp.py`）。

- 只修了纵向（块边界）。视场的上下左右边界仍按 T50 局限 5：视场外不生成晶体，边框处密度偏低，各检验照旧去边框。

# T17：手动镜头光圈缺失时的截断亮度（Claude；并入研究代际 `next_lab_halo_edge`）

## 问题

T14 认为"没有 EXIF 的照片灯偏暗、没有光晕"。核查 89 张 RAW 后发现：
- 11 张 EXIF 确实读不到；其中 6 张可由内嵌 JPEG 补齐（`complete_exif`，默认关闭，见 RAW_EXIF_CANDIDATE.md）。
- 另有 **7 张（8%）快门、ISO 都在，只是光圈 = 0**：
  - city_11569、city_26925、day_11437、dusk_12686、n20595、n27416、n33920；
  - 这是手动镜头（无电子触点、转接老镜头）的标准记录方式。

`clip_luminance` 只要光圈缺失，就把整份 EXIF 作废，退回"截断点之上 2–5 档"（黄昏水平）的先验。

## 物理

ISO 12232：L_clip ≈ 120·N² / (t·S)。t、S 是实测值，只有 N 未知。
- 光圈取 f/1.4–f/8 的几何中值 f/3.35。
- 不确定范围是 ±2.5 档，且不会系统性偏向黄昏水平。

例：n27416（1/50 s，ISO 800）L_clip ≈ 84 cd/m²。按灯具亮度先验 2e3–3e4 cd/m²，灯约在截断点之上 4.6–8.5 档，原来是 2–5 档。

## 实现

- `rawio.APERTURE_RANGE`：默认 `None`，即原行为，逐位不变。
- `generation.APERTURE_RANGE`：仅研究代际 `next_lab_halo_edge` 设为 (1.4, 8.0)。
- 光圈有记录时不使用该范围。

## 结果（`docs/figures/t16/aperture_*.jpg`，无手动旋钮）

- n27416 街景：路灯、尾灯出现红晕（与 T14 手动 +4 档的效果相当）。
- n20595 塔楼（20 s，ISO 100）：灯和亮窗出现红色描边。
- n33920 霓虹：红色灯管内侧出现红色光晕。

EPFL 的 RW2 文件不经 `complete_exif` 时整份 EXIF 读不到（不是光圈缺失），所以 T16 的 EPFL 结果不受影响。

## 验证

- current / legacy / next 严格逐位回归各 42/42。
- 全部测试 388 项通过；新增 1 项：光圈缺失才使用范围、有光圈时不变、默认原行为。

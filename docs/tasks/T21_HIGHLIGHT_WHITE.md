# T21：灯芯附近"印成纯白"的映射复查（Claude；结论：研究代际无需修改）

## 疑点

`scanning/timing.py` 中有一个额外的指数肩部，把高光压向 `SHOULDER_WHITE = 0.93`。
- `SHOULDER_ABLATION.md` 已说明它是经验呈现假设，没有测量依据。
- 推测它让灯芯过渡区的三个通道都停在白点之下，于是颜色比例被保留下来，过渡区印成橙色。

## 核查

**定光路径。** 实际扫描时追踪 `PrintTiming`：
- 主线 `next`：逐帧自动定光，`x_knee = −0.24`，肩部生效，成片最大值 0.92–0.93；
- 研究代际 `next_lab*`：走 `lab_measured` 固定光号路径，`x_knee = None`，**没有这个肩部**，成片可到 1.0。
- 研究代际的高光已经是"负片密度 → 数字相纸曲线"的物理映射，不需要去掉什么。

**EPFL 灯芯附近对比**（`red_band.py`，代际 `next_lab_halo_e2`，以传感器截断为原点；`tools/eval/t20/t21_redband_e2.json`）：

| 场景 | 灯芯外 25–100 µm 的情况 |
|---|---|
| R1-02-3、R1-04-5、R1-05-6、R1-06-7 | 模型 L* 与真实一致；真实略偏黄，b* 高约 5–15 |
| R1-00-1 | 真实更黄：b* 17–43，模型 2–15 |
| R1-03-4 | 真实为白（L* 96–99），模型为橙（L* 70–93）。模型在 100 µm 处的三层曝光只比中灰高 +0.5、+0.2、−1.2 档，真实必须高 3 档以上才会印成白。这是该帧胶片曝光与数码曝光不一致（T13 已记录），不是映射问题 |
| R1-07-8 | 真实反而暗得多，同样是曝光不一致 |

- T13 观察到的"灯旁过渡印成橙色"在加入 T16（蓝层 XYZ 映射、边界取色）后，已没有系统性残留。
- 剩下的残差是逐帧的曝光不一致，单张 RAW 中没有这个信息；另有一项轻微的系统差：真实灯旁略偏黄。

## 结论

研究代际的"多亮印成纯白"映射不需要修改。没有改动代码。

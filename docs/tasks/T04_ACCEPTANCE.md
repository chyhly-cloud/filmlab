两项不一致都追溯到**规格**：
- **合并 k 未定义**：Codex 让 R、B 共用一个截距，验收方各自一个截距。R、B 的固定偏移本就不同，共用截距会把两者均值差混进斜率；以**各自截距**为准（−0.393 [−1.55, 0.44]）。两种定义结论相同。
- **0.02 区间容差对本数据不可行**：c_auto 的帧间差异很小（SD 0.02），斜率分布长尾。验收方用 10000 次 × 8 个种子，k_B 上限本身就在 5.45–5.91 之间浮动，报告值落在此范围内。不放宽容差，记录为规格缺陷。

判定：**测量有效**（闭合、复现、代码未改都严格通过），结论按预设规则为**数据不足以区分**。

## 主要发现

1. **k 无法识别：模型自动定光的颜色几乎不随帧变化。** c_auto 帧间 SD 只有 R 0.024 / B 0.020；真实冲印店对应的 c_lab 为 0.061 / 0.100，大 3–5 倍。
   - 三个光源组的 c_auto 均值几乎相同；c_lab 则随光源明显不同：白光灯管 B +0.166，钨丝 −0.030，品红 −0.018。
   - 这一差别可能来自冲印店按光源校色，也可能来自模型对这些光谱的胶片响应有误。本数据无法区分两者。
2. **每帧 3 个光号就能消除一半误差。** 21 个场景平均（每个场景取 ΔE00 中位数）：

   | 阶段 | 全图 | 中间调 | 近灯（100–300 µm） |
   |---|---:|---:|---:|
   | auto | 11.63 | 18.94 | 16.44 |
   | O1 | 6.00 | 7.89 | 12.22 |
   | O2 | 5.53 | 7.58 | 12.04 |

   O2 加斜率与反差后几乎没有额外改善。近灯区经理想定光后仍约 12，这部分误差不在定光。
3. **O1 偏移有系统成分**：x 的均值为 K −0.056 / R −0.105 / B +0.011，帧间 SD 为 0.14 / 0.08 / 0.095。R 的 −0.105 在各帧方向一致，是固定偏差，不是逐帧差异。
4. **黄昏组最差**：O2 后仍为 9.43，b* +5.6。

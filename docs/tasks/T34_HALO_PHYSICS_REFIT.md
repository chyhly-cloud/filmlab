# T34：纳入三个无自由参数的光晕物理项后重新定 cos^m（Claude）

## 0. 摘要

- 新研究代际 `t34_phys` = `t31_base` + `halo_oblique`（T03 下行斜程）+ `halo_layered`（T11 按层深度）+ `halo_return`（T15 返回斜光程）。不含 `halo_plate`（有参数）。定光、灯亮度先验、遮罩放置、蓝层映射都与 t31_base 相同。
- 三项并不都是"减少大角度返回光"：下行斜程与按层深度降低核总量、收窄外圈；**返回斜光程让红层吸收更多斜返回光，红层核总量 ×1.46–1.75、外圈变宽**。三项合起来（m = 4）：红层核总量 ×0.81，曝光峰值 ×0.87，700/峰 0.013 → 0.009；**绿层核总量 ×0.35**（光晕更红）。
- 曝光空间里三项约等于 m 加 1：t34 m=3 与 t31_base（m=4）的核形状几乎相同（700/峰都是 0.013），成片测量也几乎相同。
- 扫 m ∈ {1.5, 2, 3, 4}，按光晕部分的形状（灯芯 60–150 µm，归一到峰值）：
  - 700/峰（真实 0.11）只有 m=2 吻合（0.11），但 m=2 在 400–500 µm 宽 1.4–1.7 倍；
  - 8 档形状 RMS：m=4 0.081（去掉 city_61360 0.078），m=3 0.086（0.096），m=2 0.113（0.140），m=1.5 0.130（0.168）；t31_base 0.080（0.095）。
  - **选 m=4**（两种分组的形状 RMS 都最小；m=3 在全部灯上只差 0.005，在噪声内）。也就是 **m 不需要因纳入三项而改变**；t31_base 的 m=4 并不是靠吸收这三项得到的最佳形状——形状判据在等效 m 4–5 之间是平的，分不出来。
- 强度：中等灯光晕部分 100–500 µm 为真实的 1.11–1.70 倍（t31_base 1.57–2.05 倍），强度 RMS 0.135 → 0.091。
- T31 的"灯色扩散光 : 片基光晕"（200 µm，模型用配对真值、去掉 city_61360）：0–60 µm 灯 1.95 → **2.68**（真实 3.15），60–150 µm 灯 0.60 → **0.71**（真实 1.18）。红晕相对偏强从 1.6 / 2.0 倍降到 1.2 / 1.7 倍，没有消除。
- 代价：小灯（< 40 µm，去掉 city_61360）红色光晕部分从真实的 0.40–0.67 倍降到 0.27–0.54 倍；**EPFL 光源旁 ΔE00 变差 +0.59**（15.52 → 16.11，8 个场景中 7 个变差），全图不变（10.64），红带 RMS 0.252 → 0.246。光源旁变差与光晕变得更红（片基光晕部分 G/R 0.06 → ≈ 0）一致；EPFL 真实灯旁近中性。
- 结论：三项是已有物理，物理上应纳入；但纳入后形状仍要 m≈4，强度偏强只部分缓解，而颜色（更红）在 EPFL 光源旁变差。**建议暂不替换基准**，交负责人与用户目视决定（整图见第 8 节）。

## 1. 目标与方法

T26/T28 用真实片基光晕剖面（800T − 带碳对照，灯芯 60–150 µm）的形状把散射角分布定为 cos^4，当时三个无自由参数的光晕物理项没有打开。按第一性原理的顺序，应先纳入全部无自由参数的项，再用形状定唯一未定标的量 m。

- 代际：`generation.t34_phys`（第 9 节）。m 由 `engine.HALO_FORWARD`（`t19_model.py` 的 `FWD`）给出。
- 渲染：8 个夜景，`t19_model.py`，STOPS=0，REMJET=0，m = 1.5 / 2 / 3 / 4。带碳对照与 m、与这三项都无关（Vision3 500T 没有光晕核），复用 `scratchpad/t31/cache` 的带碳成片（符号链接）。
- 逐位核对（n29240）：
  - t31_base 新渲与 `t31/cache` 的 `t31_mask_0`（t31_base 的同义代际）、`t32/cache` 的 `t31_base_0` 逐像素相同（最大差 0）；
  - t34_phys 带碳（FWD=2）与 `t31_mask_0_remjet` 逐像素相同（最大差 0）。
- 测量：同 T25–T31——`t25_halo_part.py`、`t27_size_halo.py` + `t28_summary.py`（真实 = `t27/sz_ref.json`、对照 `t27/sz_ctl.json`）；T31 的逐灯数据与蓝示踪（`t31/m1.py`）；`t19_criteria.py`；EPFL `t15_eval.py`（新增环境变量 FWD）。

## 2. 三项在代码里如何与 cos^m 组合

`film.halation_kernel` 的角权重（θ 为光进入片基的角度，r = 2·t·tanθ）：

    w(θ) = refl(θ) · ang_m(θ) · dθ · A_c(θ) · g_c(θ)
    ang_m(θ) = sinθ·cos^mθ / ∫ sinθ·cos^mθ dθ        （只对角分布本身归一）

- `A_c(θ)` = `oblique_attenuation(θ, D_c, w)`：下行斜程的额外衰减（T03 均匀深度平均；T11 中比例 w 在红层之上散射、整层斜穿 10^(−D·u)），u = 1/cosθ − 1。**乘在角分布上，不再归一**：吸收的就是损失。
- `g_c(θ)` = `return_gain` 的第 c 层函数：返回光以 θ 斜穿乳剂时该层吸收相对垂直返回的倍数（按到达片基的光谱加权，用同一叠层；t31_base 的遮罩按层放置也在其中）。**乘在返回吸收上**（halation_response 的 back 是垂直值，g 把它换成斜光程）。
- 栅格化后按"衰减后的解析总量"校正（T03 v2）。多次反射外环（`multi_bounce_kernel`）每环用同一个 A 与 g；定光中灰的光晕总量（`gray_halo`，`_halo_total_multi`）用同一核，3200K 灰卡彩度 0.212（t31_base 与 t34_phys 在 m=3、4 相同）。
- 模型数值：逐层密度 D = 0.532 / 1.115 / 3.039（R G B），w = 0.765（三层同用红层的 w，T11 的近似），红层多次反射保留 rho = 0.094。

## 9. 结论

1. 三个无自由参数的项已纳入为研究代际 `t34_phys`。它们对核的作用并不同向：下行斜程与按层深度"减弱 + 收窄"，返回斜光程让红层"增强 + 变宽"；合起来红层核总量 ×0.81、峰值 ×0.87、外圈略收（m=4），绿层光晕 ×0.35。曝光空间里等效于 m 加约 1。
2. 重新定 m：形状 RMS 在 m=3–4 之间最小、m=4 略好，**选 m=4（与 t31_base 相同）**。700/峰 单点支持 m=2，但整条剖面不支持。t31_base 的 m=4 并非"吸收了三项才得到的"：纳入三项后，等效 m 4–5 的形状在这组测量里分不开。
3. 强度：中等灯光晕 1.57–2.05 → 1.11–1.70 倍真实；"灯色扩散光 : 红晕"200 µm 处 1.95 / 0.60 → 2.68 / 0.71（真实 3.15 / 1.18）。红晕相对偏强从约 2 倍降到 1.2–1.7 倍，**没有消除**，60–150 µm 灯仍偏强约 1.7 倍。
4. 代价：小灯（< 40 µm）红色光晕部分 0.27–0.54 倍真实（原 0.40–0.67）；T19 外圈 Δr 档数变差；**EPFL 光源旁 ΔE00 +0.59（7/8 场景变差）**，推断原因是光晕变得更红；全图与灰卡不变，红带略好。
5. 建议：三项在物理上应保留在模型里，但纳入后的 t34_phys（m=4）在 EPFL 光源旁变差、小灯红晕更少，不建议直接替换 t31_base；请负责人结合整图目视决定。剩下的 1.7 倍偏强与"光晕随灯芯大小增长"（T27/T28）仍是同一个结构问题，m 与这三项都解决不了。

## 10. 局限

- 真实 800T 与对照是不同场景、不同灯的总体；没有估计抽样误差。m=3 与 m=4 的形状 RMS 只差 0.005（全部灯），m 不能定得比"3–4"更细；m=3.5 没有渲染。
- 按层深度对绿层、蓝层沿用红层的 w = 0.765（T11 的近似）。绿层光晕 ×0.35 的大部分来自这里与 D_G；如果绿层的 w 实际更小，光晕不会红得这么多。这是已有项的已知近似，本任务没有改。
- 多次反射的外环用同一个 A 与 g（T03 规格），后续往返整层斜穿的额外衰减未计入。
- EPFL 光源旁变差的原因（光晕更红）是推断，未逐灯核对。
- 蓝示踪在模型上的验证误差 R ±15%、G/R ±0.1–0.25（T31）；比值只用了 200 µm 一档做结论。

## 负责人结论（Fable 审核）

- 三项纳入后 m 仍为 4，红晕相对灯色扩散光的偏强从 1.6/2.0 倍降到 1.2/1.7 倍，方向对。
- 暂不替换 t31_base：EPFL 光源旁 ΔE00 变差 +0.59（7/8 场景），原因很可能是按层项对绿层沿用了红层的 w=0.765（T11 的近似）使绿层光晕降到 0.23–0.35 倍、光晕变得过红，而 EPFL 真实灯旁接近中性。这是近似，不是物理结论；下一步按同一方法单独算绿层的 w（scatter_above_green），再评估。
- halo_return 的方向记录更正：它使红层对斜返回光吸收更多（×1.46），不是减弱项。
- 裁切对照（真实参考灯 vs 模型）显示的结构性差别：真实是从白芯向外连续的橙色辉光，模型是白芯—暗缝—红环。暗缝处灯色扩散光已衰减而红环尚未升起；物理上能填这一段的是片基背面 42° 以内透出、被压片板漫反射回来的光（halo_plate，哑光黑板 3–6%），下一步用物理取值评估。

# T42：整体偏饱和——按色相量化与沿链逐级定位（Claude；研究代际）

## 0. 摘要

- **口径**：EPFL 18 帧已确认配对（夜景 8、暖光灯箱 4、白光灯箱 4、色卡 R1-20-21、灰阶楔 R1-17-18，与 T40 相同），t31_base。两种口径：
  - Lab C*ab：每帧三通道光号重新拟合到真实（O1，s = 1），只比 C*ab；
  - 单通道传递（T32 第 6 节）：每个通道用本帧中性像素建 logH → 输出的单调传递，真实、模型各一条，输出反查成"等效曝光"。等效曝光的通道极差 ÷ logH 的通道极差 = 跨通道增饱和。定光和影调都是逐通道单调的，被传递吸收，不进入这个比值。
- **"所有色相都更饱和"在 O1 下不成立**：
  - Lab C*（O1）模型 / 真实：红 1.06、黄 0.89、绿 1.10、**青 1.33**、蓝 0.97、品红 1.04（2 帧），全部 **0.96**。夜景 8 帧 1.09，室内 0.95。
  - 单通道传递（跨通道）模型 / 真实：红 0.98（彩度 0.5–0.8 档 1.15）、黄 0.82、绿 0.62、青 1.06、**蓝 1.27**、品红 1.21（1 帧），全部 1.05。夜景 1.22，室内 0.90。
  - 默认定光（t31_base 实际出图）下 Lab C*：红 0.77、黄 0.89、绿 0.99、**青 1.17、蓝 1.21**、品红 1.07，全部 0.87。
  - 稳定偏饱和的只有冷色（青、蓝）和夜景整体；暖色（红、黄）在 Lab 下反而偏淡。
- **逐通道看，多出来的饱和集中在两个通道、两级**（等效曝光偏差 eq − logH，log10，第 3 节）：
  - **R 通道**：青、蓝物体的 R 被压低 0.08–0.10，红、黄物体的 R 被抬高 0.05–0.06；真实在这些位置是 −0.04…+0.03。
    - 这一项在 Dn 级几乎为 0（青 +0.01，蓝 −0.03，红 −0.01）：DIR 在 R 上的放大已被印放矩阵 P 抵消。
    - 它是在 **S4d 数字相纸**（相纸染料 → D50 观看 → sRGB 原色的色度换算）重新出现的。该级在等效曝光下的雅可比 R→R 为 1.09–1.13，有跨通道项（第 3.3 节）。
  - **G 通道**：红、品红物体的 G 被压低（Dn 级 −0.04 / −0.11，真实 +0.01 / +0.12），绿、青物体的 G 被抬高（+0.09 / +0.05，真实 −0.02 / 0）。
    - 来源是 **S2 DIR 层间抑制**（绿层受抑制最强，A[:,G] = 0.8）；P 只抵消一部分。
    - 在 t31_base 的输出里，S4d 对 G 的压缩（0.83）又把它掩盖了一部分。
  - B 通道的偏差（真实红 −0.10、黄 +0.10）来自 S1 相机同色异谱（T33），不属于本任务。
- **模型链各级的跨通道增益**（全部色相，胶片曝光彩度 ≥ 0.25）：DIR 后 1.43 → Status M 1.33 → 扫描密度 1.33 → Dn 1.08 → 相纸密度 1.08 → 输出 1.15；真实整条链 1.03。
- **与 Kodak 5219 官方数据核对（Status M 级）**：
  - 模型 500T 染料比数据手册"纯"：青在绿区的副吸收 0.040，Kodak 0.123；黄在绿区 0.048，Kodak 0.142；品红在红区 0.072，Kodak 0.084。
  - 换成 Kodak 带符号染料谱（含遮罩补偿）后，Status M 级跨通道增益 1.33 → 1.28（重新解混曲线后 1.26），输出 1.15 → 1.06。
  - 但它作用在 G 通道，不消除 R 通道的相纸项（青 R −0.067，真实 +0.030），而且改变中性 G 反差（模型 / 真实 1.16 → 1.47–1.60）。
  - 这就是 `t32_k5219`，T32 已评估，不重复建代际。
- **DIR 矩阵形状没有可核对的官方数据**：
  - Kodak H-1-5219 只给中性特性曲线（横轴是相对曝光）、单色曝光的光谱感光度（D-min + 0.2 处，erg/cm²）、染料光谱、MTF、颗粒度，没有分色曝光曲线。
  - 光谱感光度与中性曲线的横轴之间没有共同的绝对标尺。仓库里 spektrafilm 的感光度又已按参考光源归一，绝对值已丢失。
  - 而且在 D-min + 0.2 处，层间抑制在模型里本来就只有约 0.05–0.1 logH，与绝对标定误差同量级。
  - 现行矩阵按 Kodak US 6,210,870 的民用 C-41 片标定，"分色 / 中性 γ"为 1.14 / 1.35 / 1.22（T33），处于专利范围下沿。按文献，减小层间项没有依据。
- **修正**：`t42_base` = t31_base + `paper_channel`（S4d 数字相纸输出按通道独立；中性灰阶与原色度换算逐点相差 < 0.7%）。
  - 依据：过饱和中 R 通道那一项定位在 S4d；它不是胶片物理量，而是"Frontier 文件输出 = Crystal Archive 印放的色度"这一代理假设。
  - Frontier 的输出在其专利里是逐通道灰平衡 LUT（Fuji US6668096B1）。T32 已确认这家冲印店没有饱和度矩阵，真实整条链对自己的中性传递基本是逐通道的。
  - 修正没有新参数，也不加矩阵或 LUT，只去掉一项没有依据的跨通道换算。
  - **但这不是胶片物理量的修正**，是否接受由负责人决定。
- **评估**（t31_base → t42_base）：
  - R 通道的跨通道偏差回到真实附近：红 +0.047 → −0.003（真实 −0.003），青 −0.076 → +0.033（真实 +0.030），蓝 −0.100 → −0.023（真实 0.000）。
  - Lab C*（O1）青 1.33 → 1.21、红 1.06 → 0.99、黄 0.89 → 0.95、夜景整体 1.09 → 1.00；但绿 1.10 → 1.23、品红 1.04 → 1.22 变差（露出了 DIR 的 G 项）。
  - EPFL 红带 0.252 → 0.254，光源旁 ΔE00 15.52 → 15.86，全图 10.64 → 10.78（都变差，与 T32 的 S4d 反事实逐位一致）。
  - T19 三档红色度 Δr 明显改善（超出区间 6 / 6 / 5 → 3 / 3 / 2）。光晕部分强度 RMS 0.135 → 0.149（变差），形状 RMS 0.080 → 0.079。
  - **红环几乎不变**：60–150 µm 灯 150 / 200 µm 处 R 0.751 / 0.700 → 0.758 / 0.726（真实 0.439 / 0.357），G/R 0.48 → 0.49（真实 0.56）。红环过亮不是链条饱和度问题，而是红层光晕强度。
  - **不建议 t42_base 替换 t31_base**，作为研究代际保留。

## 1. 目标与方法

- 目标：
  1. 量化各色相的模型 / 真实彩度比；
  2. 沿链条逐级定位过饱和；
  3. 只改定位到的已有物理量；
  4. 评估；
  5. 出图。
- 规则同前：第一性原理，不做经验调色，不加饱和度矩阵 / LUT；基准 t31_base；灯亮度先验不在范围内。
- 数据：EPFL 18 帧（第 0 节），`t32_epfl_trace.py` 存档（数码几何，真实扫描反向配准；楔帧用手工几何）。
- 工具（`tools/eval/`，新增）：

| 工具 | 内容 |
|---|---|
| `t42_chain.py` | 从存档 S1 logH 逐级重算模型链：dye（DIR 后）、Status M（Kodak 数据手册 Status M 响应）、扫描窄带密度、Dn、相纸密度、输出。每级沿中性灰阶（G0 + 本帧白 v0）反查成等效曝光；只用斜率 ≥ 最大斜率 5% 的连续段 |
| `t42_sat.py` | 每帧：A. 24 px 格子 Lab，O1（s = 1，Lab soft_l1，同 T40 A3）；B. 单通道传递（真实 / 模型各自，中性 = 本帧白 v0，同 T32 的 mode）；C. 逐级等效曝光 |
| `t42_report.py` | 按色相、彩度汇总（每帧中位再取中位） |
| `t42_cf.py`、`t42_cf_report.py` | 逐级反事实（只诊断）：无层间 DIR、层间 × 0.5、Kodak 染料谱、t32_k5219、相纸按通道独立；同时给出 O1 Lab、输出中性斜率 |

- 像素：5×5 平滑，距灯芯 > 0.5 mm，光晕份额 < 0.2，真实 / 模型 0.002–0.97，腐蚀 3 像素，隔 2 取 1。
- 色相分组：按胶片曝光（logH − G0 − v0）的色相，60° 一扇区。这样分组与两边的输出无关，没有"按真实彩度选样"的回归偏差。
- 核对：从存档 logH 重算（不做抑制剂空间扩散）与存档的差，dye 中位 2e−4，Dn 3e−4，out 相对 0.14%。

读法：
- **R 通道**：
  - DIR 给出 ±0.06–0.08，Status M 略减，P 把它抵消到 ≈ 0（Dn 列）；
  - 然后 S4d 重新给出 +0.05…+0.09（暖色）/ −0.07…−0.08（冷色）；
  - 真实在 R 上没有这一项。
  - **R 通道的过饱和定位在 S4d。**
- **G 通道**：
  - DIR 给出最大的项（绿 +0.16、品红 −0.24），Status M 减约 1/4，P 留下 −0.04…+0.09；
  - S4d 的 G 压缩（雅可比 0.83）又在输出里掩盖了大部分。
  - **G 通道的过饱和定位在 S2 DIR**（层间对绿层的抑制）。
- B 通道：真实的 −0.10 / +0.10（红、黄）是 S1 相机同色异谱（T33），模型链在 B 上 Dn 级 ≈ 0。

### 3.3 S4d 数字相纸的雅可比（等效相纸密度 → 输出等效密度，在中灰 Dp = 0.7）

| 输入 \ 输出 | R | G | B |
|---|---|---|---|
| Dp_R（青） | **1.105** | 0.116 | 0.010 |
| Dp_G（品红） | −0.040 | **0.830** | 0.085 |
| Dp_B（黄） | −0.055 | 0.055 | **0.907** |

- Dp = 0.3 / 1.2 时 R→R 为 1.09 / 1.13。列和 = 1（中性不变）。
- 物理来源：sRGB 的 R 原色比相纸青染料的"互补"更窄。R = 3.24X − 1.54Y − 0.50Z 中 Y 的负系数让品红、黄的增加抬高 R，所以只动青时 R 的相对变化大于中性。
- 对真实的 Crystal Archive 印放，这是正确的色度。但 Frontier 的文件输出不是印放，真实数据中 R 通道没有这一项。

### 3.6 官方"同一灰阶 vs 单色曝光"能否核对层间分离度

不能：
- H-1-5219 的特性曲线横轴是"log relative exposure"；
- 光谱感光度是"reciprocal of exposure (erg/cm²) required to produce D-min + 0.2"（Effective exposure 1/25 s，Status M）；
- 两者没有共同的绝对标尺。仓库数据（spektrafilm）把感光度按参考光源归一，绝对值已丢失；
- 即使有绝对值，模型在 D-min + 0.2 处的层间抑制也只有约 0.05–0.1 logH，与 lux → erg 换算和互易律的不确定性同量级；
- 数据手册没有分色曝光曲线。

所以 500T 的层间强度与形状只能沿用 US 6,210,870（民用 C-41 片，"分色 / 中性 γ" 1.15–1.64）。现值 1.14 / 1.35 / 1.22 已在下沿。

## 7. 结论

1. **过饱和的量**：
   - O1 定光、只看 C*ab 时，模型整体不比真实饱和（0.96）。稳定偏饱和的是青（+33%）与夜景整体（+9%）。
   - 跨通道口径下，冷色（蓝 +27%、品红 +21%、青 +6%）与高彩度红（+15%）偏饱和，黄、绿偏淡。
   - 任务前提"所有色相都更饱和"只在冷色上成立。
2. **出现的级**：
   - R 通道的过饱和出现在 **S4d 数字相纸的色度换算**（雅可比 R→R 1.09–1.13）。前面 DIR 在 R 上的放大已被印放矩阵 P 抵消。
   - G 通道的过饱和来自 **S2 DIR 层间抑制**（对绿层），P 只抵消一部分，在 t31_base 输出里又被 S4d 的 G 压缩掩盖。
   - Status M 级模型染料比 Kodak 数据手册纯（青、黄在绿区的副吸收只有 1/3），方向是增饱和，量小（1.33 对 1.28）。
3. **修正**：t42_base 去掉 S4d 的跨通道换算。依据是定位结果、Frontier 的逐通道 LUT 结构，以及真实链的逐通道性。这不是胶片物理量。
   - 胶片侧没有找到有官方依据又能改善的修正：
     - DIR 形状无 500T 数据，文献值在下沿；
     - Kodak 染料谱即 t32_k5219，破坏中性 G 反差，已冻结。
4. **评估**：
   - R 通道各色相回到真实附近，T19 Δr 三档都明显改善；
   - EPFL 三项都略差（红带 +0.002，光源旁 +0.34，全图 +0.14），光晕强度 RMS 变差；
   - 绿、品红在露出 DIR 的 G 项后更饱和；
   - 红环不变。
5. **不建议 t42_base 成为基准**，基准仍为 t31_base。
   - 若负责人接受"Frontier 输出逐通道"这一结构判断，应与 T07 逐帧颜色偏移的重标一起做，并在同一任务里处理 DIR 对绿层的层间项。后者需要 800T 的分色曝光读数。
6. **红环**：饱和度来自 R 接近饱和与 G 被 DIR 抑制。链条修正不改变它，主因仍是红层光晕强度。

## 8. 局限

- 真实一侧的"等效曝光"用的是模型 S1 的 logH，包含 S1 误差（T32 / T33），尤其是 B 通道和 570–600 nm 一带。
- 夜景的"本帧白"v0 是曝光色度的众数，不一定是冲印店当作中性的点。v0 只影响分组和中性像素的选择，不影响单通道传递本身。
- 绿只有 4 帧，品红 1–2 帧，高彩度档帧数少。
- 反事实从存档 logH 重算，没有抑制剂的空间扩散（与存档差 < 1%）。
- t42_base 在默认定光下与 T07 的逐帧颜色偏移有交互，未重标。
- S4d 的真实结构只由成片推断，没有 Frontier 文件 LUT 的测量。

## 负责人结论

审核范围：色相分组表、链条逐级增益、Kodak 染料与 DIR 的核对、`paper.py` / `scanner.py` 差异、449 项测试（通过）、逐位核对、整图、灯区裁切与 3 张 EPFL 三列对照。

1. **任务前提被部分否定，接受。** 稳定偏饱和的只有青、蓝和夜景整体；红、黄在 Lab 下反而偏淡。模型与真实之间还有约 11° 的色相差。
2. **定位：** 多出的 R 通道跨通道增益来自数字相纸这一级的色度换算，代码里本来就注明这一级是代理假设。G 通道的问题来自 DIR 对绿层的抑制，但没有官方分色数据，无法核对。

4. **红环不受饱和度链影响**：150 µm 处 R 仍是 0.76，真实 0.44。红环过亮确定是红层光晕强度的问题。T39、T41 两次独立测量都表明，t31 的灯亮度比真实高 3–4.5 档；在真实亮度下，光晕又只有真实的约 0.4 倍。下一步（T43）专门查光晕链里这个不足。

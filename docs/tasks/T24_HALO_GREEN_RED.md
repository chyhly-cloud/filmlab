# T24：光晕的绿/红之比（Claude；第 1 项）

目标：用真实 800T 校正决定"光团偏橙还是偏红"的物理量。只校正真实存在的物理量。

## 1. 这个比例由什么决定（`film.emulsion_stack`，3200K）

光晕 G/R（以各层中灰曝光为单位）：

| | 乳剂散射 0.15（原设定） | 散射 0 |
|---|---|---|
| 有成色剂遮罩 | 0.107 | 0.234 |
| 无遮罩 | 0.440 | 0.970 |

- 各层吸收密度几乎不影响这个比例（0.15→0.4：0.107→0.099）。
- 绿光主要被**成色剂遮罩**挡掉：红感层里的有色成色剂，就是冲洗后橙色片基的来源，拍摄时已经存在。
  - 550 nm 处遮罩密度 0.44。
  - 下行到片基时整层经过，返回时再经过红感层。
- 结论：从片基背面反射回来的光，物理上只能是红色。
- 新增 `film.TURBIDITY`（默认 0.15，输出逐位不变）。

## 2. 测量方法与撤回的结果

- **撤回**：用模型光晕掩膜选像素（`t24_gr_track.py` 初版）。真实光晕范围与模型不同，选进了背景。
- **撤回**：按亮度自选像素。选进了被灯照亮的物体（G/R 1.5–4）。网上参考图"G/R 0.75–0.86"的初步数也属于此类。
- EPFL 暗场景法：场景本身暗的像素在灯旁 1.5 mm 内几乎没有，只有 R1-07-8 可用（亮处 G/R 0.15，深红）。

**采用**：`t24_dark_track.py`。条件：
- 灯芯等效半径 60–400 µm；
- 灯芯外 1.5–2.5 mm 背景线性 R、G < 0.02；
- 取距灯芯 100–1500 µm 的像素；
- 按线性 R 分档，取 G/R；
- 参考图与模型成片用同一规则。

## 3. 结论与局限

1. 模型在灯旁（亮档）的颜色与真实一致；中段（线性 R 2^-3–2^-2）是深红（G/R 0.34–0.39），真实为 0.76–0.89。
2. 减弱或改变片基反射的光晕都去不掉这圈深红：遮罩把返回光里的绿挡掉，散射为 0 时红晕更强，反而更差。
3. 叠加从乳剂正面进入的灯色光，G/R 轨迹可以对上（6%：0.48→0.11）。但按现在的空间形状，灯外亮度剖面变差，越紧凑颜色越对不上。
4. **目视反证**：加入灯色光后，车站的钠灯从橙色变成发白、发粉（用户此前否定的样子）。
   - G/R 一个数分不出白和橙，需要同时看蓝；
   - 参考集以工业夜景的荧光、LED 白光灯为主，大灯芯 B/G 1.2–2.5，不等于钠灯街景。
5. 本项没有给出可采用的校正。中段深红是实测差异，但来源（乳剂正面散射、镜头、胶片与镜头间的反射，或参考集灯型构成）未定。

## 下一步建议

1. 按灯型（钠灯橙色 / 白光）分开，用完整色度（含蓝）重测。
2. 对照集：带 remjet 的 Vision3 500T 夜景（同一乳剂、没有片基光晕）。
   - 那里的灯旁光只来自乳剂正面和镜头，可以直接测出这一部分的形状和颜色；
   - CineStill = 这一部分 + 片基红晕。

# T35：灰阶楔偏陡的分段定位与冲印店扫描影调的整体反差（Claude；研究代际）

## 0. 摘要

- **偏陡不在负片，在扫描映射。** EPFL 灰阶楔 R1-17-18 第 5–11 条（同 T32 口径），逐级斜率（对各层 logH）：
  - 负片 Status M gamma：模型（C-41，τ 名义 1.176）R/G/B 0.543 / 0.589 / 0.682。同一段 logH 上 Kodak 5219 数据手册（ECN-2）0.470 / 0.559 / 0.540；模型在 ECN-2 下 0.503 / 0.533 / 0.605。**绿层与官方一致到 ±5%**，C-41 的 τ 让绿层比官方陡 5%（τ 冻结在 [1.0, 1.3]，CRITERIA）。
  - 经档案 gain 后 Dn：0.585 / 0.595 / 0.659，**R/G 0.98**。到 Dn 为止，红通道并不比绿通道陡。
  - 扫描映射（log 输出 / Dn）：1.377 / 1.044 / 1.023。
- **红通道多出的 30% 全部在数字相纸这一级，而且来自工作点，不来自斜率。**
  - 相纸 Dp / Dn：R 1.318、G 0.991，R/G 1.33。参考印放（Dp → 输出）R/G 0.99，P、档案 gain 都不偏。
  - 楔的红通道相纸曝光比绿通道高 0.091 logE（约 3.6 个光号）：画面偏青，红通道落在数字相纸趾部更陡的位置。
  - 只把红光号放开拟合到真实（ΔK_R = −0.090，G、B 不动），红斜率就从 0.806 降到 0.579，R/G 1.30 → 0.96。
  - 0.091 的来源：楔对胶片不中性（S1：红层 logH 比 3200K 中灰的比例低约 0.11）占 +0.072；T07 逐帧颜色偏移 +0.012；固定光号的力度残差 +0.007；楔在中灰以上各层 Dn 反差不同 +0.001。**这一项属于定光 / 输入颜色，不是影调，本任务不改。**
- **整体偏陡**（G 0.620 对真实 0.529，+17%）：负片 C-41 约占 5%，其余在扫描映射。以模型负片为准，冲印店扫描映射的斜率是模型的 **0.85 倍**；若按官方 ECN-2 gamma 计，真实扫描斜率 0.529 / 0.559 = 0.946（每 Status M 密度），模型 1.053，比值 0.90。
- **修正**：只改一个已有量——固定光号的整体反差 s（`PrintTiming.s`，三通道同一个，原为 1）。在楔上把三通道光号放开（O1，冲印店本来就有的自由度）后，与真实最一致的 s = **0.851**（只用 G 0.845，全部 14 条 0.872），取 `LAB_SCAN_CONTRAST = 0.85`。支点保持现有定义：设计光源中灰（固定光号下中灰亮度不变）。新标志 `lab_contrast`，新代际 **`t35_base` = t31_base + lab_contrast**。现有代际逐位不变（52 组合成图逐位相同；t31_base 的楔与车站重渲与旧缓存最大差 0）。

- **意外**：
  1. 默认定光下楔斜率几乎不变（G 0.620 → 0.613）。支点在设计中灰，楔（中灰以上 0.2–0.8 logH）随反差降低变暗，落到数字相纸趾部更陡处，抵消了 s。楔的"斜率"在默认定光下主要由工作点决定。
  2. 其他 11 帧配对用同一方法拟合 s：中位 **0.95**（四分位 0.91–0.98；夜景 0.84–1.01），比楔的 0.85 弱。CRITERIA 早先 O2 拟合得 0.92。

- **建议：不替换基准，t35_base 作研究代际保留。** 定位是清楚的：偏陡在扫描映射，红通道 30% 在定光工作点。但 s 只有一帧的测量，与其他帧不一致（0.85 对 0.95），支点无法由数据确定，而且光源旁与光晕形状变差。

## 1. 目标

T32/T33 遗留：灰阶楔中间段的模型输出斜率 0.81 / 0.62 / 0.67，真实 0.55 / 0.53 / 0.56，模型整体偏陡，红通道比绿通道陡 30%。分清偏陡来自负片还是扫描，把红通道单独追到具体环节；只修正定位到的已有量。

规则：拟合只修正已有物理量，不做经验调色。灯亮度先验（U[6,8] 档）、光晕链、遮罩、蓝层映射、τ（冻结）都不动。现有代际逐位不变。

## 2. 定位

### 2.1 方法（`scratchpad/t35/chain.py`）

- 输入：`t32_epfl_trace.py` 渲出的楔帧（数码几何、真实扫描反向配准），按 `epfl_wedge_geometry.json` 的手工几何取 14 条的中位（同 `t32_wedge.py`）。
- 每条的 logH 重新显影，逐级给出：Status M 密度（数据手册的 Status M 响应）→ 窄带扫描密度 → 印放密度（×P）→ Dn（×档案 gain）→ 数字相纸曝光 xe → 相纸密度 Dp → 输出。
- 重算的 Dn 与输出和图像中位一致（斜率差 ≤ 0.001）。

- 数据来源：仓库已有的 Kodak H-1-5219 特性曲线与 Status M 响应数字化（spektrafilm 提交 049f677^ 的 csv，CC BY-SA 4.0，https://github.com/andreavolpato/spektrafilm；`tools/eval/gamma_tiers.py` 同一份）。本任务没有引入新的外部数值。标准区间（密度 0.3–1.3）的 gamma 与 CRITERIA 表一致（Kodak 0.473 / 0.555 / 0.538）。
- 模型 ECN-2 的绿层比官方低 5%，红层高 7%，蓝层高 12%（T32 已记录）。C-41 的 τ 1.176 让绿层比官方高 5%，红 / 蓝的偏差再由扫描仪档案 gain 拉齐到绿通道（Dn R/G 0.98）。
- 结论：**负片 gamma 与官方一致到绿层 ±5%**，不足以解释输出偏陡 17%（G）。τ 冻结在 [1.0, 1.3]，名义值不由冲印店扫描反推，本任务不动。

### 2.4 整体偏陡在扫描映射

以绿通道为参照（红通道受 2.5 节的工作点影响）：

| | 模型 | 真实 | 真实 / 模型 |
|---|---|---|---|
| 输出 / logH | 0.620 | 0.529 | 0.853 |
| 负片：Status M / logH | 0.589（模型 C-41） | 未测；官方 ECN-2 为 0.559 | — |
| 扫描映射（每 Status M 密度） | 1.053 | 0.529 / 0.559 = **0.946**（按官方 gamma） | 0.90 |
| 扫描映射（每 Dn） | 1.044 | 0.529 / 0.595 = **0.889**（按模型负片） | 0.85 |

- 真实负片的 C-41 gamma 没有测量。按官方 ECN-2 gamma 算，冲印店的扫描映射是模型的 0.90 倍，剩余 5% 归于 τ；按模型负片算是 0.85 倍。
- 模型的负片（τ 名义值）是进入扫描仪的实际输入，所以修正量按模型负片取 0.85。其中最多约 5% 可能实际属于 τ，这一点无法用一张楔区分。

### 2.5 红通道多出的 30%：数字相纸的工作点（`fit.py`、`redsplit.py`）

- 到 Dn 为止 R/G 0.98；参考印放 R/G 0.99。斜率差只出现在相纸一级：Dp / Dn R 1.318、G 0.991。
- 三个通道共用同一条中性相纸曲线。斜率不同只能来自工作点不同：红通道 xe 比绿通道高 0.091（逐条 0.090–0.092），即红通道印得更暗（楔偏青，G/R 1.05–1.49）。在趾部，局部斜率随密度升高增加很快。
- **验证**：只放开三通道光号（O1），G、B 光号几乎不动（+0.004），红光号 −0.090。红斜率 0.806 → 0.579，R/G 1.30 → 0.96，楔中间段 G/R 0.97–1.00（真实 0.95–1.04）。

**0.091 的来源分解**（第 5–11 条平均，`redsplit.py`）：

| 项 | xe_R − xe_G |
|---|---|
| ① 固定光号基准：扫描力度 0.75 没有补全 Portra 800 档案与 800T 中灰的差 | +0.007 |
| ② T07 逐帧颜色偏移（a − k·整帧偏色，本帧 −0.012） | +0.012 |
| ③ 楔在 3200K 中灰之上 0.47–0.58 logH，各层 Dn 反差不同 | +0.001 |
| ④ **楔对胶片不中性**：红层 logH 比绿层低（相对 3200K 中灰约 −0.11） | **+0.072** |
| 合计 | +0.091 |

- 主项是 ④，属于 S1（数码 RAW → 胶片曝光）或拍摄光本身。真实冲印店把这帧印成了中性（G/R 0.95–1.04）：可能真实底片本来就中性（即 S1 误差），也可能是冲印店逐帧校正掉了。一张楔无法区分这两种情况。
- 无论哪种，红通道的 30% 都不是影调斜率的属性，也不是负片（DIR、遮罩、层间）或 P、档案 gain、参考印放的属性。按规则，本任务不改它。

## 3. 修正

### 3.1 候选与依据

| 候选（已有量） | 作用 | 依据 / 结论 |
|---|---|---|
| **扫描整体反差 s**（`PrintTiming.s`，固定光号下为 1） | 三通道同一个，改变 Dn → 相纸曝光的比例 | 偏陡定位在扫描映射；s 是冲印店数字扫描真实拥有的自由度（光学印放为 1，数字扫描可调），可由灰阶楔直接测。**采用** |
| C-41 显影程度 τ | 负片三层 gamma | 绿层只差 5%，不够；且 CRITERIA 已冻结（不由冲印店扫描反推）。不采用 |
| DIR、遮罩、层间、P、档案 gain | 通道间比例 | Dn R/G 0.98，这些项不造成红通道偏陡；T33 已证 DIR 不影响中性反差。不采用 |
| 红通道光号 / 逐帧颜色 | 红通道工作点 | 是红通道 30% 的原因，但属于定光（T07）或 S1 输入颜色，不是影调。只有一帧，不采用 |
| 数字相纸曲线形状 | 影调形状 | 替换为楔的实测曲线就成了经验 LUT，违反规则。不采用 |

### 3.3 实现

- `engine.LAB_SCAN_CONTRAST = 0.85`；修正标志 `"lab_contrast"`（配合 `lab_measured`，timing="frame"）：固定光号用 `scanner.balance(g, mid_gray, stretch=LAB_SCAN_CONTRAST)`，支点 = 设计光源中灰（`gray_point` 的现有定义）。未启用时 stretch=None，与原来逐位相同。其他定光方式不受影响。
- T07 的逐帧颜色偏移作用在 Dn 域（xe = K − s·(off + Dn)），"中和负片偏色的 65%" 这一比例与 s 无关，不重拟合。
- 代际 `t35_base` = t31_base + `lab_contrast`（session 测光、stops 先验、遮罩按层、取色与光圈同 t31_base）。
- 逐位核对：
  - 改动前（`git archive HEAD` 副本）与改动后，全部现有代际在合成灯光图上的 52 组输出逐位相同（`scratchpad/t35/bitwise.py`、`bw.txt`）；
  - t31_base 的楔帧重渲与改动前 npz 逐位相同；
  - 车站 n29240 的 800T 与带碳重渲与 T31 缓存最大差 0。

## 5. 意外

1. **默认定光下楔的斜率几乎不随 s 变。**
   - 支点在设计光源中灰，楔的中间段在中灰之上。s 降低时这一段变暗，落到数字相纸趾部更陡处，log 斜率被抵消（G 0.620 → 0.613）。
   - 只有亮度同时放开（O1）时才看得到 s 的作用。楔在默认定光下的"斜率"主要反映工作点（亮度与颜色），不只是影调。
2. **其他帧给出更弱的反差修正**（`frames_s.py`、`frames_s.txt`；同一方法：三通道光号 + s，Lab 残差，soft_l1，24 px 格子，排除传感器饱和灯芯）。

| 组 | 帧 | s |
|---|---|---|
| 夜景 | R1-00-1 / 01-2 / 02-3 / 03-4 / 04-5 / 05-6 / 06-7 / 07-8 | 0.893 / 0.836 / 0.904 / 1.006 / 0.975 / 0.961 / 0.950 / 0.977 |
| 钨丝灯箱 | R1-27-28 / 28-29 / 30-31 | 0.977 / 0.927 / 0.920 |
| 灰阶楔（全帧格子） | R1-17-18 | 0.868 |

   - 11 帧中位 0.950（四分位 0.912–0.976）。方向一致（都 ≤ 1，只有一帧 1.006），量比楔小。CRITERIA 早先的 O2 也拟合到 0.92。
   - 场景格子以暗部为主，对中间调以上的斜率约束弱；楔对中间调最干净，但只有一帧。冲印店的整体反差在 0.85–0.95 之间，数据不能定到一个值。
3. **灯样本随黑位变化。** s < 1 抬高黑位（片基 Dn = 0 → xe = need + s·g），暗背景判据（背景 < 0.02）筛掉更多灯：60–150 µm 149 → 129 盏，< 40 µm 677 → 307 盏。光晕统计对比的不是同一组灯。
4. **结果依赖支点，而支点由逐帧亮度决定，数据中没有。**
   - 支点上移 0.25 Dn（≈ 楔 O1 拟合中 t31 与 t35 输出相同的点）时：全图 10.22 → 10.67（回到基准），光源旁 15.70 → 15.47，红带 0.226。
   - 光晕部分强度 / 形状 RMS 都更差（0.151 / 0.134）。
   - t35_base 全图的改善主要来自中灰以上变暗（R1-03-4 −1.61、R1-06-7 −0.81、R1-07-8 −0.59），是亮度效应。

## 6. 结论

1. **定位**：
   - 负片 gamma 与 Kodak 5219 官方曲线一致到绿层 ±5%，τ 的 C-41 增量约 +5%（冻结区间内）。
   - 整体偏陡的主体在扫描映射：模型 log 输出 / Dn 为 1.044，冲印店为 0.89（按模型负片）或 0.95（按官方 gamma）。
2. **红通道 30%**：只在数字相纸一级出现。原因是红通道工作点偏暗 0.091 logE（楔偏青），叠加相纸趾部的曲率。不是负片（DIR、遮罩、层间）、P、档案 gain 或参考印放的问题。工作点偏移的 80% 来自楔对胶片不中性（S1 输入颜色，或冲印店的逐帧校正）。放开红光号后 R/G 0.96。
3. **修正**：冲印店扫描的整体反差 s 由楔实测为 0.85（已有量 `PrintTiming.s`，原 1），代际 `t35_base`。
4. **评估**：
   - 改善：红带 0.252 → 0.234，全图 10.64 → 10.22，光晕强度 RMS 0.135 → 0.120，T19 三档 RMS(Δr) 都降低。
   - 变差：光源旁 15.52 → 15.70，光晕形状 RMS 0.080 → 0.106。
   - 楔在默认定光下的斜率几乎不变。
5. **不建议 t35_base 替换 t31_base。** 理由：
   - s 只来自一帧，其他 11 帧给出 0.95；
   - 支点（亮度）无法确定，而全图的改善主要是亮度效应；
   - 光源旁与光晕形状变差。
   - 建议保留为研究代际，`lab_contrast` 默认关闭。
6. **下一步**：
   - 用同一方法在全部可配准的 EPFL 帧上联合拟合一个共同的 s（光号逐帧），给出区间；
   - 楔帧的偏青（S1 对这一光源的红层曝光）单独核对：拍摄光源光谱、RAW 白点；
   - 真实影调与 Crystal Archive 代理在暗端形状不同，需要多张楔才能谈形状。

## 7. 局限

- 楔只有一帧、一家冲印店，没有独立验证。
- 楔的手工几何每条只取 3 个点（同 T32）。真实与模型的镜头眩光不同，对暗条影响最大，中间 5–11 条影响小。
- s 与 τ 的乘积可辨识，二者的分配不可辨识。按 τ 冻结的约定，全部归入扫描。
- 支点固定在设计中灰，是现有 `gray_point` 的定义，不是测量。
- 光晕统计的灯样本随代际改变（意外 3），强度 / 形状 RMS 的变化有一部分是样本变化。
- 诊断版本（s = 0.95、支点 +0.25）通过 scratchpad 里的猴补丁（`pv/pv.py`）实现，没有进仓库。

## 负责人结论

审核范围：分段斜率表、`engine.py` 与 `generation.py` 差异、439 项测试（通过）、逐位核对、`$SP/t35/full` 整图、灯区裁切与灰阶楔三列整帧。

1. **定位成立。** 负片绿层 gamma 与 Kodak 5219 官方曲线相差不到 5%，偏陡在扫描映射。红通道多陡的 30% 不是斜率问题：楔对胶片偏青，红通道的相纸曝光高约 0.09 logE，落在相纸趾部更陡处。只放开红光号，红绿斜率比就从 1.30 回到 0.96。
2. **不换基准，t35_base 保留为研究代际。** s = 0.85 只来自一张楔，其他 11 帧给出的中位是 0.95。全图 ΔE 的改善主要来自亮度，而且依赖支点。灯旁 ΔE 和光晕形状 RMS 变差，光晕统计里的灯也因黑位抬高少了一部分。证据不足以定这个量。
3. **灰阶楔整帧上最显眼的差别是颜色，不是斜率。** 真实楔是中性略暖的灰，背景是抬起的暗紫灰；模型的楔整体偏青绿，背景接近纯黑。这与第 1 点的"红层曝光偏低 0.072 logE"是同一件事，属于输入颜色（S1）或定光。它影响所有场景，比 s 更值得先查。
4. **下一步（T40）：**
   - 用全部可配准的 EPFL 帧联合拟合一个共同的 s，给出帧间离散；
   - 查楔帧偏青的来源：拍摄光源的光谱、S1 对红层的曝光、真实冲印店是否对这一帧做了校正。能从数据分开就分开，分不开就如实写明。

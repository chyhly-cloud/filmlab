# T48：黑白片各自的光谱感光度与特性曲线（Claude；研究代际）

## 0. 起因与结论

- T47b 的四种黑白片整图"差别实在太小"。负责人核对：颗粒度本身接近 Schmidt 实测，差别小主要因为 T-Max 与 Plus-X **借用了 Tri-X 的光谱感光度**，Plus-X 还借用了 **Tri-X 的曲线形状**。
- T48 从官方数据手册数字化每种片自己的光谱感光度与 D-76 类特性曲线（10 种：Kodak Tri-X 400 / T-Max 100 / T-Max 400 / Plus-X 125，Ilford HP5 Plus / FP4 Plus / Delta 100 / Delta 400 / Pan F Plus，Fujifilm Acros 100），放进黑白片档案（`filmlab/data/bw_t48.json`），晶体模型逐片拟合银量（10 种都过 0.10 门槛），用官方感光度。颗粒路径、冲印店定光与自动曝光都不变。
- 新代际 **t48_bw**（= t47_bw 的修正集 + `materials.BW_PROFILE_SET = "t48"`）。Tri-X 的数据本来就是自己的（F-4017 光谱、Schmidt D-76 曲线），在 t48_bw 下逐位不变；T-Max / Plus-X 在 t47_bw 下仍用 T47b 的档案，现有代际逐位不变。
- 结果：光谱差别传到了图上——红色、橙黄色阴影、绿色与暗部在不同片上相差可达 1–1.6 档，Plus-X 不再与 Tri-X 几乎一样；但冲印店逐帧自动定光不变，整图层面的差别仍然温和：Kodak 三种片相对 Tri-X 的整图 ΔL* 平均 2.3（T47b）→ 2.5（T48），新片种中只有 Pan F 一眼可见（ΔL* 5–8），其余 1–4。**整图上的可见差别没有明显增大，增大的是颜色相关的局部明暗**（第 4.3 节）。

### 1.1 光谱感光度的定义与换算

模型的光谱感光度口径是"每单位能量的相对 log 感光度"（仓库其他档案与 Tri-X 的 F-4017 一样；绝对尺度不起作用，测光按感光度定标，只有形状起作用）。各手册的定义不同，统一换算：

| 来源 | 手册里的定义 | 换算到模型口径 |
|---|---|---|
| Kodak（Tri-X、T-Max 100、T-Max 400） | log10 [1 / 达到 D-min + 1.0（或 + 0.3）所需的曝光（erg/cm²）] | 已是每单位能量，直接用（只用形状，峰值归零） |
| Fujifilm（Acros） | 对日光（5400K）的光谱照相，相对 log 感光度（图上标出 1.0 log 的跨度） | 减去 log D55 相对光谱功率（5400K 日光近似） |
| Ilford（HP5、FP4、Delta 100 / 400、Pan F） | 对钨丝灯（2850K）的楔形光谱照相，纵轴 "Sensitivity" 0.5 / 1.0 | **按相对 log 感光度读（假设）**，减去 2850K 黑体光谱功率的 log |

- Ilford 楔形光谱图的纵轴没有写是 log 还是线性。楔形光谱照相的高度按惯例正比于 log 感光度；两种读法换算后与同类乳剂（Tri-X）的形状比较，log 读法的形状偏差都更小（RMS 0.09–0.17 对线性读法 0.14–0.19），所以取 log 读法。这是假设，写在局限里。
- T-Max 400 的 D-min + 1.0 曲线是点线、无法可靠跟踪，用 D-min + 0.3 的实线（只取形状）。
- Plus-X（F-8）没有光谱感光度图 → **借用 Tri-X**（档案里标明 `borrowed`）。

## 6. 局限

1. **Ilford 光谱的纵轴是假设**（按相对 log 感光度读）。若实际是线性，Ilford 片的蓝 / 红差别会更大约 0.05–0.2 log。
2. **借用**：Plus-X 的光谱（Tri-X）与曲线（HC-110）、HP5 / FP4 的曲线（ILFOTEC HC）、Pan F 的曲线（Schmidt D-76，而非 Ilford 官方）。
3. **只用一种显影时间**：Kodak / Fuji 的曲线取推荐时间附近的一条，没有按 Schmidt 的 γ 插值；Delta 400 的 ID-11 曲线是 24 °C。
4. **光谱只取形状**：T-Max 400 用 D-min + 0.3 的曲线；不同密度判据下的光谱形状略有不同（T-Max 100 两条曲线红端差约 0.3–0.4 log）。
5. **晶体形态**：Delta 与 Acros 按 T 颗粒处理（假设，同 T47b）。
6. **冲印店定光**按要求不变：逐帧自动定光把各片的整体亮度拉向同一目标（±0.12 密度以内；反差固定 s = 1，不拉平），所以整图亮度的差别被部分抹掉，剩下曲线形状与光谱造成的局部明暗关系（第 4.2、4.3 节）。
7. **颗粒的检验**仍只有 T47b 的那几种片；新片种（HP5、FP4、Acros）的颗粒是预测。

## 负责人结论

审核范围：10 种黑白片的数据来源和借用表、曲线拟合残差、光谱对比、区域亮度表、T47b 与 T48 的 ΔL* 对照、`materials.py` 差异、526 项测试（通过）、97 组逐位核对、四个场景的整图。

1. **数据补齐了，可以接受。**
   - 10 种片里，9 种用了自己的光谱感光度，10 种都用了官方曲线或 Schmidt 实测曲线；
   - 拟合残差最大 0.089，在 0.10 门槛以内；
   - 借用的只剩 Plus-X 的光谱、Plus-X / HP5 / FP4 的显影口径，以及 Pan F 的曲线来源，都已标明。
2. **整图差别没有明显变大，这是物理结论，不是缺陷。**
   - 大面积中间调的光谱很宽，几种片光谱感光度的差别在上面大部分互相抵消；
   - 各片曲线斜率本来就只在 0.53–0.70 之间；
   - 差别集中在有颜色的局部：红花、红色背景、橙黄色物体、蓝天，可达 1–1.6 档。人像皮肤各片之间只差约 0.05 档。
   - 实际拍摄中，黑白片"看起来很不一样"，大多来自这些地方：镜头滤镜，显影液与推拉冲，相纸或扫描的影调与锐化，曝光取舍。它们不是胶片本身的光谱和颗粒。
3. **采用**：t48_bw 作为黑白片的候选基准，取代 t47_bw。各片使用自己的光谱和曲线；颗粒与 T47b 相同，只适用于 D-76 一类显影液。
4. **局限**：
   - Ilford 光谱图的纵轴口径是按假设读的；
   - 逐帧自动定光在两个场景里撞到了 ±0.12 的上限。这本身是冲印店的属性，没有改；但它会把各片整体亮度拉向同一目标，在比较不同片时要记住这一点。

# T16：灯芯边缘的黄色硬边（Claude；研究代际 `next_lab_halo_edge`）

现象：近处大灯在成片中为白色灯芯，外面紧贴一圈边界生硬的饱和黄环（`docs/figures/t16/lamp_edge.jpg` 左）。

## 1. 成因（`tools/eval/t16_lamp_profile.py`，n40481 沿灯芯水平剖面）

| 位置 | 输入（sRGB 线性） | 蓝层曝光（相对中灰档） | 成片 |
|---|---|---:|---|
| 截断区内，重建 | [3.9, 1.5, 0]（颜色取外圈较远处最亮像素，R/G = 2.6） | +2.2 | 白 |
| 截断区外第一个像素，实测 | [1.29, 1.01, −0.09] | −18（即 0） | 饱和黄 (1.06, 0.89, 0.06) |

两个原因叠加：
1. **输入表示**：这盏灯的光在相机原始通道里稳定为 R/G = 1.07、B/G = 0.145。
   - 从 5% 到 100% 截断电平都不变，没有接近饱和时的非线性失真。
   - 相机→sRGB 矩阵把这个色域外颜色的 B 压成负值。
   - 人造光源的 3×3 映射（sRGB 里的非负拟合）中，蓝层系数约为 17 × B，于是蓝层曝光为负，被截为 0。
   - 但胶片蓝层与相机蓝通道是同一个波段，真实收到的是正的光。
2. **重建颜色**：截断区颜色取自外圈较远处最亮的 30% 像素，与边界外第一圈的实测颜色不同。边界两侧颜色跳变。

## 2. 检验与取舍（不拟合任何扫描）

在训练反射率（独立随机种子 2000 条）× 各类灯光，以及窄带光源（LPS 589、红/琥珀/绿/蓝 LED）上，比较蓝层的直接积分真值：

| 光源类 | 全部颜色：sRGB / XYZ 映射误差（中位 \|Δlog10\|） | sRGB 蓝为负的真实颜色：sRGB / XYZ |
|---|---|---|
| 钨丝 | 0.053 / 0.058 | 8.13 / 0.12 |
| 高压钠 | 0.036 / 0.048 | 0.23 / 0.10 |
| 荧光 | 0.022 / 0.037 | 7.35 / 0.09 |
| LED | 0.005 / 0.006 | 0.39 / 0.04 |
| 金卤 | 0.050 / 0.052 | 8.20 / 0.14 |

- **蓝层改在 XYZ 里做非负映射**：
  - XYZ 是非负配色函数的积分，任何真实的光都 ≥ 0；
  - 蓝层感光度与 Z 同在短波，可写成非负组合；
  - 在全部颜色上的精度几乎不变，在 sRGB 蓝为负的真实颜色上，误差从 7–8 个数量级降到 0.1。
- 红、绿层保持 sRGB 映射。三层都放进 XYZ 时，红层误差升到约 0.03–0.05 log：胶片红层比任何人眼基都偏红，无法用非负组合表达。
- 窄带长波光（LPS、红/琥珀 LED）两种映射都不准，sRGB 偏向 0、XYZ 偏高约 2.6 log。这是三通道输入的同色异谱极限，如实保留。
- **截断区颜色取紧邻边界外 1–3 像素的实测颜色**（不截负值）：这些像素是同一盏灯经镜头扩散出来的光，内外同色，颜色和亮度连续。

试过并放弃的做法：
- 逐通道重建：外推出的 sRGB 蓝值为 −12，整个灯芯变黄。
- 截去负的输入分量：会冲淡钠灯下的黄叶。
- 投影到可实现色域：投影不连续，或误伤红色 LED。

## 3. 结果

剖面：灯芯 1.0 → 边界 0.97 / 0.81（蓝）→ 外圈 0.76 → 0.67，三层曝光连续，无跳变。

目视（`docs/figures/t16/`）：
- lamp_edge：黄色硬环消失，白芯平滑过渡到黄白眩光，钠灯下的黄叶不变；
- snow_street、station、street：灯芯更白，红晕保留，场景其余部分不变。

EPFL（`tools/eval/t15_eval.py`，`t16_eval.json`；对照 `next_lab_halo_plate`）：

| | 红带 RMS | 光源旁 ΔE00（8 场景均值） | 全图 ΔE00 |
|---|---:|---:|---:|
| next_lab_halo_plate | 0.235 | 14.79 | 10.60 |
| next_lab_halo_edge | 0.237 | **14.66** | 10.63 |

- 光源旁改善最大的是 R1-03-4（22.33 → 21.42），也就是真实扫描里灯旁过渡为白色、模型原来印成橙色的那一帧。
- 其次是 R1-07-8（−0.35）和 R1-05-6（−0.30）。
- R1-02-3（+0.24）、R1-06-7（+0.20）、R1-00-1（+0.15）略差。
- 全图与红带基本不变。

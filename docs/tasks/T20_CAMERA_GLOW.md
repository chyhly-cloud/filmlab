# T20：胶片物理（压片板）复查与"拍摄端眩光"选项（Claude；研究候选，未通过验收）

用户决定"两者都做"：
1. 以 EPFL 为准修胶片物理；
2. 另加一个明确标注、可开关的拍摄端环节，用来逼近网上参考图的外观。

## 1. 胶片物理：压片板单独检验（`t19_epfl.py`，`t20/t20_epfl_plate.json`）

候选 `next_lab_halo_e2p` = e2 + 压片板反射（不含返回斜光程）。EPFL 上的 RMS（三组灯芯均值，50–1000 µm）：

| 代际 | RMS Δr | RMS log 亮度形状 |
|---|---:|---:|
| next_lab_halo | 0.048 | 0.180 |
| next_lab_halo_e2 | 0.051 | 0.221 |
| e2p，压片板 5% | 0.050 | 0.213 |
| e2p，压片板 20% | 0.054 | 0.189 |
| e2p，压片板 50% | 0.055 | 0.165 |

- 压片板能改善亮度形状，但红色在 200–300 µm 进一步偏强，Δr 略差。**不采用**。
- 灯芯外 50–150 µm 的差距，与"以白色灯芯边缘为原点"的定义纠缠在一起：真实冲印把更大一片区域印成白色。这一项仍属于 T13 的扫描高光映射问题，未解决。

## 2. 拍摄端眩光（`filmlab/optics.py`，修正项 `camera_glare`，参数 `engine.CAMERA_GLARE`）

- **模型**：光 → (1 − η)·光 + η·(光 ⊗ K)，K(r) ∝ (1 + r²/r0²)^−1.5，在胶片面上计算。
- **性质**：
  - 能量守恒，均匀画面与灰卡定光不受影响；
  - 作用在到达乳剂之前的场景光上，所以带灯本身的光谱，三层都会曝光。
- **定位**：这是相机（镜头或柔光镜）的性质，**不是胶片物理**。研究候选为 `next_lab_halo_e2g`，生产代际都不启用。

**网格**（28 张夜景 RAW，对网上参考集，T19 指标，`t20_glare_fit.py`，`t20/t20_fit.json`）：

| η \ r0 | 50 µm | 150 µm | 400 µm |
|---|---|---|---|
| 0（无） | 0.074 / 0.304 | | |
| 0.5% | 0.064 / 0.294 | 0.061 / 0.269 | 0.057 / 0.237 |
| 1% | 0.063 / 0.289 | 0.052 / 0.253 | 0.051 / 0.190 |
| 2% | 0.062 / 0.294 | 0.049 / 0.222 | **0.051 / 0.136** |
| 4% | 0.045 / 0.294 | 0.053 / 0.182 | 0.054 / 0.181 |
| 8% | 0.051 / 0.202 | 0.042 / 0.167 | 0.054 / 0.304 |

（每格为 RMS Δr / RMS log 亮度形状，100–1000 µm）

- 取 **η = 2%，r0 = 400 µm**。普通镜头的杂散光指数（ISO 9358）常见 1–5%，2% 在这个范围内。
- **EPFL 不受损**（`t20/t20_epfl_glare.json`）：RMS Δr 0.051 → 0.051，亮度形状 0.221 → 0.205。EPFL 的胶片相机本来也有镜头眩光。
- **按 T19 写定的合格标准**（三组灯芯各至多 2/11 个环超出参考集 90% 区间）：

| | 灯芯 < 60 µm | 60–150 | 150–400 |
|---|---|---|---|
| e2 | Δr 5，Y 9 | Δr 5，Y 5 | Δr 1，Y 4 |
| e2 + 眩光 2%/400 µm | Δr 6，Y 4 | Δr 5，Y 4 | Δr 3，Y 3 |

亮度形状明显改善，但**仍未通过**。

## 现状

- 胶片物理：以 EPFL 为准，亮度衰减已吻合。剩下灯芯外 50–150 µm 的红色起点，以及大灯芯 300–500 µm 的亮度，这两处与扫描高光映射纠缠，尚未拆开。
- 外观：加 2% 镜头眩光后，模型更接近网上参考图的柔和辉光，但参考图里那种围绕路灯的大块橙红光球（如雾中路灯）仍然不足，红色程度在中小灯芯上也还有 5–6 个环超出区间。

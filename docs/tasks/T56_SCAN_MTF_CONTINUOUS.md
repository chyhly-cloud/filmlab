# T56：冲印店空间传递的高斯按连续传递实现（scan_mtf）——取样核的问题、实现与 σ_o 复核（Claude；研究代际）

## 0. 摘要

- **问题**（T55 第 6 节在 silvergrain 里发现，此处在 filmlab 里确认）：`Engine._scan_psf` 用 `gaussian_filter(T, (σ, σ, 0))` 在**输出像素**上加 T51 的扫描光学。Noritsu σ_o = 0.35 像素时，取样核的中心权约 0.97、邻点约 0.016，近似恒等。但 T51 拟合 σ_o 时用的是**连续传递** e^{−2π²σ²f²}：在 5 µm 细网格上加高斯，再按冲印店像素方盒积分（`t51_fit.model_reference`）。USM 的模糊（σ_u = 0.68 像素）也有同类偏差，只是小一些。T51 拟合的 U(f) 是解析式。
- **实现**：修正标志 `scan_mtf`（默认关），只作用于 T51 的空间阶段。扫描光学、USM 模糊、色度低通三项高斯改为在频域乘连续传递，函数是 `spatial.gauss_mtf`，用 DCT-II，等价于整幅反射填充，无截断、无回绕。
  - 新研究代际 **t56_base = t51_base + scan_mtf**（Frontier）、**t56_bw = t51_bw + scan_mtf**（Noritsu）。
  - 器件参数（`LABS`）不变。现有 57 个代际（122 组渲染）逐位相同。
- **谱形复核**（第 4 节，引擎域，无扫描仪噪声底 N）：连续传递下与真实 RPL 黑白谱形最吻合的 σ_o 为 Tri-X **7 µm**、HP5+ **6 µm**。
  - 谱形残差：Tri-X 0.295 → 0.181，HP5+ 0.191 → 0.156（σ_o = 7 µm）。
  - **σ_o 不需要重新拟合**，保留 7 µm。
- **量级复核**（第 3 节，T51b 同一套）：连续传递使模型的像素级颗粒 ×0.72、48 µm 颗粒 ×0.87。
  - Tri-X 真实 / 模型（40–200 码值）由 σ_48 0.90–1.03 变为 **1.04–1.18**，像素级由 0.77–0.95 变为 **1.06–1.32**。
  - 胶片侧由 0.98–1.12 变为 **1.13–1.29**；影调斜率 0.91–0.93 不变。
  - HP5+ 胶片侧由 1.28–1.42 变为 1.47–1.63。
  - 即 T51b / T52 所说"模型像素级颗粒略强于真实"来自取样核；按 T51 的连续定义，Noritsu 上的模型颗粒反而**偏弱约 15–30%**，偏差落在胶片侧颗粒量级，不在 σ_o。
- **Frontier**：σ_o 0.91 像素、σ_c 1.75 像素都已充分取样，两种实现只在 0.4 周/像素以上不同（传递 < 0.04）。800T 均匀灰的像素级亮度颗粒差 0.05%，可以忽略。

## 1. 问题：取样核与连续传递（单位脉冲经 `gaussian_filter(mode="wrap")` 的 256 点 DFT，对 e^{−2π²σ²f²}）

| | | 连续 | 0.971 | 0.860 | 0.712 | **0.573** |

- Noritsu 的 |O·U|² 在 0.48 与 0.11 周/像素之比：取样核 **2.40**，连续 **1.03**。
  - T55 在 silvergrain 里测得的输出颗粒谱比为 2.36 / 0.99。
  - 20 µm 像素上的胶片侧颗粒近似白，谱比主要就是这一传递。
- σ ≥ 0.9 像素时两者一致。所以问题只在亚像素的 σ，即 Noritsu 的光学与 USM。
- 引擎里同类的取样核还有 T45 的 `scan_psf`（SCAN_PSF_UM，未开 scan_spatial 时）与传感器孔径方盒（`spatial.aperture`，只在渲染比冲印店细时）。本任务按要求只改 T51 的三项高斯；这两项没动。

## 2. 实现

- `filmlab/scanning/spatial.py`：
  - 新函数 `gauss_mtf(a, s, axes=(0, 1))`：DCT-II 系数乘 e^{−2π²σ²(k/2N)²} 后逆变换。
    - 半样点对称延拓到 2N 后的循环卷积由 DCT-II 对角化，所以它与"整幅反射填充（scipy `reflect`：d c b a | a b c d）后 FFT 相乘再裁回"完全相同（测试到 1e-12），但不需要 4 倍内存。
    - 直流增益严格为 1。
  - `_blur`、`usm`、`chroma_nr`、`apply` 增加参数 `continuous=False`。默认走原来的 `gaussian_filter`，逐位不变。
- `filmlab/engine.py`：`_scan_psf` 在 scan_spatial 分支里，`scan_mtf` 时光学用 `gauss_mtf`；S4f 把 `continuous="scan_mtf" in corrections` 传给 `spatial.apply`。
- `filmlab/generation.py`：`t56_base`、`t56_bw`，以及 `SCAN_SPATIAL`、`BW_PROFILES` 与各表的继承。
- 逐位核对：57 个现有代际 × {CineStill 800T, Tri-X} × {默认, Noritsu, Frontier（仅 t51_*）}，共 122 组，40 × 56 像素，颗粒开。改动前后 SHA-256 全部相同。
- 测试 `tests/test_t56_scan_mtf.py`（15 项）：
  - 连续传递的余弦增益（4 组 σ、f）；
  - 取样核近似恒等（问题本身）；
  - 等价于整幅反射填充；
  - σ 充分取样时与 `gaussian_filter` 一致；
  - 均匀场不变（彩色与黑白）；
  - USM 在 0.45 周/像素吻合 T51 的 U(f)，取样核偏弱 > 0.05；
  - 默认 `continuous=False` 与原实现逐位相同；
  - 代际定义；引擎的 `_scan_psf`；
  - 颗粒关均匀场 t56 = t51（差约 1e-6，来自输出里约 1e-5 的缓变）；
  - 颗粒开时像素级颗粒下降、低频不变。
- 已有测试里列举后代代际的 6 处名单加入 t56_*（与 T51 的做法相同）。

## 4. 引擎域的 σ_o 复核（`tools/eval/t56_engine_fit.py`，结果 `tools/eval/t56/engine_fit.json`）

- T51 的拟合形式是 真实(f) = |U|²·(K·参照(f; σ_o) + N)，N 是每帧自由的白噪声底（扫描仪传感器）。引擎没有 N。
- 这里直接用引擎渲染做参照：
  - t56_bw，20 µm/像素，1024²，EV −1 … +3，每档底片显影一次，再换不同的扫描传递扫描；
  - 用 T51 同一套测量（`t51_scan_measure.measure_array`）；
  - 与 `tools/eval/t51/spec_rpl_bw.json.gz` 的真实谱比较（各 7 帧，按 Do 取最近档）。
- 两种拟合：
  - 引擎域：每帧 K 自由，N = 0，即引擎实际能给出的谱形；
  - "带 N"：每帧 K、N 自由，与 T51 同形。
- 频档为 T51 的 FIT_BINS（0.08–0.45 周/像素）。

| 扫描光学 | Tri-X 引擎域 RMS | 带 N | P(0.48)/P(0.11) | HP5+ 引擎域 RMS | 带 N | P(0.48)/P(0.11) |
|---|---|---|---|---|---|---|
| t51 取样核（7 µm = 0.35 像素） | 0.295 | 0.295 | 2.38 | 0.191 | 0.191 | 2.37 |
| 连续 0 µm | 0.347 | 0.345 | 2.92 | 0.242 | 0.242 | 2.91 |
| 连续 3 µm | 0.301 | 0.301 | 2.41 | 0.197 | 0.197 | 2.39 |
| 连续 5 µm | 0.230 | 0.230 | 1.71 | 0.136 | 0.134 | 1.69 |
| 连续 6 µm | 0.195 | 0.194 | 1.34 | **0.126** | 0.106 | 1.33 |
| **连续 7 µm（t56）** | **0.181** | 0.161 | 1.01 | 0.156 | 0.088 | 1.00 |
| 连续 9 µm | 0.272 | 0.122 | 0.50 | 0.318 | 0.070 | 0.50 |
| 连续 13 µm | 0.768 | 0.080 | 0.07 | 0.844 | 0.044 | 0.07 |
| 真实（帧中位，帧间范围） | | | 1.46（0.81–1.74） | | | 1.82（0.95–2.12） |

- **引擎域最优**：Tri-X 7 µm、HP5+ 6 µm，即 T51 的 7 µm 在 ±1 µm 网格内。连续传递使谱形残差下降（Tri-X 0.295 → 0.181）。
  - 取样核的 0.35 像素其实等效于连续约 3 µm（谱比 2.38 对 2.41）。
- **"带 N"的最优仍在网格上限（13 µm）**，与 T51 fit.json 的黑白留出一致。原因是 σ_o 与 N 简并：N 在光学之后、USM 之前，被 |U|² 抬高，所以替代了高频的颗粒功率。引擎不产生 N，所以引擎该用的是引擎域的结果，不是带 N 的结果。
- **残差的形状**（Tri-X，7 µm，按频档的帧平均 log(真实 / 模型)，0.08 → 0.45 周/像素）：
  - +0.15 +0.08 +0.04 +0.05 +0.01 −0.11 −0.14 −0.16 −0.12 −0.05 −0.01 +0.07 +0.19；
  - 两端偏高、中频偏低，任何单一 σ_o 都消不掉。
  - 低频端可能是真实块里残留的景物纹理（T51b 第 13.3 节的局限）；高频端是 N 一类的白底。不另加噪声（T51 规则）。
- 不能用缩小 σ_o 来补第 3 节的量级：5 µm 时谱形残差升到 0.23，而且量级差在 48 µm 上就有（×1.04–1.18），不只在高频。

## 5. 结论与建议

1. **确认问题**：Noritsu 的光学在引擎里近似恒等（取样核 0.48 周/像素传递 0.93，连续 0.57），USM 在高频偏弱（U 1.82 对 1.91）。T51 的 σ_o 与 U(f) 是按连续传递拟合的。Frontier 不受影响。
2. **实现**：`scan_mtf` 与 t56_*，默认关。现有代际逐位不变。
3. **σ_o 不需要重新拟合**：引擎域连续传递下最优为 7 µm（Tri-X）/ 6 µm（HP5+）。LABS 不改（按负责人指示只报告）。
4. **新的未解释量**：按 T51 的连续定义，Noritsu 上模型的黑白颗粒比真实**弱**。
   - Tri-X：48 µm 弱 4–18%，像素级弱 6–32%，胶片侧 1.13–1.29；HP5+ 胶片侧 1.47–1.63。
   - T51b"Tri-X 残差约 0"的结论依赖取样核，应改为"胶片侧约 1.2"。
   - 候选：T47 的 Tri-X 定标（对 Kodak RMS 颗粒度的孔径换算）、RPL XTOL 的实际颗粒、真实块里的残余纹理。HP5+ 另有晶体群推导（T51b 第 13.3 节）。
   - 下一步应在胶片侧（颗粒定标）而不是在扫描侧找；不在输出端调。
5. 若采用 t56_bw 作为黑白默认，T52（手机尺寸观感）与 T53（颗粒粗细）的 Noritsu 数值应按 t56_bw 复算：像素级颗粒约 ×0.72。

## 6. 局限

- 连续传递作用在已取样的输出上：混叠进基带的颗粒分量按混叠后的频率得到传递，而 T51 的参照是在细网格上先加光学再积分。20 µm 像素上胶片侧颗粒近似白，第 1 节的谱比与 T55 一致，说明影响小，但没有单独量化。
- 引擎域拟合只有黑白两种片、一家冲印店、一个场景；σ_o 网格间距 1–2 µm。
- 真实帧的谱比帧间差别大（Tri-X 0.81–1.74）。

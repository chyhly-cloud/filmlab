# T06：光源颜色与亮度在哪一级被"压向中间"（Claude 执行）

T04 / T05 之后的问题：真实冲印店"遇冷则冷、遇暖则暖"，模型把光源偏色压掉了。本轮逐级追踪，并用预先命名的结构变体在留出集上检验。
所有变体都在验收入口（`accept_t03.scene_job`：next、roll=None、grain=0）上施加，不改仓库生产代码，判定沿用 T05 的留出条件。

工具：
- `tools/eval/light_colour_trace.py`：逐级追踪，结果在 `t06/trace_result.json`；
- `tools/eval/accept_variant.py`：变体的留出验收；
- `tools/eval/t06/*.py`：各项反事实诊断。

## 2. 逐项排除与定位

| 检验 | 结果 | 结论 |
|---|---|---|
| 模型自动校色是否被上限卡住 | 上限 0.6，未触及 | 否 |
| 光源识别（同色异谱）：荧光灯下模型胶片蓝层曝光比光谱积分低 0.1–0.15 | 改为已知光源类别：钨丝改善 ≤ 0.5，灯管反而变差 0.3–1.7 | 存在，但不是主因 |
| 下游增益：蓝层曝光 ±0.1 log | 底片 ±0.065，成片 b* 变化 3–6 | 用于量化 |
| 逐帧定光拆分 | 各通道斜率灰平衡压掉钨丝 / 黄昏的偏色（关掉后：钨丝 b* 22 → 32，黄昏 −10 → −22）；高光肩部无影响；亮度 K 决定 L* | 斜率是偏色压缩的一部分 |
| 不做逐帧定光（固定光号） | 钨丝灯箱 L* 仍为 55（真实 73） | **亮度问题在底片本身，不在冲印店定光** |
| 测光倍数与 T04 实测亮度偏移 x_K | 正相关，训练 / 留出斜率 +0.22 / +0.24，r = 0.36 | 逐帧测光把场景亮度差抹平了 |

灯箱帧的数码曝光全部是同一组 f/11、1/6 s（固定曝光）。可是 `film_metering` 每帧都重新测光，把中心加权平均统一拉到中灰。

## 结论与下一步

- 亮度：最强的线索是**输入端逐帧测光**。它是本轮唯一使光源旁大幅改善（−3.1）、且多数分组同时改善的结构改动。未通过的是白光灯管和色卡，这两组的残差主要在颜色上，不在亮度。
- 颜色：偏色压缩来自两处，一是逐帧定光的斜率灰平衡，二是荧光灯下的同色异谱。单独修任何一处都会让另一类场景变差，还没有找到能同时成立的物理解释。
- current / next 不变；所有变体都未并入任何代际。

## 第二轮（2026-10-31）：彩度与输出调整

**彩度比**（`t06/chroma_ratio.py`，24 px 格子，真实 C* > 10）：模型 / 真实的中位数为 **0.63**（21 个场景，范围 0.27–1.05；黄昏 0.27–0.37）。
偏色被压、蓝块偏紫、色卡发白、黄昏不够蓝，本质都是彩度不足。
例如 R1-32-33 的蓝色色块：a* 模型 +13 / 真实 +11，b* 模型 −21 / 真实 −50。不是红色混入，而是蓝色彩度只剩约四成。

输出调整中的 `SATURATION_MATRIX` 是在他店（SillyStill 5 对）上拟合的经验矩阵：对角线只有 0.77–0.85，非对角为正，实际是降饱和。
它不属于显影物理。

## 第三轮：亮度预言机评估（只看颜色）

胶片每帧的实际曝光在数据中缺失（胶片相机无 EXIF），冲印店又逐帧调整亮度，所以每帧的亮度无法由物理推出。
全图 ΔE 中位被这部分主导，会淹没颜色上的进展。

新评估 `tools/eval/k_oracle.py`：
- 做法：每帧只放开一个亮度自由度 K，按 oracle_timing 的同一损失对准真实扫描后，再算全图 ΔE。颜色光号不放开。
- 判定：条件与之前相同，只看留出集；原全图指标照常报告。
- next 的基准（`k_oracle_next.json`）：auto 平均 11.628（与 T03 基准一致），K 预言机平均 8.581。

| 变体 | 留出变化 | 未通过 | 主要改善 |
|---|---:|---|---|
| `plain` | −0.478 | 平均差 0.022 未达 0.5；钨丝 +1.04 | 黄昏 −4.37、品红 −2.20、白光 −0.53 |
| `fixed_exposure,plain` | −0.496 | 平均差 0.004 未达 0.5；钨丝 +1.12 | 黄昏 −5.27、品红 −1.51、白光 −0.44 |
| `no_satmat` | +0.179 | 白光 +2.12 | 品红 −2.70 |

| `fixed_exposure` | +0.062 | 品红 +0.89 | 颜色上无作用（其改善全在亮度，符合预期） |
| `fixed_exposure,no_satmat` | +0.175 | 白光 +2.20、钨丝 +0.53 | 品红 −2.14 |

结论：

- 原输出调整中的 `LAB_TINT`（中间调偏暖，b* 约 +6）帮了暖光场景、伤了冷光场景。
- 任何固定的结构开关都让冷、暖两类此消彼长。
- 真实冲印店保留的光源偏色差约 40 b*，而模型在各固定配置下都只有约 20。

下一步需要的不是开关，而是对冲印店颜色处理本身的测量（见 T07）。

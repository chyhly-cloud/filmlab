# T46：通用银盐颗粒——多片种官方数据、跨片种通用常数、冲洗工艺与输出端相关（Claude；研究代际）

## 0. 这是一个银盐颗粒模型：从卤化银晶体到最终颗粒

```
 ① 卤化银晶体（每个颗粒 = 一个晶体）
    每层 3 个亚群（快 / 中 / 慢），等效圆直径 ECD 对数正态；形态 T 颗粒（体积 a·t）或立方 / 八面体（a^1.5）；
    位置 = 涂布堆积（比泊松更均匀）；尺寸由该胶片的感光度、设计光源、晶体形态推出（第 3 节）
        │
 ② 曝光：晶体表面的增感染料吸收光子，有效光子数 ~ 泊松(λ)，λ = Φ·η·a·(a/a0)^β·H
        │  （T 颗粒吸收面积 2a，立方体 6a；小晶体量子效率低：β）
 ③ 显影：吸收 ≥ 4 个有效光子的晶体可显影（二项）；灰雾晶体与曝光无关地显影
        │  —— 颗粒的"位置"与"数目"到这里就定了：哪些晶体显影
 ④ 最后一步（只决定颜色、产量与边缘，不产生新的颗粒）：
        彩色片：显影晶体在漂白前原位生成一团染料云（产量随机，伽马分布，CV 由冲洗工艺定；云大小 = 晶体大小 ⊕ 扩散长度 L）
        黑白片：显影晶体变成银丝团，保留银（覆盖力随机，同上）
        │
 ⑤ 叠加成每层密度场 → 扫描仪光学点扩散 → 冲印店定光、数字相纸、输出
```

- 彩色片看到的颗粒，**位置和数量都来自卤化银晶体**（①–③）；染料云只决定这一显影晶体的颜色、染料量与边缘大小（④）。模型不把染料云当成独立的颗粒来源，也不在任何一步另加噪声；输出端没有统计噪声。
- 全部参数以晶体为单位：晶体尺寸分布、晶体数密度（涂布量）、显影阈值光子数、每 µm³ 显影晶体的染料 / 银量。

## 1. 摘要

- **多片种官方数据表**（`tools/eval/t46/films.tsv`，46 种，来源 URL 逐行）：Kodak 电影负片 4 种（每层颗粒度曲线，250D 为本次新数字化）、Kodak 彩色负片 7 种（只给 Print Grain Index）、Fuji 彩色负片 10 种（Fuji 自己的 RMS）、反转片 12 种（Kodak / Fuji，含 Kodachrome）、黑白 13 种（Kodak / Fuji 有 RMS；Ilford 不给 RMS）。进入留一检验的 38 种。晶体尺寸与银量：所有厂家都没有公开数值，只公开晶体类型（T-GRAIN、Σ 晶体、core-shell、传统三维）。
- **通用常数**（第 3 节）：显影阈值 r = 4 光子、T 颗粒厚 0.12 µm、表面吸收（立方 / T 颗粒 = 3）、乳剂结构（5219 标定的亚群结构）是先验；只有 **η = 0.025（1 µm² 处每面积量子效率）与 β = 0.875（量子效率随投影面积的指数）** 由多片种官方颗粒度定。另有两个冲洗工艺常数（E-6 的染料产率 ×5.4、黑白显影银覆盖力 0.68 密度/(g/m²)）和两个测量定义常数（PGI 标度零点、Fuji 负片测法）。
- **留一预测误差**：38 种胶片的 |log(预测/官方)| 中位 0.17（×1.19），RMS 0.21。电影负片 500T / 200T / 250D / 50D 的留一预测为官方的 **0.89 / 0.91 / 0.92 / 0.97**（T45 纯预测：200T 0.80、50D 0.54）。同一组常数下 T45 的做法（β = 0、η 同 5219）为 RMS 0.28，50D 0.60。黑白片是弱项（Tri-X、Plus-X 偏粗 1.3–1.5，T-Max 偏细 0.7–0.8）。
- **最后一步的随机过程**（第 5 节）：每晶体产量随机（复合泊松）占 48 µm 方差的 10–39%；它已包含在 Kodak 的实测颗粒度里，所以不能解释与真实扫描的差距——要让 R、G 变 2–3 倍需要 CV 0.9–2.7，远超物理范围。云大小只影响像素级（6.6 µm）颗粒，不影响 48 µm RMS。
- **冲洗工艺**（第 6 节）：同一 5219 乳剂、同一曝光，C-41 比 ECN-2 的底片 48 µm 颗粒最多高 15%（低曝光 G 层），中间调相当或更低。**C-41 不是 800T 输出端 2–3 倍差距的来源。**
- **800T 输出端差距的定位**（第 7 节）：
  1. 真实扫描的三通道相关**随空间尺度下降**：EPFL Frontier（未压缩 TIFF）R–G 从 7–13 µm 尺度的 0.91–0.98 降到 26–53 µm 的 0.22–0.74；另一家冲印店的 Noritsu 扫描（5 种彩色负片、6 种曝光）同样从 0.9 以上降到 0.56–0.72。线性的通道换算（染料旁吸收、扫描仪色彩矩阵、相纸换算）给出与尺度无关的相关，模型正是如此。所以让通道相关的环节是**扫描后的空间选择性处理**（细尺度的亮度锐化或色度降噪），不是胶片，也不是线性的色彩换算。
  2. 模型输出 R–B 负相关的来源已定位：链条在颗粒尺度上的局部雅可比 ∂Do_R/∂黄染料 为正（+0.08 至 +0.94），即数字相纸 / 输出换算的负交叉项（与 T42 的 R 通道跨通道放大是同一处）。整帧均匀扰动的雅可比因冲印店逐帧定光的补偿给出正相关——颗粒是零均值的局部起伏，不触发定光，所以要用局部雅可比。
  3. 量级：t46 的输出颗粒与 t45 相当（同场景 0.7–1.2 倍），T45 测到的中间调与暗部 R、G 差距（真实为模型 2–3 倍）仍在，它与正相关同源（第 7.4 节）。
- **实现**：`grain.py` 加 T46 三项（量子效率随尺寸、每晶体产量随机、按亚群的染料云），默认值时走 T45 原路径；`grain.derive_spec`（由公开物理量 + 通用常数推导晶体群）；`materials.grain_spec_t46`、`GRAIN_PROCESS`、`GRAIN_PHYS`。代际 **t46_base = t45_base + grain_t46**（= t44_base + 新颗粒）。现有 17 个代际 × 2 像素尺度 × 颗粒 0 / 1 及 t45_base 上 4 种胶片的颗粒，与 git HEAD 逐位相同（第 8 节）。新增测试 13 项，全部 485 项通过。
- **建议**：t46_base 可取代 t45_base 作为颗粒候选；是否定为基准由用户看图后决定；不要改输出端追 EPFL 观感（第 10 节）。

### 2.3 Print Grain Index 能否换算

- Kodak E-58（2000，https://125px.com/docs/techpubs/kodak/e58-2000_07.pdf ）给出方法的三步（负片 R、G、B 颗粒度 → 相纸 R、G、B 颗粒度 → 视觉颗粒度 → 感知标度），但**没有给出公式与常数**；Kodak 专利（US 5,629,769 / 5,709,972）说明标度来自 Bartleson（1985）：颗粒度变化 6% = 2 个单位，即 PGI = C + (2 / ln 1.06)·ln σ_视觉 = C + 34.3·ln σ_视觉。
- 本任务能做的：斜率 34.3 已知，零点 C 不知道。所以只给 PGI 的片按**同一放大倍数（4.4×）之间的差**参与检验：σ_视觉 ∝ √Σ(g_c σ_c)²（σ_c 为负片灰卡处每层 48 µm 颗粒，g_c 为 Kodak 相纸染料的视觉密度），C 作为 1 个族常数由训练片定（留一时不含被预测的片）。核对：同一胶片 4.4× → 8.8× 的 PGI 增量为 +22（σ 比 1.9），与 Selwyn 律下放大加倍 σ 加倍一致。8.8× → 17.8× 的增量 +29 大于面积律（视觉 MTF 的影响），所以只用 4.4×。Ektar 100 的 "<25" 作为不等式。

## 3. 通用常数：用公开物理量推出卤化银晶体群

### 3.1 推导

对每种胶片，只用：感光度 EI、设计光源（决定三个波段的光子数）、晶体形态（T 颗粒 / 三维）、彩色染料或黑白银、自己的特性曲线、冲洗工艺。

1. **绝对曝光轴**：负片与黑白每层净密度 0.1 处 H = 0.8 / EI（ISO 5800 / ISO 6 简化，同 T45）；反转片按 ISO 2240，绿层 Dmin + 0.2 与 Dmin + 2.0 两点曝光的几何平均 H_m = 10 / EI，三层共用同一轴（`grain.exposure_axis`）。
2. **晶体尺寸**：亚群 k 的中位晶体在速度点吸收的有效光子数为通用常数 λ_ck（乳剂结构，取 5219 的 T45 标定：快亚群约 1 个光子、中 0.06–0.1、慢 0.004–0.005——速度点处只有快亚群分布的上尾显影）。由
   Φ_c·η·s·a·(a/a0)^β·H_s = λ_ck 解出投影面积 a（s：吸收面积系数，T 颗粒 1，立方体 3）。
3. **涂布量（晶体数密度）**：由该胶片自己的特性曲线非负最小二乘（同 T45）。
4. **每晶体的染料 / 银量** m = κ·v：v = a·t（T 颗粒）或 a^1.5（三维）；κ 为每种染料的通用值（5219 标定，青 / 品红 / 黄 2.49 / 2.60 / 3.20 密度·µm²/µm³），乘冲洗工艺的产率系数。

由此 5219 本身也不再是"拟合的特例"：它的绝对晶体尺寸同样由 η、β 与自己的感光度推出，留一时由其余片种预测（第 4 节）。仍取自 5219 的是**乳剂结构**（亚群的相对速度、σ_ln、每种染料的 κ、灰雾面积、堆积），这是"现代彩色乳剂都这样设计"的假设（第 11 节）。

### 3.2 常数及其依据

| 常数 | 值 | 怎么定的 | 依据 |
|---|---|---|---|
| 显影阈值 r | 4 个有效光子 | 先验（T45） | 可显影潜影中心约 3–4 个银原子；优良增感乳剂的量子灵敏度为每个可显影晶体吸收 3–6 个光子（James《The Theory of the Photographic Process》第 4 版第 4–5 章；Hamilton 1988） |
| η（a0 = 1 µm² 处每面积有效量子效率） | 0.025 | 多片种官方颗粒度（留一） | = 增感染料单分子层在 100 nm 波段上的平均吸收率（百分之几）× 潜影形成效率（约 0.5）的量级；T45 的 0.05 是假设值 |
| β（量子效率随投影面积） | 0.875 | 多片种官方颗粒度（留一） | 小晶体内光电子与空穴更易复合、潜影分散，量子效率随晶体尺寸上升（Hamilton 1988；Tani《Photographic Sensitivity》1995 第 4 章）；与之相反的大晶体潜影分散在这里的尺寸范围（0.2–2.5 µm）内未见。旁证：5219 的蓝 / 红快亚群 ECD 比的独立拟合值 1.85，介于 β = 0 的预测 2.19 与 β = 0.875 的 1.52 之间 |
| 吸收面积系数 s | T 颗粒 1、立方体 3 | 几何 | 增感染料吸附在晶体表面：T 颗粒两个大面 ≈ 2a，立方体 6a |
| T 颗粒厚度 t | 0.12 µm | 先验（T45） | Kodak T-GRAIN 公开描述为"薄平板"，0.1–0.2 µm 量级 |
| 乳剂结构 λ_ck、σ_ln、κ_染料、a_f、S0 | 5219 的 T45 标定 | 一种胶片 | 假设所有现代彩色乳剂按同一结构设计；第 11 节 |
| 显影银 κ_Ag | 1.86 × 1.36 = 2.52（覆盖力 0.68 密度/(g/m²)） | 黑白族常数 | 显影银覆盖力文献范围约 0.4–1 密度/(g/m²)（随显影液、晶体大小变） |
| E-6 产率系数 | 5.4（κ = 13–17） | 反转族常数 | E-6 彩色显影把第一显影后剩下的晶体全部显影、成色剂过量；负片成色剂不足（coupler-starved）且有 DIR 抑制，κ = 2.5–3.2 只有 2 当量成色剂理论上限（约 86）的 3–4%，E-6 为 16–20%，都在物理上限以内 |
| PGI 零点 C、Fuji 负片测法系数 | 6.06；0.63 | 测量定义 | 不是物理量，只换算测量定义 |

**按片种调的量**：没有。每片种只有公开物理量（EI、光源、形态、曲线、工艺）。

- **弱项**：
  - 黑白：传统三维（Tri-X、Plus-X）系统偏粗，T 颗粒（T-Max、Acros）偏细。T 颗粒与三维晶体的差别仍被高估约 1.6 倍（σ）。β = 0 时黑白反而更好（0.20），说明三维晶体的量子效率随尺寸变化与 T 颗粒不同；没有加第二个 β（第 11 节）。
  - Gold 200、Superia 100 / Reala、RTP II 实际比预测粗约 1.35 倍：都是较老或消费级的设计，与"现代乳剂同一结构"的假设不符。

## 5. 最后一步的随机过程（显影晶体 → 染料云 / 银丝团）

T45 的最后一步是确定的：每个显影晶体的染料量只按尺寸档取固定值，整个涨落场统一做 σ = 1 µm 的高斯。T46 改为：

1. **每晶体产量随机**：N 个显影晶体（某尺寸档、某像素）的总染料 / 银量 ~ Gamma(N/CV², m·CV²)，即每晶体产量独立、均值 m、变异系数 CV 的伽马分布之和（复合泊松）。均值与颜色不变，方差中每晶体项乘以 1 + CV²。
   - 物理来源：成色剂油滴分散的局部浓度（云体积内的油滴数为泊松）、显影中心数与部分显影（大 T 颗粒不一定显影完全）、银丝团疏密（黑白覆盖力）。
   - 文献：J. Photogr. Sci. 33(4)（1985，"The Noise-Power Spectrum of Colour Negative Film with Incorporated Couplers"）发现高斯轮廓的染料云与显微照片最符合，且需要两种云尺寸才能拟合功率谱——即云大小确有分布；J. Photogr. Sci. 40(4)（1992）与 44(4)（1996）用成色剂涂布量改变云大小、由显微照片 / MTF / 功率谱估计云轮廓。**没有找到单个染料云产量的变异系数的公开测量**，所以 CV = 0.3（伽马）是量级估计，放在工艺参数里（C-41、ECN-2、E-6、黑白同值——没有可区分各工艺的公开数据）。
2. **云的大小随晶体**：每个亚群单独展开，高斯 σ_k = √((ECD_k/4)² + L²)：ECD/4 为显影晶体圆盘的二阶矩，L 为氧化显影剂 / 成色剂的扩散长度（工艺参数：彩色 1.0 µm——T45 由 EPFL 扫描颗粒自相关定的 1 µm 量级；黑白银丝团 0.2 µm）。5219 的 σ_k = 1.01–1.17 µm（大晶体的云更大）。不再对整个场统一做一个高斯。
3. **银丝团形态**：只做到对颗粒度统计有影响的程度——覆盖力随机（产量项）与空间范围（L），不画丝状形状（形状只改变亚微米尺度，48 µm 与 6.6 µm 像素都看不到）。

**定量**（5219，C-41，`scratchpad/t46/work/decomp.txt`）：

| 层 / 净密度 | σ48 ×10³（全部） | 无产量随机 | 产量项占方差 | σ 变 2 倍需要 CV | 3 倍需要 |
|---|---|---|---|---|---|
| R 0.1 / 0.5 / 1.0 | 9.4 / 9.0 / 8.7 | 8.9 / 7.6 / 7.0 | 10% / 28% / 36% | 1.7 / 1.0 / 0.9 | 2.7 / 1.6 / 1.4 |
| G 0.1 / 0.5 / 1.0 | 10.6 / 9.7 / 9.6 | 10.1 / 8.0 / 7.5 | 10% / 32% / 39% | 1.7 / 1.0 / 0.9 | 2.7 / 1.5 / 1.4 |
| B 0.1 / 0.5 / 1.0 | 19.3 / 18.8 / 17.4 | 18.2 / 16.5 / 14.4 | 11% / 23% / 32% | 1.6 / 1.1 / 1.0 | 2.6 / 1.8 / 1.5 |

- 产量项在高密度更重要：涂布致密（S0 ≈ 0）时"哪些晶体显影"的二项项 p(1 − p) 在 p 大时变小，产量项 ∝ p 不变小。
- 云大小：48 µm 孔径对 1 µm 的云不敏感（< 0.1%）；6.6 µm 像素级 σ：按亚群的云（含产量随机）R / G / B 58 / 63 / 122，无产量随机 50 / 53 / 107，L = 3 µm 时 42 / 46 / 87（×10³）。
- **能否解释 800T 真实扫描多出的 2–3 倍 R、G 颗粒：不能。**
  1. Kodak 的 RMS 是对显影后底片的测量，已经包含产量随机；T46 的 η、β 由官方颗粒度定，产量项只是把同一个总方差重新分配。
  2. 即使忽略这一点，要让 σ 变 2 倍需要 CV 0.9–1.7，3 倍需要 1.4–2.7——相当于有的晶体产量是平均的几倍、很多晶体几乎不出染料，与单一染料云的显微观察（高斯轮廓、两种尺寸）不符。
  3. 各层仍独立，产量随机不产生三通道相关。

## 6. 冲洗工艺

- 模型里冲洗工艺有两条路：显影化学（`chemistry.run`：显影程度、推拉、DIR，决定哪些晶体显影，即平均密度 d）与最后一步（`GRAIN_PROCESS`：产量 CV、扩散长度 L、产率系数 κ）。
- **C-41 与 ECN-2（同一 5219 乳剂、同一曝光；t46，6.6 µm/像素，底片 48 µm σ ×10³）**（`scratchpad/t46/work/chain.json`）：

### 7.3 模型的通道换算与量级（`scratchpad/t46/work/chain.json`、`uni.json`、`perch.json`）

### 7.4 定位结论

| 候选 | 检验 | 结论 |
|---|---|---|
| C-41 与 ECN-2 | 同一乳剂、同一曝光，底片颗粒最多 +15%（第 6 节） | 不是主因 |
| 最后一步的随机（产量、云大小） | 已含在 Kodak 实测里；要 2–3 倍需 CV 0.9–2.7（第 5 节）；不产生相关 | 不是 |
| 模型的印放 / 相纸通道换算 | 局部雅可比有负交叉项，解释模型的 R–B 负相关（7.3） | 是模型 R–B 负相关的来源；但不能产生真实的正相关与多出的 R、G |
| 冲印店扫描后的处理 | 真实相关随尺度下降，两家冲印店、两种扫描仪、五种彩色负片都如此；线性换算给出与尺度无关的相关（7.2） | **是**真实三通道正相关的来源；多出的 R、G 颗粒与相关同源（细尺度把各通道拉向同一亮度，蓝层的粗颗粒进入 R、G） |

胶片三层颗粒物理上独立，这一点不变；链条中让它们相关的是扫描后的空间选择性图像处理（亮度锐化或色度降噪），它不是胶片物理量。要把它作为物理量加入，需要同一底片在 Frontier 与不做处理的扫描仪上各扫一次，测出处理的频带响应（T45 第 9 节的建议仍适用）；按 EPFL 输出直接拟合一个空间滤波属于输出端调色，本任务不做。

## 8. 实现

## 10. 结论与建议

1. **银盐颗粒模型可以跨片种通用**：每种胶片只用公开物理量（感光度、设计光源、晶体形态、特性曲线、冲洗工艺），通用常数中只有 η、β 由官方颗粒度定。38 种胶片的留一预测误差中位 ×1.19；电影负片 0.89–0.97（T45 纯预测 200T 0.80、50D 0.54）。不再逐片调 η。
2. **量子效率随晶体面积上升（β = 0.875）**是 T45 慢片偏细的物理解释：慢片晶体比"面积 ∝ 1/感光度"大，官方颗粒度随感光度只按约 EI^0.27 变化。
3. **冲洗工艺**：E-6 的染料产率约为负片的 5.4 倍，解释反转片同感光度颗粒更粗；C-41 对 ECN-2 的底片颗粒差 ≤ 15%。
4. **最后一步的随机过程**已按晶体实现（伽马产量、按亚群的云大小），占 48 µm 方差的 10–39%，但不改变总量（已在官方数据里），不产生相关，不能解释 800T 的差距。
5. **800T 输出端差距**：不是胶片、不是 C-41、不是产量随机。真实三通道正相关来自扫描后的空间选择性处理（两家冲印店、两种扫描仪、五种彩色负片都显示相关随尺度下降）；模型的 R–B 负相关来自数字相纸 / 输出换算的负交叉项。
6. **建议**：
   - t46_base **可以取代 t45_base 作为颗粒候选**：同一套物理链，档案改为跨片种推导，留一误差更小，反转片与黑白不再明显偏离（T45 的反转片颗粒只有官方约 1/7，且 HEAD 上反转片颗粒会内存耗尽）；颗粒关闭时与 t45 / t44 逐位相同，研究惯例 grain=0 不受影响。
   - **不建议据此改动输出端去追 EPFL 的颗粒观感**：差距在冲印店处理，需要同底片的中性扫描对照后，把处理作为扫描仪的空间响应加入。
   - 是否把 t46_base 定为研究基准，由用户看多片种 100% 图与 EPFL 三列后决定。
7. **下一步**：同底片 Frontier / 中性扫描对照（定冲印店处理的频带响应）；黑白三维晶体的量子效率尺寸关系（现在 T 颗粒与三维差别高估约 1.6 倍）；找较老 / 消费级乳剂的结构数据（Gold 200、Superia 100 偏粗）。

## 11. 局限

- **晶体尺寸与银量没有公开数据**：所有厂家只公开晶体类型。模型的晶体尺寸是由感光度与通用常数推出的，无法直接检验；5219 推出的快亚群 ECD 1.8–2.4 µm、Tri-X 约 1 µm 在常识量级内。
- **乳剂结构取自 5219**（亚群的相对速度、σ_ln、每种染料的 κ、灰雾、堆积）。较老或消费级的片（Gold 200、Superia 100 / Reala、RTP II）系统偏粗约 1.35 倍，说明结构并不完全通用。
- **β 对黑白不理想**：T 颗粒与三维晶体的差别被高估约 1.6 倍；没有为三维晶体另设 β（会多一个常数）。
- **族常数**：PGI 零点、Fuji 负片测法、E-6 产率、黑白覆盖力各 1 个，留一时都在训练片上定；只给 PGI / Fuji RMS 的片只检验了片间比值，不检验绝对量。PGI 用的是 Bartleson 标度斜率与简化的相纸视觉权重，未含视觉 MTF（只用 4.4×）。
- **代用曲线**：没有仓库曲线的 19 种片用同厂同类的曲线，只换感光度；黑白都用通用全色曲线（仓库没有 Tri-X / T-Max 的实测曲线）。
- **最后一步**：CV = 0.3 与工艺间相同是估计，没有单个染料云产量的公开统计。
- **数字化**：250D 自动跟踪（叠图核对），误差约 ±5%。
- **真实扫描**：Noritsu 的 µm/像素 依赖画幅假设，且为 4:2:0 JPEG；两家都是冲印店输出，没有未经处理的扫描。7.2 节的结论（空间选择性处理）不依赖这些，但它的具体形式（锐化还是色度降噪、参数多少）需要同一底片在中性扫描仪上的对照扫描。

## 负责人结论

审核范围：46 种胶片的官方数据表、通用常数与依据、38 种留一检验、冲洗工艺项、最后一步的随机过程、多尺度通道相关分析、485 项测试（通过）、72 组逐位核对、多片种整图与 100% 图、EPFL 三列对照。

1. **通用银盐颗粒模型成立。** 颗粒的位置和数量全部来自卤化银晶体；没有逐片种调的量。由官方颗粒度定的常数只有两个（η、β），各有物理解释。38 种胶片留一预测 |log 误差| 中位 0.17（×1.19），电影负片 0.89–0.97（T45 为 0.54–0.80）。多片种 100% 图上，颗粒粗细按感光度和冲洗工艺排列，与常识一致。
2. **已知弱项**：黑白片中 T 颗粒与三维晶体的差别被高估约 1.6 倍；较老或消费级彩负（Gold 200、Superia）偏细约 1.35 倍；Portra 800 偏细；染料产量 CV = 0.3 是量级估计，没有显微测量。
3. **800T 输出端颗粒差距定位到冲印店扫描后的空间处理。** 真实扫描（Frontier 与 Noritsu 两种机器）的三通道相关在细尺度上很高、到粗尺度下降，模型与尺度无关。胶片三层物理上独立，线性色彩换算也给不出随尺度变化的相关，所以来源是扫描后的细尺度处理（锐化或色度降噪）。C-41 冲洗和最后一步随机项都已定量排除。
4. **t46_base 取代 t45_base，作为颗粒候选。** 颗粒关闭时与 t44 逐位相同，研究渲染惯例 grain=0 不受影响。
5. **下一步（可选，由用户决定）**：冲印店扫描的空间处理是冲印店属性，和 T07（定光）、T44（黑位）同类。胶片侧颗粒现在已经独立预测，真实与模型颗粒在各空间尺度上的谱比，就是扫描处理本身，可以像 T44 那样实测并留出检验。

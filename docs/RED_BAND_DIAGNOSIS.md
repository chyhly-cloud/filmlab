# 红带诊断：光源周围的颜色与空间分布（Claude, 2026-10-24）

工具 `tools/eval/red_band.py`：在真实扫描几何里，以传感器饱和区（灯芯）为原点按距离（胶片 µm）分档，只取光源最密集处 ±1.8 mm 的窗口，
比较真实扫描、模拟成片、模拟输入（RAW）与模拟胶片红层的"光晕增量 / 直接曝光"。next 代际、自动定光、标称胶片、grain=0。
有效窗口: R1-00-1、R1-03-4、R1-04-5、R1-07-8（R1-02-3、R1-05-6 的窗口落在整片过曝的亮区，不含信息）。

## 观测（真实扫描，红色度 r = R/(R+G+B)）

| 场景 | 红带位置 | 红带外侧 |
|---|---|---|
| R1-00-1 | 150–400 µm，峰 r 0.69 @ 300 µm | 500 µm 起回到偏青 (r 0.23–0.39) |
| R1-03-4 | 150–300 µm，r 0.57–0.59 | 400 µm 起转为蓝 (b 0.37–0.54) |
| R1-04-5 | 200–400 µm，r 0.57–0.61 | 700 µm 起回落 |
| R1-07-8 | 本窗口无红带 | 蓝 |

真实红带的位置与片基全反射几何（2·t·tanθc ≈ 235 µm 起）一致；**宽度很窄，约 400–500 µm 外即消失**。灯芯 ≤ 100 µm 处真实已带红 (r 0.37–0.47)，模拟为纯白。

## 模拟的偏离与来源

1. **光晕延伸过远**。现行核把 42% 的光晕能量放在 400 µm 以外（14% 在 700 µm 以外）；红层"光晕/直接"在 500–1000 µm 仍为 0.6–1.9。
   原因（物理遗漏）：`halation_kernel` 按角度分配到达片基的漫射光时，对所有角度用同一个（垂直方向的）乳剂透射率；
   斜射的光在乳剂里路程为 1/cosθ 倍，应衰减 10^(−D·(1/cosθ − 1))。D 取到达片基的红层密度（emulsion_stack 已有，0.53）的一半到全部
   （散射发生在乳剂中段到顶部），**不需要拟合**。加入后：>700 µm 能量 14% → 1–4%，光晕总量 ×0.40–0.59。
   检验（150–1500 µm 红色度相对真实的 RMS 差，现行 / D=0.27 / D=0.53）：R1-00-1 0.236 / 0.181 / 0.151，R1-03-4 0.431 / 0.387 / 0.365，
   R1-07-8 0.407 / 0.361 / 0.330；R1-04-5 0.101 / 0.111 / 0.134（该处红带变得偏弱）。3/4 场景改善，外围亮度也更接近真实。
   这也与此前 T01 光晕强度被推向下限、以及（已撤销的）"光晕偏强"迹象方向一致——但现在有了具体机制。
2. **远处的暖色不是光晕**：700–1500 µm 处模拟仍偏橙 (r 0.4–0.6)，而真实为青蓝。模拟输入 (RAW) 在这些区域本身就是暖色 (r 0.6–0.7, b ≈ 0.02–0.12)，
   来自暖色灯照亮的场景 / 数码镜头眩光。真实胶片把它们印成青蓝——这就是此前"夜景不够蓝"的问题，与光晕无关。
3. **灯芯纯白**：≤ 100 µm 模拟平到白，真实保留红色——扫描高光肩部 / 白平台的问题（`SHOULDER_ABLATION.md`）。

## 建议
- 第 1 项是有物理依据、可独立实现并验收的修正候选（任务 T03，按层计算 D，只改光晕核）。
- 第 2、3 项是不同的问题，不在 T03 内处理。

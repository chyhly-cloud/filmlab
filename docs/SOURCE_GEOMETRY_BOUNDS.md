# 未知灯芯空间分布的条件边界

目的：区别“几个空间模板没有找到解”和“当前固定源支持内，任意非负重新分配能提供多大变化”。
不拟合材料、扫描或真实光晕。工具为`tools/eval/source_geometry_bounds.py`。

## 解析关系

对固定传播核与两组接收权重，每个源单元i在近、远区域的单位响应为n_i>0、f_i≥0。
任意非负源s的远/近返回曝光比为：

```
R(s) = sum(s_i f_i) / sum(s_i n_i)
     = sum(w_i f_i/n_i),  w_i=s_i n_i/sum(s_j n_j)
```

因此它位于各源位置f_i/n_i的最小与最大值之间。
若另固定源总输入M，并施加逐位置相机代理删失下界l_i，则s=l+u、u≥0、sum(u)=M−sum(l)。
线性分式的极值在单纯形顶点达到；可直接枚举`l+(M−sum(l))*e_i`求精确有限支持界，
不需要再次优化或扫描亮度参数。

接收权重由原25µm平均和固定双线性投影的伴随算子生成；采用零边界卷积，保留原有限画幅语义。
三个测试独立核对非对称卷积的伴随恒等式、分式边界对任意混合的覆盖/顶点达到、尺度不变与不可行总量拒绝。

## 本次条件结果

沿用两处灯严格四CFA失测的88/34个单元、原谱形/传播核与上轮输入总量，
近区为原50–300µm训练＋留出采样，远区为原300–800µm外缘采样。
红层新增返回曝光的远/近比：

| 灯 | 原空间轮廓 | 任意非负轮廓、同总输入且满足代理下界的范围 | 最多降低 |
|---|---:|---:|---:|
| 近顶灯 | .20017 | .18327–.29620 | 8.44% |
| 中顶灯 | .26301 | .23702–.35810 | 9.88% |

允许最极端的光集中到一个单元，仍只有上述降低幅度；这些极端图并不自动代表可实现的灯具或已测镜头PSF。
不固定总输入的纯非负必要界最小值为.18294/.23623，同样不能任意削掉远尾。
这与有限模板试验互补，说明**在这一固定支持与固定模型中，改变源内部轮廓对远/近返回比例的杠杆有限**。

## 不能从中推断什么

- 数值是现有引擎红层返回曝光比，不是最终RGB色差或实测真实光晕。
- 真实图相对模型的残差不能直接充当所需返回曝光，故这里没有给真实800T“不可能”的证明。
- 改变未恢复源的支持范围、角分布、谱形、背景或响应模型，会改变上述条件问题。
- 本轮仅移除再替换88/34个严格四CFA失测单元。支持外的部分饱和和可测发光边缘仍沿原RAW重建、
  局部照明与曝光路径；同饱和分量至少另有4/2个RGB三标志全真但非四CFA全饱和的单元未替换。
  缓存不能量化整个灯具所有外侧单元，因此该界不能排除整个灯具辐射场的空间或光谱结构偏差。
- 相机下界使用CIE/解码代理；没有获得独立G81谱感度或绝对辐射标定。
- 不据此自动调整核宽度、尾部或吸收系数，也不把三层曝光相加当作光能。

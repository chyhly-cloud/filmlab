# 走廊光晕的RAW源信息依赖（2026-10-20）

## 问题与实验

检验R1-02-3近/中顶灯、玻璃反光外围的模型返光，来自哪些传感器信息区域。
使用与现有局部审计相同的next_sensor、RAW解码、固定随机种子、测光及光谱推断。
在S1捕获原直接曝光与halo_source后停止；不进行新的显影、扫描或调光。

用原传感器逐通道饱和掩膜把源像素划成互不重叠的三类：

- unflagged：三个传感器通道均未被饱和判定标记；
- partly_saturated：至少一个通道饱和，但不是三个全饱和；
- fully_saturated：三个通道全饱和。

三类分别用同一原光晕核、同一多次返回权重卷积。逐通道验证它们相加等于未分解的模型返光。
接收区域使用brightness-local已有的未饱和周边掩膜、距离及真实线性Y分区。
0–300/300–800µm均为名义36mm片幅换算；近灯以旧传感器core掩膜为边界，另两处为旧人工中心排除盘。
这些不同边界的径向数字不作为精密实测灯芯尺寸的比较。

## 结果

原生半尺寸画面共有3,990,528个源像素：未标记3,913,023，部分饱和42,509，全饱和34,996。
全画面只有约1.94%的源像素被至少一通道饱和标记，但局部返光对它们的依赖大得多。
三类返光相加的逐通道相对L1误差最大1.03e-15（全帧验证），因此分解没有丢失原模型的返光。

以下是灯外0–300µm、既有未饱和接收掩膜中，各类源对返光曝光总量的份额。
三通道分别统计，不把R+G+B曝光单位当光学能量相加。

|区域|源类别|R返光份额|G返光份额|B返光份额|
|---|---|---:|---:|---:|
|近顶灯|未标记|32.62%|34.46%|34.95%|
|近顶灯|部分饱和|18.78%|18.31%|18.17%|
|近顶灯|全饱和|48.60%|47.23%|46.88%|
|中顶灯|未标记|62.60%|65.18%|65.78%|
|中顶灯|部分饱和|19.03%|18.48%|18.17%|
|中顶灯|全饱和|18.38%|16.34%|16.05%|
|玻璃反光|未标记|39.45%|38.93%|41.69%|
|玻璃反光|部分饱和|15.15%|14.32%|13.72%|
|玻璃反光|全饱和|45.40%|46.75%|44.59%|

在真实仍处于亮度过渡区Y=.4–.85的接收像素中，结论相同：
近灯R/G/B返光来自至少部分饱和源的比例为67.60/65.76/65.27%；
中灯为38.08/35.56/34.97%；玻璃为64.82/65.89/63.08%。

到300–800µm，未标记源的返光份额增加：
近灯R/G/B约62.25/68.35/69.35%，中灯78.21/83.77/84.19%，玻璃50.08/51.54/54.31%。
所以不能把整个远晕都视为从未知灯芯产生，也不能把中灯所有缺红归因到饱和灯芯。

## 解释和限制

1. 近灯及玻璃的G/B返光同样大半由传感器饱和源像素的模型信号产生。
   这意味着“去掉G/B返光”的实验若有效，还须检查这些信号有多少依赖旧高光先验，不能立即推导真实乳剂不应有G/B返光。
2. 中灯多数返光来自无饱和标记的源，说明源饱和不确定性不是统一解释。
3. 份额是某一返光通道的来源分配，不等于该返光足以改变输出颜色：还要看其相对该通道直接曝光的幅度。
4. 当前HIGHLIGHT_RECON为prior；部分饱和像素中原本未饱和的通道也可能被重建覆盖。
   “部分饱和”不表示整个RGB均是未知，也不能说其中保留的实测通道必然直接约束了当前模型值。
5. 无标记源仍使用处理后的RGB、光源分类及光谱重建，不是实测SPD；高光处理的膨胀邻域也可能覆盖部分无饱和标记像素。
6. 每个ROI可能接收其他灯及反射表面的贡献。这里量化的是同一现有模型的依赖，不是真实灯具孤立的光晕贡献。
7. 没有改变任何先验、常数、核尺寸、扫描曲线或正式代际，也没有根据真实扫描反推丢失灯芯的强度。

## 返光占总曝光的幅度约束

来源份额之外，再统计每通道 `sum(halo) / sum(direct + halo)`；不跨通道相加。
以下仍为0–300µm全部有效周边接收像素：

|区域|R返光/总曝光|G返光/总曝光|B返光/总曝光|额外曝光EV中位数 R/G/B|
|---|---:|---:|---:|---|
|近顶灯|27.40%|2.71%|.000909%|.609 / .0493 / .0000159|
|中顶灯|14.17%|1.22%|.000429%|.332 / .0244 / .00000834|
|玻璃反光|26.82%|3.60%|.001722%|.739 / .0762 / .0000292|

在真实Y=.4–.85的亮度过渡区，G占比分别2.84/1.42/5.27%，B仍仅约.00095/.00050/.00210%。
因此，本模型在这些位置的返光已很偏红层，B返光本身几乎可忽略。
不能仅凭RGB各自来源份额相似，就说“RGB三层返光都很强，因而一起冲白”。
G的几个百分点是否因后续非线性而产生可见影响，须由固定定光的去G/B返光对照判断。
这里不能用小曝光份额证明其最终颜色影响严格为零。

每像素EV是在局部warp后的线性直接/返光量上计算，再取中位数；与先计算EV再warp的旧stage数组
可能有少量插值次序差异，不能把它们视为逐像素相同的运算。
源依赖图为 `source_dependency.png`；它显示返光来源，而不是三通道绝对能量或真实灯具恢复质量。

# 固定负片的五场景色彩策略实验

继日间/蓝调灰平衡审查，本轮重新取得五个场景的完整native扫描密度，避免先投影密度再扫描的近似。固定同一负片、材料、显影、输入、K、s、指数肩部、数字相纸及无输出调色条件；仅改变颜色仿射M。正式current、next均未改。

## 预先声明的范围

两张主诊断：日间咖啡馆、R1-07-8蓝调。三张回归控制：R1-06-7草地、R1-02-3走廊、R1-00-1校园建筑。五个策略在读取目标成绩前固定：

- saved_two_point：原逐帧两点/LATD算法。
- no_M_diagnostic：撤销M，只作隔离诊断。
- us6160634：已有专利示例三估计混合，近中性选取相对帧中位色。
- us6160634_axis：已有专利解释的相对标准灰轴选取。
- fixed_film_design_gray：以本帧引擎中该胶片设计光源的中灰作为固定颜色参考，M=(-gray_colour,1)。这是计算参考，不是实测灰卡或真实冲印店设置。

没有搜索权重、0.2阈值、颜色矩阵、DIR、感光度或肩部，也不按目标扫描选算法。专利示例只说明候选来源，不证明实际Frontier使用该算法。这里颜色策略沿用旧候选，新增的是同一native负片、固定其他定光条件和这五场景的共同验收，而非宣称发现新算法。

## 结果

固定几何远区24px稳定格，样本数依次498/795/23/696/137；这些不是全部画面，也不等于纯直接光。格位置和真实稳定性筛选与模型误差无关。表中为各格ΔE00的场景中位数，越小越好：

|场景|原逐帧|撤销M诊断|专利中位参考|专利灰轴参考|固定胶片中灰|
|---|---:|---:|---:|---:|---:|
|日间咖啡馆|24.69|23.68|23.74|23.82|23.17|
|蓝调道路|10.04|7.72|9.45|8.85|6.71|
|草地建筑|19.94|17.35|23.92|21.82|14.90|
|走廊|4.73|9.76|4.77|3.94|6.47|
|校园建筑|17.56|9.55|13.70|13.62|8.14|

固定胶片中灰使主诊断两张及校园ΔE00和ab二维距离都改善，但走廊两指标均退步。草地ΔE00虽下降，ab二维误差中位数22.46→25.50反而增加，不能报告为整体颜色修好。草地仅23个受控远区格，不代表上轮指定前景草块，也不与此前局部中位b*直接混用。

日间咖啡馆固定中灰后仍有约−22.11 L*、−7.21 a*、−15.20 b*的残差中位数，严重过暗、偏青蓝未解决。蓝调残差约+3.42/−9.67/+2.86，蓝黄方向好很多，但绿方向仍错；真实扫描蓝紫与模拟青蓝的区别仍存在。

专利灰轴参考使走廊/蓝调改善，但草地退步。所有策略均未在五场景同时通过完整ΔE00和ab颜色距离两项“不退步”检查。没有以平均分掩盖退步，也未根据这五张图设计按场景切换规则。

## 核验及结论边界

原M重算误差为0；完整native输出先扫描后单次配准，五图相对原线性缓存的最大差0至5.92e−8。K/s/肩部字段逐候选精确冻结。五个场景的native Dn分别仅准备一次，各策略共享，未再显影或改负片。旧的先投影密度近似草地未通过门槛，本轮不复用那个近似。

由此可确认：逐帧灰平衡是场景相关色差的重要模型环节，固定参考有可见改善但不是通用修正。结果不证明显影物理已经准确；也不证明真实冲印店应该固定中灰。现有同一批扫描多次使用，三个回归场景不是新外部盲测。输入光源估计、真实扫描设置、材料非中性响应仍需分别约束。

保留所有候选及完整对比，暂不采用为默认。后续若研究新灰平衡，重点是中性参考的可信度而非凭昼夜标签套颜色；必须同时验收日间、蓝调、走廊和草地。日间严重亮度残差应另审查曝光/亮度依据，不在本轮调整K追回。

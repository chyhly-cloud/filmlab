# 固定扫描密度矩阵与精确虚拟印放积分（2026-10-20）

## 结论

固定P矩阵确实会改变非中性密度响应，而且误差随染料组合和密度变化。
同一负片改用精确相纸光谱积分，走廊近顶灯的橙红方向有所改善，但中顶灯没有一致改善，
白晕也未恢复为真实紧凑的橙红过渡。因此不能把P作为唯一主因，更不能据此认定已修正Frontier输出。

这里的“精确”只针对**当前模型假定的光学印放过程**。实际Frontier是否执行相纸式转换、
使用什么光谱响应和设备LUT，仍没有测量证据。
P本来就是按通用Portra材料拟合的近似；它不等于精确印放，不自动构成程序错误。

## 无拟合对照

相同模拟负片T(λ)，原路径为：

```
Dn_matrix = ((Dscan(T) - Dscan(Tbase)) @ P) * gain
```

对照直接计算：

```
S_paper(λ,c) = TH-KG3(λ) * 10**paper.log_sensitivity(λ,c)
D_print_exact(c) = -log10(sum(T*S_paper) / sum(Tbase*S_paper))
Dn_exact = D_print_exact * gain
```

Tbase由同一引擎的未曝光片头透射谱计算，与扫描去片基使用同一基准。
随后gain、K/s/M、指数肩部（以及既有paper_only对照）、相纸特性曲线、相纸染料光谱、
输出黑点全部不变。没有重拟合矩阵、调整曝光或重新自动定光。
精确路径不经过窄带扫描测量，因为这是检验窄带→宽带代理的理想信息上限，
**不是声称真实扫描仪能从三个观测值唯一重建81波长透射谱**。

## 受控负片检验

以同一Tbase叠加已知光谱中性吸收，不需要任何乳剂感光或显影假设。
若吸收密度为1D，宽带精确密度必为[1,1,1]；固定P给出[.95457,.97909,.88234]（均未乘gain）。
误差分别−.04543/−.02091/−.11766D。
在2D中性吸收时，误差按比例为−.09086/−.04181/−.23532D。
这证明此P不是保持中性光学密度的通用印放变换；不能把其满秩误认成物理颜色正确。
但设备软件可能有意执行其他变换，故这不是对真实Frontier的实测反证。

另用同一模型CD-4染料谱构造已知染料量：

|染料量CMY|P给出的R印放密度|精确R印放密度|P−精确|
|---|---:|---:|---:|
|[.2,0,0]|.15503|.19883|−.04380|
|[1,0,0]|.75996|.86426|−.10431|
|[2,0,0]|1.47603|1.29396|+.18207|
|[0,1,0]|.24382|.08614|+.15768|
|[.2,1.5,.4]|.52392|.33855|+.18537|

这些是指定染料谱下的数学对照，不是新测得800T材料。
宽带密度是“先对透射率积分再取log”，对浓度通常非线性；一个固定线性P无法精确表达所有染料组合。
误差能变号，故不能用统一红色增益补偿。

## EPFL固定局部验收

复用亮度审计保存的原生裁切81波长负片密度；无需重解码RAW或重新显影。
三处同一geometry，next_sensor、同CRC种子/roll/frame、grain=0、conditioning=None。
保存D为float32，重算原路径与原局部最大线性RGB误差≤7.24e-8。
基于真实亮度分区和原未饱和周边掩膜，固定定光，线性RGB只在显示时编码。

近顶灯12.85→14.92、中顶灯8.05→8.56、玻璃反光23.46→31.44。
因此P可削弱这组模型内红响应，但削弱幅度/方向因背景不同而变，
并非把红晕统一压到零，也没有解释所有空间/颜色差异。
这些差分不是测得的真实乳剂红导数。

paper_only也已在相同负片/光号下运行并保存，不因其某项较好就选新扫描候选。
current/next/paper_only正式路径不变，实验只在工具中实现。

## 追加：中性光学密度守恒的受约束矩阵

按原算法相同seed=0、2000个Portra虚拟染料样本，加入每列和为1的约束重新求最小二乘：

```
P_neutral = [[ .83729575, -.01780828, .08924650],
             [ .14506898,  .91106124, .18878907],
             [ .01763527,  .10674705, .72196443]]
```

使用零列和基B参数化P=ones(3,3)/3+B·Q后求线性最小二乘，没有真实照片参与。
这约束有独立数学依据：中性光谱吸收d在每个宽带通道都应增加d密度。
它只约束乘gain之前的印放密度；保留的档案gain本来就按通道不同，不能声称最终RGB中性。
新增测试检查列和、允许零和扰动下的最小二乘残差正交、中性输入恒等。
目前4项测试通过。

1D中性吸收下受约束结果为[1,1,1]，修复了此光学代理的恒等式。
代价是原2000样本的印放密度RMSE从.09768D增至.14343D。
固定线性矩阵受表达能力限制，满足一个物理极限并不让它逼近所有非中性负片。

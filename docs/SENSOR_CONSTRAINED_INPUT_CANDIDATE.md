# 实测通道保持：输入候选与实际退步

本轮针对用户的 DSC03906 失败案例实现独立输入工具，不修改生产模块、`current`、`next`、扫描曲线或材料参数。
问题与旧链路追踪见 [USER_RAW_HALATION_FAILURE.md](USER_RAW_HALATION_FAILURE.md)。

## 可独立修正的输入合同

`tools/eval/sensor_constrained_input.py` 从半尺寸Bayer读扣黑后的相机通道，用LibRaw数字输入探针取得线性变换矩阵，
在浮点域转换到XYZ和线性RGB。这里没有用照片或800T扫描拟合矩阵；该矩阵仍是相机解码器的颜色转换，
不是实测相机光谱感光度。

- `floor` / `observed_floor`：保留全部相机观测。饱和值只是删失观测的占位，不是已恢复灯芯。
- `local_ratio`：邻近未饱和区域提供颜色假设，只估计部分饱和像素的缺失通道；已有实测通道逐值保持。
- 全部饱和标志不触发随机亮度；`unknown_mask`始终保留饱和标志，估计值不会变成实测。

饱和判定仍是既有堆积启发式；两绿通道先平均，其任一饱和都会标记G未知。
因此全RGB标志不等于每个CFA感光元都完全丢失。负噪声与超1浮点值保留；
由于颜色矩阵可含负系数，不能把相机观测的删失下界解释为RGB分量下界或严格场景辐射下界。

这是保留实测值的修正机制，不是已经验证的通用高光恢复，更不是800T材料修正。

## 用户RAW：固定链路实测

复用原3012×2012尺寸、原测光比例和原扫描光号。只替换传感器标记饱和的单元，
其他单元保留原重建前解码数据；既有显影、返回光核、额外肩部及输出设置全部固定。
饱和位置的新输入同时绕开了旧XYZ16位截断及旧饱和区降噪处理，不能把全部变化归因于取消随机先验。
缓存以float32保存，没有把缓存读写声称为原float64链路的逐位回归。

红球反光点中心外围18–26模型像素范围的新增红层曝光均值：

| 输入 | 新增红层曝光均值 |
|---|---:|
| 旧整像素亮度先验 | 1.806924 |
| 观测占位 | 0.082129 |
| 部分通道颜色比例估计 | 0.092151 |

单位是现有引擎的相对红层曝光，不是瓦特、光子数、真实800T光能或最终RGB红色。
规整大红圈明显减弱，但桌灯仍有黄白泛光，颜色比例候选还更黄。
该画面没有真实800T配对，所以只能证明改变输入能消除这处明显模型伪影，不能证明新结果更接近真实胶片。

## 必须保留的配对反证

同两张已有EPFL配对，固定原几何、旧版本测光和一次计算的定光，复用既有灯芯/外围掩膜。
模型分辨率为866×1152，不与历史原生半尺寸径向数值混用。
下表为0–300µm、输入未饱和支持区域的中位ΔE00；误差越低越好。

| 场景局部 | 旧先验 | 观测占位 | 颜色比例估计 | 只替换纯部分饱和块 |
|---|---:|---:|---:|---:|
| 走廊近顶灯 | 20.56 | 22.76 | 22.91 | 21.23 |
| 黄昏左路灯 | 11.10 | 11.48 | 11.51 | 11.10 |
| 黄昏右路灯 | 13.66 | 14.46 | 14.49 | 13.70 |

走廊灯芯本身中位ΔE00也从1.50升至5.99/4.38；不能用整体分数的小变化掩盖局部退步。
输入变化还会经过既有局部光源估计，因此不能把全部输出变化解释为返回曝光能量变化。

最后一列是由前两候选的退步触发的单次边界核查：只在不含任何全RGB饱和原生单元的块内采用`local_ratio`，
含完全失测单元的块继续保留旧先验，明确仍是未知估计，不声称测量恢复。
它保护了走廊9808个块，替换11379个纯部分饱和块；黄昏保护892个、替换1430个。
走廊灯芯ΔE00退步缩小至1.50→1.80，外围仍退步；两处黄昏外围大致维持原误差，没有恢复真实橙红。
用户照片同策略也已全尺寸渲染，红球规整圈消退，桌灯黄白问题仍在。

## 研究决定

保留逐通道实测值保护、浮点转换和未知覆盖机制，作为独立研究能力。
三种组合均不推荐并入正式代际：取消先验可清除该用户照片的一处夸张红圈，却不足以通过已有真实800T局部验收。
只保留完全失测灯芯的原估计可以减少退步，但不能证明这些原估计物理正确。
因此，本轮得到的是具体输入错误的修正机制与可见局部改善，不是完整800T光晕解决方案。
返回核的材料依据和未知源光谱仍按既定独立测量条件冻结，不通过新参数、扫描调色或多层复杂度弥补。

## 验证与私有产物

`tests/test_sensor_constrained_input.py`五项测试覆盖矩阵方向/线性、未饱和通道保持、
全饱和持续未知、负噪声/超1保留以及无可用邻域时不编造恢复。
另用同一输入验证固定PrintTiming的`standard`执行与原`frame`执行在曝光、染料和RGB上逐位一致，
避免将重新自动定光混入候选对比。59个既有生产文件的SHA256与本轮之前快照一致。

用户照片和大数组均在仓库外，不提交：

- `/workspace/filmlab-audit/user-DSC03906/input-candidates/`：输入缓存、冻结设置、全尺寸输出、局部对比、逐层曝光和执行脚本。
- `/workspace/filmlab-audit/sensor-constrained-pairs/`：两真实配对的固定链路结果、局部掩膜、对比图和运行脚本。

现有核的独立审查没有发现足以消除第一环的数值错误；第一环符合它所假定的角分布和界面。
补齐多次返回的界面Fresnel只改变本帧约0.564%的总返回量，首次返回不变，不作为外观修正候选。

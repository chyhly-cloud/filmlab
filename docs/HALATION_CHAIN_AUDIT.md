# 光源到负片的因果链审计（2026-10-20）

本轮由用户要求继续核查光源/红晕的底层机制。输出高光曲线仍冻结；`paper_only`、`current`、`next` 均未改动。
结论：光源外观仍未通过验收。确认了输入照明推断的背景依赖与传播模型的近似；未获得可正式采用的物理修正。
这里的“物理核心”是按物理阶段组织的近似模型，不意味着每一阶段已经由真实 800T 测量标定。

## 1. 模型实际知道什么

| 环节 | 实现与依据 | 尚未独立确定的部分 |
|---|---|---|
| 光谱输入 | RAW → 日光白平衡 RGB；区域照明类别；CIE/灯具光谱库 | 相机光谱响应、逐灯真实光谱、饱和灯芯的辐亮度；库内成员按种子选择，并非测量 |
| 直接曝光 | 光谱 × 分层感光度积分；人造光用训练得到的 RGB→层曝光映射 | 发光体也按周围反射物的照明来解释；三通道不能唯一还原光谱 |
| 二次曝光 | 分层透射/吸收代理 + 菲涅耳反射 + 卷积核 | 未冲洗乳剂的吸收/散射、角分布、界面结构；显影后片基密度不等于拍摄时吸收 |
| 显影 | 5219 原生特性曲线 + DIR 模型 + C-41 动力学与染料变化 | 不是逐颗粒化学求解；动力学借自 Portra 800，C-41/ECN-2 活性比是估计；通用专利数据并非 800T 专属测量 |
| 扫描 | 负片光谱透射 → 扫描密度 → 固定定光/相纸/输出 | Frontier 响应与数字相纸代理仍未独立辨识 |

`S_nom` 已含标准显影效果，模型用 `_intrinsic_curve` 尝试撤回灰阶 DIR 后再计算；不能将其称作从未经显影的乳剂物性完全推导出成片。
漂白/定影按步骤去除银与卤化银，正常成片由染料形成；本轮没有改变显影程度或染料光谱来追回红色。

## 2. 已知光谱的背景依赖检查

工具：`tools/eval/light_context_audit.py`。理想 CIE 相机；256² 图像，中心半径 4 px 发光圆盘，Y=3；
周围 Y=.02，分别中性、蓝、暖背景。源的光谱、RGB、亮度、大小、种子完全固定；无 RAW 截断、重建、测光或扫描。
参考是已知光谱直接积分得到的三层曝光。

| 固定光源 | 仅换背景时 R/G/B 层直接曝光极差（档） | 红层光晕源极差（档） |
|---|---|---|
| 2700K 黑体 | .194 / .146 / .128 | .227 |
| LED-B3 | .196 / .045 / .131 | .133 |

2700K 灯的红层曝光相对精确光谱积分低 .246–.441 档；蓝背景中被赋予的暖光类别权重仅 .00011。
已知真实光谱时，现有 `linear_wp` 白点约束可在约 4e-16 相对误差内恢复该纯发光光谱的曝光；这是构造一致性，不是对实拍的验证。

问题来自 `_expose_mixed` 的区域照明推断：它没有区分直接发光体与受照反射物。背景会改变对同一个 RGB 光源的光谱解释。
这证明当前估计器在受控场景中有误差；不证明实际 EPFL 某盏灯必属某光谱，也不能直接把周围颜色当作灯芯光谱来修复。

## 3. 传播近似的受控检查

工具：`tools/eval/halation_transport_audit.py`。使用现有标称材料参数，比较已知 2700K、HPS、LED-B3 光谱，统一入射光度。
不经 RGB 反演、不拟合实际照片。现有核的连续角积分对应：`p(theta) R(theta) rho_c^(n-1)`，
后续反射仅在 `rho_c>.01` 时启用；对同一层，归一化空间分布不随光源光谱改变。

条件性替代推导将返回层的光程乘 `1/cos(theta)`，后续往返逐次乘界面反射，保留波长依赖的往返透射率。
仍假定叠层折射率相同、入射下行垂直、在片基处分配角度、散射只作消光；只统计向上返回的吸收，遗漏后续下行吸收。
它不是完整辐射传输求解，也不是新的正式光晕候选。连续径向积分与生产代码的离散方形核并非逐像素相同。

**反例结果**：2700K 的红层二次曝光/直接曝光比从 .193 升到 .285；红层能量中半径 >800 µm 的比例从 .133 升到 .155。
较长光程让首先遇到的红层吸收更多，不能推断“补光程必然使光晕更窄、更正确”。后续返回占红层能量约 9.3%，条件模型约 2.5%。
这也提示先前把远端尾部主要归于多次反射的解释不充分：第一次返回自身就有长尾。

校验：均匀叠层的 Beer–Lambert 解析解、掠入射极限；真实估计叠层的垂直入射与原函数逐值相同。
吸收加透射不超过入射能量；未计入部分包括滤光层/遮罩吸收与散射消光。这些只验证条件模型的计算，不是材料验证。

## 4. 真实夜景逐阶段消融

工具：`tools/eval/halation_chain_audit.py`。3 帧、5 个原先固定区域，其中红色信标没有可确定的饱和灯芯，只有目视比较。
2304×1732 原生半尺寸 RAW；512² 原生 TIFF 裁切。固定上一轮全部几何、测光、输入重建、卷号、帧号、显影、扫描转换、定光和 lab 输出。
只在 S1 对比：无二次曝光、第一次返回、现有多次返回。无二次曝光是诊断干预，不是“正确胶片”。
4 栏图片宽 4096 px，2 倍最近邻展示；无锐化。标称 36 mm 画幅与局部配准的不确定性沿用上一轮。
基线与上轮保存的 float32 图最大差 <2.981e-8（存储舍入）。这避免了重新定光掩盖上游变化。

| 光源 | 150–300 µm 红层曝光增加（档，多次−关闭） | 红层染料当量增加 | 0–300 µm 红/绿对数比：真实 / 关闭 / 单次 / 多次 |
|---|---:|---:|---|
| 外墙灯 | .656 | .141 | .454 / −.056 / .004 / .006 |
| 步道暖灯 | .699 | .151 | .183 / −.031 / −.004 / −.003 |
| 黄昏左灯 | .398 | .084 | .287 / −.004 / .023 / .025 |
| 黄昏右灯 | .288 | .062 | .399 / −.008 / .013 / .016 |

曝光与染料表用仍有完整实测通道的环带；曝光值是 logH 均值之差换算档数。红/绿比是输出描述，不能视为孤立胶片光晕量。
二次曝光确实更偏红，且经过显影进入染料；成片相对于关闭有改善，但仍然黄白泛光、红边不足。
单次与多次很接近，不能靠删除后续反射解决这些局部差异。也不能由此断言显影或单次核一定正确。

图像与逐层 JSON：`/workspace/filmlab-audit/halation-chain`，例如
`R1-00-1_facade_lamp_compare.png`、`R1-07-8_twilight_lamp_left_compare.png`。

### 输入不确定性如何传到红晕

按源像素的传感器饱和标记分解现有卷积贡献（是当前模型内的贡献，不是真实能量测量）。在 150–300 µm 实测环带：

| 光源 | 红层二次曝光来自任一通道饱和源 | 来自三通道全饱和源 |
|---|---:|---:|
| 外墙灯 | 73.0% | 53.5% |
| 步道暖灯 | 80.0% | 71.6% |
| 黄昏左灯 | 57.1% | 39.7% |
| 黄昏右灯 | 37.0% | 24.3% |

部分饱和源仍含实测信息，但现行 `prior` 重建混入颜色/亮度先验；以上不是“完全虚构能量占比”。
全饱和源的真实亮度与光谱不能从本帧恢复，周围未饱和像素也不因此成为独立的光晕强度标定。
真实黄昏左灯的源区域被当前估计器分配约 44.6% 日光、40.9% LED；这只是估计权重，不是真实类别标签。

## 6. 处理与后续证据

- 本轮只增加审计工具、解析测试和证据说明；修改生产文件中的过强物理断言，没有修改计算。
- 不采用“关闭”“单次”作为修复；不调整肩部、红晕强度、锐度、颜色或显影常数。
- 优先获取源端约束：同场景更短曝光 RAW 能检验亮度和部分通道恢复；仍不能唯一解出光谱，也不能自动去掉镜头眩光。
- 如果要替换光晕传播，需要未冲洗材料的角度/光谱透射或已知光谱与辐亮度的点源—负片密度配对。
- 光源与反射物应有独立的输入契约；在有已知发光光谱时直接积分，未知时保留可行光谱/亮度范围。
  不能用一个“更好看”的灯具类别代替这些缺失的测量。

验证：130 项测试通过（3 条既有光谱对齐警告）。原 42 图回归夹具仍未恢复，不将缺数据的检查称作通过。

## 本轮回答

旧五模板只有4个独立方向，红层far/near比例界也不等于最终非线性颜色界。
本轮开放严格失测核心的全部88/34个幅度，确实找到了此前没有的训练下降方向。
但它仍未恢复灯旁橙色，且得到极度集中的、随训练象限变化很大的源场。
不能把这些场称为准确灯具辐射或可采用的800T修正。

另有新的独立输入证据：[SOURCE_PROFILE_HOLDOUT.md](SOURCE_PROFILE_HOLDOUT.md)。
两个有短曝光参照的透光孔中，实际全幅旧重建在相同支持上归一后仍过尖，seed0峰均比为参考的2.139/1.747倍；
32个种子均过尖。这证明旧profile不能当作已测几何，但不认证走廊主要灯芯的新形状。
相同算法另查严格四CFA子集326/37单元，seed0峰均比为参考2.120/1.136倍，
TV为.18725/.06569；这与671单元any-RGB域分别报告，不能混成相同覆盖。
两条研究须分开：短曝光用于检验旧输入假设，自由场用同图最终RGB作数学诊断。

## 协议与实现

复用原19px、25µm Gaussian+双线性稀疏P、points/groups/target，包含已修补partial-edge与HDR全测body的背景不变。
每盏灯固定之前112谱训练选定的共同SPD（LPS+Mercury只是数学witness），不再拟合谱或总输入。
严格支持外不变；每单元同一幅度同时乘直接和返回的三层响应。

```
s_i >= max_c(observed_camera_ic / same_SPD_camera_response_c)
sum_i(s_i) = sum_i(original_profile_i)
H(s) = fixed_background + sum_i(s_i * unit_source_basis_i)
```

总幅度是既有源接口单位：88/34；乘固定谱后对应的积分引擎输入Y保持61318.37/16217.41。
它不是SI辐射量，不把三层曝光相加充当光能账本。
相机约束仍是已标注的CIE/逆数字矩阵代理，不是实测相机SSF。
这些下界仅占总输入1.917%/2.385%，不足以排除极端集中图形。

每方向最多三次有限差分Jacobian和带总量等式、box信赖域的QP。
初始每单元box半宽为总幅度的1/4，即22/8.5，**不是每单元自身幅度的25%**。
局部QP只建议步长；依次用1、1/2、1/4、1/8、1/16完整前向验证，
仅在训练误差实际下降、且实际/预测下降比至少0.1时接受。不用留出或外观选步。
没有平滑/稀疏材料正则，没有重拟合核、颜色、DIR或扫描肩部。
首方向近灯第一次QP到达迭代上限，虽满足约束且全非线性下降比约.970，不能说该QP已收敛或全局最优。

## 实现与已知输入控制

逐单元basis叠加复现原固定profile的H，最大误差近/中灯1.36e−12/9.09e−13；
完整初始样本Lab与原112谱候选的重放检查通过。
固定总量前后分别88.00000000000003/88.00000000000018、33.99999999999999/34.00000000000005；
相机代理最大下界差为舍入量级3.33e−16/0。

预声明已知合成场为原场与固定种子非负扰动的5%混合，仍同谱/同总量/满足下界。
其模型输出经过同一完整后端成为算法控制目标；这不是实际800T的独立实验数据。
单次局部步骤的输出MSE下降约300/570倍，但真实已知场L1误差仅.03348→.03142、.02994→.02271。
因此它检查实现、方向导数和有限变化接受，并没有证明空间反演唯一或精确恢复了已知源。

## 一次象限角色对调

再固定同一SPD/总量，将原groups1/3作为训练、0/2作为评价，仍最多三步，不选择两方向中较好者，不平均推广。
原112谱由第一方向的上游数据选过，同张RGB也反复使用；这只是**同图再拟合敏感性**，不是新盲测或独立交叉验证。
JSON stats保留原group标签，反向目录中的`inner_heldout/outer_heldout`实际参与了反向训练，不能误报为留出成绩。

两个方向得到的归一源场相差：

| 比较 | 近灯 | 中灯 |
|---|---:|---:|
| 源场TV，0.5×单位和L1距离 | .7123 | .9543 |
| 质心距离，native半尺寸像素 | 1.804 | 2.971 |
| RMS半径，第一方向/反向 | 2.981 / 7.568 | 1.625 / 6.551 |
| 反向有效单元数 | 6.75 | 3.17 |

反向拟合在原groups0/2的预测MSE约28.95/16.22，均劣于固定场的25.83/13.50。
同一灯具不应因拿哪两个象限训练就成为两种截然不同的辐射图。
该结果表明反演在补偿当前条件模型的局部残差，尚未识别出稳定的实际源场；
不证明唯一错误属于源输入，也不定位传播、显影或扫描中的具体环节。

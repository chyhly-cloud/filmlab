只对通过几何验收的近顶灯执行；中顶灯不套用近灯变换，也未改变其源参数。

## 1. 几何helper与不变项审查

`apply_accepted_ceiling_geometry(case)`从已记录的线法几何中只接受同名且`adopt_for_diagnostic=True`的唯一记录。
随后使用正向`A@H_old`，重建原采样点的25µm测量P，检查train/heldout native列不共享，
并拒绝需要既有safe范围外native像素的变换。中顶灯显式启用时正确抛出没有接受几何的异常。
本轮constructor只应用一次；helper会复合变换，并非可在同一case反复调用的幂等接口。

独立比较旧、新`MomentCase`：除matrix外，25个case数组逐值相同，包括背景、basis、源支持/profile、
points、target、groups、旧系数、相机观测、factor和响应。B、S10、m0与归一坐标scale也逐值相同。
因此这项helper改变的是观察对应/采样，不是暗中修改光学核宽度、源field或曝光标定。

## 2. 八起点共同源谱重拟合

仍在预声明112谱锥内，要求同一非负混合同时生成三个直接和三个返回响应；
相机删失下界用同一混合的LP验证。只按原groups0/2等权Lab分量MSE选择，不用groups1/3或照片外观选解。
改变几何后重新估计这项已授权的未知源输入，是受影响最优的复核，不是重新拟合材料或扫描。

八起点均成功终止、共同谱LP可行、未触数值上界，训练MSE范围13.99584397–13.99584418。
最大锥facet违约约1.22e−10；按数值容差接受。所有witness清理舍入微负值后仍非负，
六响应相对闭合最大约3.72e−10，相机代理下界最大deficit为0。
这些是有限数值一致性检查，不证明全域最优、所有物理灯谱的可达性或真实800T的参数正确。

这是当前冻结模型中的目录混合代表，不识别实际顶灯类型；输入Y也不是SI辐亮度。

固定六矩后的LP最小/最大Y在报告精度内相同，同样不包含源profile、材料、扫描或相机谱响应的不确定性。
不能因数值区间窄就宣布真实辐射已恢复。

## 3. 必要的固定谱近/外幅度一致性诊断

目的：在已验收几何和重新选定的同一SPD下，仅以一维幅度检验近/外目标是否仍要求不同源强。
工具为`tools/eval/geometry_strength_radius.py`；它不重新选择谱形、空间profile或成像参数。

令本轮六矩为m、共同witness为c，仅开放`t>=0`，使用`m(t)=t*m`、同一个`t*c`约束相机代理。
解析下界为：

```
t_min = max(required_camera / (c @ camera_response)) = .04556566
t_max = min(4096 / (m / original_coordinate_scale)) = 4212.4725
```

上界沿用原六坐标数值盒，不是测得的辐射上限。下界是原相机代理删失必要条件。
共同谱六矩相对闭合约1.26e−14，保证直接和返回沿同一源ray缩放，没有独立加光晕倍率。

预声明32点对数网格，两目标共享同一完整前向结果；对每个网格局部极小和两端邻区作bounded对数细化。
所有幅度只按各自单一区域Lab分量MSE选择，其余组不参与选幅度。
有限网格+局部细化不证明严格全局最优。共135次完整局部前向，没有全幅重渲染。

| 单一区域拟合目标 | 幅度t | 均值源输入Y | 该目标Lab分量MSE | 数值边界是否激活 |
|---|---:|---:|---:|---|
| groups0近区train | 1.200507 | 512.877 | 15.01999 | 否 |
| groups2外区train，重用诊断 | .711842 | 304.111 | 8.78278 | 否 |

两者相机代理下界deficit均为0。近区/外区最优源输入比仍为 **1.68648**。
它说明当前条件模型下仅换拟合区域就要求明显不同的源幅度，不是硬下界或数值上界夹住。

提高源强有利近区却损害外区，降低源强的效果相反；单一幅度仍没有解决两区取舍。
SPD和两个训练区都已经使用同张扫描，不能把这项复核称新外缘盲测或实测灯芯辐射。
历史FL2/旧几何诊断给过约2.057的比例；当时谱形、边缘/HDR输入及采样划分也不同，
不能把目前1.686与历史比值的差单独归功于几何修正。

## 4. 研究结论与边界

已验收天花板几何会改变源谱/幅度的最优，故旧源参数不能不经复核便称真实灯具性质。
本轮重拟合及固定谱标量诊断仍未通过橙红局部验收；但有限失败不排除所有源输入、材料或扫描解释。
近/外幅度差可包含源空间/光谱、固定背景、传播、显影或扫描的条件误差，不能唯一归因某一环节。
灯体视差仍未独立测得；中顶灯几何不足，未套用新变换。
保持current/next及生产冻结，不将数学源谱、minY或局部误差极小值当作独立物理测量。

# 配准warp与物理传播坐标的尺度核查

只读取固定H、缓存、已有RAW尺寸和扫描清单；不解码图像、不拟合几何、不改光晕核或任何成像参数。
工具`tools/eval/inverse_geometry_scale_audit.py`与三项解析测试；JSON位于
`/workspace/filmlab-audit/inverse-registration-audit/geometry-scale.json`。

## 管线里使用了两个独立的36mm约定

`Engine.develop_negative`先将原生半尺寸RAW网格1732×2304的长边赋为36mm，得到15.625µm/模型像素，
在该均匀网格进行散射和返回传播。随后将输出依固定H配准到实际扫描。
实际TIFF为5456×3649，现有评估另将扫描宽赋为36mm，得到6.59824µm/扫描像素。

如果两个标称坐标完全一致，H的局部奇异值应约等于15.625/6.59824=2.36806扫描像素/模型像素。
实际固定H不满足这个单位等距条件。

## 局部Jacobian与量级

对投影`u=(H x)[:2]/(H x)[2]`，使用解析导数
`J=(H[:2,:2] - u[:,None] H[2,:2])/(H x)[2]`。
解析式与独立中心差分最大差<2.9e−11扫描像素/模型像素。
下表在旧512裁切中心计算，源核心严格支持的质心结果几乎相同。

| 区域 | J奇异值（扫描px/模型px） | 两个标称µm坐标间的奇异值 | 各向异性 |
|---|---|---|---:|
| 近顶灯 | 2.56813 / 2.52795 | 1.08449 / 1.06752 | 1.01589 |
| 中顶灯 | 2.56671 / 2.52937 | 1.08389 / 1.06812 | 1.01476 |

主要差异是约7.6%的近似等向尺度，而非强各向异性（长短轴只差约1.5%）。
面积等效尺度约1.07597，面积比例约1.15772。
在中心±800模型µm的5×5预定网格内，近灯两主尺度范围分别约1.0831–1.0859、1.0668–1.0682；
中灯约1.0825–1.0853、1.0675–1.0687。局部透视变化远小于上述共同尺度偏移。

按当前名义单位，模型内的圆半径经warp后约为：

| 模型半径 | 扫描名义µm中的长/短半径（近灯） |
|---:|---:|
| 100µm | 108.45 / 106.75µm |
| 235µm | 254.86 / 250.87µm |
| 300µm | 325.35 / 320.26µm |
| 800µm | 867.59 / 854.02µm |

235µm特征的位置差约16–20µm；800µm位置差约54–68µm，达到约8–10个扫描像素。
因此该尺度混杂可能影响精确径向比较，且**不由先前±8像素的平移敏感性检查完全覆盖**：
平移与径向尺度变化是不同扰动。
它不足以在没有另行验证时解释8–19倍源强反演，更不能据此宣称已找到了真实光晕根因。

## 为什么先传播再warp与先warp再传播不自动相同

在局部仿射近似`u=A x`下，均匀平面的线性卷积满足

```
warp_A(K * f) = K_A * warp_A(f)
K_A(u) = K(A^-1 u) / abs(det A)
```

若K在模型物理坐标中各向同性，warp后其协方差为`A Sigma A^T`。
只有A为单位等距旋转时，它才与在目标物理坐标中使用同一个各向同性K等价。
本次两个标称物理坐标的A约为1.076倍缩放并带约1.5%各向异性，
故“先RAW网格传播再配准”与“在已校准的实际胶片平面坐标中传播”原则上不交换。
这里是坐标变换与算子关系，不是对真实800T核的新测量，也未开发或采用替代候选。

## 不能将这个H当胶片平面标定

- 清单对TIFF明确记录画幅尺寸不一、可能裁切；5456像素是否对应未裁切的36mm片门没有独立确认。
- TIFF像素数、sRGB ICC和扫描仪标签不提供真实扫描裁切边界或有效片门毫米数。
- 数码相机与胶片相机的焦距、视场、镜头畸变及拍摄位置不一定相同。匹配场景纹理的H包含这些因素。
- 走廊场景有深度，灯具突出于天花板，单一平面H还可能混入视差；它不是全场真实光线到胶片的光学映射。
- 所以1.076只是**现有两套名义长度约定之间的局部比例**，不是测得胶片缩放了7.6%、片基厚度错了7.6%，
  也不授权把frame_width或kernel半径直接除以1.076来追照片。

研究判断：需要把这项尺度不确定性列为精确物理径向验收的坐标混杂。
它与输入源强错误可同时存在，但本核查没有证明它足以修复外缘颜色或空间分布；
确认未裁切片门/有效扫描宽度及相机几何之后，才能将映射用于材料尺度校准。

图像精度须由实际像素尺寸、坐标网格、线宽、压缩、交叠和标记遮挡确定，保留数字化不确定性；不能预设0.01D、21级=0.15logH或用URL版本戳证明文章发布日期。不能将第一个可见低曝光点自动当作真正D-min。

只有横轴与密度定义足以支持比较时，才进行一次固定参数三色中性曲线对照；没有绝对曝光校准时不能判定ISO速度。若密度Status不明，应限定可比的定性/相对特征，不做虚假的精确残差。不得按通道移动曲线、搜索tau或改KIN/染料参数追回一致。

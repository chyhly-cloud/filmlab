# DIR 自洽闭合候选（2026-10-20）

## 要回答的问题

用户要求继续尝试物理修正黄白光晕，而非再次增强红色或拟合扫描曲线。
本轮只检验一个具体假设：在现有有效DIR模型中，让抑制剂释放量与最终形成的银量一致，
是否能改变非中性显影并改善真实灯外围过渡。

原 `chemistry.develop_image` 用名义特性曲线的初次预测值生成抑制场，再计算最终显影量。
二者在中性设计条件下近似一致，在不均衡曝光下会不同。
这是可检验的单次预测近似，**不能未经实验证明就称为化学实现错误**：
真实抑制发生在显影过程中，最终银量并不直接给出时间积分的局部抑制。

## 候选与数值验证

独立模块 `tools/eval/self_consistent_dir.py` 解现有静态有效模型的闭合方程：

```
D = min(C(logH - blur(D / halide_cap) @ A), halide_cap)
```

C仍由原中性曲线逆推，A、显影动力学、材料光谱、卤化银上限、空间扩散尺度均不调整。
固定点松弛仅为数值算法，不作为拟合的物性参数；迭代不收敛必须报错。
默认代码不导入本模块，研究脚本只在显影调用的局部上下文临时替换求解器，随后恢复。

三项新增测试用独立SciPy求根器核查非中性解、核查松弛步长不改变解、检查无抑制极限、
失败显式报错及空间解的有限性/非负性/卤化银上限/几何对称性。
测试只验证这个指定方程，不证明它是800T的真实化学。
原25³曝光网格只用于检查该假设，无新常数扫描。

## 真实照片验收合同

只取既有R1-02-3三处用户关注的小灯，固定同一RAW输入、随机种子、曝光标定、光学返光、
帧变化、原扫描光号和颜色转换，grain=0、output_conditioning=None。
使用与亮度审计完全相同的真实扫描、配准、512像素局部和亮度分区。
像素只在既有未饱和周边掩膜内比较；主灯芯辐射/SPD仍未知。

基准局部必须复现已保存的exp_plain，否则停止；真实/基准/候选全部在浮点线性RGB上比较，
Lab显式不重复解码，显示图最后才进行sRGB编码。
记录dLab和ΔE00用于观察方向，不以整图分数或“更红”作为验收依据。

## 验收结果：不采纳

采用与真实帧相同的显影程度τ=1.1921603。25³网格候选闭合残差9.03e-9，
改变数值松弛从.5到.25所得解最大差8.19e-10；全帧30次迭代，残差6.55e-9。
原单次预测结果代入这个假设方程的全帧最大残差.04856染料当量。
这些只描述对所选方程的求解，不是原近似的实测化学误差。
中性输出与原实现最大差7.62e-5，不声称逐位保留中性；上端仍有微小自导数负值（红59点，最小−.000141），
因此也不能把闭合求解当作已证明单调或物理充分的显影法。

三处既有基准全部复现，最大线性RGB误差2.981e-8。以下仅取0–300µm且真实Y=.4–.85：

|区域|基准Δa（模拟−真实）|候选Δa|基准中位ΔE00|候选中位ΔE00|
|---|---:|---:|---:|---:|
|近顶灯|−11.89|−12.92|20.19|20.75|
|中顶灯|−8.84|−10.56|8.72|9.50|
|玻璃反光|+6.82|+6.62|47.41|47.24|

近、中顶灯的红色不足反而加重；原分辨率局部也未恢复真实紧凑橙红过渡。
玻璃区域的微小误差下降伴随原有巨大亮度失配，不能据此接受化学假设。
所以不推广到更多场景、不扫描抑制强度、不并入current/next，也不修改扫描颜色或肩部。

这排除了“单次预测近似只要改成最终银量自洽就能解决当前白晕”的简单方案，
没有排除其他非中性显影机制。现阶段不能宣称已修正真实800T光晕。
下一项可解冻的修正仍须有独立约束：源辐射/SPD、未显影材料的前/背照吸收，
或设备的非中性密度响应；不能用同一张未知灯芯照片倒推全部自由度。
三项新增求解测试及两项先前亮度域测试共5项通过，git diff --check通过。

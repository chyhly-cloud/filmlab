# 光晕机制的单因素对照（2026-10-20）

## 本轮范围

在自洽DIR候选未改善之后继续检验不同机制，不重复扫描某个强度参数找颜色。
本轮主实验有三个预定义对照；角度输运、印放密度积分和源依赖实验由三个独立子代理完成，
对应专项文档在下文链接。所有研究不改current/next或既有paper_only。

## 主实验：同一输入、化学及固定定光

R1-02-3原半尺寸RAW，固定既有seed、帧变化、曝光标定、配准、扫描设置；颗粒关闭、输出conditioning=None。
用同一帧相同光号比较三个局部，复现原exp_plain到<2.981e-8线性RGB误差。
距离、亮度分区、未饱和周边掩膜与亮度审计相同；输入源灯芯仍未恢复，不能把模型干预当作实测。
真实扫描只解码一次，Lab转换不重复解码，全部先以浮点线性RGB比较，最后才编码显示。

三个对照均**不是建议采用的胶片/扫描仪模型**：

1. **仅红层返光**：保留原红层总曝光，去掉G/B层二次返光，再用原化学显影。
   检验G/B返光是否是把红色过渡冲白的主要机制。不是声称真实胶片只接受红返光。
2. **首次返回**：保留原首次菲涅耳/几何核，去掉第二次及以后的返回；不缩核、不重归一化、不补能量。
   检验后续往返是否单独解释宽白晕。不是把后续反射判作不存在。
3. **可分离相纸颜色**：负片、Dn、K/s/M、肩部、相纸Dp全不变。
   输出通道c取原参考印放对中性输入(Dp_c,Dp_c,Dp_c)的第c通道，隔离非中性色彩耦合。
   对所有中性Dp逐点精确保留原响应，不重拟合中性曲线，不把亮度修正伪装成颜色改善。
   这不是测得的Frontier设备LUT，也不是实际相纸的物理替代。

初步理想独立反射率实现与原中性输出曾有最大.00664线性RGB偏差，因此未用它作结论，
正式对照改为上述逐点匹配的可分离函数；现报告的中性RGB偏差为0。

- 去G/B返光使a略向真实靠近，但b更偏离，未恢复紧凑橙红过渡。
- 去后续往返未恢复轮廓与颜色，a缺口反而加重；不能把全部问题归于多次反射外环。
- 去相纸非中性耦合可改变b和亮度，但a缺口并未消失。ΔE的小幅下降不构成设备模型依据。
- 玻璃反光仍有巨大输入/输出亮度失配，三个对照未解决；不拿它校准扫描曲线。

这些干预只能排除简单的单因素解释，不能证明真实材料参数或扫描响应正确。
不把三个失败对照组合后再调权重找一个好看的版本。

复用全部297扰动，不增加曝光网格；按原指数基准线性Y分区，固定负片、光号和Dp。
+.5EV下的色度增量/青染料增量中位数：

|原线性Y|原指数+相纸|指数+可分离相纸|
|---|---:|---:|
|<.005|7.99|7.49|
|.005–.05|42.38|39.44|
|.05–.4|72.66|79.98|
|.4–.85|31.39|37.11|
|≥.85|.198|.194|

因此，相纸染料/LUT颜色耦合会改变非中性增量，但移除它没有解除近白的大幅压缩。
paper_only近白组也仍很弱（原.0377，可分离.0619，精确值见JSON），
原材料曲线的白端斜率仍在，不能把这一步的改善推广为取消所有压缩。
暗部a增量甚至可下降，颜色变化具有方向和背景依赖。

## 独立代理实验的交叉判读

### 源信息与分层曝光

见 `CORRIDOR_SOURCE_DEPENDENCY.md`。近/中/玻璃处0–300µm，
模型返光占各通道总曝光R/G/B分别：27.40%/2.71%/.000909%、14.17%/1.22%/.000429%、26.82%/3.60%/.001722%。
当前模型的返光本来已经明显偏向红敏层，G/B一起很强而把返光冲白的解释受到明显削弱，
与主实验去G/B变化较小且未恢复橙红过渡相符。
这些比例是模型内曝光，不是实测800T分层曝光；它们也不排除非线性显影对小G增量的作用。

近灯/玻璃多数返光来自至少一通道饱和的源，中灯只有约34–37%。
因此未知源幅度/SPD仍是重要混淆，却不能把所有失配统一归于RAW灯芯丢失。
未标记饱和也不等于测得SPD；prior路径可能修改部分饱和像素的全部RGB。
三类源分解与原卷积相对L1闭合误差≤1.03e-15。

### 固定P与直接光谱印放积分

见 `PRINTING_DENSITY_AUDIT.md`。保持同一负片T81和原gain/光号/相纸/肩部，
直接积分T×印放光×相纸感光度，与Portra代理线性P比较。
1D中性光谱吸收本应使三印放密度均增加1D，旧P却给约[.955,.979,.882]D。
这是虚拟印放代理内部可独立验证的近似误差，不等于发现Frontier真实输出曲线错误。

用原2000个虚拟材料样本加入“中性吸收守恒”约束，没有真实照片参与拟合。
其列和精确为1，但其他材料组合的密度RMSE从.09768增至.14343D，
说明这个固定线性映射对非线性宽带积分存在真实的逼近取舍，不能只加一个约束就宣布整体正确。
直接光谱积分不需要这个矩阵逼近，但仍仅在当前虚拟相纸模型内具有物理含义。

同一真实过渡区（Y=.4–.85、0–300µm）：

|区域/对照|Δa|Δb|中位ΔE00|
|---|---:|---:|---:|
|近顶灯 原P|−11.89|−13.46|20.19|
|近顶灯 中性约束P|−7.56|−14.90|19.09|
|近顶灯 直接积分|−9.96|−12.75|18.46|
|中顶灯 原P|−8.84|−7.62|8.72|
|中顶灯 中性约束P|−4.03|−9.61|7.86|
|中顶灯 直接积分|−8.87|−8.90|9.02|

中性约束P更红却更偏蓝，并使亮度升高；直接积分一处改善、另一处略退，均未恢复紧凑橙红过渡。
不能凭Δa或ΔE的改善推广为正确800T颜色。保留两个研究对照，不修改正式扫描默认。

### 角度相关分层吸收

见 `ANGULAR_COLOUR_AUDIT.md`。独立已知假想材料、固定角分布和同一能量输入，
比较垂直深度控制与斜光程吸收；实际吸收位置几何、菲涅耳反射保持相同。
解析分层能量账本与有限几何无散射MC交叉验证，证明层吸收份额可随半径自然改变，
不需要手工收窄空间核或增加红色强度。

这是支持波长/角度/吸收位置应耦合建模的机制证据，**不是800T的吸收系数、感光效率或正像红晕证据**。
未显影材料光学数据、潜影效率及真实源光谱仍须分别约束，不能借已有染料资料补成“实测”。

## 本轮决定

不把三个诊断删除方案或中性约束P并入current/next。保留直接光谱印放积分与中性约束P作为可复查对照，
在虚拟印放内部区分“矩阵近似误差”和“设备代理本身未标定”。
将后续物理研究重点收敛到波长与角度耦合的分层传播/吸收，并保持未知源与未知物性分开，
而不是继续叠加删减项或调最后颜色来重现这一张照片。

本轮合并验证：主对照、印放密度约束、角度吸收与MC、DIR求解、亮度域和已知光谱合同共35项测试通过。
`git diff --check`通过。没有把未运行的历史42RAW逐位fixture计入验证；生产代码及正式代际未修改。

# 基础成像链的受控约束核查

本轮暂停自动校色方案更换，从已知反射率和光谱建立可判别输入。结果发现输入推断的背景依赖和曝光操作语义问题，但没有得到可以直接推广的整体色彩修正。没有修改current、next、材料、DIR、肩部或输出调色。

## 什么是独立信息，什么仍是假设

使用colour-science的24块ColorChecker N Ohta实测反射率，以及D65、BB3200、LED-B3、FL11的已知谱形。R(λ)I(λ)定义受控辐射，按同一白色光视亮度归一；理想CIE观察者生成相机RGB。三层积分使用**现有库存感光度**，因此是检查RGB推断算法的条件参考，不是独立测得的真实800T分层曝光。理想CIE相机也不是G81或Sony实测SSF。没有按色卡或最终照片重拟合任何参数。

固定roll=None、exposure_ev=0、standard定光、胶片设计中灰参考、无输出调色、无颗粒，无返回曝光和空间显影，以免把曝光推断与空间效应混合。扫描定光在全部受控场景间保持不变。

## 1. 同一反射物的曝光依赖无关背景

在96×96受控场景中心放16×16的18%中性反射片，固定照明光谱、中心辐射、RGB、胶片和种子，仅把周围反射物换为中性、实测蓝/绿/橙色卡反射率。所有表面照明相同，没有把高亮像素假定为灯具。

中心4×4的三层曝光跨背景最大−最小（log2、EV）为：

|固定照明|R层跨度|G层跨度|B层跨度|
|---|---:|---:|---:|
|D65|0.347|0.086|0.242|
|BB3200|0.490|0.270|0.626|

中心原始RGB逐位相同，真实受控光谱积分不变；变化来自局部灰色世界/可行性光源推断。物理胶片的直接曝光不应因此改变。此处是**推断模型失败/不确定性**，不是光谱积分算术错误，也不意味着未知光源可以仅凭RGB唯一恢复。已知光源时可绕开推断；不能把这条结论变成对所有真实夜景强制D65。

## 2. 光谱重建与曝光倍率的操作次序

日光路径的三维LUT按反射率亮度选择光谱；不同亮度同色度可对应不同反射率谱，这是LUT本身的设计，不自动构成错误。但是，**在同一已重建光谱上增加相机/胶片曝光**应只乘积分量，不能将曝光变化再次解释为反射率谱变化。现有_expose_lin和混合路径把已知exposure_ev先乘RGB，再查谱，混用了两种操作。

受控色卡中，在D65路径比较“先乘RGB”与“积分后乘H”，±2EV时各层差最大约0.950EV。实际800/500配方倍率0.625（−0.678EV）下最大R/G/B差约0.236/0.071/0.220EV；不是增加了额外曝光档数，而是两种运算顺序造成的差。

BB3200、LED、FL11的线性映射，在未触及数值下限的样本上齐次误差为机器精度。BB3200/FL11部分理想CIE相机样本有负sRGB，响应被1e−9数值下限截住，若直接算比率会产生假2EV差；这些项另行标记，**不将数值下限反例称为线性映射的物理失效**。

`expose_with_separate_gain`是eval-only候选操作：固定RGB重建结果，再对曝光乘非负倍率；没有改变反射率模型、光谱库或材料常数。它解决操作定义，不消除RGB同色异谱误差，也未完成整套中灰/参考路径的一致重标定。

## 3. 必要的真实RAW重放，避免提前认定根因

工具exposure_gain_order_replay.py对日间咖啡馆和蓝调道路生成独立候选。直接曝光和返回源都把同一0.625倍率后置；光源类别软权重逐位冻结，成员、输入测光、引擎层校准和扫描定光不变。重新显影以比较其影响，不调显影参数。原基准回放最大线性RGB差0/5.92e−8。

|固定远区格|原ΔE00中位数|后置倍率候选|原ab距离|后置ab距离|
|---|---:|---:|---:|---:|
|日间，498格|24.68756|24.68764|21.58538|21.58539|
|蓝调，795格|10.04003|10.71302|24.14291|25.05168|

日间几乎不变，蓝调两指标退步。这排除了把该操作问题直接宣布为这两张照片色差主因的做法。原未知光谱/材料/真实扫描约束仍不完整；物理操作一致性与最终照片误差是不同验收，不应为了维持单图分数否定前者，也不应因前者成立就推广整个候选。

## 4. 显影和光谱密度目前验证到哪里

四光源×24块光谱积分输入下，逐层增加1EV，自己的染料增量最小R/G/B=0.1272/0.1862/0.1872；染料非负、完整漂白后银为0、定影后卤化银为0，T范围0.00312…0.72938。D(λ)=染料×染料吸收谱+片基的闭合误差5.55e−17。这些通过的是内部约束，**不认证真实800T的非中性显影响应、C-41动力学或染料谱**。

原生工艺特性曲线/推冲及相关材料测试22通过；已知光谱incident路径7通过。特性曲线作为模型输入，又被重放出来，属于校准闭合，不能被算作新的独立材料证据。原来的“三层模型已经物理准确”仍没有被证明，本轮也没有证据支持增加子层或调DIR。

## 5. 受控色卡如何阅读

controlled_chart.jpg三列为：同材料假设下的已知光谱积分参考、RGB+已知照明谱推断、RGB+自动照明推断。都通过同一显影与固定扫描。它不是三张真实胶片扫描。相对积分参考的输出中位ΔE00如下：

|照明|已知照明RGB路径|自动照明路径|
|---|---:|---:|
|D65|2.481|4.139|
|BB3200|3.531|5.123|
|LED-B3|2.220|4.396|
|FL11|1.844|4.186|

知道照明后仍有RGB→光谱近似误差；自动推断在这组受控输入中又增添误差。不能将以上差值当成真实800T实拍色差或修改感光度的依据。

## 决策与复现

明确将输入光谱/照明推断与材料显影分开验收。保留曝光后置的独立候选，暂不推广；保留已知照明旁路，但只有真实测量支持时才启用，不按“日间/夜间应该是什么颜色”选光谱。接下来若提出输入修正，必须先通过已知照明、相同物体跨背景和曝光操作约束，再作真实配对回归。不能继续仅更换输出灰平衡追色。

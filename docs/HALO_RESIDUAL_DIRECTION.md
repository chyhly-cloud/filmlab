# 两处真实顶灯：无光晕基底与完整返光的残差方向（2026-10-20）

## 判定

复用 R1-02-3 两处可靠配准顶灯，完成真实扫描 / 无光晕 / 完整光晕三状态比较。
**主要外围的完整光晕明显减小颜色残差；没有支持“此处无光晕基底普遍已经比真实更亮、更黄”。**
但光晕仍未通过外观验收：近灯真实橙色区域被模拟成低彩度青蓝色；部分灯芯邻域进一步过亮、近白面积增加，
一些区域的色相误差增大。不能用总 ΔE 下降代替橙红过渡验收。

**三张最终图不能唯一判定剩余误差主要属于基底、返回光谱/空间分布、显影还是扫描。**
真实扫描本身含光晕，无光晕实拍对照不存在；目标残差不是实测纯光晕。
前轮固定负片/光号移除额外指数肩部几乎不改变这两处主要明亮外围的响应，故不能把它列为本区域主因。
固定扫描颜色和数字相纸代理的设备依据仍待独立验证。
本轮无新渲染、RAW解码、合成探针或参数拟合；生产代码、current、next、paper_only不变。
DIR继续降级，不新增子层，不用反事实染料组合修图。

## 数据与测量

- 原缓存 `corridor-lights/near_ceiling.npz`、`middle_ceiling.npz` 的 `real` / `none` / `exp` 为浮点**线性RGB**。
  next_sensor、grain=0、conditioning=None、原指数路径，三状态沿用相同输入、显影、几何与R1-02-3 PrintTiming。
- 与既有独立缓存核对：真实RGB最大差<2.88e-8，完整返光<2.99e-8；可信主要区域无返光端点复现<4.31e-9。
  直接使用原无光晕图，不扩展上一轮反演缓存的可信边界。
- 主统计先对三图**线性RGB**同作sigma=25µm高斯平均，再转CIELAB；另保留原生像素统计。
  平均仅用于测量真实扫描的颗粒影响，展示照片为原图。RGB→Lab不再sRGB解码，显示仅编码一次。
  Lab采用显示范围RGB；不将编码值差与线性值差混用。
- 距离沿用既有核心边界/排除盘、未饱和接收域与名义36mm扫描宽度，6.59824µm/像素；并非独立实测的乳剂距离。
  接收像素未饱和不代表源灯芯已恢复，其强度/SPD仍未知。
- 固定分区：核心、核心外0–100µm、100–300µm、300–800µm，以及真实线性Y<.4的较暗外缘。
  橙色子集仅按真实图定义：0–300µm、Y=.05–.85、a*>0、b*>0、C*ab>10，不按模型残差选择。
  近灯2967像素，中灯仅38像素，后者不足代表完整橙色环。
- 两处指定外缘内Y<.05均无样本，**不能验收真正暗部**。像素有关联，数目不代表独立重复测量。

定义（CIELAB坐标有限差，不是EV或导数）：

```
E = Lab_real − Lab_nohalo       # 模型到目标的残差，不是实测光晕
V = Lab_halo − Lab_nohalo       # 模型完整返回曝光的最终响应
开启后残差 = E − V
||E||² − ||E−V||² = 2 E·V − ||V||²
```

正点积不保证实际改善，过冲仍可增大距离。分别计算L*、a*b*平面、色相、彩度；ΔE00另作描述，
不混入欧氏向量恒等式。色相前后比较使用R/N/H共同C≥5的像素，避免中性化改变样本集合造成假改善。

## E与V：帮助与退步

E/V为(L*,a*,b*)均值；比例为同掩膜像素的实际误差减小比例，不是物性准确度。

|近灯100–300µm|(7.14,24.83,18.49)|(3.64,11.70,5.81)|100%|79.9%|28.82→19.64|

|中灯0–100µm|(2.39,5.75,10.32)|(.61,1.99,1.00)|100%|85.5%|10.72→9.35|
|中灯100–300µm|(2.97,15.19,11.20)|(2.07,6.63,3.30)|100%|76.2%|11.76→8.31|

主过渡带E与V的a*b*聚合余弦近/中为.954/.963，总体有帮助，幅度与比例仍未达到目标。
近灯橙色子集的平均E_ab方向约43.8°，V_ab约26.4°（从+a轴朝+b）。
**相对目标残差，模型增量的黄向分量比红向分量更不足**。这只是输出端点描述，不是返回光谱测量。
不能因此放大V；增强会同时改变亮度、两色轴与空间分布，不能独立补齐E。

退步亦需保留：

- 0–100µm比真实亮>1L*的比例：近灯11.0%→24.6%，中灯4.5%→9.6%；100–300µm近/中9.4%/10.2%→20.9%/21.5%。
- 诊断性近白定义为线性Y≥.85且C<10，不是设备饱和阈值。真实不近白而模型近白，在0–100µm近灯2.7%→4.8%，中灯1.3%→1.5%。
  存在局部白斑扩张，不能夸大为整个外围都被压白。
- 0–100µm共同有效色相样本近灯仅23.5%，平均色相误差154.7°→163.0°；中灯36.8%，83.9°→86.9°。
  a*b*距离改善可包含去掉错误彩度，并不保证色相变好。
- 近灯橙色子集共同有效74.3%，色相误差166.3°→150.5°，仍很大。中灯仅38像素的橙色子集不能推广；其36个有效点128.5°→133.9°。

## 归因边界

|解释|证据判定|
|---|---|
|两灯无光晕基底在主要外围已普遍过亮偏黄|不支持，相对含光晕真实目标平均更暗、更青蓝；也不能据此证明基底正确。|
|完整返光最终响应总体背离目标|不支持，多数颜色距离改善；但部分色相/亮度与白斑退步。|
|缺橙红仅是纸白附近正常压缩|不支持，近灯真实橙区并非近白，H仍青蓝。|
|已经证明主因是返回光谱或扫描|尚未；三张最终图不能独立辨识输入、显影、材料与扫描。|
|应增强调光晕或重拟合输出|不成立，已存在局部亮度退步，且缺少真实纯光晕/设备标定。|

最具体的未解决量是：**真实橙区需要的暖色位移，与当前增量仍有比例和幅度差异，同时不能加重邻芯过亮。**
后续应以同定光非中性密度/光谱设备响应，或已知源与材料前背照测量作独立控制；
不能用未知灯芯的最终扫描残差同时校准这些环节。引用既有肩部消融与染料分解，不再重复大规模探针，
不把本次诊断升级为某个物理环节的根因判决。

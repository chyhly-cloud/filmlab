# 同画幅天花板局部对照与研究分界（2026-10-20）

**2026-10-21 版本限定与几何复验：** 本文负向a*走势属于当时的旧输入halo基准。
[格线几何核查](LOCAL_CEILING_REGISTRATION.md)在同一固定像素组复现原数值，并证明近灯平面修正后旧基准仍为−7.273，真实为+6.844。
后续源反演实验候选已为正向+2.267，幅度仍不足且未被正式采用；不能把本页反号不加版本限定地套到这些候选。
未标定新的毫米环带或灯体视差，没有据此修改材料/扫描/current/next。

## 决策

**近顶灯存在当前模型未复现的局部空间颜色过渡，不能用整图常数偏色或最终线性RGB的通道增益单独解释。**
更准确的描述不是“所有灯旁都整体缺红”，而是在选定天花板方向上，模型内侧相对过强，向外的暖色与亮度变化退得更快。
此结论是同材质表面的空间对比，**不等于测得了真实物理光晕，不定位到某个光学/显影/扫描环节**。

中顶灯在排除灯体和接缝后，没有足够内侧天花板样本；停止完整径向橙环比较。
它能提供外侧提亮/去彩的有限观察，不能当作第二个独立橙红环验证。

现有数据仍可描述局部差异、检查配准/信息覆盖和验证模型内部计算；
无法独立恢复源辐射、未显影材料参数、非中性显影和扫描响应。
**冻结用这些最终扫描反推上述参数的研究路线，保留局部失配现象；优先取得已知源、负片密度与扫描响应的分阶段测量。**
不扩大参数搜索，不改正式current/next/paper_only，不采用全局曝光补偿、负曝光、DIR调整或新输运器。

## 1. 背景是否足够可靠

只复用`halo-residual-direction`两处512×512原图缓存（real/nohalo/halo，均为线性RGB），
next_sensor、原曝光/显影/固定PrintTiming、grain=0、conditioning=None保持。
没有RAW解码、重渲染、重新配准或颜色校正。

根据原图可见结构，灯体上方有同类天花板表面，可与同一可见板面右侧相比。
框选配置在`tools/eval/local_background_regions.json`，按材质/接缝/灯体边界确定，
没有用橙色像素或模型误差选择目标。背景中不要求“颜色最接近模拟”。

- 近灯：目标为灯体上方条带，1103个原有未饱和接收像素；主要参考是同板右侧，另留相似饰面的上/下板作敏感性检查。
- 中灯：目标为灯体上方窄条带，537个像素；同板右侧参考仅100像素，另留上板参考。
  下侧参考拒绝：裁图下缘可见下一盏灯，不能拿来充当独立背景。
- 黑色接缝与灯体不纳入目标/参考。目标条带不构成完整圆环，不用于估计整灯PSF。

这些区域**只足以支持描述性局部表面对比**。同一饰面不证明反射光谱/BRDF完全相同，
没有证明相同照度、无返光或无扫描局部处理；上/下参考也含明显照明梯度。
因此不将任何一个参考称为真实无光晕基底，也不拟合背景曲面来制造对照。
原始照片只叠加框线标识，未改像素颜色。

### 配准限制比此前的“可靠”表述更具体

以附近三处结构接缝的暗线位置作独立检查，不更改原几何：
近灯模型相对真实有−7/−5个横向像素、−5个纵向像素的残差；中灯约−4/−2、−3像素。
全部暗线极小值位于检查窗口内部，没有把窗口边界当接缝。
按原名义6.59824µm/像素，量级约13–46µm；只能作为结构错位估计，不是统计误差界。

对原模型施加0及±8像素轴向/对角平移作测量敏感性检查，**全部保留，不选最好对齐版本**。
该范围约53µm，覆盖测得接缝偏移；未覆盖旋转、非刚性变形或灯体突出于天花板的视差。
源灯芯位置和场景捕捉差异仍不能据此宣布完全匹配。

## 2. 测量的量是什么

每图各用自己的相同坐标参考，定义：

```
deltaLab(x) = Lab(x) − median_background(Lab)
deltaC(x)   = sqrt(a(x)^2+b(x)^2) − median_background(sqrt(a^2+b^2))
```

Lab差与彩度差分别计算；不能用delta a或delta b直接冒称真实光晕强度。
色相为atan2(b,a)，只在C≥5的样本中定义；角度使用圆均值和合向量长度，避免±180°被平均成0。
真实/完整模型色相比较另取双方共同C≥5的目标像素，不让中性化改变支持域而造成假改善。

另计算线性RGB的相对比值：

```
qRG(x) = log2(R/G)(x) − median_background(log2(R/G))
qBG(x) = log2(B/G)(x) − median_background(log2(B/G))
qY(x)  = log2(Y)(x)   − median_background(log2(Y))
```

在通道为正、无新增裁切的前提下，qRG/qBG严格消去各图最终线性RGB的整图独立通道增益；
qY消去最终线性亮度的统一乘数。它们**不消去曝光进入胶片后产生的非线性，也不消去扫描曲线、颜色矩阵或局部处理**。
qY的单位是输出亮度比的log2，不是测得的入射曝光EV。
deltaLab只消去加性Lab常数，不声称完全消除了真实扫描的白平衡。

主结果先对所有图同作25µm尺度线性RGB平均再转Lab，原生像素结果另存；展示照片不平滑。
这里线性RGB是沿用既有sRGB约定解码的输出坐标，不是测得的场景辐射；实际扫描的非线性响应仍未标定。
无光晕反事实的部分参考红通道已裁为0或接近0。相关qRG置为未定义，不垫epsilon、不换参考；
图中的比值曲线只显示真实与完整模型。其余有限值及支持比例完整记录。

## 3. 扣局部背景后，平均“缺红”说法需要收窄

主同板参考；表为目标区相对自己背景的中位变化，非整图绝对误差：

|区域/状态|deltaL*|deltaa*|deltab*|deltaC*ab|
|---|---:|---:|---:|---:|
|近灯真实|14.74|18.92|18.83|−12.80|
|近灯无光晕反事实|15.65|15.51|15.36|−21.78|
|近灯完整模型|15.62|17.55|15.47|−23.30|
|中灯真实|9.19|15.11|9.32|−17.87|
|中灯完整模型|10.01|10.54|8.14|−13.28|

近灯平均deltaa只相差约1.37，远小于此前绝对颜色差；不能继续用绝对偏色概括全部局部误差。
上/下参考下真实deltaa为24.22/26.78，完整模型为13.80/19.53，说明幅度明显依赖背景选择。
这些变化不用于挑一个最有利参考或拟合新的补偿。

近灯目标真实像素彩度中位约6.99，背景19.79；模型目标约8.47，背景31.78。
两者彩度都下降，但真实颜色方向越过中性附近，模型仍停在青蓝侧，不能用彩度下降判断橙色是否恢复。
在共同有色度的632个像素（目标57.3%）上，真实相对背景的圆均值色相位移约165.7°，模型约10.6°。
这只是选定局部的色相描述；其物理归因仍需下述空间/比值检查，不能仅凭这个角度排除非线性扫描。

中灯共同有色度样本为402个（74.9%），真实/模型色相位移约−.60°/+.56°，主要是提亮和去彩，
**所选纯天花板区域并不证明存在一个独立橙红环**。灯体中的暖色不能直接当乳剂散射观测。

## 4. 更稳健的差异是近灯的内外空间走势

沿同一纯天花板条带，用已有核心边界距离分为0–100µm内侧（201像素）、200–300µm外侧（336像素）。
这些是原名义距离代理，非从新光晕形状拟合的半径。

|近灯条带|deltaL*|deltaa*|deltab*|
|---|---:|---:|---:|
|真实内侧|17.32|16.58|18.09|
|真实外侧|11.73|23.43|18.68|
|完整模型内侧|20.99|22.24|20.03|
|完整模型外侧|6.72|12.28|7.54|

真实向外亮度下降，但红向变化继续增加、黄向基本保留；模型向外三项均下降得更快。
因此局部特征不是“模型所有位置都弱”，而是内外的分配/响应形状不同。
无光晕反事实外侧deltaa≈−.72、deltab≈2.07；完整模型提高到12.28/7.54，表明光晕确有作用，但未重现真实23.43/18.68。

再直接计算“外侧−内侧”，此时背景常数完全抵消：

|量|真实|完整模型|完整模型的±8像素平移范围|
|---|---:|---:|---:|
|L*外−内|−5.59|−14.27|−16.93至−9.27|
|a*外−内|+6.84|−9.96|−14.49至−5.35|
|b*外−内|+.59|−12.49|−15.29至−7.77|
|log2(R/G)外−内|+.256|−.776|−1.308至−.406|
|log2(B/G)外−内|+.037|+.261|+.162至+.306|

真实/完整模型全部目标和主参考通道为正，比值有完整支持。比值走势差异保留，
所以**只对最终线性RGB施加整图对角增益不能消除该局部失配**。
原生像素方向同样保留：a外−内真实+7.26、模型−10.74；不是25µm平均单独制造的结果。

这仍不是证明传播核半径错误：同一个非线性扫描算子、光源谱/强度/几何差异和非中性显影，都可能对内外不同状态产生不同响应。
不能用这条窄条带拟合二维核宽、总光能、材料吸收或显影系数。

中灯纯天花板目标全部落在200–300µm，内侧样本为0；**在这里停止内外空间比较**，不把灯体像素补进去凑满环。

## 5. 哪些还能用现有数据解决，哪些需要新测量

|问题|现有数据的能力|继续所需的独立证据|
|---|---|---|
|近灯是否只有整图常数偏色|可排除这个简单解释；局部内外方向差异在所测错位范围保留|更精确同平面/灯体配准可收紧几何误差，但不标定物性|
|中灯是否有同样完整橙环|本次纯表面对照不足，停止该验收|不含灯体的足够同材质内外样本、低视差配对|
|RAW灯芯输入是否准确|已有饱和/包围曝光可核信息覆盖，主要灯芯仍未知|各灯光谱/辐射标定、全部通道未饱和HDR、暗电平/曝光比/闪烁和逐灯配准记录|
|真实负片是否已形成对应空间染料变化|现有最终RGB无法独立判定|冲洗后负片的空间光谱密度/多通道密度测量，未经过最终扫描影调；需要测量仪器自身PSF|
|传播、层吸收是否错误|可检数值守恒与假想反例，不能恢复800T系数|未显影层厚度、折射率、吸收/散射/角分布及活性吸收与感光效率的独立测量|
|非中性显影是否正确|可验证现模型响应，但不能由一张扫描证明化学|已知波段及强度的单色/混合曝光阶梯、同批胶片同C-41工艺、染料/光谱密度|
|扫描是否把负片空间颜色变白|本次不能与材料唯一分离|同负片/密度标准的固定设置重复扫描，含中性和有色密度阶梯；记录自动校色、影调、锐化/降噪与编码|

最有辨识力的下一组数据应串联三项：

1. 同一受控光源在同材质平面旁，测量SPD/亮度并拍摄可靠RAW包围曝光与胶片，记录几何和工艺。
2. 在扫描输出前测量该负片的局部密度/光谱空间分布，用以区分源/胶片与扫描。
3. 对同一负片和有色/中性密度标准作固定扫描设置的重复测量。

只有更多最终照片而没有中间测量，仍难分开三套未知系统。
本轮不继续用最终RGB选择光学、显影或扫描参数；保留假设与可复现失配，等相应测量解冻。
没有由此启动快慢子层、改变核形或扫描曲线。

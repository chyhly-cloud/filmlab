# 现行光晕核的数值域与离散化审查

2026-10-20；本轮不使用真实照片、最终 RGB、扫描或显影，不修改生产代码。

## 研究结论

发现一项可独立验证的小型实现不一致，以及一项分辨率相关的点采样近似误差：

1. 单次 `halation_kernel` 用圆域 `r≤r_max` 的角度总质量归一化，却把密度采样到未屏蔽角点的方形数组。
   在15.625µm网格上，约0.478%的核质量位于与1.5mm圆域**完全不相交**的像素中，因此不是圆周边缘像素的归类问题。
   总核量仍近似正确；这是质量分布与声明截断域不一致，**不是能量凭空增加或消失**。
2. 在完全相同的既有角分布下，按接收像素面积积分与现有中心点采样的差异随网格变粗增加。
   这说明低分辨率计算中存在可量化的离散误差，但参照只对应“源像素中心点源→接收像素面积”。
   若实际输入代表有限面积均匀源，还需源像素足迹积分，不能把这个参照称为所有图像语义下唯一精确的替换核。
3. 现有5219/NOMINAL代理的红层实际使用6mm范围的多次核，绿蓝层才使用1.5mm单次核。
   对实际红层复合核独立核查，0–300µm累计量在原生15.625µm网格上仅约 **+0.206%** 差异；
   把完整36mm场景压到512像素（70.3125µm/px）时约 **−8.38%**。
   **512像素的原生裁切不等于把完整场景缩到512像素。** 不能把粗网格误差幅度套到原生走廊缓存上。

因此本轮产生了新的**数值实现证据**，没有产生新的800T材料证据或橙红过渡根因。
可以保留面积积分器为独立数值参照，后续若开发数值候选，应先明确源/接收像素语义及截断账本。
不据此解冻对真实RGB的材料反演，不缩窄物理尾部追外观，不修改current/next/paper_only。

## 独立标准及单位

沿用现有条件模型：单位能量已到达片基前表面，给定内部角分布

```
p(theta) = C sin(theta) cos(theta)^f
r = 2 t tan(theta)
```

`theta`范围与生产函数一致，为1e-4弧度至89.5°；`C`由该范围的解析积分确定。
不是声称真实800T具有这个角分布。背面按非偏振Fresnel计算。

由极坐标Jacobian，二维条件返回密度可以独立写为

```
q(r) = C R(theta) cos(theta)^(f+3) / (8 pi t^2)
```

`q`单位为条件输入能量分数/µm²，不是三层感光度标定的曝光H。
独立实现Fresnel与解析表达式，分别按theta和r进行一维求积；1500µm累计量差约2.16e-14。
另用8、16、32阶Gauss–Legendre求积对每个接收像素的面积与圆域交集积分，**不重新归一化**。
保持f=1.5、t=130µm、n=1.5，未拟合任何材料参数。

单次条件能量账本为：圆内返回0.51378757、圆外返回0.01204709、背面逃逸0.47416535，总和1。
截断外返回量独立保留，未将它重新撒进计算域。完整胶片、下行吸收、潜影等不属于此账本。
多次核只核查原有加权近似，不冒称其构成完整光子输运守恒账本。

## 离散结果

L1差以独立圆域返回质量0.51378757归一，不是照片色差或视觉误差百分比。
CDF比较对离散结果使用相同的像素面积圆孔测量，不混用原像素中心分箱数。

|像素间距µm|旧核完全圆域外质量/旧核总量|旧核与32阶面积积分参照的归一L1差|参照16→32阶归一L1变化|
|---:|---:|---:|---:|
|15.625|0.478%|1.886%|0.00414%|
|31.25|0.469%|2.426%|0.00866%|
|62.5|0.436%|4.073%|0.02882%|
|70.3125|0.548%|7.036%|0.04213%|

旧核总量0.51376450，相对解析圆域总量差约−0.00449%，属于原4000角度样本积分差。
可见总量正确不足以证明空间分布正确；但它也排除了“核总量大幅凭空变多”的说法。

现有实际代理 `rho=(0.09361224, 0.00738712, 0.00000759)`，红层触发四次近似返回核，范围6mm。
固定这些既有值，不作参数扫描，解析参考按各次返回厚度`n*t`加权求和：

|红层测量半径|15.625µm网格相对解析CDF|70.3125µm网格相对解析CDF|
|---:|---:|---:|
|0–100µm|−0.802%|−10.265%|
|0–300µm|+0.206%|−8.379%|
|0–800µm|+0.0138%|−0.391%|

这既不能说明扫描颜色应当改变多少，也不能用来解释真实与模拟的a*空间走势反向。
材料与源输入未知，以及现有核的物理近似仍然保留；本轮仅隔离了该给定模型的数值实现。

# 固定成像链的光源数学反演

本轮用户明确授权从实拍扫描反推未知辐射，再作物理与留出验证；这替代此前停止最终RGB反演的研究边界。
所有拟合仅为独立候选，`current`、`next`及生产模块不变，未重新拟合材料、DIR、返回核或扫描曲线。

## 受约束的前向模型

对象为同一走廊两处顶灯。使用原生半尺寸RAW与既有固定配准，源支持只含四个CFA感光元均被既有堆积判定标记饱和的2×2单元。
近/中灯为88/34个单元；原RGB-all标志有92/36，区别来自两个绿通道不能用ANY代替全部丢失。
这仍是饱和启发式，不是独立传感器标定。

保留源空间轮廓和其余场景。先从原S1总曝光减去该源的直接散射与返回贡献，再替换为

```
L(lambda,x) = profile(x) * sum_j c_j E_j(lambda), c_j >= 0
H_new(x) = H_background(x) + sum_j c_j [H_direct_j(x) + H_return_j(x)]
```

同一非负光谱同时产生直接与返回曝光；没有独立拟合三层返光、光晕强度或颜色。
十个候选谱为D65、2700K、3300K、FL2、FL11、LED-B1/B3/B5、HP1、Metal Halide。
以当前理想CIE相机的线性Y=1归一；系数是引擎输入单位，不是已测SI辐亮度。
CIE加解码器逆矩阵只提供相机光谱代理，不能称为G81实测感光度。

原源移除再加回闭合误差不超过3.6e-15；原生q复现误差不超过6.6e-9，RGB复现误差不超过4.9e-8。
显影沿原完整局部上下文计算，原同图搅拌场由染料缓存恢复并验证通道标量一致。
每次输出使用原同一PrintTiming，不重新自动定光。

## 搜索与真正留出

每灯先计算十个固定谱×64幅度候选，再逐固定谱做一维细化；之后16个预设起点做非负联合拟合。
正式运行共8080次前向计算，16个起点均收敛至几乎纯FL2的同一条件解，没有命中数值上界。
有限多起点一致不是全局最优证明；选择结果只依据训练损失。

训练位于距灯芯50–300µm的两相对象限；另两象限持出，300–800µm外缘另作预测。
以25µm线性RGB平均后转Lab，两集合距象限轴超过4σ，有限高斯测量足迹不交叠。
初次仅12度间隙的探索运行可能有平均足迹共享，已归档至`exploratory_aperture_overlap/`，不作为正式持出证据。
同灯空间留出不是独立材料、独立胶卷或扫描仪标定，精确尺度及配准仍受既有假设限制。

## 改善与退步

中位ΔE00，低为好。以下均为固定采样位置的25µm测量结果，不能与历史不同区域/分辨率的整体指标直接混比。

| 灯/区域 | 原基准 | 仅原源整体增益 | 非负谱反演 |
|---|---:|---:|---:|
| 近灯训练 | 17.41 | 6.93 | 5.62 |
| 近灯持出象限 | 23.14 | 6.10 | 4.76 |
| 近灯300–800µm | 4.87 | 6.16 | 5.99 |
| 中灯训练 | 6.87 | 4.32 | 4.17 |
| 中灯持出象限 | 8.82 | 4.86 | 4.31 |
| 中灯300–800µm | 3.52 | 4.28 | 4.10 |

近/中灯拟合平均输入Y为488.03/280.29，旧先验为40.52/14.74，相对约12.05/19.02倍。
这不是测出了真实灯具辐射，也不能作为全局光晕倍率。
单独放大原源的控制最优增益为8.03/13.30，也解释了大部分改善；谱形与直接/返回比例的变化提供较小额外改善。
因此不能把本轮成功全归于FL2光谱，更不能称已证实真实灯谱为FL2。

所有正式最优解在既定相机代理下都满足饱和观测的单侧下界，违反率为0。
该事实没有提供真实亮度上界；全失测条件允许很大范围的源辐射。
`.03`相机单位为明确声明的数值删失容差，不是事后拟合噪声或实测置信区间。

## 跨灯预测和整幅实现

把另一灯的谱形固定，只用目标灯训练L*拟合一个幅度（不看目标a*b*或持出值），随后预测：

| 目标灯 | 幅度Y | 持出ΔE00 | 外缘ΔE00 |
|---|---:|---:|---:|
| 中灯：采用近灯谱形 | 106.38 | 5.18（原8.82） | 3.04（原3.52） |
| 近灯：采用中灯谱形 | 357.53 | 5.99（原23.14） | 4.83（原4.87） |

这揭示颜色拟合与亮度拟合的取舍，不能从各灯Lab最优幅度直接断定真实辐射。
若把全部系数连幅度原样迁移，需额外假定两灯同面辐亮度/轮廓归一；中灯持出退至10.90。
该附加假设未经实测，失败不能直接归罪于谱形。

两源最终同时通过`IncidentSpectrum`注入实际全幅管线，provenance明确为inverse fit / not measurement。
没有改变其余场景或重新拟合。联合持出ΔE近4.764、中4.309，外缘5.988/4.110；与独立局部预测接近。
最大局部RGB交叉影响约.00104/.00591，已单列为同时替换另一灯造成的返光耦合。

## 可作出的判断

数学反演确实能找出明显恢复橙红过渡的源端候选；此前用未知亮度作为唯一理由停止探索过于保守。
但候选的外缘仍偏红，部分区域偏亮，尚未通过整体局部验收。
源强估计可以补偿返回比例、材料响应或扫描代理的误差；正谱、非负曝光和删失下界只是必要条件，不是实际800T正确性的证明。
本轮不推广全局参数、不修改正式默认；保留可渲染候选、跨灯预测和失败区域。

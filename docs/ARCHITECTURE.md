# FilmLab 成像链架构 (实验分支 `film-physics-decoupling`)

目标: 按真实成像过程的物理顺序拆分系统, 使 **胶片物理** 与 **某家冲印店的扫描效果** 在结构上分离、可以分别验证,
并为日光 / 夜景 / 混合光源的色彩准确性改进提供逐级可测的误差分解。正式基线 (`Engine.render` 的现有输出) 保持逐位一致。

## 1. 设计原则

1. **物理核心的终点是底片本身**, 不是任何 RGB。底片 = 三层有效曝光 → 三层染料量 → 光谱密度 / 透射率 T(λ)。
   一切 RGB (扫描、印放、观看) 都是"用某个仪器测量这张底片"的结果。
2. **扫描仪的各步留在它们真实发生的位置**:
   光学测量作用于 T(λ); 去片基与胶片类型换算在扫描密度域; 自动校色 (= 印放光号) 在负片密度域、成正像之前;
   数字相纸把密度变成正像; 只有输出调整 (饱和度矩阵、tint) 在最终 RGB 上。
3. **每个参数标明身份**: 物理实测 / 硬件估计 / 软件标准 / 操作员变量 / 经验拟合。
   经验拟合只允许出现在操作员变量与输出调整两级, 不得反向修改上游。
4. **每一级有自己的验证数据**, 不用终点统计去调上游参数。

“物理核心”表示阶段与数据域的组织方式，不表示所有参数已由材料测量确定。
光源区域推断、未冲洗乳剂透射代理、光晕角分布和交叉显影都有未验证假设；
最新受控检查及逐阶段夜景消融见 [HALATION_CHAIN_AUDIT.md](HALATION_CHAIN_AUDIT.md)。

当前实现是遵循胶片成像阶段的有效模型，不是已独立标定的 CineStill 800T 材料与扫描仪模型。
`FilmState.latent` 存储三层 log H，不是逐颗粒潜影中心；显影以特性曲线、动力学和 DIR 近似求染料量，
不能仅凭这些变量的名称断言已复现实际乳剂化学。来自其他胶片或原生工艺的数据，也不能自动等同于800T在C-41中的响应。
DSC03906 的单路径追踪已在显影前找到环形曝光峰，见 [USER_RAW_HALATION_FAILURE.md](USER_RAW_HALATION_FAILURE.md)；
物理阶段顺序正确不足以保证输入先验、返回光分布和最终颜色正确。

独立候选输入契约：`incident.IncidentSpectrum` 可把已知总入射光谱直接积分到 S1，
`brackets.replace_measured_highlights` 可替换经独立曝光验证的传感器测量。
二者均显式启用，不自动将高亮像素分类为发光体，默认代际不变。
实际测量验收与未恢复灯芯见 [MEASURED_SOURCE_VALIDATION.md](MEASURED_SOURCE_VALIDATION.md)。

## 2. 阶段与数据契约

```
RAW ──S0 输入──▶ 相机线性 RGB (日光白平衡, WB_REFERENCE)
     ──S1 曝光──▶ LayerExposure    log10 H (…,3), 光源类别权重图
     ──S2 显影──▶ FilmState        三层染料量 c, 银, 卤化银
     ──S3 底片──▶ Negative         光谱密度 D(λ) = D_base(λ) + Σ c_i ε_i(λ) + 银 / 乳白; T = 10^−D
═══════════════ 物理核心终点 (Negative): 可导出 Status M 密度、任意仪器的测量 ═══════════════
     ──S4a 扫描光学──▶ 扫描密度 D_k = −log10 ∫T R_k / ∫R_k  (R_k: 光源 × 传感器通道光谱响应)
     ──S4b 胶片类型换算──▶ Dn: 去片基 (片头读数), 窄带 → 印放密度 (P), 档案反差 gain / 中灰 gray0
     ──S4c 定光 (自动校色)──▶ PrintTiming: 每通道偏移 + 受限斜率 (灰平衡), 曝光 K、反差 s、高光肩部
     ──S4d 数字相纸──▶ 输出参照的线性 RGB: 相纸特性曲线 + 相纸染料串扰 (参考印放, D50 观看, 黑点补偿)
     ──S4e 输出调整──▶ 冲印店风格: SATURATION_MATRIX, LAB_TINT
```

| 级 | 模块 | 内容 | 参数身份 | 独立验证数据 |
|---|---|---|---|---|
| S0 | `lights`, `rawio` | 相机 RGB, 白平衡参考, 光源类别, 光谱重建 | 物理 + 信息极限 (同色异谱) | libraw 约定; 已知光谱图卡; RAW 曝光分解 |
| S1 | `film`, `engine` | 三层感光度积分, 测光, 散射, 光晕 | 感光度来源数据 + 光谱/吸收/传播近似，未独立标定完整800T材料 | 图卡与真实配对约束整链；假想材料验证传播算法，不能确定800T系数 |
| S2 | `chemistry` | C-41 / ECN-2 动力学, DIR, 颗粒 | 特性曲线驱动的有效模型；跨材料/工艺外推未独立验证；τ 冻结 [1.0, 1.3] | Kodak 曲线 (同源, 仅自洽); CineStill 对照，缺800T非中性独立显影测量 |
| S3 | `negative.Negative` | 染料光谱, 片基 + 遮罩 | Kodak 来源光谱及混合吸收模型；不等于当前800T/C-41批次实测 | Status M 灰阶; 遮罩审计；同源检查不构成独立材料验证 |
| S4a | `scanning.optics` | LED 峰值 / 带宽 | 硬件估计 | 真实扫描图卡 (相对灰轴) |
| S4b | `scanning.conversion` | 去片基, P, 档案 | 虚拟印放代理 (以 Portra 800 近似通用通道)，非实测Frontier输出换算 | 真实扫描图卡 (相对灰轴，约束整链) |
| S4c | `scanning.timing` | standard / gray / frame (Frontier 自动) / 固定光号 | **操作员变量** | RAW 配对 (定光预言机, 见 §4); ref3 总体 |
| S4d | `scanning.paper` | 相纸曲线、染料、黑点（额外肩部在 S4c） | 材料实测 + 扫描输出代理假设 | 灰阶/真实配对可检验整链，不能单独辨识设备响应 |
| S4e | `scanning.conditioning` | 饱和度矩阵、tint | **经验拟合** (冲印店风格) | 只能用冲印店扫描 |

`scanner.Scanner` 保留为组合这些阶段的外观类 (原有属性与函数名不变), 现有工具和基线输出不受影响。

## 3. 预设

| 预设 | S4c | S4e | 用途 |
|---|---|---|---|
| 正式基线 (`timing="frame"`, `frontier`) | Frontier 型逐帧 | 矩阵 + tint | 与现行输出逐位一致 |
| 物理参考 (`recipe("cinestill_800t_reference")`: `timing="standard"`, `output_conditioning=None`) | 胶片在设计光源下的中灰一次定标, 不逐帧 | 无 | 检验物理核心 + 扫描硬件, 不含操作员与风格 (光源偏色按物理保留) |
| 冲印店预设: 无输出调整 (`recipe("cinestill_800t_frontier_plain")`) | Frontier 型逐帧 | 无 | 不加 ref3 网络总体风格的冲印店 (EPFL 同店验证, 可选) |
| 定光预言机 (评估专用) | 按真实扫描拟合限定的每帧光号与反差自由度 | 无 / 有 | 控制模型内逐帧平衡差异，不能独立剥离真实扫描仪与材料误差 |

## 4. 定光预言机: 控制模型内的逐帧平衡差异

评估将逐帧校色限制为密度域的每通道偏移 (印放光号 / C·M·Y 校正键)、有限的通道斜率，
以及整体曝光与反差。这是模型的受限操作集合，不是对真实扫描软件全部功能的物理证明。
对每个 RAW 配对, 在 Dn (S4b 输出) 上拟合这几个自由度使模拟最接近真实扫描:

- **剩余误差** 是受限操作集合不能解释的整链残差，仍可能包含输入、配准、材料和未建模的扫描处理，不能直接归因某一级;
- **拟合出的光号** 与 S4c 自动定光预测之差，是模型内平衡差异，也可能吸收其他环节的偏差。

这样可减少模型内逐帧平衡在配对与 ref3 之间的冲突 (CRITERIA.md "模块消融")，但不能使物理修正 (WB65、P、染料、遮罩) 自动获得独立可辨识性。
预言机只用于评估, 不进入任何渲染预设。

## 5. 为日光 / 夜景 / 混合光源创造的条件

- **逐级可观测**: `Engine.develop_negative()` 返回 `Negative` (log H、染料量、光源权重图); `Scanner.trace()` 返回
  扫描密度、Dn、定光参数、相纸密度、调整前后的 RGB。不再需要猴子补丁截取中间量。
- **按估计光源类别分组的残差**: 预言机定光后, 用 S1 的光源权重图把残差分到日光 / 钨丝 / 钠灯 / LED …，提出 S0
  (光源识别) 或 S2/S3 (胶片对该光谱的响应) 的待验假设；分组本身不能独立定位原因。
- **日光**: 区分"偏暗偏冷"来自定光 (冲印店把暖色校掉) 还是来自物理 (灯光片在日光下的层间平衡)。
- **夜景**: 区分光源识别错误 (S0) 与暗部 / 光晕 / 肩部 (S1, S4d)。
- **经验部分可替换**: S4e 可以整体关闭或按冲印店替换, 物理修正在关闭 S4e 的物理参考下验证, 不再被经验参数抵消。

## 6. 管线代际 (`filmlab.generation.use`)

| 代际 | 用途 | 内容 |
|---|---|---|
| `legacy` | 历史复现 | 2026-10-18 之前的基线 (分支 `baseline-legacy`) |
| `current` | 正式默认 | legacy + `gray_halo`、`grain_aperture` |
| `next` | 色彩准确性研究的基准 | current + WB65 (RAW 日光白平衡按 D65 中性) + `linear_white`; 经验常数不变 |
| `next_sensor` | 修正候选 | next + RAW 截断按传感器饱和堆积判定 (未过曝画面不再被当作截断重建; 过曝画面与旧法重合 ≥ 97%) |
| `next_halo` | 历史实验 | next + 光晕强度 ×0.1；旧 halo_edge 重复解码使外侧红边依据失效，相关定标证据已撤回，不作为物理修正推荐 |
| `next_k5219` | 实验 | next + 5219 按 Kodak 来源数据重新解混；同源底片重建自洽不等于800T/C-41非中性响应正确，成片退步未解决 |

代际是进程级设置 (WB 参考、默认修正集、胶片数据修订一起切换并清空缓存), 保证扫描档案等内部构造的引擎与之一致。

# 固定后端可达性与光谱—空间可分离性（2026-10-20）

后续必要核查见`BASE_COLOUR_SYSTEMATIC_AUDIT.md`：局部数值结果可复现，但不是严格不可达；
跨场景正常远区不支持统一青蓝基底偏差，咖啡馆另有明显远区青蓝偏差。不得据本记录采用负曝光或改蓝层感光度。
另见`LOCAL_BACKGROUND_AND_RESEARCH_BOUNDARY.md`：结构接缝显示原局部配准有2–7像素残差，
不能将原固定坐标可达性结果升级为真实材料约束；模型内反事实和数值复现本身不受此改动。

## 决策

**本轮不把新输运器接入FilmLab。** 已证明假想材料的波长/半径/吸收层存在不可完全分离的耦合，
但尚未证明它是走廊失真的主因，更未证明改变返回光谱与空间分布足以修复固定基底下的颜色和亮度。

后端并非绝对不能编码目标橙色：近灯橙色代表点允许改变基底后，可在原显影/扫描下精确得到目标Lab。
然而找到的这个解需要**减少蓝层基底曝光**，不能由额外返光实现。
固定无光晕基底、仅允许非负三层追加曝光时，八个局部代表点的有限搜索均未通过预定义的亮度+颜色门槛。
这支持先核查基底与后端的颜色—亮度约束，尚不足以直接把实拍误差归因于新光学传播机制。

严格解释：有限搜索失败**不是全域不可达证明**。本实验干预局部平滑曝光，不覆盖所有空间异质曝光图；
接近阈值的差异也不能冒称超过实拍配准/纹理不确定度。没有证明“任何非负曝光都不可能”。
正式current、next、paper_only、DIR、光晕强度和扫描参数不变；本轮只新增研究脚本/记录。

## 1. 可达性检查的边界

### 输入与后端确实固定

使用既有`corridor-dye-response/cache`的原生q_alloff、q_base、已验证染料、可信域、固定投影，
以及`halo-residual-direction`的两灯原图/分区。无RAW重解码、重新配准或自动定光。
保持原next_sensor、卷1/帧15、grain=0、conditioning=None及R1-02-3 PrintTiming。
原生像素间距15.625µm来自原`corridor-lights/results.json`，非本轮拟合。

不能用孤立均匀色块替代本次实际后端。原q包含空间显影上下文；缓存可信域外不参与验收。
以原完整负片的染料/重放显影染料比值提取**同一已有搅拌场**，三通道标量一致性另作检查，
不重新抽搅拌，不把染料差当新的显影参数。原生局部保留足够边界，在未改原DIR的情况下重新完整显影。
无光晕输出经固定投影和25µm线性RGB平均后的代表点Lab复现最大误差<1.75e-7。
场景无加性灰雾，允许在线性有效曝光中准确追加，不在logH中直接加光能。

### 干预与目标

每灯四个目标只由真实图与既有掩膜选择：核心外0–100µm、100–300µm、真实橙色子集、Y<.4较暗外缘。
取该区最接近真实平均Lab的实际像素，作为**局部代表点**；不是区域平均颜色，也不是四个独立材料样本。
保留同一25µm测量算子，并将其与原双线性投影组合为原生像素权重。

在其原生邻域增加均匀三层曝光，外围显影上下文固定。主干预为：

```
H_new(x,c) = H_nohalo(x,c) + control(x) × delta_H(c)
delta_H(c) >= 0
q_new = log10(H_new)
```

delta_H是模型感光度标定的有效层曝光，不是瓦或焦耳。三层总和不能用于光学能量账本。
非负三层可独立变化是**宽松可达域**，并非任意三元组都有真实光谱/能量预算。
数值上界覆盖原特性曲线的饱和平台，不宣称是测得的灯芯功率上限。
额外用当前旧吸收代理的D65标定光谱锥检查最佳正增量；其近似可由非负光谱组合构成，
但此锥没有未显影800T独立物性依据，也没有灯芯强度约束，不将其称为真实灯谱测量。

预先定义诊断门槛：|L−L_real|≤1且a*b*距离≤2，均为Lab坐标单位，**不是实拍误差置信区间**。
先作三起点完整有限Lab距离搜索，再作两起点、显式|ΔL|≤1的颜色搜索。
输入优化只判断可行性，不修改材料、显影、扫描或采用这些输入渲染成片。
搜索最优值是“本次找到的最好值”，没有全局下界证书。

### 有符号输入对照：定位限制，不能当返光修正

另允许delta_H某层为负，但总H仍为正，所有显影/扫描参数保持原值。
这是改变基底的反事实，**不是物理返回光、更不是推荐曝光替换**。

近灯橙色代表点得到目标Lab的数值残差<1e-8；找到的delta_H/H_ref约为：

```
R: +2.32335   G: +.40831   B: −.11569
```

H_ref是该点测量权重下原无光晕线性层曝光均值。B减量相当于该参考B曝光的11.6%，
不是照片整体减11.6%，不是负的总曝光，也不是测量出真实胶片应该减少多少蓝层曝光。
近灯主过渡点和中灯橙色小子集也找到精确目标解，均含B减量。
有些其他点受均匀减量的总H>0边界限制，未精确闭合，完整结果保留。

**这排除了“当前后端绝对不能表示该橙色”。** 它不能独立证明基底曝光错在RAW、光谱重建或显影，
也不能证明实际Frontier颜色转换正确；这些环节合起来决定了此处的约束。
“基底平均还偏暗”不保证其三层组成能靠非负返光修正。
本轮未尝试用负曝光修图、改蓝色、改光号或拟合扫描曲线。

## 3. 复用光子输运器的联合分布

没有新开发MCML或新材料。直接复用已验证的三个波长假想材料缓存：

- `photon-transport/synthetic_{450,550,650}nm.npz`：包括散射的完整蒙特卡洛返回吸收。
- `angular-colour/{450,550,650}_True.npz`：无散射、片基前单位条件源、斜光程与有限层深度积分。

保留J(λ,c,r)的实际主动层沉积与径向overflow，不把返回平面的半径误当成吸收位置半径。
下/中/上主动层按R/G/B标签排序；标签并非800T实测感光效率。
径向沉积+overflow与缓存总吸收最大差<3.51e-15；原全MC能量账本闭合误差≤1.87e-13。
两种条件源不相同，其绝对吸收比例不互相比作同一个实验。

以下为450/550/650nm等输入光能控制下，下层（R标签）在**主动吸收光能**中的份额：

|半径|完整散射MC|斜光程无散射积分|
|---|---:|---:|
|0–100µm|40.71%|35.05%|
|100–300µm|35.18%|37.03%|
|300–800µm|40.31%|38.01%|

可见径向组成确实变化，且不必单调。最大的层份额变化主要在更远半径，不能将它直接套给紧凑橙环。
另记录按吸收光子数、假定所有主动层每吸收光子产生同等事件的控制：按λ/550换算能量权重。
它仍不是FilmLab的有效H或真实800T潜影，未知层/波长量子效率没有被暗中设为测量值。

## 4. 可分离近似究竟丢失什么

当前film.py先积分波长成为三层返光源，再用每层K_c(r)卷积。
多次往返rho_c不同，所以**现有模型本来就能产生半径相关三层比例**；发现径向比例变化本身并不推翻它。
问题是：单个接收层的空间核不再依赖源波长。

对已有联合张量构造纯诊断Q(λ,c,r)=A(λ,c)K_c(r)，严格保持每个λ,c的总沉积，
同时保持等能三线源的每层径向沉积（包括overflow）。不改变材料，不丢能量，不把Q作为新核。
然后只更换声明的三线源权重，检验丢失的波长/半径相关性。

|既有假想条件|J与边际乘积Q的总变差|红富源(.1,.3,.6)沉积误差|蓝富源(.6,.3,.1)沉积误差|
|---|---:|---:|---:|
|完整散射MC|3.45%|1.41%|1.81%|
|无散射斜光程积分|1.91%|.88%|1.12%|

总变差=.5×全部绝对沉积差/实际总主动吸收；不是Lab色差或真实照片误差百分比。
对等能源Q按构造精确重现每层径向沉积，**固定一种光谱时，三层各一个核可以表达此积分结果**。
换光谱后无法同时精确重现，才是缺少联合变量的可检验限制。
原MC每波长只有一个种子，不把细箱噪声当统计显著性；确定性积分仍有非零不可分离误差。
其各层最佳秩1相对L2残差R/G/B约1.29%/1.06%/2.68%，任何AλcKc都无法完全表示这个假想张量。
一个严格可分离阳性控制的重建误差仅4.45e-16，检查不是必然拒绝所有模型。

也直接调用原`film.halation_kernel`，用与无散射条件相同的130µm片基、forward=1.5、10µm离散，
比较0–1500µm内部条件径向份额。四环份额约1.22%/33.28%/57.50%/8.00%；
与各波长/层的假想斜吸收分布总变差约4.5–10.9%。这包含共同角度吸收/有限厚度形状差，
**不能全部归为波长提前积分的损失**。条件归一化只用于图表，不回写输运；区外尾部在联合统计中完整保留。

## 5. 下一步门槛

1. 后端可表示目标橙色，但固定基底的非负返回曝光搜索未找到兼顾亮度的解；此关尚未通过。
   应优先独立核查基底有效三层组成与非中性扫描/显影的颜色—亮度关系，不能立即增加传播复杂度。
2. 联合传播假设有明确原理依据，但这些是假想材料，误差尚未转化为两灯实拍的可验证修正。
   尚不能认定近芯过亮和外圈缺橙由同一近似导致。
3. 若日后找到符合源光谱/能量约束的非负曝光见证，再检验传播是否给出相应径向曝光；
   或取得未显影材料与实际源测量后再评价耦合幅度。当前不调DIR、不加快慢层、不重拟合扫描。

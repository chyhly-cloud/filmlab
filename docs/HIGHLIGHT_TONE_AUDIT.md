后续真实配对复核及数据恢复状态见 [EPFL_HIGHLIGHT_VALIDATION.md](EPFL_HIGHLIGHT_VALIDATION.md)；

## 问题与证据范围

用户要求区分传感器丢失的信息、仍在 RAW/负片中却被输出映射压平的信息，以及部分通道饱和时仍有的约束。
本次优先核查第二类，不拟合印放光号、不重拟合经验常数、不修改 current / next 或任何实验代际。

新增 `tools/eval/highlight_transfer.py`：保存每级浮点数组、导出前后 RGB 和指数肩部局部斜率；重建结果必须与
`Engine.scan()` 逐位相同，否则报错。另保存同一底片、同一定光、不经过额外指数肩部的消融结果。

证据是**受控构造的一致性检验**，不等于真实 CineStill 成片验证。EPFL 原始数据尚未恢复，Google Drive
下载请求返回 HTTP 403。本次另用 rawpy 上游 Bayer NEF 验证实际 RAW 路径和掩膜对应，不用它代表 EPFL 夜景。

## 三类信息的边界

| 类别 | 现有数据能说明什么 | 曝光补偿能做什么 |
|---|---|---|
| 传感器所有相关通道真正饱和 | 只剩各通道达到饱和值的下界，原亮度、色比和纹理不能唯一确定 | 把截断平台变暗，不能恢复丢失纹理；生成细节属于先验 |
| 传感器未饱和，负片密度仍不同 | 曝光或染料密度差异确实存在；输出层次丢失可以是映射造成的 | 在层次丢失前重新渲染可以保留；对已量化成同一码值的图像降亮度无济于事 |
| 部分通道饱和 | 未饱和通道仍是实测值，饱和通道有下界 | 可在颜色/光谱假设下约束缺失通道，不能保证唯一恢复；不能把整像素当作完全未知 |

亮度高、RGB 大于 1、看起来白，都不能单独证明传感器饱和。现有 `sensor_saturation()` 是堆积启发式，
不是独立标定的传感器饱和标准。工具分别记录半尺寸 RGB 掩膜及下采样后的保守分类；掩膜有任何饱和的块不归入全实测组。
两个绿色 CFA 样本按 ANY 合并，因此三个 RGB 标志均饱和也不等于每个 CFA 样本都已丢失。报告明确保留这一限制。

## 在哪里压平

实际扫描顺序为：

```
负片染料 → 扫描密度 Dn → 灰平衡/定光 → 额外指数肩部
→ 数字相纸密度 → 光谱反射率/输出 RGB → 输出调整 → [0,1] 裁切 → sRGB → 8 位
```

1. `filmlab/scanning/timing.py:PrintTiming.paper_exposure` 先计算 `xe = K - s*(off+r*Dn)`。
   对高光侧 `xe < x_knee`，再施加指数压缩。令 `w=x_knee-x_white>0`，其导数为
   `d(xe_out)/d(xe) = exp(-(x_knee-xe)/w)`：连续、单调，但越亮斜率越接近零。
   `frame_auto()` 启用它；standard / gray 没有额外肩部。
2. `filmlab/scanning/paper.py:DigitalPaper.density` 再用相纸实测曲线反转。高场景曝光形成高负片密度，
   相纸曝光随之降低，落到相纸低曝光趾部，密度接近零，即接近纸白。**所以去掉第一道指数压缩，也不自动获得宽容的 RAW 显影。**
   曲线范围外的 `np.interp` 还会固定到端点；本次列出的 +8/+10 档样本未超出横轴范围。
3. `filmlab/spectral.py:srgb_encode` 最后才裁切到 [0,1]；`filmlab/io.py:save_srgb` 量化到 8 位。
   这是另一种真实信息损失，不能与此前的低斜率压缩混为一谈。

正常 RAW 显影也需将宽动态范围映射到显示范围，但其显示曲线/局部处理不必复现相纸的有限曝光范围。
FilmLab 当前采用“底片 + 数字相纸 + 可选额外肩部”，因此并不天然保留普通 RAW 显影的高光表现。
这不表示剩余负片信息无法再利用，而是当前输出映射没有给它分配足够的显示层次。

## 可重复的量化例子

`next`、标称材料、CineStill C-41、关闭颗粒和输出调整；固定同一中性参考的三层曝光比例，按 1/8 档
扫描 −6 至 +10 档。不使用每档重新估计的反射光谱，排除空间散射/光晕。逐帧定光只拟合一次整条阶梯，
对比时固定它，不逐点调亮度。这是曝光传递诊断，所列阈值不是现实夜景的通用阈值。

| 输入相对曝光 | 负片 Dn 绿密度 | frame 输出 Y | 额外肩部局部斜率（绿） | 导出 RGB |
|---|---:|---:|---:|---|
| +4 档 | 1.444 | 0.8809 | 0.2047 | 237,242,244 |
| +6 档 | 1.822 | 0.9215 | 0.0409 | 246,246,246 |
| +8 档 | 2.133 | 0.9276 | 0.0109 | 247,247,246 |
| +10 档 | 2.315 | 0.9288 | 0.0050 | 247,247,246 |

+8 到 +10 档负片仍增加 0.182 D，浮点 RGB 也不同，但导出像素完全相同，而且三通道浮点值均小于 1。
因此它明确属于**映射压缩加量化导致的层次丢失**，不能归咎于传感器，也不能称为浮点硬截白。
未启用额外肩部的 standard / gray 路径中，同一曝光段也因相纸趋白而输出接近纸白；工具的固定定光消融可分离这两个因素。

## 处理决定与下一步

此次确认的是层次丢失机制，尚未证实一个可以直接采用的替代影调公式。相纸曲线本身有实测来源，
但把它作为目标扫描仪的完整数字输出传递，以及额外肩部起点、指数形状、渐近白点，是不同层级的假设。
不能因曲线来自相纸，就把整套扫描映射视为已测定；也不能仅凭“更有层次”选择新参数。

保留所有代际和经验常数。下一步恢复真实配对后，应只用全实测像素，固定同一底片和同一定光，分开验证：
无额外肩部、相纸趾部、输出调整、最终裁切/量化。独立目标宜为同一负片的原始扫描密度与输出阶梯，
或带已知曝光级差的胶片阶梯扫描；需覆盖高光且检查中间调/颜色是否退步。传感器全饱和核心不参与拟合。

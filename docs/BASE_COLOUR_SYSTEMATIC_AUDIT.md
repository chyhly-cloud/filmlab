# 正常区域的跨场景基底偏差与可达性收敛（2026-10-20）

## 本轮结论

**现有配对不支持一种跨场景、统一青蓝方向的无光晕基底偏差，也不支持全局减少蓝层曝光。**
但青蓝问题并非只存在于灯具附近：咖啡馆的正常远区也明显偏青蓝、偏暗，完整光晕输出仍然如此。
走廊正常远区与灯旁表现不同，其他夜景还出现偏红、偏黄、偏绿黄等不同方向。
因此暂不将近灯约+2.08L*的有限搜索结果升级为基础后端的严格不可达或蓝层感光度错误。

这里排查的是**可观测的共同残差方向**。真实三层曝光/灯谱/扫描设备响应未测，
不能排除被其他环节抵消的共同物性误差，也不能排除基础管线中依赖场景的算法偏差。
本轮结束于：未支持统一青蓝基底假设，确认场景/区域依赖；无依据采用共同的三层补偿。
不接新输运器，不采用负曝光，不修改DIR、肩部或正式默认/current/next/paper_only。

## 1. 数据与正常区域的定义

使用原有八组EPFL夜景与SillyStill咖啡馆配对；未新找数据或重新拟合几何。
EPFL均为同一卷/同实验来源，咖啡馆是另一台相机且扫描编辑/照明变化记录不完整，单列结果。
保留原next_sensor、roll=1、原帧种子、grain=0、conditioning=None、原逐帧自动定光数值。
全部输入沿用原+0.53EV；没有改成历史咖啡馆专用+1.5EV，亦未按目标亮度重新定光。
九组完整输出对原缓存最大线性RGB差<5.92e-8（咖啡馆<2.11e-15）。

全图缓存缺少无光晕曝光阶段，故每组补算一次原输入负片并记录直接/返回曝光，
以原散射后的直接曝光重做原空间显影和同一搅拌场，再用原固定定光扫描。
这不是把最终RGB减去一个光晕图。原曝光响应、色彩常数与颗粒设置不动。
全图基准使用既有max_size=1400输入与固定配准；不将其数值冒称前轮原生15.625µm灯旁裁图。

预定义排除和测量：

- 保守高亮排除包括传感器饱和、输入测光后线性Y≥1、真实扫描线性Y≥.85。
  **这些是排除区，不是将高亮反射面识别为自发光体。**
- 正常区域要求未饱和、配准有效、真实Y=.05–.65，距排除区>1.5mm；距离沿用名义36mm片幅。
- 严格附加条件：模型返光占每层总曝光<1%，开/关输出各Lab分量变化<1。
  **九组严格条件均无有效远区网格**，不能把它们说成测得的“纯无光晕实拍对照”。
  当前模型本身会给普通反射表面分配返回曝光，不仅给灯具。
- 几何远区是事先另行定义的描述性对照，不要求返光为零；分别保留无光晕与完整输出，避免把真实−无光晕当真实纯光晕。
- 使用24×24像素网格，>90%有效；按真实图纹理排除不稳定表面（L中位绝对偏差≤4，ab偏差范数≤6）。
  每格取同一批像素的线性RGB中位数再转Lab。选择不使用模型误差。
- 所有图仅解码/编码一次sRGB，RGB→Lab输入是线性值。另将距离加严到3mm作同规则敏感性检查。

七组有几何远区支持，共2675网格；R1-04-5、R1-05-6没有满足条件的正常远区，不填值也不降低门槛。
网格高度相关，不能当2675次独立拍摄，更不代表不同胶片/冲洗/扫描仪重复实验。

## 3. 能否区分输入估计、曝光响应与扫描

### 输入光源估计：确有贡献，但不是唯一解释

增加一个输入端对照：用已有单一D65参考曝光映射替换空间光源推断，保持同一RAW、测光、材料、
无光晕、显影、扫描和原光号。D65是隔离控制，**不是假定所有场景都由D65照明，不作为修正候选**。

走廊远区的同格变化中位数约Δa=+4.62、Δb=+2.24；咖啡馆Δa=+6.10但Δb=−.91，蓝向没有改善。
草地Δb约−6.24，而城市/黄昏Δb约+3.40。影响有明显场景依赖，不能通过关闭光源估计统一修复。
咖啡馆远区的推断日光权重均值仅约.95%，其他是暖光/荧光/LED/金卤软混合；
其画面含明显窗光，这提示输入估计值得检查，但没有实测SPD，不能直接将分类判为真伪或据此重标感光度。

保存q_D65−q_auto以及B/G相对曝光变化（EV）：咖啡馆中位约+.079EV，走廊−.019EV，
草地+.406EV。它们是**两种模型推断之差**，不是测得的真实三层曝光误差。

按模型光源软权重分组：蓝调场景771格主导日光，草地20格主导LED，城市12格主导暖光，
其余多为没有任一类≥.5的混合。各组没有重复同一青蓝方向，但这些标签不等于测量过光谱的独立光源实验。

### 胶片曝光响应：本轮不能测得真实三层组成

实拍扫描没有分层潜影/染料/未显影材料测量，也缺准确源SPD与拍摄胶片有效曝光。
因此不能用Lab残差反推“蓝层感光度高11.6%”，也不能由本次异向残差证明感光度曲线完全正确。
此前已知光谱积分的线性闭合只验证计算一致性，不替代这种独立物性证据。

### 扫描基准：仍是可能的场景依赖因素

同一无光晕负片/定光下，仅移除额外指数肩部的控制，对多数正常远区中位Lab没有变化；
咖啡馆也没有改善。R1-01-2因模拟已过亮有约(+.92,+1.82,+1.32)变化，仍不解决青蓝问题。
这进一步限制额外肩部的解释范围，**没有验证数字相纸或固定扫描颜色转换的正确性**。

原逐帧自动光号下，模型设计光源灰片的输出色度本身随帧改变，EPFL参考a多为正，
咖啡馆约(a=.32,b=−4.91)，没有一项共同青蓝偏移可以直接解释所有场景。
这只是模型中性见证，不是场景灰卡或Frontier设备标定。
实拍操作员的实际定光未知；固定模型光号避免本轮凑图，却不能排除模型定光与真实冲印店的差异。

**可区分的结论：** 输入推断能改变部分颜色，但单独替换并不统一修复；额外指数肩部不解释正常远区普遍误差；
三层曝光物性、扫描颜色/相纸代理和真实定光仍不能唯一分离。没有据此拟合共同补偿。

## 4. 对有限可达性结果的必要数值复核

只复核已有近灯橙色点和中灯100–300µm点，不扩材料网格或光晕倍率。
从逐点NPZ恢复原空间显影、搅拌与固定扫描端点；重新计算相同目标。

- 将原非负输入搜索容差收紧、迭代上限提高，换用线性delta_H/H_ref坐标重算。
  两种参数化的输出Lab向量差分别约1.09e-6、8.64e-10，残差未改变。
- 雅可比绝对差分步长从1e-4换到2e-5，相对差约5.50e-6、8.91e-6。
  两点都停在B额外曝光的下界；该方向的一侧梯度指向不应增加B的局部约束。
  投影梯度最大绝对值约6.82e-5/3.50e-4（半平方Lab误差对u的导数，u=log2(1+delta_H/H_ref)）。
- 收紧显式亮度约束的SLSQP报告`Positive directional derivative for linesearch`，
  仍有约1e-8–4e-8的约束越界。**这些终止不能写成严格收敛成功。**
- 另在已发现的B=0、L=L_real+1边界上，用标量括区间求根严格满足亮度，再作一维局部颜色最小化。
  得到a*b*残差2.97014897、7.32416905；亮度误差与+1边界的数值差约3e-14，独立复现原结果。
  R单独曝光可能在亮度目标前已平台化，求根先检查括区间，不能假定一定存在根。

这支持“原局部结果不是明显的参数化/步长/松弛约束错误”。它仍没有全局下界证书，
不覆盖所有空间非均匀曝光、所有灯旁像素、真实源光谱/能量限制，也不证明后端根本不可达。
|ΔL|≤1和ab≤2是诊断门槛，不是实拍测量置信区间；近灯+2.08L*不能升级为基础管线的物理定罪。
负的蓝层增量继续只作反事实诊断，绝不用于曝光替换或标定感光度。

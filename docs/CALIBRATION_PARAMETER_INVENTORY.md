# 校准前的参数清单 (2026-10-23)

用户确定的拟合原则: 只纠正显影链里已有的物理量, 每个参数有事先写好的物理范围, 自由参数远少于独立约束, 不得破坏已核实事实,
用留出数据检验, 冲印店差异只进扫描档案, 拟合值称"校准值"。本文是第一步: **不拟合**, 只测每个参数的影响与可辨识性。

方法 (`tools/eval/param_sensitivity.py`): next 代际, 9 个 EPFL / 咖啡店 RAW 配对 (夜景 4、黄昏 1、钨丝灯箱 1、白光灯管 1、TE226 色卡 1、
他店日光 1)。每个参数一次只改一个, 取物理范围两端; 每个场景用定光预言机 O1 (只给三个印放光号) 消去整体亮度与偏色,
剩下的才是冲印店无法补偿的变化。每格 (24 px) 记录 Lab, 汇总为各组 ΔE00 中位、光源旁 (传感器饱和区 ≤ 500 µm) 与真实为绿色的格子的残差,
并计算参数效应 (上端 − 下端) 之间的余弦相似度。另检查每个变体下 3200K 灰卡在物理参考中仍为中性。

## 解读与分类

| 参数 | 显影链位置 | 物理范围 (出处) | 效应大小 | 可辨识性 | 结论 |
|---|---|---|---|---|---|
| τ 显影程度 | S2 显影 (C-41 冲 ECN-2 乳剂) | 1.0–1.3 (冻结区间; 现值 1.18) | 大 (3.1) | 独立 (与 DIR 0.50, 与扫描 LED 0.57) | **可校准** |
| DIR 层间抑制强度 | S2 显影 (不改中性灰阶) | 现值 1.0 标定于 US 6,210,870 分色 gamma 比; 试探 ±40% | 大 (3.0) | 与扫描印放矩阵 P 相似 0.72 | **可校准, 但必须固定 P** (P 属扫描软件标准, 不与 DIR 同时拟合) |
| 青 / 品红黄染料峰移 | S3 染料 | 7–15 nm (US 5,183,729) / 2–10 nm (无数据) | 很小 (0.3) | — | 数据约束不了, **保持估计值, 不拟合** |
| 光晕: 漫射比例、层吸收、前向程度、乳剂浑浊度 | S1 曝光 (片基反射) | 均为估计 | 中 (0.6–1.7) | 四者互相相似 0.88–0.98 = **只有一个可辨识方向 (光晕总强度)** | 只能校准**一个**光晕强度量; 其余保持估计值 |
| 扫描 LED 波段 | S4a 扫描 (冲印店档案) | Frontier / Noritsu 估计 | 中 (0.9) | 与 τ 0.57 | 只进冲印店档案 |
| 扫描印放矩阵 P | S4b 扫描 (冲印店档案) | Portra 标准近似 | 大 (2.3) | 与 DIR 0.72 | 只进冲印店档案; 与 DIR 二选一 |

- 每个变体下灰卡彩度都 < 0.25 (中性保持), 独立事实未被破坏。
- **范围内的单参数改善都不大** (各组最多约 0.5–1.5 ΔE, 且方向因场景而异: 例如 DIR 加强改善白光灯管 / 色卡 / 钨丝, 却使黄昏变差)。
- **光源旁误差 (约 9 ΔE) 几乎不随任何胶片参数变化** (8.6–9.9): 灯芯与周围的问题不在显影参数, 与此前结论一致 (输入高光信息与扫描影调)。
- 预言机定光下的残差约 5 ΔE, 而现行自动定光约 12 ΔE (CRITERIA "输出调整的拆分"): **成片最大的误差来自扫描定光与影调 (冲印店过程)**,
  它们按原则属于扫描档案 (亮度定光上限、相纸肩部), 可以作为冲印店档案校准, 但不进胶片参数。

## 校准计划建议 (待用户确认)

1. 胶片参数 (对所有冲印店通用): τ、DIR 强度、光晕总强度 —— 3 个自由参数, 范围如上; P 与 LED 固定。
2. 冲印店档案 (EPFL Frontier): 亮度定光、相纸肩部 —— 单独一步, 只用该店数据, 留出另一部分场景检验。
3. 拟合用 EPFL 部分场景, 留出: 其余 EPFL 场景、咖啡店 (他店)、TE226 色卡; 必须保持灰卡中性与 Kodak ECN-2 Status M。
4. 拟合值顶到边界即停下检查结构, 不放宽范围。

- 直接调用 `accept_t02.scene_job`，仅按v2替换apply。临时返回事件观察器读取实际渲染、对齐、Dn和自动光号；每场景独立进程，不注入额外随机调用。

- 每帧200次成对格子bootstrap；每帧种子由固定20261025、scene CRC32和流号决定。帧级10000次成对R/B/K重采样、百分位95%区间。合并k为展开R/B后带共同截距的OLS；另报R、B、K与逐组剔除斜率。
- 区域定义保持原样：核心≤100µm、近100–300µm、中300–1500µm、远>1500µm；按真实扫描L*分暗部<25、中间调25–70、亮部>70。无灯芯不产生距离区域；空区域n=0且统计为null。ΔL/Δa/Δb均为模拟减真实。

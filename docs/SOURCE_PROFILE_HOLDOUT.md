# 实际全幅高光重建的空间形状：短曝光留出核查

日期：2026-10-21 UTC。只验证输入，不拟合扫描、胶片或材料。

## 结论

两个已恢复短曝光的透光孔中，旧重建的错误不仅是总亮度：
把总信号归一到相同时，其中心仍过尖，且一处质心明显偏移。
因此不能把旧重建后的空间profile当成RAW实际测得的光源形状，再仅以一个标量拟合源强。

这是一项**透光孔输入控制**，不是走廊顶灯测量。
它不能证明走廊光晕差异由源轮廓造成，也不能自动授权平坦化灯芯、收窄核或调光晕颜色。
自由空间反演若改善同图最终RGB，仍须标为数学估计，不能由本实验认证为准确辐射。

输入、饱和掩膜、LibRaw上限、降噪、组件面积分类和全幅RNG顺序均保持。

## 指标与结果

对完全相同的有效域M，分别归一估计和参考：

```
p_i = estimate_i / sum_M(estimate)
q_i = reference_i / sum_M(reference)
TV = 0.5 * sum_M(abs(p_i-q_i))
centroid = sum_M(position_i * p_i)
peak/mean = max_M(signal) / mean_M(signal)
```

没有使用参考选择空间平移或缩放。TV属于单位总和空间分布差，不是图像的梯度正则项。
RGB-Y由实际线性RGB的既有LUMA定义；参考相机值经既有数字矩阵转到同一Y代理。
这恰是legacy profile的标量定义（全局测光常数在归一中抵消），**不是实际光度或光谱辐射标定**。
逐相机代理通道也另行报告，结果方向一致；它们仍是逆解码代理而非新传感器测量。

| RGB-Y空间指标 | 透光孔1 | 透光孔2 |
|---|---:|---:|
| 实际seed0旧重建 TV | .18715 | .13394 |
| 先验前输入 TV | .10412 | .07956 |
| 两已接受短曝光之间 TV | .00589 | .00597 |
| 实际seed0旧重建质心距离，native半尺寸px | 1.1556 | .1690 |
| 两参考质心距离，native半尺寸px | .02145 | .02108 |
| 实际seed0旧重建峰均比 / 参考峰均比 | 2.1392 | 1.7474 |
| 旧重建RMS半径，native半尺寸px | 9.0213 | 6.4640 |
| 参考RMS半径，native半尺寸px | 9.4843 | 7.1577 |

这些是**共同条件掩膜内**的分布特征，不是整个透光孔边界或胶片µm尺度。
小的双曝光差异经过一致性门限选择，本身不是无偏误差条或置信区间。
尽管如此，本次实际旧重建对这份已验收参考的形状误差，不能只靠重标一个整体亮度来消除。

严格四CFA子集也保留此现象，seed0单位和TV为.18725/.06569，
而先验前为.07441/.01202；旧重建峰均比/参考为2.1199/1.1364，
质心距离为1.1056/.2144 native半尺寸px；双参考TV为.00470/.00427。
孔2的严格支持只有37单元、范围更小，因此不能与292单元全any-saturated域的数字直接排序。
这些依旧只是透光孔，不能作为走廊顶灯源场测量。

### 32种子的算法变化

不根据隐藏真值挑seed。每次仍在原全幅域执行，仅在执行后取局部Y并归一。

| RGB-Y形状分布 | 透光孔1 min / median / max | 透光孔2 min / median / max |
|---|---|---|
| TV | .08458 / .13809 / .19894 | .05162 / .12820 / .21513 |
| 峰均比 / 参考峰均比 | 1.2424 / 1.7094 / 2.2497 | 1.2518 / 1.7111 / 2.3198 |
| 质心距离，native半尺寸px | .9185 / 1.0510 / 1.1802 | .1503 / .1668 / .2129 |

32个seed的峰均比都高于参考；“只换一个幸运seed”没有消除过尖倾向。
不能说每个seed的每项形状都比先验前更差：有些seed的TV低于先验前。
这些只是算法随机样本的分布范围，不是物理不确定性区间、覆盖保证或实际源形状置信区间。
它们没有包括配准、镜头、相机矩阵、材料或扫描的不确定性。

## 机制与应用边界

旧 `reconstruct_highlights` 用组件内部距离变换定义穹顶，
`lum = base * 2**(stops * (distance/max_distance)**0.7)`。
因此随机档数同时改变总亮度和归一化空间形状；它不是独立实测的光源几何。
本次没有拟合指数、改常数，或用参考重新设计穹顶。

结果支持把这个profile视作待验证输入假设，支持对失测空间自由度作明确有限诊断。
它不提供真实走廊profile，也不证明自由场优化中的尖峰/边界集中是可实现灯具或真实镜头PSF。
归一化还主动去除了总量误差，不能用本表代替[强度验收](EXIF_PRIOR_HOLDOUT.md)。

# 非中性局部传递矩阵与新增结构证据（2026-10-20）

## 本轮实际完成

复用已有99种曝光背景（即297种有限红曝光扰动的基准），不新增背景网格、不拟合物性/扫描常数。
从三层有效log10 H分别作±.001/.0001/.00001的局部差分，保存完整输出×输入矩阵：

```
logH(3) → dye(3) → Dλ(81) → Dscan(3) → Dn(3)
                         → Status M近似(3)
Dn → xe(3) → Dpaper(3) → raw RGB(3) → nonnegative RGB(3) → displayed Lab(3)
```

固定原R1-02-3光号，指数/paper_only共享同一负片及光号；grain=0、roll=None、conditioning=None。
真实灯区域的亮度位置沿用先前审计，不把合成层曝光解释为实测灯光谱。
另外三个子代理独立完成扫描染料扰动、深度充分性和历史来源核查，各自保存代码、测试与文档。

## 矩阵不是黑箱：逐级解析闭合

本轮基准浮点RGB与原缓存逐位相同（最大绝对差0）。
主步长1e-5，分别使用实际染料光谱、探测器光谱权重、原P/gain验证：

|解析关系|与独立直接logH差分的最大绝对残差|
|---|---:|
|J(Dλ,logH) = dye_spectrum × J(dye,logH)|4.37e-11|
|J(Dscan,logH) = spectral detector weights × J(Dλ,logH)|3.59e-10|
|Status M近似对应关系|1.38e-9|
|J(Dn,logH) = (P·gain)ᵀ × J(Dscan,logH)|3.30e-10|
|J(RGB,logH) = J(RGB,dye) × J(dye,logH)|1.05e-8|
|J(Lab,logH)对应关系|7.65e-7|

Status M使用仓库高斯响应近似，**不是ISO 5-3完整标准表**，只用于模型内相对比较。
阶段矩阵有不同单位，不能把范数比叫作光能效率。
1e-4与1e-5步长的RGB矩阵相对差所有99背景均<.1%；较粗1e-3会在少量分段LUT邻近样本跨越区段，
这些点保留而不声称每一级全局光滑。

## 新发现：增红与保留橙色不是同一指标

在原q=(0,0,0)背景，红层logH增加时，模型染料导数为：

```
∂(C,M,Y)/∂logH_R = (+.681584, −.122311, −.077259)
```

扫描输出颜色导数可按三种染料路径精确分解。以下是**同一个样本**，不是相互独立中位数相加：

|指数路径，单位/红层log10 H|青染料路径|品红染料路径|黄染料路径|合计|
|---|---:|---:|---:|---:|
|∂a*（红绿方向）|+12.305|+6.423|−.092|+18.636|
|∂b*（黄蓝方向）|+5.608|−4.033|+1.888|+3.462|

交叉显影与后续映射在该例里**增强红方向，却削弱黄方向**。
橙色需要红与黄同时保留，因此“红层有增量/最终a增大”不足以判定橙红过渡正确。
这也不能证明应改DIR：这些交叉导数是现有模型行为，800T真值未测；此前去DIR和自洽DIR均未修复真实轮廓。
不能从本例取一个经验倍率去补b或改显影常数。

## 亮度分段：损失与旋转分别报告

按扰动前指数输出线性Y分类，固定光号，主步长1e-5。
下表是背景中位数，导数单位为每红层log10 H（不是每EV）：

|线性Y区间|样本数|指数：红层曝光→色度增益|paper_only：同增益|
|---|---:|---:|---:|
|<.005|10|1.052|1.052|
|.005–.05|11|20.533|20.533|
|.05–.4|15|53.002|52.421|
|.4–.85|9|24.233|29.907|
|≥.85|54|.08346|.01794|

增益为sqrt[(∂a)²+(∂b)²]，不是ΔE，也不能直接跨亮度比较为材料效率。
近白仍强烈压缩，暗部/中间调并非统一没有响应。
本轮完整矩阵让“红色量变小”和“红黄方向改变”可分开检查；没有预设全部归扫描或全部归显影。

## 独立扫描扰动与深度实验

- `SCAN_CHROMA_JACOBIAN.md`：直接给固定负片施加青染料谱增量，分开raw RGB、非负裁切、显示裁切与原经验输出调整。
  染料谱一致扰动不是Lab注入红色；未裁切XYZ/Lab可对应sRGB色域外的真实颜色，负RGB本身不等于材料错误。
  裁切可使红色导数转向，必须先看色域位置，不能把反号归于化学。
- `DEPTH_SUFFICIENCY_AUDIT.md`：同总吸收、不同沉积深度，在深度无关效率下完全相同；假想深度效率只说明需正确加权积分，
  并不自动要求更多显影状态。现有三有效曝光记录尚未被这一实验推翻。
- `HISTORICAL_EMULSION_SOURCE_AUDIT.md`：12次有限原始来源访问均被代理CONNECT403阻断，取得原文/表格数为0。
  未核实JOSA表I数值、K/S定义/单位，不以附件数值代替测量。DLF的指定JPG/RAF也未恢复，LED实际SPD在原脚本中明确未知。

## 决定与可解冻条件

继续保留三有效曝光记录，研究重点放在有效曝光应如何由波长/角度/材料吸收产生，以及模型内交叉显影如何改变红黄方向。
没有新设备测量，不把裁切诊断变成一个新的拟合色域映射；没有800T分色显影测量，不调DIR去追这张图。
已有扫描近似候选保留为对照，current/next/paper_only数值不改。

要证明须增加状态，应测到相同正确计算的三层有效曝光在不同深度/时序条件下仍产生不同染料光谱密度。
单纯总光能吸收相同不等于有效曝光相同；单纯深度不同也不构成这个证明。

## 独立计算的最终交叉核对

扫描子代理从同一Dλ直接加青染料谱，主实验从三轴染料Jacobian逐列求扫描导数。
99个基准全部样本的显示Lab青染料列最大差：指数2.84e-9、paper_only5.55e-9，
原始数据见 `independent_scan_crosscheck.json`，不是只核对一个示例。

纯扫描在指数基准99种状态的未裁切Lab中，青染料的a导数均为正。
四种背景却会在R<0后非负裁切产生a导数反号，原线性Y=.0628–.3466，属于本轮中间亮度区间。
负sRGB分量对应色域外颜色，原反射谱非负、XYZ为正；不能将其称作显影或材料产生了负光。
走廊近/中灯与玻璃反光真实Y=.4–.85、0–300µm区的负R和任意显示越界比例均为0%，
所以这些裁切反号例子不能解释该明亮外围的白晕。详见专项原分辨率数组复现结果。

在q0示例，只开启原经验输出调整，纯青染料的a导数从18.053降至12.523，b从8.228降至7.856。
这是经验输出处理的独立干预；没有据此重拟合矩阵/tint，且原走廊plain实验关闭此级，
因此不能把plain白晕归因到这个经验处理。

本轮2项局部矩阵合同、4项扫描导数合同、3项深度充分性、3项角度吸收和2项既有亮度域测试，
合并14项全部通过。`git diff --check`通过，生产代码与正式代际未修改。

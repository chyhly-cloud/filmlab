# EPFL 高光验证：预先固定的方法与证据边界

## 方法登记（读取本轮数值结果之前）

保留 `paper_only` 作为独立消融候选；不修改 current、next、SHOULDER_WHITE、相纸曲线、矩阵或 tint。
不假定指数肩部或数字相纸曲线中任一个错误，不拟合替代曲线。

1. 恢复 `epfl_800t_manifest.csv` 中 36 对指定 RAW/扫描，逐文件验证清单 SHA256。
   首要比较固定为 R1-00-1 至 R1-07-8 八个夜景，不按结果筛选。R1-17-18 灰阶楔只作额外检查，不替代夜景。
   这些数据此前参与过研究，因此不是全新留出集；本轮方法是独立复核，不称为独立于历史调参的数据验证。
2. 复用 `oracle_timing.geometry()` 的固定种子配准；缓存目录由 FILMLAB_DATA 指定。
   不为不同扫描候选重新求几何，也不为任何候选重新拟合印放光号、反差或颜色。
3. 输入使用 next_sensor 的传感器判定，所有路径共用一次解码、测光、物理底片及自动定光 K/s/M。
   这不是修改 next。主比较保留现有高光重建先验，但统计只用所有传感器通道均未标为饱和且远离饱和边界的像素。
   遮罩按实际整数下采样保守聚合，配准后再保守排除，不把部分通道饱和像素当作完全实测。
   全饱和灯芯不用于判断影调。其未知亮度仍可能通过物理光晕影响周边，不能宣称这个混杂已经消失。
4. 比较指数肩部 / paper_only × 无输出调整 / 原有 lab 输出调整，共四种路径。
   前者隔离扫描影调，后者检查默认颜色表现；不另加经验调色。颗粒关闭，以避免模拟随机噪声掩盖层次。
5. 以同一 RAW 测光后线性亮度定义曝光区间，固定每 0.5 档一组（−6 至 +6 档），记录像素数。
   每帧每组至少 200 个有效像素才报告。真实扫描按其 sRGB 标签线性化；模型比较同样的 [0,1] 显示范围，
   并另记越界/8 位码值统计。不得把数值未裁切的 HDR 输出与 8 位扫描直接当成同一输出条件。
6. 分别报告各区间亮度、Lab、色差、彩度和色相变化。曝光区间之间的 log2 亮度增量是主要层次证据，
   不把绝对高光更亮/更暗当作改善。逐帧先报告，再按场景等权汇总，不把所有像素混成一张大图。
7. 局部反差使用同一对齐坐标上轻度低通后的相邻像素，固定间隔 4 个扫描显示像素，
   仅取 RAW 输入相差 0.125 至 1 档、两端均有效的邻居。比较 |Δlog2 Y| / |ΔEV_input| 的中位数。
   它是配准场景上的操作性指标，不等于扫描仪 MTF；真实扫描锐化、颗粒及不同镜头仍是混杂。
8. 几何失败、无有效区间和样本不足必须明确记录；不以零样本或失败帧产生通过结论。
   可视化必须并列真实扫描和模型，曝光、颜色与显示尺度固定，不逐图调亮。

## Frontier 数字相纸模型的审查范围

必须分清材料实测曲线与设备输出模型：Crystal Archive 相纸曲线可支持相纸曝光→密度，但不自动证明
Frontier 的负片密度→sRGB 文件等同于一次虚拟光学印放。还需核对数字曝光、输出 LUT/ICC、显示与打印分支、
相纸过程及文件白/黑点约定。即便厂家以逼近相纸印放为目标，也不能直接确定采用哪条裸相纸曲线及其组合方式。

真实 RAW/扫描配对能检验整条链的预测，但没有同一负片的独立密度测量时，不足以唯一分离胶片响应和扫描传递。
若结果无法辨识，记录缺少的测量并冻结，而不是继续在这些场景上拟合曲线。

### 层次、局部反差与颜色

先逐帧计算，再对八帧取中位数。固定比较区间中心 +1.75 至 +3.75 EV 的输出亮度跨度如下：

| 输出 | 保留的亮度跨度（档） |
|---|---:|
| 真实扫描 | 0.730 |
| 指数肩部，无输出调整 | 0.481 |
| paper_only，无输出调整 | 0.599 |
| 指数肩部，原有 lab 调整 | 0.465 |
| paper_only，原有 lab 调整 | 0.574 |

无输出调整时，paper_only 的该区间跨度在 7/8 帧更接近真实，另 1 帧越过真实值而变差。
这是对同一 RAW 区间保留层次的比较，不是因为候选变亮就判为改善。候选没有恢复所有高光层次。

局部反差的中位增益（相同输入邻居，未经亮度匹配）也显示剩余缺口：

| 输入区间 | 真实 | 指数肩部（无调整） | paper_only（无调整） |
|---|---:|---:|---:|
| +2.0～+2.5 EV | 0.380 | 0.254 | 0.313 |
| +3.5～+4.0 EV | 0.163 | 0.056 | 0.061 |
| +4.0～+4.5 EV | 0.116 | 0.036 | 0.031 |

移除额外肩部在部分区间改善层次，但最亮区仍明显缺乏局部反差，且仅相纸路径开始更快趋白。这不支持把整个缺口
归因于指数肩部，也不足以证明相纸曲线本身错误；曝光、负片密度响应、扫描变换、配准/镜头差异与未知饱和核心仍需区分。

颜色亦没有一致改善。对 +2～+4 EV，逐区间、逐帧等权汇总的 ΔE00 从 10.52→11.36（无输出调整）、
8.45→9.25（保留原有 lab）变差。ΔE 包含亮度，不应将其单独解释为色相变差。
无调整的彩度比从 0.864→0.925，部分饱和度更接近真实；色相误差中位数则几乎不变（约 21.54°）。
保留原有 lab 时，彩度比 0.758→0.821，色相误差约 13.57°→13.42°。不能把更亮/更有彩度当作真实颜色已修复。

附加灰阶楔第 10→14 级：真实输出跨度 0.159 档，指数肩部 0.072 档，paper_only 0.094 档（无输出调整）。
候选保留了更多上部层次，但最后一级 Y=0.972，超过真实的 0.930；原路径为 0.883。与夜景一样，不能只看白点亮度。
此处没有重做历史的 +0.53 档拟合，也不据此覆盖早期报告中不同实验条件下的灰阶结果。

### 数字相纸代理的依据是否充分

已取得并审阅富士 [US6668096B1](https://patents.google.com/patent/US6668096B1/en) 的说明书。
其中“image processing apparatus 14”“image data converting subsection 52 / 58”描述：扫描数据经过 LUT/矩阵、
灰平衡、反差/密度处理；显示和打印有面向相应输出的 3D LUT 转换；打印分支用 RGB 光束调制并曝光感光材料。
这支持数字冲印存在可设置的处理链与输出转换，但不是 EPFL 所用 Frontier 具体机型/设置的响应测量。

它没有证明“导出的 sRGB 文件 = TH-KG3 宽带光学印放密度 + 一条裸 Crystal Archive 材料曲线”。
当前模型的印放矩阵、三层相纸曲线对齐平均、相纸染料映射与黑白点约定，构成了一个可测试的扫描输出代理，
并非整套由设备实测直接给定的变换。源材料谱线有实测来源，不等于这个组合已经获得设备级验证。
“Fuji 2001”仍缺少明确论文标题、页码和所对应公式，不能作为当前整套映射充分成立的依据。

原材料数据的出处是 [spektrafilm](https://github.com/andreavolpato/spektrafilm)，但其相纸感光曲线对应的处理、
曝光方式与 Frontier 文件 LUT 是否一致，仍需独立确认。代码/架构文档已将“材料实测”和“扫描输出代理假设”分开标注；
未修改任何数值计算。

### 决定及解冻条件

继续保留 paper_only，不并入 current 或 next；本轮不拟合任何新曲线，不改白点、锐化、经验调色或相纸数据。
真实配对验证了扫描输出高光层次不足，也显示移除单级转换不是全面修复。
**冻结新曲线拟合和默认采纳**，不反复用这八帧追分。

解冻优先需要同一负片的可测密度/透射阶梯及其 Frontier 输出，记录机型、LUT/ICC、自动校正和导出设置；
或能核对到本机型的厂家响应资料。现有 RAW→胶片→扫描配对没有独立底片密度，不能唯一辨识哪一级响应导致剩余缺口。
全饱和灯芯的未知光量仍不是任意调影调的理由。

# 远场格线约束的近灯局部几何与光晕复验

2026-10-21 UTC。只从实际RAW与真实扫描的天花板结构估计局部对应关系，
不用模拟成片、灯芯、橙红边界或ΔE选择几何。胶片、核、显影、扫描、定光保持。

## 结论

找到并通过了**近灯天花板平面**的局部配准修正：未参与拟合的8个交点，中位误差7.931→.630扫描px。
这可以保留为有独立结构验收的评估几何；它不是胶片物理参数修正。
中灯只有4个可靠验证交点，未达到预设6点门槛，不采用其估计。

冻结近灯几何后重放相同负片，部分误差下降，但橙红过渡仍不符。
进一步按相同有限协议重做源场正反象限拟合，场TV由.712变为.974，没有观察到稳定恢复。
**不能把源场不稳定或橙红缺失全部归因于天花板平面配准。**
突出灯体的视差仍未独立测量，不能扩展成“已排除全部几何因素”。

## 结构取样、方法与验收

从既有全幅解码后捕获的`preprior_rgb`原生局部输入，经原H映到512扫描裁片；另一侧是真实800T扫描。
仅在既有名义距离>800µm、裁片边缘40px外的天花板格线上取点，避开灯芯和灯旁颜色。
结构量为log线性Y经sigma12与1.5 Gaussian之差的暗脊；单独亮度归一仅用于结构图显示，不用于颜色输出。

第一方法：RAW Harris角点、±16px局部NCC、25×25 patch，NCC≥.6、峰差≥.025、互逆误差≤1.5px。
按固定128px棋盘块分train/validation。预设每组至少6点，近灯仅4+4、中灯2+2，**均未采用**。
没有因不足而降低门槛或用灯旁颜色补点。

第二方法使用同一远场格线的**一维法向位移**，不把沿直线不可测的切向位移当成二维对应。
RAW Hessian选择直脊法向；±16px NCC轮廓搜索，NCC≥.8、峰差≥.025。
所有旧角点中心40px内不布线法拟合中心；Gaussian、轮廓平均和搜索足迹仍可共享像素，
因此只能称未参与线法拟合的角点验收，不能称像素独立或新外部场景。

6参数仿射由法向线性约束、固定soft-L1尺度.5px稳健估计。
预设门槛：至少18个法向约束、设计条件数≤20、中心在训练凸包内，
至少6个未拟合角点，中位误差≤1.5px、p90≤3px且相对原几何改善20%；
仿射主尺度.97–1.03、旋转≤3°、中心位移≤16px。阈值不使用胶片颜色或模型误差选择。

另保存四个几何空间块逐一移除的敏感性，不根据角点/颜色结果挑选某一块的变换替代完整拟合。
近灯移除块后的中心dx为5.525–6.656、dy4.093–4.242px，角点中位残差.981–1.966px；
部分子拟合未达到完整拟合的1.5px门槛，说明仍有局部结构/离群和取样敏感性。
这些范围不是置信区间，也不将完整拟合称为唯一、精确的真实映射。

## 1. 发光体与反射表面的物理区分

出射辐射满足边界条件：

```
L_o(x,ω,λ) = L_e(x,ω,λ) + ∫ f_r(x,ω_i,ω,λ) L_i(x,ω_i,λ) |n·ω_i| dω_i
```

透光物体另有透射项。前一项来自自身发光，后一项来自照明与表面反射；相机和胶片接收的是它们的总和。
同一束已知入射光谱经过同样镜头/快门时，乳剂曝光应相同，不取决于这束光来自灯具还是太阳照亮的反射面。
仅凭三通道或亮度阈值无法唯一分解这些项：明亮镜面反光、白墙、天空、亮窗都可能很亮，发光指示灯也可能很暗。

可独立提供的约束包括光源的光谱/亮度测量、设备与场景几何、已知照明与反射率、同位置受控开关照明测量。
物体语义或可见灯具结构可用于标注研究区域，但不等于测得了它的光谱、直接发光占比或物理尺寸。
本轮使用人工固定的灯具/信标/透光孔/表面对照区域，未新增自动高亮分类器。

为核对实现语义，阅读了 PBRT 第四版配套实现的
[发射与反射贡献](https://github.com/mmp/pbrt-v4/blob/master/src/pbrt/cpu/integrators.cpp#L412)：
发射 `Le` 与 BSDF 的反射项分别计算。只阅读外部代码，没有执行。获取地址、文件摘要在实验 `acceptance-summary.json` 中。
教材网页本轮访问返回 403，未将未读页面作为实验来源。

### 显式已知入射信号候选

新增 `filmlab.incident.IncidentSpectrum`：81 点光谱、空间强度图、显式布尔区域、来源。


在指定区域，已知**总入射信号**直接与乳剂感光度、镜头滤镜积分；不再除以估计照明或重新选一款灯具光谱。
区域外继续走已有路径。重叠的完整入射替换会被拒绝，避免双重计数；混合辐射需要调用方先提供总光谱。
空参数不改变既有计算。普通高亮像素不会自动进入此路径。

单位边界：光谱与强度使用既有引擎的相对曝光归一化；没有声称已标定为 W/sr/m²/nm 或绝对 cd/m²。
已知 SI 辐射要用于绝对曝光，还需要镜头/快门与感光度的相应绝对标定。波长步长沿用原引擎约定。
光晕源的吸收换算仍继承现有估计叠层；显式光谱积分不能证明这些光晕物性正确。

| 固定光谱 | 原算法换背景时 R/G/B 直接曝光极差（档） | 显式输入极差 | 显式红层光晕源极差 |
|---|---|---|---|
| 2700K | .194 / .146 / .128 | 0 / 0 / 0 | 0 |
| LED-B3 | .196 / .045 / .131 | 0 / 0 / 0 | 0 |

这是受控计算一致性，区别于真实材料验证。不同背景仍可通过实际空间散射/二次曝光影响成片，
因此不要求整张最终图或经过空间输运的所有像素在换背景时完全相同。

## 2. 测量方法：保留 RAW 中实际存在的信息

### 传感器与解码器的两种截断

直接读取 Bayer 数据，逐通道扣黑电平，按同一机身白电平归一化；两个绿色感光元平均到半尺寸单元。
饱和判定仍使用传感器堆积值，不使用“每帧最亮若干百分比”。
另发现 LibRaw 的 16 位 XYZ 输出可能在传感器尚未饱和时先截断，所以不能只从该输出判断可恢复范围。

`linear_raw_measurements.py` 通过四个已知数字输入向量计算 LibRaw 的线性变换：
在内存中给同一解码器输入 .125 基底和单通道 .25 的受控向量，取有限差分；没有修改磁盘 RAW。
这是查询既有数字变换，不是拟合场景、胶片或照片颜色。
保留高于 1 与色域外的变换结果，直到最终显示才裁切。

实际低亮未饱和区域与原 LibRaw 解码比较，RGB 中位差约 5.10e-5 / 8.34e-6 / 4.51e-6，
99 百分位绝对差约 1.43e-4 / 4.14e-5 / 2.57e-5；包含数字探针与 16 位输出的量化误差。
这些校验只约束解码变换，不代表相机三通道是完整光谱测量。

### 配准、曝光与时间一致性

- 六张备用 RAW 与主帧均检查机身归一化参数、ISO、光圈和已记录 SHA256；新增文件摘要是采集记录，不冒充此前独立哈希。
- 辐射比例仅来自快门/光圈，ISO 200 相同；没有拟合增益或白平衡。ISO 从内嵌 JPEG EXIF 补读，仅用于审计。
- 全局 ORB/RANSAC 后，在灯具外围未饱和结构上只优化局部平移；灯芯不参与平移优化。
  棋盘奇偶像素划分训练/留出检查。几何优化不是胶片参数或亮度拟合。
- 研究性几何门限：外围留出绝对 log 亮度差中位 <.15 档、p90 <.5 档、局部平移未触及 ±4.95 px。
  这些是保守接收规则，不是仪器校准精度，也没有按扫描成片分数优化。
- 短曝光需要三通道均有未饱和的 3×3 邻域，避免插值混入饱和信号。
- 原帧三通道全饱和时：要求两张独立备用曝光逐像素、逐通道在 .15 档内一致，信号高于噪声门限。
- 原帧仅部分通道饱和时：可在源区域三个通道的可测部分均稳定、且该像素剩余实测通道吻合时接收一张备用曝光。
  这是较弱的证据，单独记录；不能据此恢复全饱和中心。
- 优先选通过核查的最长未饱和曝光，以提高信噪比。跨曝光变化不会被重新归一化抹掉。

有限次长曝光不能证明灯在时间上绝不闪烁。只能检查采样时间内、可比较信号是否一致。
红色信标的暗绿/蓝通道和缺少周边结构的位置无法可靠验证；不把噪声/几何残差判定为已确认的灯光闪烁。

## 4. 实测候选的完整成像链

新增 `filmlab.brackets.replace_measured_highlights` 与 `MeasuredHighlightPatch`。
它们没有自动找灯、没有光谱推断、没有随机补值；只把明确验证的相机通道测量转换成相对场景 RGB，替换指定的饱和像素。
未验证位置与未饱和位置保留输入逐位不变，且保存未恢复掩膜。

```python
rgb_measured, replaced = replace_measured_highlights(
    original_rgb, primary_camera_saturation, validated_patches, decoder_matrix
)
```

实际灯具光谱没有测得，因此此候选不会将 RGB 颜色最近的一款库内灯宣称为真光谱。
为了隔离输入测量的作用，两分支使用相同且冻结的原有光源类别权重和库内成员、同一曝光归一化、
同一卷/帧/显影、无颗粒、同一扫描光学/转换/输出颜色和此前保存的定光/指数肩部。
冻结权重的计算与原始权重路径已逐数组核对。这里没有把第一项“已知光谱”修正冒充应用到未知光谱的实拍灯具上。

逐级保存：输入替换与不确定性 → 直接曝光 → 光晕源 → 空间返回曝光 → logH → 染料量 → Status M 密度 → 扫描密度 → 最终输出。
另外分解了仍依赖未恢复源像素先验的光晕贡献。

### 有可靠新测量的区域

| 指标 | 透光孔 1：先验 → 实测候选 | 透光孔 2：先验 → 实测候选 |
|---|---|---|
| 核心平均红层直接曝光（引擎单位） | 176.65 → 83.82 | 79.21 → 32.95 |
| 核心平均红层光晕源 | 42.70 → 19.24 | 20.94 → 7.98 |
| 核心平均 logH 变化 R/G/B（档） | −.875 / −1.066 / +.740 | −1.092 / −1.397 / +1.107 |

实测证实旧先验改变了强度和通道比例，并非只缺一个整体亮度倍数。
改动沿曝光、显影、负片密度传递到输出，但两处的黄亮外圈仍明显不符，未通过真实颜色验收。
没有单独从 ΔE 的降低推断光晕机理正确。

限制：候选在第一处 150–300 µm 环带仍有约 33% 的红层二次曝光来自全画面其他未恢复饱和源/剩余源像素，
第二处约 42%。因此即使该孔大部分被测量，也不能把周围所有剩余差异唯一归因于胶片或扫描。
亮窗、相机镜头眩光、相机到胶片的光谱歧义和未标定乳剂传播仍然混在结果里。

### 主要路灯

外墙灯仅接受 6 个边缘像素，0–300 µm 的 Y、红/绿比与色差几乎未变；约 73% 的红层返回曝光仍依赖未恢复的饱和源。
步道灯没有接收像素，输出与原图逐位一致。它们的橙红过渡问题没有解决，也不能用这批输入证明或否定一种新的材料传播模型。

## 7. 验收收尾与研究冻结（2026-10-20）

用户认可本轮结果，并要求保留两项能力、记录区域证据边界。两条路径都保持显式启用，来源字段不得为空或仅含空格。
API 不能凭来源文字鉴定测量真实性；调用者须提供可追溯的实际测量或受控实验依据。
实际 EPFL 区域没有已知光谱，因此没有在这些区域启用 `IncidentSpectrum`，也没有从 RGB 猜定光谱后冒充测量。

逐区域的可版本化记录：[MEASURED_SOURCE_COVERAGE.json](MEASURED_SOURCE_COVERAGE.json)。
它包含 16 个区域的原始来源文件/摘要/曝光时间、局部几何检查、时间比较、实际接收数量、覆盖率、
原全饱和核心的恢复与剩余数量，以及明确的 `spectrum_status: not_measured`。

证据类别不是统计概率：

- `cross_exposure_rgb`：两处透光孔接收的 671 个单元均有独立备用曝光一致性支持；这不等于已测光谱。

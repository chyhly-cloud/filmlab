# 输入曝光下限：受控光谱、真实输入与可辨识范围

本轮承接厂家中性曲线归档，研究输入端的明确数值问题；不是重启光晕、DIR、肩部或全局颜色拟合。工具均在eval中，59生产文件SHA保持，current/next不变。

## 1. 已知光谱下的负曝光反例

Ohta实测24色色卡反射率，分别乘已知BB3200和FL11光谱，形成48组输入。相机为理想CIE代理；按库存感光度积分得到条件参考H，不是实测800T分层曝光真值。

48组中7组，现有linear_wp映射至少一层得到非正H，而直接正光谱积分的三层H均为正：BB3200下orange、yellow green、orange yellow、yellow；FL11下yellow green、orange yellow、yellow。证明该线性近似的适用域有限，不能用“输入有负sRGB”直接认定光不存在。

## 2. 已有真实输入的覆盖

复用固定几何远区缓存，未重定光、未按目标扫描残差选样本。

|场景|远区像素数|线性RGB至少一通道负值|至少一层触底分支权重>0.5|
|---|---:|---:|---:|
|咖啡馆|537233|3.685%|2.458%|
|蓝调夜景R1-07-8|564664|0.000177%|0.000354%|
|日间R1-06-7|308918|49.855%|11.399%|

触底权重仅为无效照明分支的权重合计，不是真实损失曝光比例、传感器饱和比例或可信度。负RGB也可以表示有效宽色域颜色。蓝调夜景此指标几乎为零，因此不能拿这个问题统一解释日间草色和夜景不够蓝。

从上述触底集合等距抽取16/2/16个输入，全部可在理想CIE相机下找到非负光谱、保持三通道RGB。仅说明这些选中输入不需要靠改RGB才能数学上可行；不说明找到了真实光谱，也不代表实际相机SSF已验证。

## 3. 两种固定数学先验的全48组检查

没有使用目标扫描。两个目标函数都预先固定为离散二阶差分平方和最小，没有曲率权重扫描、材料参数拟合或按场景选结果。

- 未知光源：非负辐射谱、保持RGB，最小辐射谱曲率。
- 已知光源：反射率0–1、保持RGB，最小反射率曲率。仅对实际已知光源的色卡成立，没有把真实照片的照明估计冒充测量。

每个误差数是`abs(log2(H_candidate/H_reference))`，在组内所有样本×三层上统计，单位EV；不是照片ΔE。

|样本组/方法|中位绝对误差|95百分位|最大|
|---|---:|---:|---:|
|7组旧映射非正，非负平滑辐射谱|0.184|0.461|0.613|
|同7组，已知光源+平滑反射率|0.062|0.306|0.361|
|41组旧映射为正，旧线性映射|0.053|0.809|4.828|
|同41组，非负平滑辐射谱|0.182|0.868|1.150|
|同41组，已知光源+平滑反射率|0.034|0.394|1.085|

两种求解均48/48成功；已知光源候选相对RGB闭合最大约6.7e−16。中位数改善不能等同于无回归：按每块最大分层绝对EV误差，已知光源候选仍使7/41块正常样本退步，BB3200 bluish green从0.180到0.440EV，FL11 moderate red从0.098到0.201EV。BB3200 cyan的候选红层误差仍约−1.085EV。因此保留验证工具，不接入默认或真实照片候选，不宣称颜色修复。

此前已有spectral lookup在7个问题色块上虽可给出非负谱，但重投影RGB相对最大分量误差约9.3%–19.1%；不能只因正值就当成保留实测通道的替换。

## 4. 非负光谱并不唯一：解析范围实验

逐层线性规划，在保持相同RGB的非负光谱中求H最小/最大，另加已知照明与反射率≤1约束。48组条件参考H均在两种边界内，LP最大RGB闭合约3e−15。

所有受控样本×三层的区间宽度`log2(Hmax/Hmin)`：未知光源中位7.37EV；已知光源+有界反射率中位1.73EV。这里允许任意非负尖峰谱，**是宽松条件下的数学外界，不是典型真实材料误差、测量置信区间或可随意调的曝光范围**。每层极值一般由不同光谱取得，不能把三层极值拼成一个物理解。

真实输入选样的宽外界同样不构成物理真值。此实验只否定“保持RGB且光谱非负就能唯一恢复胶片曝光”的推断；不能据此将拟合出的光谱宣称为灯芯实测。

## 决策与复算

这轮确认了可修正的算法适用域问题，同时排除了两个过快结论：负输入必定无物理意义；任意正平滑谱即可可靠替换。已知光源约束确实改善受控表现，但正常色块回归与光谱歧义尚未消除。本轮不采用通用谱替换，不调感光度或显影，不将其归为全部照片偏色的根因。

后续若研究输入映射，应固定相机测量约束，优先增加独立源光谱/相机SSF或反射率先验的外部验证；没有这些测量时，可以继续开发条件算法验证，但必须把新先验和真实测量分开。厂家中性资料不提供这些输入约束。

可复算工具：`tools/eval/exposure_floor_audit.py`、`spectral_admissibility.py`、`spectral_exposure_bounds.py`。摘要已入库`tools/eval/exposure_floor_results.json`；逐点条件结果和真实输入缓存位于`/workspace/filmlab-audit/exposure-floor-audit/`，缓存不在仓库。

验证：`tests/test_spectral_exposure_bounds.py`的3项解析小系统检查通过，涵盖唯一谱、同色异谱极值、光源上界、曝光倍增与不可行输入。它们验证LP实现，不验证800T材料。

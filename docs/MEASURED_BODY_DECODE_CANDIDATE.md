# 全测灯体的浮点 RAW 颜色候选

## 结论与归因范围

本轮只恢复已声明灯条 polygon 内、三个相机通道均未饱和的 68/47 个单元。
其浮点解码红峰约 3.72/3.78，旧 prior 前后的红峰只有 1.22/1.09。
这些输入数值差异值得保留为解码合同问题，但本轮成片 ΔE00 变化约 0.01 或更小，
**不足以解释缺失的橙红光晕，也没有恢复真实扫描中的局部过渡。**

这一结论仅适用于这 115 个全测灯体单元、继承严格核心逆解与最小输入 Y 边缘候选的组合。
没有更换其余像元的解码，不能推广为整个 HDR 解码路径没有影响，或认定核、材料、扫描已被验证。
不扩候选，不做全幅新渲染，不修改正式 `current`、`next`、生产代码或物理参数。

## 独立输入与固定条件

输入为 `lamp-edge-input-audit/<name>.npz`，使用原有：

```
mask = body_mask & ~saturation.any(-1)
old_rgb = postprior_rgb * metering_scale * 2**exposure_ev
new_rgb = (camera @ cam_to_rgb) * metering_scale * 2**exposure_ev
```

完全可测灯体与原 strict core、已接受的 partial edge 均零重叠；不按扫描误差扩 mask。
两灯共 345 个可测通道，没有用假设 SPD 或随机先验补其中任何通道。
这里恢复的是相机平均测量经固定矩阵转换后的浮点颜色，不是灯具的光谱、绝对辐射或纯发光体分量。

运行时强制 `FILMLAB_DATA=/workspace/filmlab-data`，并检查 RAW 路径与历史 capture 完全一致，
以保留路径 CRC。只重新读取一次 `/workspace/filmlab-data/epfl/data/digital/P1480512.RW2`。
原 `_expose_mixed` 在原全幅 1732×2304 网格上执行一次，捕获原照明权重及成员：

- 测光比例 `3.427185475900887`，曝光补偿 `−0.6780719051126377 EV`。
- 原低分辨率权重为 `347×461×6`，保留原 `order=1` zoom。
- zoom 因子为 `(4.991354466858789, 4.997830802603037, 1)`。
- 保留每类的全幅 share、`share < .003` 截止和实际选择的光谱成员。
- 替换浮点颜色后不重新估计照明，不重新挑选成员。

因此该候选只检验固定旧 RGB→层曝光映射收到不同浮点输入的结果，
不声称已经修复自发光体与反射表面的物理区分。
浮点 Bayer 路径也绕过旧降噪，故不能把整个候选的变化都归因于某一项 XYZ 硬上限；
旧解码内部的两种上限由独立数字探针核查。

## 复现检查先于替换

| 检查，最大绝对差 | 近顶灯 | 中顶灯 |
|---|---:|---:|
| 本次 RAW 与旧 postprior RGB | 0 | 0 |
| 原全幅 direct / return 与缓存 | 0 / 0 | 0 / 0 |
| 固定局部 W/member 重放 direct | 1.14e−13 | 1.71e−13 |
| 固定局部 W/member 重放 return | 2.84e−14 | 7.11e−15 |
| 原最小 Y 边缘候选 RGB / Lab | 0 / 0 | 0 / 0 |
| q 反变换再变换 | 1.11e−16 | 1.11e−16 |

旧 direct/return 重放阈值为 `2e−6`，未通过即停止。
保留原核，线性移除旧灯体两条贡献并加入新贡献。
从缓存 `minimum_input_Y_q` 反变换时保留原潜影灰雾，之后使用原显影、染料因子与固定 PrintTiming。
没有修改曝光基底、材料、DIR、扫描肩部、光晕强度、定光或空间几何。

灯体内部曝光预算确实发生变化：

| 灯体区域、模型层曝光单位 | 近灯旧→新 | 中灯旧→新 |
|---|---:|---:|
| 红层直接曝光总量 | 298.968→374.428 | 155.796→200.699 |
| 红层返回源总量，尚未空间传播 | 74.769→89.165 | 40.452→48.790 |

这些数字是条件模型的感度标定层曝光，不是瓦特、实测返回光子或总灯具能量。
继承的失测核心仍用此前同画幅逆解，不能把灯体增加百分比当作整个灯具的增加百分比。

## 原 480 点结果

沿用每灯 160 train、160 heldout、160 outer 点与固定 25 µm 测量算子。
先在线性 RGB 上孔径平均，再转 Lab；不对编码 RGB 作物理平均。
train 仅作旧区域诊断，不参与本轮 mask、颜色或参数选择。
µm 标签仍受现有未校准 36 mm 与配准尺度假设限制。

以下均为中位 ΔE00：

| 灯 / 状态 | train 诊断 | heldout | outer 300–800 名义 µm |
|---|---:|---:|---:|
| 近灯旧研究基准 | 17.40720 | 23.13551 | 4.86822 |
| 近灯严格核心逆解 | 5.62267 | 4.76432 | 5.98800 |
| 近灯此前最小 Y 边缘 | 5.90018 | 4.84832 | 5.90715 |
| 近灯本轮全测灯体浮点颜色 | 5.88882 | 4.84498 | 5.91547 |
| 中灯旧研究基准 | 6.87418 | 8.81724 | 3.51959 |
| 中灯严格核心逆解 | 4.17025 | 4.30676 | 4.09905 |
| 中灯此前最小 Y 边缘 | 4.01593 | 4.08014 | 4.01455 |
| 中灯本轮全测灯体浮点颜色 | 4.02558 | 4.08791 | 4.02188 |

近灯 heldout 改善约 .0033，但外缘退步约 .0083；中灯两区分别退步约 .0078/.0073。
两灯五状态局部图的最后两列目视几乎重合。没有足够效果支持“这个全测灯体解码缺口是光晕主因”的说法。
这些微小指标差异也不应用于选参数或主张有统计意义的改善。

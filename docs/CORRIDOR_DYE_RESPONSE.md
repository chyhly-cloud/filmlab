# 走廊实际明亮外围：有限染料抵消与扫描压缩（2026-10-20）

## 明确结论

**研究判定：已完成“合成探针发现→实际灯旁缓存验证”；将该机制降级为模型内次要色相效应，根因假说不获支持。**
此处“实际验证”是把既有模型端点与真实配对局部对应，不是测得真实胶片的染料贡献。
图由已计算的每像素有限变化生成，没有手绘橙红响应。
目前不据此启动DIR调整、显影系数标定或子层扩展。
只有新增证据证明它对可靠对齐的实际区域有重要、可重复的误差贡献，才重新研究对应显影测量。
不能用合成基准的较强抵消、数值分解闭合或颜色机制看似合理来替代这个门槛。

此前合成q0的5.61→3.46不能直接解释走廊照片。
在两处顶灯的**当前模型完整返光幅度**下，品红/黄染料路径合计仅使黄色增量相对青染料路径净减少约4–5%；
红向a增量反而增加。它能解释模型中一小部分“增红时少黄”的响应，不能解释大幅缺红或整个紧凑橙红过渡的缺失。
仅隔离红层返光时，抵消较明显（约15–17%），但这不是该帧完整返光输入。

主要明亮外围的颜色差仍明显传到输出，不能说它们都被扫描压成无差纯白。
少量模型近白像素确有较低扫描增益；原相纸代理也产生明显有限幅度非线性。
这不证明真实Frontier应该怎样映射，更不支持调整DIR/曲线去补照片。

第三处玻璃反光的固定区域数学分解有效，但真实灯点与模拟亮点存在明显局部错位，
**不用于同一灯具的材料/扫描因果判定**。该处不与两处顶灯合并为一个可靠实拍结论。

本轮没有读取RAW、重新显影、扩展合成曝光网格、调DIR、增加子层或修改生产输出。

## 1. 5.61与3.46到底是什么

原基准：next、roll=None、grain=0、有效层曝光q=(log10 H_R,log10 H_G,log10 H_B)=(0,0,0)，
同一原R1-02-3 PrintTiming、conditioning=None、指数肩部、浮点线性sRGB→Lab。
它是合成有效曝光坐标，不是走廊某个像素的物理照度或ISO曝光阈值。
q0没有显示裁切；实际局部采用的帧变化/负片状态也不等于这个合成基准。

链式法则对三染料系数c=(C,M,Y)：

```
∂b*/∂q_R = Σ_i (∂b*/∂c_i) (∂c_i/∂q_R)
          = +5.60795571 −4.03340057 +1.88789641
          = +3.46245155
```

5.61是青染料路径，3.46是三路径相加。**单位都是b*/log10(H_R)**；
b*正方向为黄色，不是a*红方向，也不是650nm密度或染料量。
染料系数为模型内部光谱基底的系数，不冒称实际摩尔数或实测Status M密度。

一档曝光δEV_R对应δq_R=log10(2)δEV_R，因此：

|量|青路径|品红路径|黄路径|合计|
|---|---:|---:|---:|---:|
|b*/每红层log10曝光|5.60796|−4.03340|1.88790|3.46245|
|b*/EV_R|1.68816|−1.21417|.56831|1.04230|
|+.5EV一阶Δb*|.84408|−.60709|.28416|.52115|

原缓存q0实际+.5EV的完整Δb*只有.24043；+.1EV一阶.10423、完整.08567；
+1EV一阶1.04230、完整.07650。均不能用“未量化”或“没有显示裁切”保证局部斜率可作有限外推。
这也是本轮必须用实际端点而不把3.46乘曝光就当照片答案的原因。
详见 `DYE_CONTRIBUTION_UNITS.md` 与 `units.json`。

## 2. 缓存、区域和可信范围

复用以下既有数据：

- `brightness-local`：原生局部81波长负片密度、保留/移除红层返光两端点、真实扫描、固定掩膜/亮度分区。
- `halo-mechanisms`：已有有效曝光和染料/扫描阶段缓存。
- `corridor-lights`：原完整返光on/off的染料差、曝光差和最终浮点RGB。
- 原R1-02-3固定光号和几何。

native Dλ与实际CD-4染料谱的线性反解只恢复模型染料系数，不拟合物性。
对缺少原生字段的缓存，构造与原skimage完全相同的稀疏双线性采样算子A，
逆算现有线性缓存并作重投影；这是像素坐标代数，不恢复RAW灯芯或真实光谱。

全局逆算**不成立**：LSMR达到迭代上限，弱约束边缘有约1e-3重投影误差、个别染料误差约.9。
这些像素已置NaN/排除，只使用native_trusted和output_trusted的共同支撑。
主区重投影误差<3e-9；独立重现原alloff扫描RGB误差≤4.31e-9。
两端点通过原生Dλ、染料和RGB三种证据交叉核查，不能把全局边缘填充值当恢复结果。

主统计固定为既有未饱和接收像素、名义灯芯外0–300µm、**真实平滑线性Y=.4–.85**：
近灯13051、中灯7878、玻璃957像素，所需native支撑均可信，覆盖没有减少。
更宽的缓存恢复检验区域另含Y=.05–.4，故缓存报告中的13201/8061/8471不是本主表样本数。
接收像素未饱和不代表返光源灯芯已恢复；源辐射/SPD仍未知。
距离沿用既有传感器核心边界/人工60µm排除盘与名义36mm扫描宽度，非独立物理半径测量。

## 3. 两个返光对照分别回答什么

1. **red_return**：移除红层返光→保留原完整返光；G/B返光一直保留。
   这里R输入改变引起的M/Y染料变化可用于诊断当前模型的层间作用。
2. **all_return**：关闭全部返光→原完整返光。
   这是实际模型完整返光幅度。G层本身的小幅额外曝光会部分抵消R造成的品红变化，不能用第1项替代。

没有把反事实端点称作真实另一张底片；真实扫描也没有被减去模拟来当“真实纯光晕”。

## 4. 分解与局部矩阵的验证方法

扫描函数F从**原生染料图**依次经过实际染料谱、扫描密度、P/gain、固定光号、相纸曲线、参考颜色、非负RGB，
再使用原几何投影到真实坐标，最后作显示范围的Lab测量。没有在Lab中加红，也没有重复sRGB解码。
必须先投影线性RGB再转Lab；未把native Lab直接投影或把投影后的染料误当原生染料。

对两个实际染料端点c0、c1，8个通道组合计算全部有限变化：每个染料取c0或c1，
按六种顺序平均边际，得到Shapley贡献。三贡献之和严格等于F(c1)−F(c0)。
组合和平均路径只作诊断，**不是实际显影历史，也不是物理修正候选**。
报告六顺序范围，不能因总和闭合就把某个路径分配当真实化学因果。
统计使用同一掩膜的均值以保留可加性；不把独立中位数相加。

另外直接计算实际端点处的局部扫描矩阵，乘同一原生Δc，再投影RGB、通过该位置Lab导数。
比较起点/终点/中点的一阶预测与实际完整变化；再沿c(t)=c0+tΔc积分并细分数值区间。
这条染料直线路径也只是数学积分路径，不宣称实际显影按此发生。

### 完整返光（all_return）、指数路径的预测误差

相对L2误差=主区全部Lab增量向量的预测误差范数/实际增量范数；不是整图ΔE或物性误差。

|区域|起点局部矩阵一次外推|沿路径积分|积分区间数|
|---|---:|---:|---:|
|近顶灯|48.84%|.428%|32|
|中顶灯|40.31%|.354%|32|
|玻璃固定区（配准不可靠）|17.90%|.443%|4|

paper_only的相应起点误差49.29%/40.57%/17.90%，积分.419%/.355%/.443%。
所以**一个局部矩阵不足以预测完整实际幅度**，即使在实际像素重新求矩阵也不能一次线性外推。
路径积分可在给出的误差内解释同一模型的完整扫描变化；它验证数值链路，不能验证真实化学/设备正确性。
剩余积分误差及细分变化保留，不用它反推材料常数。有限8角点分解没有此积分误差，闭合到浮点精度。

## 5. 实际有限幅度：抵消有多大

主表为指数路径、同一真实亮外围掩膜、均值Δb*，每项单位是**该帧完整有限b*变化**，不再是导数。

### 仅改变红层返光

|区域|青路径|品红路径|黄路径|总Δb*|相对青路径的净抵消|
|---|---:|---:|---:|---:|---:|
|近顶灯|5.666|−1.576|+.620|4.709|16.9%|
|中顶灯|3.376|−.873|+.383|2.886|14.5%|
|玻璃固定区|9.106|−2.740|+1.701|8.067|11.4%|

### 完整返光（all_return）

|区域|青路径|品红路径|黄路径|总Δb*|交叉路径净影响|
|---|---:|---:|---:|---:|---:|
|近顶灯|5.622|−.917|+.678|5.383|−.239（−4.3%）|
|中顶灯|3.352|−.573|+.411|3.190|−.162（−4.8%）|
|玻璃固定区|9.036|−1.058|+1.932|9.911|+.874（+9.7%）|

百分比的分母是指定分解的青染料黄色路径，**不是“真实照片误差的百分之几”**。
完整返光时，近/中灯交叉路径的a*净贡献反而为+.796/+.467，增红而不削红；
黄色方向净减少导致响应方向相对青路径偏向少黄约2.82°/2.93°。
单独红层对照则偏转约7.21°/6.28°。这些角度是增量(a,b)向量方向，不是整盏灯的绝对色相。

六顺序的保守黄色交叉贡献范围仍保持符号：近灯约−.254..−.224，中灯−.167..−.157；
玻璃约+.772..+.977。但玻璃错位，不能拿正号作真实800T材料的反证。

这解释了当前模型的部分黄色响应为什么减少，也说明合成q0的38%抵消不应推广到实际完整返光。
它不能说明真实800T的层间作用应较弱，不能用改变DIR或保留C/冻结M/Y的组合去“修好”外观。

|近顶灯|.607|.13374|−.02506|−.01546|.12633|.12286|11.671 / 4.709|
|中顶灯|.339|.07519|−.01393|−.00861|.07103|.06923|6.838 / 2.886|

负片、扫描密度与输出增量均存在。完整返光的近/中灯最终ΔL/a/b为
[3.358,10.859,5.383]、[2.004,6.475,3.190]，不是被映射成完全无差的白色。
L变化也部分受到不同染料路径相抵（近灯C路径+4.399 L，其他两路径合计−1.041 L），
不能把较小总亮度差自动解释成扫描肩部消失。

同一完整负片与光号，移除额外指数肩部后完整返光Δa/b仅变为：
近灯10.883/5.445，中灯6.498/3.213。该变动远不足以恢复真实橙红过渡。
这不是宣布数字相纸曲线正确；起点矩阵的40–49%外推误差在paper_only中仍在，
说明额外指数肩部以外的扫描非线性也重要，且真实设备响应仍未测定。

### 小部分近白像素确实压缩，但不能覆盖整个目标区

以同一实际最终负片加同幅青染料系数微扰，隔离输入幅度差异：

|区域/模型亮度|像素数|纯扫描色度导数中位数 指数 / paper_only|
|---|---:|---:|
|近灯Y=.4–.85|12700|86.92 / 86.07|
|近灯Y≥.85|131|21.70 / 33.49|
|中灯Y=.4–.85|7775|96.63 / 95.80|
|中灯Y≥.85|56|19.44 / 29.36|

单位为sqrt[(∂a/∂C)^2+(∂b/∂C)^2]，每模型青染料系数，**不同于5.61/3.46的单位**。
表中只用1e-4/1e-5步长相对差<1%的点；实际稳定覆盖近灯主亮区99.37%、近白93.89%，
中灯主亮区99.29%、近白100%。其余折点不丢弃主有限变化，只不据其导数下结论。

近白组每单位染料增量的扫描响应确实降低，且这组实际ΔC也更小（近灯约.0377对.1319；中灯.0138对.0747）。
因此不能只凭其最终色差小就全归因扫描。模型近白仅占本真实亮外围1.00%/.71%，
其余多数保留明显色度响应。

## 7. 与真实误差的关系与玻璃限制

近/中灯完整成片相对真实的均值Δa/b约−12.26/−12.79、−8.48/−8.46。
交叉路径对a为正，不能解释这里大幅缺红；对b的净影响仅−.239/−.162，不能直接等同这些真实残差。
真实负片的返光增量、光源辐射/SPD、设备响应均未独立测量，所以不把这个数值分配当物理误差归因比例。

玻璃目标区模拟平均线性Y约.099，ΔL约−46.94，明显不是同一亮外围已经被印到纸白。
局部图显示标记的真实灯点与模拟亮点错位；固定全局配准不能保证镜面反光的视差/时序一致。
不重新移动ROI去找改善，也不把该处过暗、净黄色增强等固定坐标结果作为材料或扫描结论。
三处完整图均保留，第三处如实标注不能可靠验收。

**能解释的：** 当前模型红层独立响应的部分少黄、完整返光时两处顶灯少量的红黄比例变化、
以及少量模型近白像素的低扫描响应。

**不能解释的：** 两处顶灯的大幅缺红、真实紧凑橙红轮廓的缺失、整个亮外围被统一压成白的说法，
或第三处玻璃错位后的亮度/色差。不能因此认定DIR、相纸或指数肩部某一项已被证明物理错误。

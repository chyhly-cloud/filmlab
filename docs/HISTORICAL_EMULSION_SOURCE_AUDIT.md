## K、S与MCML参数的导入门槛

在没有原始方程之前，连该文是否采用附件所称的Kubelka–Munk/双通量系数定义，也不能独立确认。
即使最终证实K、S的量纲都是长度⁻¹，也不能只按单位转换就当作MCML的微观吸收系数μa和散射系数μs。
必须先取得：

- 文中K、S的精确定义、通量/角度约定和任何近似；
- Table I的实际值、单位、试样厚度及误差；
- 波长、未显影/已显影状态、乳剂组成、边界折射率与测量几何；
- 原文对应的可观测量和实验/计算方式，例如总反射/透射、角分布、深度吸收或MTF。

这些观察量在此只是**待原文确认的候选**，没有声称论文全部测过。
只有在定义和数据都齐全后，才能复现其指定模型/观察量，再讨论与当前输运器的对应。
历史乳剂方法验证即使通过，也不提供现代5219或800T的实际材料系数。

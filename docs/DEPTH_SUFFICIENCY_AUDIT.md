# 同总吸收、不同深度：三记录充分性的最小检验

2026-10-20。本实验只判断一个逻辑问题：**同一感光层的吸收深度改变，是否已经足以证明必须增加显影状态维度？**

结论：不是。若每单位吸收的感光事件效率与深度无关，总吸收相同时线性有效曝光相同。
引入一个明确假想的深度效率梯度，可以让同总吸收产生不同有效曝光；但即使这样，
已知的静态效率也仍可先加权积分为一个有效曝光H，不能据此要求增加快慢子层或更多显影状态。
本实验没有推翻真实800T的三有效曝光记录，也没有独立验证它对真实非中性显影已经足够。

## 1. 一对严格同吸收的输入

复用既有假想650nm下层材料的3µm厚度、µ_a=.05/µm，单独取一个均匀层。
它不是Kodak/CineStill测量。µ_s=0，层内和外部折射率都为1.5，排除界面反射和其他层的影响。
正面和背面都输入相同的单位单色光子通量，不做方向相关的强度归一，也不拟合真实照片。

深度z从物理正面起算，厚度d：

```
a_front(z) = mu_a exp(-mu_a z)
a_back(z)  = mu_a exp(-mu_a (d-z))
A = integral a(z) dz = 1-exp(-mu_a d)
```

两者总吸收解析上完全相同：**A=.13929202357494222**。
平均吸收深度却分别为 **1.4625141µm / 1.5374859µm**，沉积轮廓互为镜像。
因为波长固定，光能份额和吸收光子份额相等；没有从光能直接推显影染料。

## 2. 零假设：效率与深度无关

给定同一个假想常数q=.5，定义线性响应统计量：

```
H_eff = integral q(z) a(z) dz
```

前/背照都得到 **.06964601178747111**，差为0。
深度分布不同，尚不足以改变这一线性有效曝光。若后续模型只依赖它，后续结果也不应因为
深度标签改变而不同。这正是三有效曝光记录仍可能充分的零假设。

这里H_eff是给定线性效率下的初级感光事件期望，不能等同于测得的稳定潜影颗粒数、
显影银或染料量，也不是直接校准了Engine里名为latent的logH字段。
真实卤化银潜影形成可能需要多次光化学事件；本实验没有假定其动力学已经被这个q描述。

## 3. 反例：只有主动引入深度效率时才出现差异

只替换为一个事先声明的假想梯度 **q(z)=.2+.6z/d**，不改变任何光学参数或总吸收。
这是一个数学反例，**没有证据说明800T存在这样的效率梯度**。

|输入|总吸收|H_eff|
|---|---:|---:|
|正面|.1392920236|.0686017132|
|背面|.1392920236|.0706903104|

背减正的差为 **.0020885973**，完全由引入的q(z)与沉积位置相关产生。
不能把这个假想差异解释成原模型对800T的预测误差，更不能将q梯度拟合到光晕照片。

更强的边界是：这个反例只推翻“**未加权总吸收**永远足够”，
并不推翻“**正确加权的有效层曝光**可能足够”。一旦q(z)已知，H_eff本身还是一个标量。
光学模块可以积分出每层各一个H_eff，再交给原有三记录显影模型，不需要为此增加显影状态。

## 4. 独立数值验证

- 闭式总量和一阶矩，与SciPy自适应积分独立核对；梯度响应差≤9.72e-17。
- 使用既有MC输运器，将**同一种均匀材料**细分成48个数值深度箱，前/背照各16万光子，固定独立种子。
  这些箱没有不同材料参数或显影速度，不是增加物理子层。背照把MC入射坐标重新标到同一物理正面深度。
- MC能量闭合误差0、事件残余0；最大深度箱误差为前2.44σ、背2.81σ，与统计幅度相容。
- MC箱中心积分的梯度响应离散误差已单独计算，为±4.534e-7；不将它或独立种子的统计差误认作物理差异。

|情况|前MC响应|背MC响应|每方向理论MC标准误差量级|
|---|---:|---:|---:|
|常数q|.06929375|.06968437|.0004328|
|梯度q|.06831484|.07079559|.0004559 / .0004680|

零假设的严格相等由解析式决定。两次独立MC运行不会逐位相等，不能用该随机差声称深度效应存在。

## 5. 何时才有理由增加深度表示

需要区分曝光端的加权积分和显影端的状态表示：

1. **静态线性q(z)**：即便前/背照不同，也可能只需要在曝光端正确积分，不必增加显影状态。
2. **相同H_eff仍得到不同显影密度**：若层内响应取决于局部剂量、局部容量、显影时序或局部耦合，
   则一般有integral f(h(z)) dz不只由integral h(z) dz决定。这才可能需要保留额外的深度信息。
   但“非线性存在”的一般知识并不能确定真实800T在当前灯周围的差异有多大。
3. 必须用已知输入与工艺进行独立前/背照或分色曝光，控制好实际有效层曝光并测量显影后的光谱密度，
   排除光谱、界面传播、其他层曝光和扫描响应差异，才能检验现有三记录模型是否在这些条件下失败。

当前真实RAW/扫描配对不提供这组条件，主要灯芯还存在辐射/SPD未知。
所以不能从现有三记录积分的形式，推导出“必须增加多速子层”的结论。
本轮不增加快慢层、不重拟合感光曲线、不改变生产实现或current/next。

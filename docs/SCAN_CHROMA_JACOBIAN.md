# 青染料到扫描颜色的独立局部Jacobian（2026-10-20）

## 实验范围

本实验把扫描端从非中性显影交叉作用中分离：在同一基准负片上，仅对青染料系数做
±epsilon增量，并用**最终CD-4显影所对应的完整81波长染料谱**改变负片密度。
不调整Lab，不增加红色输出常数，也不重新显影或自动定光。

```
D_plus/minus(λ) = D_original(λ) ± epsilon * dye_spectrum_C(λ)
T(λ) = 10**(-D(λ))
T → Dscan → 原P及gain → 固定定光 → 原相纸曲线 → 原相纸染料光谱 → 浮点RGB
```

99个未扰动背景为主表，另外297个既有红层曝光负片也分别核查，共396个既有状态。
它们不是396个独立测量；没有新增曝光网格。
所有state的基准分区均使用其对应的**原未扰动指数路径Y**，而非染料小扰动后重新分区：
Y=.2126R+.7152G+.0722B，为线性RGB，区间[0,.005)/[.005,.05)/[.05,.4)/[.4,.85)/[.85,+∞)。

next、roll=None、grain=0、standard引擎，所有输入使用同一预存R1-02-3定光。
指数肩部及paper_only均运行。原缓存raw浮点RGB复现误差分别≤6.67e-16/8.89e-16。
本实验是**现有扫描模型的导数**，不是实测Frontier或真实乳剂量子效率。

## 明确区分的输出阶段

- off/raw：相纸反射光谱→XYZ→线性sRGB，未裁切。
- off/nonnegative：原无输出调整路径的max(RGB,0)。
- off/display：在前者基础上裁切至[0,1]，尚未8位量化。
- on/raw：严格沿用原SATURATION_MATRIX与LAB_TINT；包括原程序在矩阵前和tint转换前的非负裁切。
- on/nonnegative：在on/raw之后附加非负裁切，仅作诊断，不能说生产代码新增此步。
- on/display：on/raw裁切至[0,1]的显示颜色。

原经验输出调整是固定干预，**不叫胶片或设备实测物理响应**。其开关用于分清影响，不据此重新拟合。
每阶段同时保存RGB、XYZ、Lab。Lab转换明确`apply_cctf_decoding=False`；没有量化或重复sRGB解码。

负线性RGB只表示超出该RGB色域，**不等于光谱或XYZ不物理**。
来自非负反射谱的有效XYZ可以给出负sRGB分量；raw Lab仍可作为该颜色的色度描述，
但不能冒充裁切后实际显示的颜色。

## 三种步长和折点

epsilon=1e-3/1e-4/1e-5（青染料系数单位）。所有396点的两侧染料量均在模型0…coupler_cap范围内。
保存三套导数和完整数组，并比较1e-3对1e-4、1e-4对1e-5；记录各步两侧导数不一致、
相纸特性曲线/逆中性层LUT折点、肩部、tint锚点、探测器下限及RGB黑/白裁切边界跨越标志。
不因中央差分给出一个数值就认定它是唯一导数。

396点中，指数路径Lab在1e-4与1e-5比较时仅1点相对差超过1%（state index136，既有+.1EV组，原中亮区）；
paper_only为0点。粗步1e-3相对1e-4，指数显示Lab有15点、paper_only无调整24点/有调整26点超过1%。
因此主表使用小步收敛且两侧导数一致的点，全部点及折点标志仍保留。
相对判定使用导数范数下限1e-6，避免把纯浮点近零差放大。各阶段也记录Lab原点计数；
不能把原点的色相或近零色度增量的方向当作稳定色相。

## 裁切可以使红色导数反号，但不能推广到用户关心的白晕

指数路径99基准在未裁切raw Lab中∂a/∂C全部为正。
有4点在max(RGB,0)之后变为负；都来自raw R<0的超sRGB颜色。
四点的XYZ各分量均为正，由原相纸反射谱计算，不能称为非物理材料输出。

|基准index|有效logH=[R,G,B]|非负输出Y|原亮度区间|raw ∂a/∂C|非负后∂a/∂C|
|---|---|---:|---|---:|---:|
|15|[−1.5,−.9,−2.1]|.06845|.05–.4|+46.898|−9.798|
|16|[−1.5,−.9,−1.5]|.06282|.05–.4|+45.708|−9.395|
|17|[−1.5,−.9,−.9]|.07575|.05–.4|+26.719|−4.707|
|26|[−1,−.4,−.4]|.34657|.05–.4|+66.307|−25.852|

以index15为例，raw RGB=[−.005244,.095110,.005887]，raw XYZ=[.032911,.067333,.016832]。
青染料增加时raw R/G/B导数约[+.119409,+.061271,−.003811]。
非负裁切把R及其局部增量钉在0，G仍增加，于是显示a向绿移动。
±1e-5两侧都仍然R<0，故这不是黑边界处不可导造成的数值假象，而是稳定的有损显示映射响应。

但这4点都不在原Y≥.4的亮过渡组，更不能据此推断真实走廊灯外围的主因。
用已有三处原生D81裁切重新计算raw RGB并复现基准（最大误差7.24e-8），
在**真实Y=.4–.85且名义灯芯外0–300µm**的周边掩膜内：

|真实局部|像素数|raw R<0比例|raw任意通道<0或>1比例|
|---|---:|---:|---:|
|近顶灯|13051|0%|0%|
|中顶灯|7878|0%|0%|
|玻璃反光|957|0%|0%|

原生负R通过插值贡献超过1%的比例也均为0%。
因此，**裁切反号不是这三处主要亮外围缺橙红的解释**。未增加色域映射候选或经验调色。

paper_only在99基准raw中有32个负a导数，均在原近白组、且原RGB超sRGB；
它们并非全部由最终显示裁切产生（raw阶段已经有负号）。其∂a中位数−.03697、
极值−.41406（每单位染料），与强中间调响应不在同一量级。
不能混为“显影反号”，也不能仅凭超色域关联认定裁切造成了所有raw反号。

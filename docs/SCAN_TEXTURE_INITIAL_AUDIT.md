# 颗粒研究起点：扫描输出纹理的可辨识性

## 数据与方法

使用已验证 SHA256 的 EPFL 白场 R1-19-20 和 ISO 15739 噪声卡 R1-18-19。两文件均为
5456×3649、RGB、每通道 8 位、嵌入 sRGB、TIFF Compression=1（本文件未压缩），软件标签为
Adobe Photoshop 25.6。未压缩容器不证明上游没有锐化、降噪、重采样或有损编码。

在查看数值前选定白场中心区域的 3×3 个位置，以及噪声卡中部三块平坦灰阶，各取 256×256 原生像素。
位置图和最近邻放大的纹理图供核对，没有将图卡边缘、文字或分辨率条纹当作颗粒。
各块分别去二次低频趋势，计算残差 RMS、RGB 相关、径向 PSD、方向自相关及 8 像素相位差分能量。
这些是**扫描输出残差**；去趋势也可能移除真实低频成分，不称为纯颗粒分离。

## 首轮观察

| 区域 | R/G/B 残差标准差（8 位码值） | 相邻像素水平相关 |
|---|---|---:|
| 白场中心 | 1.10 / 1.57 / 2.31 | 0.565 |
| 图卡较暗灰 | 10.93 / 9.45 / 13.61 | 0.652 |
| 图卡中灰 | 8.43 / 7.00 / 11.51 | 0.636 |
| 图卡较亮灰 | 6.88 / 5.74 / 9.34 | 0.628 |

选定区域没有 0/255 端点裁切。白场中心仅使用约 12/13/24 个通道码值；量化不可忽略，但不能因此认定所有纹理都是量化。
九个白场块相邻相关约 0.56～0.59，PSD 高频衰减明显。图卡中灰 RGB 残差高度相关，R/G 约 0.94。
这些现象可同时受到染料云、扫描光学 PSF、传感器噪声、滤波/锐化和颜色转换影响，不能唯一归因。

8 像素相位差分能量最大/最小比在这些块约 1.03～1.10，没有据此建立明显 JPEG 分块证据；
这不是证明从未压缩，也没有做过已知压缩样本的检出率校准。PSD、较弱负相关或边缘外观本身也不足以确定锐化核。

白场与中灰输出噪声幅度不同，不能直接解释为胶片密度决定的颗粒规律：扫描影调导数、曝光、RGB 混合和
量化精度也在改变幅度。更不能把输出 RGB 残差直接与 Kodak 的负片密度 RMS 颗粒度或 48 µm 测量孔径比较。

## 本轮不做的采纳与下一步

没有修改 FilmLab 的颗粒参数或代际，没有将全部扫描纹理拟合到乳剂。

优先独立检查模型的孔径平均颗粒度是否随渲染分辨率保持一致，以及其 PSD/空间尺度的构造是否自洽；
这可在不把扫描噪声当作胶片的前提下推进。用于真实物理定标则需要：

- 同一底片至少两次独立扫描，估计随机扫描噪声；固定扫描噪声仍需控制样本。
- 同一底片不同摆放方向或位置，区分跟随胶片的纹理和跟随扫描器的条纹/固定图样。
- 未经自动影调和锐化的高位深扫描及处理设置，或者独立微密度计测量。

这些证据未取得前，只报告输出纹理统计，不识别 film-only PSD、负片 RMS、扫描器噪声底或锐化核。

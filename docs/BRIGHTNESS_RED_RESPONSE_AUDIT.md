# 红色响应在哪个亮度区间丢失（2026-10-20）

## 结论与边界

近白区的输出压缩很强，但它不能解释所有真实灯周围的橙红过渡差异。
部分真实过渡区确实被模拟推入近白；另一些缺红区域的模拟并不近白，仍有明显的红层→染料→扫描→RGB响应，去掉指数肩部也几乎无效。
因此不能把“负片有差、最终高亮没差”推广成“真实光晕的问题全部在扫描端”。
current、next和已有paper_only均不改；没有重拟合、调光晕倍率、改颜色或增加子层。
本轮只增加审计和输出，源图校验和、光号、分区及逐阶段数组可复查。

## 实验合同

- 复用99种R/G/B背景×红层+.1/.5/1EV的297组探针，不增加曝光网格。分区依据扰动前的指数输出；另保存两候选各自分区结果。主表用+.5EV，其余两档交叉检查。
- Y是**线性sRGB**点积[.2126,.7152,.0722]，区间为[0,.005)、[.005,.05)、[.05,.4)、[.4,.85)、[.85,+∞)。这些是预先定义的诊断区间，不是相纸物理边界或新拟合参数；尤其Y≥.85不保证三个通道都近白。
- EPFL四个已校验RAW/TIFF配对、七处局部区域：立面灯、走廊近/中顶灯与玻璃反光、暖色步道灯、黄昏两灯。固定既有配准及同一帧已保存光号；指数/paper_only不各自重新定光。这里“固定定光”指每一场景的比较固定，不要求四场景共用一套光号。
- RAW原生半尺寸2304×1732，真实TIFF原分辨率，512×512局部。传感器未饱和的周边像素用于统计，灯芯仍依赖旧先验，**不是测得的光源辐射**。真实亮度用25µm高斯尺度抑制扫描纹理后分区，保存真实→模拟亮度交叉表；颜色统计来自原局部图，不把纹理当乳剂物性。
- 基准与“仅去掉模型红层返光”的全帧显影对照；G/B返光、校准、空间DIR、定光不动。逐级记录有效层曝光、CMY染料、81波长负片密度、扫描密度、归一化密度、相纸曝光/密度和浮点RGB。该对照给出模型内红色增量，不是从真实扫描测到的乳剂导数。
- 既有五处局部的指数输出复现误差≤2.981e-8；两处新增人工中心使用60µm中心排除盘，其距离不是实测灯芯边缘。36mm扫描宽度换算的µm为名义尺度，裁幅、配准和模型分辨率限制实际精度。
- 模拟输出直接作为线性RGB；真实扫描只做一次sRGB解码；Lab转换显式关闭再次解码。8位编码只用于显示/量化检查。所有Lab色度增量均在最终显示裁切后计算，并保留裁切标志。

但接近有限白点时色域必然收缩；**这些数据不确定真实Frontier应该从哪一负片密度开始收缩**。

### 哪一级参与

1. 染料、光谱密度、扫描R密度仍保留差异。局部统计均未碰到扫描探测器的1e-6透射率下限。
2. 固定密度转换C=P·gain的奇异值为1.030/.870/.685，条件数1.504；实际差分满足ΔDn=ΔDscan·C，最大残差6.71e-16。这一步没有近白时才发生的数量级坍缩。但矩阵可旋转色方向，满秩不证明Frontier颜色正确，更不保证特定红绿对立投影不变。
3. 在近白组，+.5EV使相纸曝光R变化的中位数：指数−.000212，paper_only−.04317。前者被额外肩部明显压小。
4. paper_only仍有Δxe，但相纸密度局部|ΔDp/Δxe|中位数仅.000970；它在真实相纸材料曲线的白端也会变平。所有既有探针的xe仍在曲线表范围内，不能把这部分简化成np.interp越界截断；有少量表格趾部微小起伏，不能解释为真实红色反号。
5. paper_only在这54个背景中96.3%至少有一个显示通道越界（基准或扰动）；指数为0%。去掉肩部未提供无限颜色空间，也不必然更红。前者实际包括相纸低密度到中性层LUT、相纸反射光谱→XYZ/sRGB及显示裁切的共同响应。

各阶段中位数可能来自不同样本，不能相乘当作一条代表光线；逐样本数组保留供核查。

### 真实仍有亮度层次，模拟已近白

暖色步道灯属于这种情况；立面灯、黄昏左灯也有部分像素。不能用“真实灯芯本来就是白的”解释。
立面灯该组真实亮度10–90百分位跨度.786档，模拟.446档。
paper_only可恢复部分红色增量，但也更亮、更易裁切，整体颜色不保证改善。
暖色步道灯该组Δa已经偏正，增加红色响应不是自动朝真实颜色前进；还必须检查b、亮度和空间轮廓。

### 缺橙红过渡，但模拟并未接近纸白

走廊近顶灯是明确反例：该组模拟Y约.601，99%未进入本轮近白区；显影和扫描对红增量并不失灵。
逐级中位数为：额外红曝光.632EV → 青染料+.1402 → D650+.1324 → Dscan,R+.1289 → Dn,R+.1108
→ 指数路径Δxe,R−.1275、ΔDp,R−.2421 → Δa+11.87、Δb+4.89、Δab12.85。
即使如此，相对真实扫描仍Δa−11.89、Δb−13.46。paper_only的Δab仅12.93，实际Δa差变为−12.03。
因此，**移除额外指数肩部没有解释或解决这个区域的橙红缺失**。

三层模型在这些条件下确实能表达红层非中性增量，不能因此验证其真实幅度。
局部非近白过渡区也观察到青染料上升、品红/黄染料下降（走廊近顶灯代表中位数约+.141/−.026/−.016），说明现有层间作用参与；仅“青染料导数为正”不足以验证真实非中性显影。
未拟合或修改这些耦合。

### 较暗外围

300–800µm中真实Y=.005–.05的立面、玻璃反光、黄昏右灯区域，模型Δab分别22.58、13.88、13.71；指数/paper_only几乎相同。
对应模型Y约.155/.042/.032；其中后两处模型也处于暗部。因此没有证据表明扫描映射普遍吞掉暗晕红色响应。
但玻璃反光/黄昏右灯的Δa相对真实反而约+8.95/+9.25，不是所有暗部都缺红。
玻璃反光的亮灯芯存在巨大亮度失配（真实近白组Y约.919，模拟约.083），不适合作扫描曲线标定样本。
不能把没有可靠源辐射/光谱的残差全算作显影或扫描的误差。

## 证据支持的下一步与冻结项

- 扫描端继续有疑点：指数肩部的经验渐近值、Crystal Archive相纸作为数字文件输出代理、以Portra档案拟合的窄带→印放密度矩阵，都不是实测Frontier非中性响应。真实配对仅给出端到端差，不能唯一辨识它们。没有设备灰阶/彩色密度楔等独立依据，不生成新扫描曲线候选。
- 局部反例要求回到输入辐射、材料返光及非中性显影：红/绿/蓝返光的比例和方向、层间作用、前/背照实际吸收。光学吸收不能由显影后染料密度或感光曲线直接替代。
- 本轮已经追到非中性染料交叉响应，未发现数值丢失、错误域转换或可凭独立证据修改的显影规则。主灯芯尚无可靠亮度/SPD，不能用现有先验定量倒推800T吸收、层间常数或散射核。
- 保留测量替换能力和已有受控输运验证器；待独立材料/设备证据再解冻相应物理项。不是“整个光晕研究完成”，也不是提前认定扫描代理正确或三层不够。

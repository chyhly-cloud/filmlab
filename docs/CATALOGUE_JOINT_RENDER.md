## 结论

两灯已经按预先选定的112谱库共同光谱witness完成全幅重放，没有使用全幅图或留出结果再次选系数。
局部112候选的主要现象在全幅保留：外缘改善，近顶灯近区反而退步；真实扫描的橙红过渡仍未复现。
因此这只是研究候选的联合验证，没有替换正式current或next，也不是已恢复真实灯芯辐射。

## 没有重新选择的内容

核心为`catalogue-source-inverse/<name>_catalogue.json`中已经按训练选定的minY共同光谱witness，
使用对应`*_scene_specific_library.npz`的actual spectra重新积分。
原88/34严格支持、原空间profile保持；同一个非负SPD同时决定直接与返回的全部三层曝光。
两灯活跃witness均为LPS和H38HT-100 (Mercury)的非负混合。
这只是在当前有限112谱库中实现选定响应的数学代表，**不意味着识别了实灯类型**。
输入Y约696.800/476.983，不是绝对SI辐亮度；固定六响应时Y范围很窄也不证明真实辐射测量准确。

- 原FILMLAB_DATA路径、路径CRC、全幅测光比例3.4271854759、+0.53档测光补偿。
- 相同胶片、DIR、散射、返回核、显影、搅拌图和捕获的PrintTiming。

完整legacy局部照明只从原输入估计一次，先加入已验证边缘/HDRbody修正，再由两组固定核心SPD分别渲染。
没有因核心替换重新估计照明或定光。
全幅基准也重新渲染，包含同样partial-edge/HDRbody输入，避免拿不同输入版本作比较。

## 重放核查

| 项目 | 近灯 | 中灯 |
|---|---:|---:|
| 原全幅直接/返回源曝光与缓存最大误差 | 0 | 0 |
| 单一actual SPD重现选中6D响应的最大相对误差 | 1.32e-13 | 2.12e-15 |
| 全幅112与局部112的最大线性RGB差 | .000900 | .004612 |
| 全幅112与局部112的最大样本Lab分量差 | .0371 | .1215 |
| 全幅112与局部112的安全区q最大差 | .00516 | .01637 |

witness中约−2e-11的舍入负值按0处理，以上SPD闭合误差记录了处理后的实际结果。
没有渲染六独立响应、不能由单一非负光谱实现的非物理解。
同一全幅中两个光源都变化，局部反演仍采用固定其他源背景，因此存在小联合传播/全幅处理差异。
没有用这些差异重新拟合参数；基准全幅与旧局部HDR也有类似小差异（RGB最大.000991/.005729）。

近灯inner留出相对真实的平均残差为`ΔL*/Δa*/Δb*=+3.367/−2.502/−1.761`，
outer留出为`−.067/+6.183/+.646`。
它仍同时存在近区偏亮与缺橙色、外缘红向过强，不能称总体光晕正确。
中灯inner留出a*/b*已接近目标，但平均L*仍高4.432；ΔE改善不等于灯芯亮度或所有局部层次都正确。

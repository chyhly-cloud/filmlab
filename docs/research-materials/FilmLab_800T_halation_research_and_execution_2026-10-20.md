# FilmLab / CineStill 800T：补齐光晕物理与成片转换的证据链

**研究日期：** 2026-10-20  
**交付对象：** Codex；在 FilmLab 的独立实验分支实施，不替换 `current`／`next`。  
**研究性质：** 原厂/论文/专利材料核查 + 当前可访问 GitHub 代码检查 + 用户转述的 Codex 本地试验结论。**没有**独立复算 Codex 目前 `/workspace/filmlab` 内的最新实验脚本及 EPFL 原件。历史 GitHub `film-physics-decoupling` 分支可能落后于 Codex 工作区；以 Codex 的实际本地代码与 SHA 为实施准据。

## 0. 要解决的具体问题

最终目标不是生成“看起来像胶片”的红圈，而是回答：为什么真实 CineStill 800T 在不同类型的亮灯芯外形成紧凑的橙红过渡，而现行 FilmLab 经常产生黄白泛光、红色过弱或过宽？需区分四个因果环节：

1. **辐射输入 `L(λ,x,y)`**：光谱、亮度、源大小、镜头眩光。饱和 RAW 的 RGB 不可唯一恢复亮度和光谱；辅助短曝光仅补回已通过局部校验的部分。已知光谱源可走显式积分路径，但不能误把所有亮处当成光源。
2. **未显影材料输运 `K_j(λ,r,z)`**：各层吸收 `μ_a`、散射 `μ_s`、相函数 `p(θ)`、厚度、折射率和边界反射；返回吸收分层、按半径及波长输出。旧模型将光谱总量与径向核分离，且用光谱感光度近似材料光学吸收。新 MCML 类验证器已通过 Codex 报告的守恒/极限检查，**未**以 800T 的测量参数定标。
3. **光化学 `F(H_R,H_G,H_B)`**：额外红感曝光经 C-41 显影生成的青色染料，与其他层层间效应及潜影深度。用户报告的 297 个受控探针已证明负片密度保留红层信息，但没有证明真实 800T 的非中性响应幅度。
4. **扫描输出 `G(D(λ);setting)`**：Frontier/Noritsu 设备光谱测量、校正、灰平衡、输出曲线、编码，且与“真实相纸的纸白和趾部”不是同一个已测系统。已有实测配对确认某些亮区高光层次被压缩，但未定量识别真正的设备输出响应。

### 关键的可辨识性问题

输出的小扰动可局部写为 `δRGB ≈ J_scan · J_develop · J_transport · δL`。即使整张照片非常相似，也可能是几层误差互相抵消；即使不相似，仅凭 JPEG 也不能唯一反求四个 Jacobian。研究目标是用**不同类型的独立证据，分别约束每一个 Jacobian**，不能把未测光学系数拟合成能让一批扫描 JPEG 变好看的常数。


### 不应重复实施的既有结论（依据用户转述的 Claude/Codex 实验）

- **代际和回归：** `current` 为正式默认、`next` 为色彩研究基准；`next_halo`、`next_k5219`、`next_sensor`、`paper_only` 是不同问题的实验候选，已通过的默认输出回归必须保留。Codex 的最新改动在本地 `/workspace/filmlab`，GitHub 实验分支可能落后。
- **Kodak 5219 重新解混：** 新构造在 Kodak 原生 ECN-2 的中性密度/光谱自洽性更好，但整张 800T C-41 扫描拟合变差；不能把 Kodak 的自洽直接等同 CineStill 800T 的真实反应。
- **扫描色彩调整：** EPFL 同店 RAW 配对中，原有 `SATURATION_MATRIX` + `LAB_TINT` 作为通用改进证据不足；ref3 同源网络图有收益而测试集 C 整体未支持。不得为改光晕重新拟合它们。
- **光晕强度 ×0.1/×0.3：** 旧红边指标存在重复 EOTF，且受高光先验、输入眩光和扫描曲线混杂；这些数字不属于已测的 800T 材料常数。
- **已知光谱输入：** 背景改变时固定 2700 K 光源的曝光差已由新路径消除；Codex 后来已修复显式源的可加性，原 2700 K＋LED 混光差约 0.097%，不宜重复研究或当作主要视觉错误。
- **RAW 短曝光：** 备用数据能恢复透光孔的一部分测量，但多数关键路灯灯芯仍然饱和或无法通过一致性校验；未知 SPD/亮度继续显式标记。
- **非中性探针：** 报告中同样额外红层曝光 0.5 档，负片 650 nm 密度变化约 0.102/0.094 D，而输出 Δa* 可由 2.70 降至 0.083；这证明**现模型中**存在亮度依赖的颜色压缩，尚未证明真实 Frontier 的曲线或真实 800T 的显影响应。
- **蒙特卡洛：** 155 项测试与守恒误差小于 2×10⁻¹³是 Codex 报告，不重复实现验证器。斜光程影响尾部取决于路径先发生被动还是活性吸收，不能预设变窄。

## 2. 执行包 A：先确认当前真实证据的测量域正确（最高优先级，短回合）

- 历史 `halo_edge.py` 错误地对已为线性 RGB 的 `Engine.render()` 再做一次 sRGB EOTF。Kodex/用户转述已经修复；只重算曾依赖该路径的光晕红边径向指标，不重算未受影响的 297 探针、固定定光、蒙特卡洛守恒和图像可视化。
- 统一**线性 RGB/编码 sRGB**、FilmLab 物理微米到像素映射、源掩膜和对齐误差；打印“输入的域”和“输出的域”元信息。不要用“真实扫描 − 关闭光晕的模拟”当纯粹的真实光晕真值。
- 在两类输出中固定扫描定光：一类提供“same negative, same timing, halo on/off”反事实；另一类保持真实冲印店成片，不强行推断相同定光。
- **验收**：同一线性数组作真实／模拟输入时，颜色差应为数值零（以及编码→正确解码的往返精度）；同一子程序再次 EOTF 应被回归测试捕获。重算前后旧“×0.1/×0.3”结论明确标为历史/撤回。

## 3. 执行包 B：建立材料输运的层级输出，而非求一个红晕系数

针对已存在的 Monte Carlo 验证器，要求逐个波长、逐层/深度、逐半径记录：

- 原始入射光子通量／能量、镜面透射、漫透射／反射、有效活性吸收、被动材料吸收、逃逸与能量账本。
- 下行与上行路径的 `A_j(λ,r,z)`，至少三条记录对应红／绿／蓝；同一半径同时输出**绝对新增活性吸收**及其**条件比例**，避免“>800 μm 占比下降”与“绝对能量下降”混淆。
- 限定源谱（2700 K 作为**已知构造源**、几个单波长作为计算基准）；已知光源直接积分使用同一材料光学响应，不因被分割计算的方式改变结果。
- 数值消融只改变明确的**材料层有无/厚度/物理机制**，而不是无证据反复扫描 `diffuse_fraction` 或 `forward`；尤其检验主动吸收和先行被动吸收为何导致相反远端趋势。
- 以 1968 年旧摄影乳剂的已发表测量重现该论文指定观察量，作为**方法迁移验证**。不要把旧 `K,S` 直接写进现代 800T 的 `μ_a, μ_s`。
- **验收**：守恒、极限、材料参数不变时辐射可加、不同波长对传播有可解释的差异；历史胶片方法检查通过。不能通过此验收推出“800T 材料数值准确”。

## 4. 执行包 C：显影非中性响应实验（当前最可能获得决定性结构证据）

重点检查当前 `chemistry._intrinsic_curve` 为中性曲线反推内禀响应的做法。在零、低、中、高背景下，对红层输入固定扰动 `δlogH_R`，并改变绿蓝背景。直接保存：

1. 潜影有效曝量（三记录）。
2. 实际形成的三记录染料量 `Δc_R, Δc_G, Δc_B`，分别报告各记录交叉效应。
3. 完整光谱 `ΔD(λ)`，包括 650 nm 仅作单点参考但**不代替三色扫描密度**。
4. Status M `ΔD_MRGB` 和模拟扫描仪自身光谱通道的 `ΔD_scanRGB`。
5. 在固定定光下，关闭／开启输出调整的浮点 RGB、CIELAB `Δa*, Δb*, ΔL*`，以及量化前后。

由有限差分得到局部导数矩阵 `J_chem=∂(D_R,D_G,D_B)/∂(logH_R,logH_G,logH_B)`。分别在中性灰阶与**红-only 增量**测，确认“中性阶梯吻合”并没有掩盖高度非中性的染料变化。已经完成的 297 组可复用，避免重复规模实验。

**科学边界：** 公开 C-41 专利的分色 gamma 与 R→G 层间作用只说明这些响应可以在化学上出现，不是 800T 的指定系数。现在可检验模型表达能力、符号一致性、边界行为，不能以这些专利样品替代 800T 测量。

**子层研究准入**：只有明确发现“三记录积分丢掉了正面/背面入射引起的层内吸收深度信息”，并证明用现有表示无法复现指定物理响应时，才启动快／慢子层模型。先以同总吸收、不同深度的理论边界构造验证必要性，不得假定现代 5219 的子层结构已知。

## 5. 执行包 D：扫描端能否保留真实红晕，而不是将其印成白

**反事实注入**：固定一份负片和一份 `PrintTiming`，直接向同一位置的红层光谱密度施加一个来自完整染料模型的、物理一致的小扰动；绝不在 Lab 层面注入任意红色。记录以下每级的扰动响应：

`D(λ) → D_scan narrowband → D_n after P/profile → paper_exposure (含/不含额外肩部) → DigitalPaper → output_conditioning → linear RGB → sRGB 8bit`。

分别在真实胶片扫描里**仍有颜色和层次的灯外圈**、接近纸白灯芯、较暗远端，进行受控亮度段分析。以 `∂a*/∂D`、`∂Y/∂D` 与 `ΔL*, Δa*, Δb*` 说明压缩位置，而不把最后 JPEG 的趋白现象立即归罪于乳剂。

**重要事实**：SP-3000 的扫描影调与校正菜单、光谱校准和输出通道独立存在；现有 FilmLab“模拟光学相纸+虚拟数码相纸”没有足够资料证明就是设备 sRGB 导出 LUT。应将设备扫描响应标为“待验证代理”。`paper_only` 仍是实验对照，并非已经被证实的正确设备映射。

**验收**：如果模拟模型在灯外、非纸白范围也将合理的色谱密度增量强行映射成接近无差色，定位是本实现的结构瓶颈；仍然需要真实负片密度和对应扫描，才能宣称是哪条设备曲线在物理上错误。

## 6. 源光谱与 RAW：哪些可以补，哪些不能

- 已知光源 `SPD` 和亮度：独立直接积分，必须不受背景变化。方法在 Codex 近期实验中已建立候选。
- **真 RAW 已饱和**：三通道全部截断时，即使另一帧少曝 3 档，也必须逐灯验证是否真的没有截断；G81 的路灯已有报告指出大多**仍未**恢复。不得用透光孔成功外推路灯。
- **恢复到 RAW RGB 不等于恢复 SPD**：不同灯谱可有相同 RGB 三刺激值，却对胶片反应不同。短曝光改善亮度估计，不足以唯一识别钠灯/LED/荧光灯的光谱线。
- 源选择应固定场景，不再通过随机胶卷种子给同一灯选不同灯谱。未测灯具只能以受限制的候选光谱作为**条件情景**，不能随机宣称真值。
- CineStill 官方明确指出荧光灯闪烁会造成快门不同步时的曝光和色彩波动；短曝配对校验须考虑闪烁、移动和局部配准。https://help.cinestillfilm.com/hc/en-us/articles/360028874992-Should-I-use-a-filter-on-800Tungsten-under-fluorescent-lights

## 7. 真实验证设计（不拟合胶片参数）

现有 EPFL 单店单卷主要真实 RAW 配对、灯箱、灰阶、色卡，以及独立的 DLF 500T/另一扫描仪，可形成三重门槛：

**第一层（算法）**：输入构造真值、守恒、数值收敛、特定波段分开合并线性一致；确定错误必须修。

**第二层（有限材料证据）**：5219 ECN-2 原厂 H-D/染料/MTF 与历史真实乳剂 `K,S` 实验，仅在各自声明的适用条件下检验，不转用于 800T C-41 的绝对指标。

**第三层（真实成片）**：对同一组已可靠对齐/未过曝或已验证亮度的独立亮源，比较 0–300 μm 的红橙过渡、500–800 μm 的尾部、各亮度段 `a*,b*,L*`、局部 PSF/轮廓、整图损失；分组记录夜景、色谱条件和冲印店。对不可靠灯芯、镜头眩光、错位、闪烁单列，不计作成功。有效独立单位是**场景/胶卷/冲印店**，不是数百万个像素。

全程旧 `current`、研究 `next`、新候选并行输出，所有默认图像回归不可更改。相同扫描/定光条件才可以比较单一阶段；不同冲印店不能靠共用一个拟合色彩矩阵强行归一。

|---|---|---|
| 800T 未显影 `μ_a(λ), μ_s(λ), p(θ,λ), t_j, n_j` | 同批胶片未显影状态的带角度/积分球透射与反射，多波段；层厚和模型反演约束。仅 R/T 积分一般不能唯一确定全部角分布和层厚 | 只可对假想/相似乳剂验证方法与条件范围 |
| 800T C-41 的非中性染料变化 | 同卷中性+分色阶梯曝光、受控 C-41，逐级 Status M／最好还有多波长光谱密度 | 只能用 Kodak 5219 ECN-2 厂商曲线与别的 C-41 专利样本约束一般性质 |
| 扫描色调、光谱与红晕转换 | 同一张真实 800T 负片的原始密度测量＋同设置尽量无自动校色的 16-bit 扫描 TIFF，记录机器/软件/通道/LUT | 只能估计负片→输出的**复合**行为，不能唯一归因扫描仪物理 |
| 特定路灯的真实亮度/SPD | 无截断且闪烁可控的更短曝光/曝光包围及灯具型号、相机光谱校准或便携光谱仪实测 | 同一个 RGB 可以由不同 SPD 造成，无法声称实际特定灯的光晕准确 |

若个人短期不做实验测量，仍可完成第 2–7 节的算法、模型表达能力、独立历史材料验证和条件研究；但**真实 800T 的绝对红晕半径、强度和颜色不可能被纯 JPEG 集合唯一标定**。与原厂/专业实验室索取或委托测量，是未来打破物理不可辨识性的两条路径，不能把找不到的数据编造为实测。

# 失测灯芯空间分布：有限候选与半径一致性检查

## 结论

允许严格失测灯芯内的非负强度重新分布后，部分局部误差改善，但没有同时恢复近灯颜色、远尾和灯芯轮廓。
更重要的是，固定原轮廓与FL2时，仅改变拟合半径，近灯最优输入Y从488.04降到237.31，中灯从280.29降到148.82。
因此这不是准确灯芯辐射的测量或恢复；这些数值是当前固定模型、光谱与采样区域条件下的逆问题解。

本轮只研究源端未知量。没有修改传播核、乳剂、DIR、显影、扫描、定光、正式current/next，也没有把返回与直接曝光的强度或颜色独立拟合。
不能从有限候选失败推出真实800T不可达，也不能据此自动缩窄核或增加吸收。

## 固定条件与候选

复用`inverse_source_radiance.py`已经准备的两处走廊顶灯、固定配准、25µm线性RGB平均后转Lab的测量算子，以及原train/heldout/outer点。
训练与报告统一在同一定光下进行；线性RGB平均没有与sRGB编码值混用。
FL2是上轮使用同一照片选择的谱形假设，不是灯具SPD实测或独立光源类别认证。
其余所有源、曝光和无光晕背景冻结。只在严格四CFA全部饱和的88/34个源单元内改变未知辐射；未饱和单元不改。

预声明五个源强度模板，均在支持内严格为正、均值为1，支持外为0：

1. 原legacy轮廓。
2. 均匀轮廓。
3. 距支持边界越远越强的中心轮廓，具有0.1正floor。
4. 沿支持本身PCA长轴的正倾斜，变化范围由`1+0.8t`规定。
5. 相反方向的负倾斜。

PCA由源支持几何确定，方向符号固定，不从目标颜色选择。
非负模板系数同时决定直接与返回FL2辐射，再通过现有相同散射、光晕核和完整显影扫描。
返回三层比例、返回/直接比均未单独拟合。
模板线性秩为4：均匀模板等于两倾斜模板的平均，故系数本身有规范冗余，不能把系数多解直接当作空间辐射场多解。

每灯8个起点，以原training Lab分量均方误差选择，未用heldout/outer选择原split候选。
训练附加相机代理删失约束；原模板拟合残差有0.03数值容差，最终所有选中结果在零容差下也没有负裕量。
这只验证原RAW代理下界，不代表相机谱感度已知、绝对辐射已标定或真实灯具几何已恢复。

## 原既定split结果

下表每格为`Lab分量RMSE / median ΔE00`，两者均越小越好。原outer为300–800µm。

| 灯与候选 | 原train 50–300µm | 原inner heldout | 原outer |
|---|---:|---:|---:|
| 近灯旧研究基准 | 12.931 / 17.407 | 12.520 / 23.136 | 5.844 / 4.868 |
| 近灯原固定轮廓FL2 | 5.420 / 5.623 | 4.830 / 4.764 | 5.836 / 5.988 |
| 近灯空间模板拟合 | 4.764 / 4.905 | 4.585 / 4.991 | 5.509 / 5.974 |
| 中灯旧研究基准 | 8.410 / 6.874 | 7.905 / 8.817 | 3.703 / 3.520 |
| 中灯原固定轮廓FL2 | 4.294 / 4.170 | 3.304 / 4.307 | 3.575 / 4.099 |
| 中灯空间模板拟合 | 4.149 / 4.322 | 3.218 / 4.186 | 3.505 / 3.930 |

近灯最优落在正PCA倾斜边界，平均输入Y为445.118；中灯落在负倾斜边界，Y为270.517。
8起点在该有限族内接近同一结果，不给出真实光源形状/强度的置信区间。
近灯inner heldout的RMSE略改善但median ΔE00略退，outer几乎没有颜色改善；中灯小幅改善，外缘median ΔE00仍劣于旧研究基准。

## 单列探索：新的空间范围留出

追加300–394.43µm训练区域，同时只把605.57–800µm称为新的径向留出。
25µm Gaussian算子的有限4σ足迹加投影余量，要求500µm分界两侧各留105.57µm保护带。
因此不会把紧邻新增训练点、共享同一平均孔径的像素冒充新径向留出。
原50–300µm的train和inner heldout点仍固定，每区最多160点。
这是一项新探索，不能与原300–800µm外缘留出混为一谈；该外缘部分进入了新增训练。

| 灯与候选 | 原inner heldout RMSE / median ΔE00 | 新605.57–800µm留出 RMSE / median ΔE00 |
|---|---:|---:|
| 近灯旧研究基准 | 12.520 / 23.136 | 4.659 / 5.161 |
| 近灯原固定轮廓FL2 | 4.830 / 4.764 | 4.870 / 5.119 |
| 近灯加径向训练 | 4.737 / 6.085 | 4.370 / 4.605 |
| 中灯旧研究基准 | 7.905 / 8.817 | 3.706 / 3.731 |
| 中灯原固定轮廓FL2 | 3.304 / 4.307 | 3.506 / 3.928 |
| 中灯加径向训练 | 2.872 / 3.178 | 3.508 / 3.841 |

拟合平均输入Y降为347.161/208.955，仍选同一PCA倾斜边界。
近灯远区改善，但inner heldout的median ΔE00退步而RMSE略改善，不能用一个指标笼统声称近区全部改善或全部退步。
中灯inner heldout改善，新远区色差略好于原FL2逆解，但仍略差于旧基准。
灯芯未参与拟合：近灯真实中位L*=97.664，原FL2为96.475，新径向拟合96.457；中灯为98.030、95.850、95.845。
这些源端变化基本没有改变固定输出链下的近白灯芯，并未恢复真实灯芯颜色。

## 必要的1D半径一致性诊断

不增加模板，固定原legacy profile+FL2，只拟合同一个非负标量Y：一次仅用原inner train，另一次仅用原outer300–800µm。
第二次是**重用外缘的新诊断fit**，其外缘结果不是heldout成绩，不能据此选择正式候选。

每次使用64个预声明对数网格点，随后对每个网格局部极小及边界邻接区间做bounded refinement。
RAW代理零容差解析下界为近灯17.603、中灯11.719；上界165950.41/60370.68仅为数值搜索限制，不是实测最大辐射。
所有最优点均不在上下界，且满足同一RAW下界。两灯共284次完整显影/选择性扫描前向计算。

| 灯与拟合目标 | 输入Y | 原inner train RMSE | 原inner heldout RMSE | 原outer RMSE |
|---|---:|---:|---:|---:|
| 近灯inner拟合 | 488.036 | 5.420 | 4.830 | 5.836 |
| 近灯outer重用拟合 | 237.311 | 7.209 | 5.904 | 4.293 |
| 中灯inner拟合 | 280.291 | 4.294 | 3.304 | 3.575 |
| 中灯outer重用拟合 | 148.822 | 5.248 | 3.531 | 3.061 |

Y是既有源接口的归一输入Y，不是W、光子数或SI辐亮度。
同一灯inner/outer拟合源强比为2.057/1.883；仅换取样半径就近一倍变化，说明不能把近灯色度改善解释成已测到准确灯芯强度。
有限网格+局部细化仍不是全域严格证明；但inner拟合也重现了上轮原固定轮廓FL2解，结果不是源强上下界夹住所致。
差异可能包括固定谱形、空间传播、背景、显影或输出响应中的条件误差，不能由该诊断独立指定根因。

## 与独立解析界合并判断

另见[SOURCE_GEOMETRY_BOUNDS.md](SOURCE_GEOMETRY_BOUNDS.md)：固定严格支持、模型与总输入，允许支持内任意非负分布并满足相机代理下界，红层返回曝光的far/near比最多比原profile下降8.44%/9.88%。
这是现有模型中的层返回曝光界，不是最终RGB、真实纯光晕或对真实残差的不可达证明。
它与本轮模板结果一致地表明：在这一固定支持与固定谱形内，继续增加源内部轮廓参数的杠杆有限。
本轮不继续扩模板、不接新输运器、不缩核，也不使用负曝光或经验调色。

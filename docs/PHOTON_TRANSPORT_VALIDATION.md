## 1. 材料域必须分开

| 量 | 物理意义 | 本轮处理 |
|---|---|---|
| 光谱感光度 S(λ) | 给定曝光/冲洗/密度判据的综合摄影响应 | 不作为吸收系数输入 |
| 未显影 μ_a(λ) | 单位长度真正吸收光能的系数，1/µm | 显式输入假想值 |
| 未显影 μ_s(λ) | 单位长度发生散射的系数，1/µm | 显式输入，事件只改变方向，不另造能量 |
| g(λ) | 单次散射方向余弦期望 | 显式输入 HG 相函数参数 |
| n(λ)、厚度 | 折射、反射及实际路程 | 显式输入；层界面用 Snell/Fresnel |
| 显影后染料谱、D-min | 处理后底片的透射测量 | 不用于构造未显影层 |
| 光化学效率 | 被吸收光子形成潜影的效率及其非线性 | 未指定，不输出“潜影”或“染料” |

自然光学厚度 τ = μ_a d；十进制吸收密度 D = τ/ln(10)。二者不能混用。
吸收光能还需区分感光组分与无效吸收；按波长换成光子数需要 λ/(hc)，
再经量子效率和潜影/显影响应才能联系摄影感光度。仅有 S(λ) 不能唯一解出
μ_a、μ_s、g 或光化学效率；已显影的 D-min 也不能唯一确定拍摄时遮罩的位置和吸收。

### 现有生产近似的核查

- `emulsion_stack` 使用归一化 `10**log_sensitivity` 构造吸收代理。
- 使用显影后 `base_density` 的颜色部分构造拍摄时的遮罩吸收代理。
- `turbidity` 作散射消光，而 `diffuse_fraction`、`forward` 独立指定角分布；
  后续 Gaussian 散射也不是同一批光子的方向追踪。
- 光谱先合成为分层源，再与角度核分离；多次返回使用与角度无关的保留率。
- 现有输出 H 经感光度单位换算，不是入射光能比例，不能把三层 H 相加声称能量守恒或不守恒。

依赖关系检查：将 `emulsion_stack(turbidity=0)` 时，独立 `diffuse_fraction=.6`
仍允许非零宽角源，原单次核 >800 µm 的质量比例仍约 8.46%。这是代码结构检查，
不是实际无散射 800T 的测量，也不是现有 H 单位下的物理能量预算。
已更正 `film.py` 相关注释；算法保持原样。忽略注释/文档字符串后的可执行 AST 与 HEAD 相同。

## 2. 最小验证器

实现：`tools/eval/photon_transport.py`，只依赖 NumPy，不读取任何胶片档案。

单色、非相干、无限平行层，法线或斜入射 pencil beam。光包携带能量，采用
MCML 风格的光学深度采样、跨层剩余光学深度、吸收权重扣除、Henyey–Greenstein
散射，以及界面 Fresnel 反射 / Snell 折射。每次往返都重新经过真实路径和界面，
不是按整数倍半径复制卷积核。吸收位置记录实际 x/y/z；在最后方界面反射后的
吸收另作子集标签，仍包含在总吸收中，不能重复相加。

账本：入口镜面反射＋上方逃逸＋下方逃逸＋各层吸收＋微小权重余量＋事件上限余量 = 1。
不采用 roulette；微小/未完成权重单列，不伪称为吸收。径向统计范围外的能量另记 overflow，
不会截断后重新归一化。径向返回能量不是额外的能量源。

限制：标量非偏振 Fresnel、HG 相函数、无荧光、无干涉/波动、无镜头、无真实材料光学数据，
也没有显影和扫描。它是传播算法验证器，不是 800T 的可用替代管线。

## 3. 角度吸收会怎样改变尾部

固定同一假想内部角分布 p(θ) ∝ sinθ cos^1.5θ、片基厚 130 µm、折射率 1.5。
光从片基前侧进入片基，在背面反射，返回后先过被动吸收层，再过活性吸收层。
此处角分布是已指定的条件输入，不声称由某个真实 μ_s 产生。

每条角度路径按同一能量账本结算：背面逃逸、被动层吸收、活性层吸收、前方逃逸。
活性吸收权重为 R(θ) exp(-τ_p/cosθ) [1-exp(-τ_a/cosθ)]。
对照仅将两个材料路径设为法线厚度，角分布、Fresnel 与几何均固定。
没有调半径、调强度、裁掉尾部或按照片拟合。

下表 τ_a=.1，半径指片基前侧的**返回位置** r=2t tanθ，
不是乳剂有限深度内的实际吸收位置；后者由完整 Monte Carlo 另行统计。

| 假想被动层 τ_p | 材料路径 | 活性层吸收/输入 | >800 µm 吸收/输入 | >800 µm 占活性吸收 |
|---|---|---:|---:|---:|
| 0 | 法线路径对照 | 5.004% | 0.5055% | 10.10% |
| 0 | 按角度路径 | 9.749% | 2.0755% | 21.29% |
| .4 | 法线路径对照 | 3.354% | 0.3388% | 10.10% |
| .4 | 按角度路径 | 3.964% | 0.2939% | 7.42% |

结论：**可以在守恒条件下自然改变尾部，但方向取决于吸收发生在哪里。**
前置被动吸收选择性压制长路径；活性层自身的斜光程则能增加远端捕获。
在第二种材料配置中，远端绝对吸收减少而总活性吸收增加，说明不是简单整体变暗。
这同时解释为什么此前给旧代理堆栈补斜光程，并没有自动得到更窄的红晕。
这些数字完全是假想材料结果，不能赋给真实 CineStill。

## 4. 全输运、极限与公开 MCML 示例

运行器：`tools/eval/photon_transport_audit.py`。
450/550/650 nm 分别使用明确列入 JSON 的假想 μ_a、μ_s、g、n、厚度；
不从感光曲线或 D-min 派生。每个波长 100,000 光包；径向分布按真实吸收位置记录。
三种颜色是独立单色实验，不是最终扫描 RGB，也不做感光度单位换算。

- 三个单色案例能量账本最大闭合误差约 1.9e-13，截止余量非负且 <3e-14。
- μ_s=0、法线入射时，仍有近轴 Fresnel 返回吸收，但 >300 µm 返回吸收为 0。
- 后方折射率匹配时，后界面返回吸收为 0；前方散射/吸收仍存在。
- 每种 N=25,000 与 N=100,000 使用四个种子。550 nm 活性返回吸收均值
  分别为 .08366 ± .00043 与 .08297 ± .00009（四次重复的均值标准误）。
  只作采样稳定性检查，不把一次标准误比例当作完整收敛证明。

官方 OMLC 与 Kodak PDF 在此环境访问返回代理 403；没有声称重新读到这些官方原文。
读取了公开 [MCML 镜像](https://github.com/bipy/MCML/tree/bd8fcb2602cdb31aca2cc253a925058e6c3b16fc)
中的 `mcmlgo.c`，核对 Hop/Drop/Spin、剩余光学深度和界面处理。
用其固定 SHA256 的 `sample.mco` 公开输出交叉检查；**没有执行下载的 C 代码**。
从原样例 cm 转成 µm：层厚 1000/1000/2000 µm，n=1.37，
μ_a=.0001/.0001/.0002，μ_s=.01/.001/.001，g=.9/0/.7。

| 能量分数 | 镜像内 MCML 公开样例（1M 光包） | 本验证器（4×25k 光包均值） |

| 入口镜面反射 | .0243729 | .0243729 |

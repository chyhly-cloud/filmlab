# 800T 模拟 "与真实成片差距不大" 的判定标准 (预先登记)

在拿到测试集 C 之前写下, 之后不再修改。

## 数据
- **测试集 C**: 全新收集的真实 CineStill 800T 冲印店扫描, 来源网页与参考集 (ref3) 不重叠,
  去掉作者声明调色的帧。C 不参与任何调参。
- **模拟**: 冻结在提交 85603a9 的渲染 (101 个场景, 按画面内容分为夜景 / 蓝调 / 室内 / 日光)。
- **对照**: 参考集 ref3 (94 张真实扫描, 曾用于调参) —— 代表 "另一组真实 800T"。

## 指标
每类 10 项: 最暗 1% / 中位亮度 (8 位), 暗部 / 中间调 / 高光的 Lab a、b, 中间调彩度, 亮度范围。
两侧都去掉大面积剪影 (L* < 5 的像素超过 30%) 的画面。

## 判定 (两条都满足才算通过)
1. **整体**: 综合误差 (各类各项 |中位差| / C 的四分位距, 求和)
   score(模拟, C) ≤ score(ref3, C)。即模拟与 C 的差距不大于另一组真实 800T 与 C 的差距。
2. **逐项**: 模拟中位数落在 C 的四分位区间之外的 (类别, 指标) 个数
   ≤ ref3 落在其外的个数。

## 结果 (测试集 C 只评估一次)
测试集 C: 130 张真实 800T 扫描, 54 个来源网页 (夜景 36 / 蓝调 27 / 室内 44 / 日光 23), 与 ref3 无重叠;
清单见 refC_manifest.tsv。模拟为提交 85603a9 的冻结渲染。

注: 首次运行时排除规则的正则把 "no editing mentioned" / "unedited" 也当成了调色声明, 只剩 33 张;
按登记的规则 (只排除作者声明调色的帧) 修正正则后运行。判定标准与阈值未改。

| 类别 | 模拟 误差 | ref3 误差 | 模拟 四分位外 | ref3 四分位外 |
|---|---|---|---|---|
| 夜景 | 6.30 | 7.40 | p50, 中b, 亮b, 中彩度 | 中a, 中b, 亮a, 亮b, 中彩度 |
| 蓝调 | 4.21 | 4.17 | 暗a, 暗b, 中b, 中彩度 | p1, 暗b, 中b, 中彩度 |

## 色卡验证 (Vision3 500T, 3200K, 真实 Noritsu 扫描) — tools/eval/chart_500t.py

数据: Die Lichtfänger 500T 测试 (同场景 X100V RAW + 500T Noritsu 平坦扫描)。色调无关指标: 每通道用自身灰阶反查,
比较 18 个彩色块的 (r−g, b−g) 分离向量, 以"理想光谱曝光"(Ohta 色卡光谱 × 3200K × 500T 感光度) 为基准。
曝光: 场记板 ISO 500 → 色卡 n5 落在胶片中灰 (底片 n5 密度 0.54, 标准中灰 0.536)。

| | 分离比 | 方向误差中位 |
|---|---|---|
| 真实 Noritsu 扫描 | 1.04 | 8° |
| 本系统 Frontier 输出 | 0.96 | 7° |
| 本系统 Noritsu 输出 | 0.97 | 13° |

- 真实扫描与理想光谱曝光一致 → 胶片感光度数据可信。
- 本系统各阶段: 曝光 5° (绿 +16° 来自相机 RGB 本身, 输入限制), 染料 7°, 扫描密度 7–11°。
- 相纸染料串扰 (参考印放) 开 / 关只差约 2°: 开时黄绿多偏 ~9°, 红少偏 ~11° → 无充分证据改动, 保留。
- 输出影调: 白 / n5 = 169 / 76 (8 位), 真实平坦扫描 L* 69 / 38, 接近。

更正: 上一版结论 ("Noritsu 去掉串扰") 来自测试脚本的错误 —— colour.sRGB_to_XYZ 默认先做 sRGB 解码,
把线性亮度算小了约 12 倍, 模拟过曝约 3.6 档, 高光压缩造成了虚假的色相偏转。已撤回该改动。

### 第二个场景: 5600K LED (灯光片不加滤镜, CineStill 的典型用法)

| | 分离比 | 方向误差中位 |
|---|---|---|
| 真实 Noritsu 扫描 | 1.01 | 10° |
| 本系统 Frontier 输出 | 0.84 | 12° |
| 本系统 Noritsu 输出 | 0.88 | 19° |

- 饱和度差距来自输入: 此场景 X100V 文件本身比色度学相机低饱和约 25% (理想 RGB 1.25 vs X100V 0.95);
  用理想 (CIE 观察者) RGB 作输入时, 曝光阶段方向误差 3–7°、不损失饱和度。
- 胶片 + 扫描链 (曝光 → 输出) 在两个场景中都基本保持色分离 (×0.94–1.0), 与真实一致。
- 黄绿在扫描阶段多偏 +10–15°: 来自通用档案 (Portra 800) 的印放换算用在 500T 上 —— 冲印店也只有通用档案,
  属于物理上真实的误差来源。试过二阶 (3D LUT 式) 换算: 无改善, 未采用。
- 结论: 在本数据可分辨的精度内 (真实扫描相对理想本身就有 8–10° 偏差), 胶片 / 冲洗 / 扫描链没有需要修正的系统误差。

### 有色成色剂遮罩 (带符号染料谱) 与 C-41 显影模型复核 (独立研究 2026-10-17)

**1. 负值的来源 (研究报告未查明)**
- Kodak H-1-5219 (2026) 染料谱图注明 "Process: ECN-2; D-mins subtracted", 纵轴到 −0.2; 原始数字化曲线 (spektrafilm 早期提交中的 csv)

  (3:00 @ 41.1°C) 比较 → 跨工艺差异全部落在一个估计值 activity=0.85 上; KIN_A / KIN_SHIFT 由 Portra 800 在 CD-4 内的推冲拟合。
  公开资料检索: 没有 5219 在 C-41 与 ECN-2 下的实测特性曲线 (只有主观扫描对比)。→ **τ 不可由公开数据标定**。

**结论**

1. **现行误差约一半来自逐帧自动定光模型, 不是胶片物理**: 只给三个印放光号, 误差 11.1 → 5.5 (日光 9.7 → 4.1)。
   自动定光的颜色校正在"不校正 → 完全校正"之间只移动 0.01–0.08 密度, 而真实冲印店需要 0.1–0.2:
   **误差不在力度, 在于模型以什么为中性**。拟合出的光号是系统性的: 夜景 8/8 红通道偏移为负、6/8 蓝为正
   (真实冲印店把夜景印得更冷, 对应之前的夜景 Δb +9); 钨丝灯箱 3/3 整体亮约 1/3 档 (对应 ΔL −9.6)。
2. **之前"物理路径更好"的结论不成立**: phys 在自动定光下最好 (9.71), 但定光公平后物理残差最差 (O1 5.97)。
   它的优势来自与自动定光模型的相互作用。WB65 在定光公平后中性 (5.61 → 5.68 / 5.50 → 5.55) ——
   白平衡误差本质上是每通道曝光偏移, 光号可以完全吸收; 它仍是已证实的输入错误, 但对 RAW 配对的颜色影响主要通过自动定光。
   P = I 使物理残差变差 (5.61 → 5.91, 日光与夜景都变差), 与 500T 图卡的方向相反 → 不采用。
3. **输出调整 (矩阵 + tint) 在公平定光下几乎不贡献** (O1 5.50 vs 5.61; 夜景、日光略好, 钨丝变差)。
4. **C-41 τ**: 公平定光后 τ = 1.0 与 1.176 无差别 (5.68 / 5.61), τ = 1.3 在所有组都更差 (6.00)。
   拟合的整体反差 s: τ 1.0 → 1.08, 1.176 → 0.92, 1.3 → 0.85, 真实反差落在 τ ≈ 1.0–1.18 之间 —— 但整体反差与扫描仪影调混杂,
   只作为对冻结区间上端的弱证据 (区间保持 [1.0, 1.3])。
5. **新发现 (最重要的线索): 真实扫描的灰阶上红 / 蓝通道反差低于绿通道**。DLF 500T 真实 Noritsu 扫描 (ECN-2, 独立来源)
   灰阶 R/G 0.80–0.82, B/G 0.82–0.89; 模拟 R/G 1.03–1.12, B/G 0.93–0.96。800T 预言机 O2 的蓝斜率也一致地 ≈ 0.89 (与 τ 无关)。
   这正是 LAB_TINT 拟合出来的形状 (暗部偏品红、高光偏绿): **经验 tint 一直在代替一个物理链里没有产生的通道反差差异**。
   物理核心重现 Kodak Status M 曲线, 所以差异应产生在扫描仪对染料的窄带测量 / 档案归一化, 或冲印店的通道曲线 —— 待查。
6. **光源识别**: 咖啡店 (实测阳光 ≈ 3500K, 白墙在阳光下的对数色度接近 3300K 黑体) 被判为 41% 钨丝 + 59% 荧光 / LED / 金卤;

   (灯箱的误差主要是荧光灯物理, 见下)。作为候选 C, 以 `Params(scan_gray_balance="us6160634")` 运行; 正式基线不变。
2. "锁定颜色"只适用于锁定设置的冲印店 (EPFL): 同店夜景 −1.65, 咖啡店 −4.6, 但在 ref3 与 SillyStill 上大幅变差 → 只能作为冲印店预设
   (`scan_neutral="film", scan_color_strength=0`), 不能作为通用规则。
3. 被否定的假设: 以高光为白 (夜景 +5.5); 每类光源取最近色度的成员 (`light_member="nearest"`, 钨丝灯箱 +2.1, 咖啡店 +0.4);
   强制荧光 / LED 光谱 (白光灯管反而更黄, db +12 / +31); CIE D40/D45; 染料光谱平移 (CD-3→CD-4) 不是暖光色相扭转的原因。

### 新的物理发现 (与定光无关, 两家冲印店一致或有独立测量)

- **蓝通道反差过高**: Frontier 灰阶楔 (同店) B/G 0.93 (纸张本身 1.03 → 胶片系统 ≈ 0.90); Noritsu 图卡 (另一店, ECN-2) 0.82–0.89;
  模拟 1.04–1.07。逐级追踪: 多出的部分在底片 Status M 上已存在 (log H 1.03 → Status M 1.08)。带符号遮罩 (Kodak 原始曲线的负值区,
  spektrafilm 截掉了) 把 Status M 降到 1.03、Dn 1.01, 方向正确, 但配对上不一致 (图卡 −0.6, 白光灯管 +1.8) → 记录, 暂不采用。
  红通道反差偏低只在 Noritsu 上出现 (Frontier R/G 1.00) → 属于该店 / 扫描仪。
- **暖光色相扭转**: 2350K 均匀灯箱, 模拟 (固定定光) a +10.9 b +39.6 (橙), 真实 a −0.8 b +31.4 (黄); 2800K 白场两者 a 都 ≈ 0。
  曝光已用黑体光谱核对 (误差 ≤ 0.07 log), 光晕只贡献 +0.03 log。扭转来自 Dn 中红偏移被保留、蓝偏移被压缩 (Status M → Dn)
  再经相纸放大; P、LED 波长、遮罩、染料平移、相纸染料串扰都不能消除 (相纸串扰贡献约 2 a)。没有真实底片密度, 无法区分
  "胶片红层响应" 与 "冲印店按通道有限校正"。
- **夜景中间调**: 真实为蓝色 (色相 −85°…−103°, 彩度 8–40), 模拟彩度只有 0.63–0.83 且色相偏离; 误差集中在 L 25–75, 与定光策略无关。
- 光源光谱映射本身准确: 白色表面在各类光源下, 引擎由相机 RGB 推出的层曝光与精确积分相差 ≤ 0.06 log; 误差在于用哪一款光源光谱。

### 需要的数据 (按价值)

1. 真实负片的扫描密度 (或 Status M) 与同场景的冲印店扫描: 才能分开胶片物理与冲印店校正 (暖光扭转、蓝反差都卡在这里)。
2. 第二家冲印店的同卷 RAW 配对 (含日光): 验证 US6160634 的跨店泛化。
3. 夜景光源的实测光谱 (或含光源的场景照片), 用于约束冷色尖峰光源下的胶片响应。

## 计算审计与修正分类 (2026-10-18)

审计方法: 逐处对照独立标准 (colour-science 参考实现、闭式积分、专利原文、标准定义) 数值核实; 只报告能被证明的错误。
开关: `Params.corrections` (逐项) 与 `lights.WB_REFERENCE`; 默认全部关闭, 正式基线逐位不变。

### 已核实的问题与独立证据

| 项 | 性质 | 独立标准 | 修正前 → 修正后 |
|---|---|---|---|
| WB65 (`lights.WB_REFERENCE="D65"`) | **输入计算错误** | LibRaw 日光白平衡 = D65 中性 (3 台相机, 4 位小数一致) | D55 → D65 |
| `linear_white` | **物理计算错误** | 中性反射率在已知光源下的层曝光可精确积分 | 中灰蓝层 +0.03…+0.06 log (3200K / 荧光 / 钠灯) → 0 |
| `gray_halo` | **物理计算错误** (光源与光晕核不一致) | 胶片设计光源 (3200K) 下的灰卡在标准定光下应印成中性 | a* +2.1 → −0.01 |
| `grain_aperture` | **单位错误** | RMS 颗粒度按 48 µm 直径圆孔测得 | σ 高 12.8% → 正确 (无颜色影响) |
| `paper_white` | **呈现约定** (与文档声明的介质相对渲染不一致) | 介质相对渲染: 相纸白 = 输出白 | 相纸白 (1.003, 0.999, 0.993) → (1, 1, 1) |
| US6160634 彩度筛选 (`us6160634_axis`) | **算法实现错误** (相对本帧中位而非灰轴) | 专利原文: 标准化后各通道密度差 | 均匀偏色画面不再被当作中性 |

注意: **负片片基 (Dn = 0) 映射为黑, 相纸白 (Dp = 0) 映射为白**, 两者在代码中分开 (片基 → 相纸最大密度 2.1–2.2 → 输出 0.002–0.0035);
`paper_white` 只改变相纸白及整条中性灰阶的色度, 不影响片基。

### 分类与建议

- **基础修复候选 (已核实, 所有评估都不退步):** `gray_halo`、`grain_aperture`。
- **呈现约定 (可选):** `paper_white` —— 与文档声明一致、影响 ≤ 0.8 ΔE、所有评估中性; 是否采用取决于约定, 不是物理问题。
- **已核实但暂缓 (输入端, 揭示了下游补偿):** WB65、`linear_white`。两者都是确定的计算错误, 但修正后改善夜景、使跨店日光与图卡略差,
  ref3 也有升有降 —— 说明下游的经验部分 (饱和度矩阵、tint、定光) 是在这些错误存在时标定的。应作为一组一起采用,
  并且只能在不依赖这些经验部分的评估 (物理参考 + 预言机) 上重新确认, 不能为了配对分数单独调整下游。
- **可选扫描策略:** 候选 C (`us6160634`, 阈值 0.2 曾在 ref3 A 上选择, 不能视为未经数据标定) 与修正版 `us6160634_axis`
  (修好灯箱, ref3 A 21.96 / B 20.04 / C 18.23, 不采用)。

这些修正都只让模型内部计算正确, **不说明整个物理模型已经准确**: 蓝通道反差偏高、暖光色相扭转、夜景中间调不够蓝都不受这些修正影响,
在没有负片密度测量之前不判定它们属于胶片层还是扫描层。

  或分支 `baseline-legacy` 逐位复现。

  不为新物理重新拟合扫描仪参数。

### 为什么不重新标定经验层

用重建的原标定程序 (LAB_TINT: ref3 A 上三个亮度段的 真实 − 模拟 中位; 矩阵: `fit_scan_matrix.py`, 5 对 SillyStill) 分别为两种物理标定:
程序能复现现有常数 (矩阵系数差 ≤ 0.03; tint 暗部 / 中间调相近, 亮部差约 2), 但两条重新标定的管线在 ref3 上都不如手工常数
(现行物理 21.73 / 21.35 / 18.41, 修正后物理 21.90 / 21.83 / 18.75, 手工常数 20.80 / 20.72 / 18.58)。重新标定本身不带来改善,
而在同一程序下, 修正后物理在同店配对上更好 (12.62 → 12.11), 跨店持平 → 物理修正的价值不依赖经验层。

## 负片层面的独立数据: Kodak 原始 5219 (2026-10-18)

公开资料检索: CineStill 未公开 800T 的特性曲线 / 光谱数据 (FAQ 只说明 EI 800 由特性曲线分析决定、蓝感层加快);
Filmtypes 链接的数据表文件已失效 (402); 未找到 CineStill 负片的 Dmin / 密度实测或含场景真值的未反转负片扫描数据集;
EPFL 仓库只有冲印店正像扫描。**可用的负片实测只有 Kodak 5219 数据手册 (经 spektrafilm 历史版本数字化)**。

### 发现: FilmLab 的 5219 数据合成的 Status M 与 Kodak 实测不一致

| 对齐横轴后的中间调 Status M | B/G | R/G |
|---|---|---|
| Kodak 实测 5219 | 0.974 | 0.852 |
| FilmLab 5219 (spektrafilm 分层曲线 + 截断染料谱) | 1.081 (+11%) | 0.922 (+8%) |
| Kodak 实测 Portra 800 (扫描仪档案胶片) | 1.135 | 0.972 |
| FilmLab Portra 800 | 1.090 (−4%) | 0.974 |

`tools/eval/unmix_5219.py` 用 Kodak 原始带符号染料谱与 D-min 按 Kodak 实测 Status M 重新解混 (按构造一致);
**独立验证** (Kodak 实测的中性中间调光谱密度, 不参与解混): RMS 0.0064 D (现行 0.0261 D, spektrafilm 带符号 0.0134 D)。
接入全化学链后, ECN-2 灰阶 Status M 与 Kodak 实测最大差 0.001 D (现行 0.185 D)。
Frontier 灰阶楔 B/G (真实 0.93): Status M 1.081 → 0.993, Dn 1.055 → 0.989, 输出 1.024–1.066 → 0.997–1.024 ——
**蓝通道反差偏高约一半来自这一数据处理错误**。

但接入 `next` 后成片在全部评估上变差 (ref3 21.10 / 20.78 / 18.40 → 22.92 / 22.95 / 19.13; 同店 11.63 → 12.47;
钨丝灯箱 10.90 → 12.02; 预言机 O1 5.72 → 5.83)。修订后 Dn 的 R/G 从 0.97 降到 0.90, 输出红通道反差低于真实。
扫描档案的抵消假设不成立 (Portra 800 只偏 −4%)。C-41 动力学 (在 Portra 800 推冲数据上拟合) 如何作用于新的分层曲线无法验证。
→ **不并入 next**, 保留为实验代际 `next_k5219`。

### 对剩余问题的判断 (不确定性记录, 停止低收益实验)

| 问题 | 现状 | 能解释的部分 | 无法辨识的原因 / 需要的数据 |
|---|---|---|---|

| 夜景中间调不够蓝 | 真实色相 −85…−103°, 模拟彩度 0.63–0.83 | 无 (光源识别预言机、天空 / 臭氧 / 倒易律 / 灯光散射均已排除) | 冲印店校正与物理无法区分 → 需要夜景负片密度或光源光谱 |

(CineStill 默认走自动光源识别, 不经过这两处) —— 验证结论不变。

### Kodak 原始 5219 的复核与冻结 (2026-10-18)

**证据层级 (不能混用)**

| 层级 | 内容 | 结论 |
|---|---|---|
| 按构造 | 重新解混后 Status M 与 Kodak 特性曲线一致 (0.000 D) | 不是证据, 是拟合目标 |
| 部分独立 | Kodak 实测的中性中间调光谱密度 (同一数据手册、同一数字化来源, 但不参与解混) RMS 0.006 D (现行 0.026 D); 全化学链 ECN-2 灰阶 Status M 0.001 D | 证明染料谱 + D-min + 分层曲线与 Kodak 自身的测量自洽; **不证明真实冲洗或真实扫描** |
| 真实 ECN-2 成片 (DLF 图卡, Noritsu) | 底片 / Dn 层面红、蓝反差向真实方向靠近, 但输出通道反差两版完全相同; 色相方向误差略差 (9°→10°, 11°→14°) | 不支持 |
| 真实 CineStill C-41 成片 (EPFL / SillyStill 配对、ref3) | 全部变差 | 不支持 |

**接入一致性核查**

- 片基: FilmLab `base_density` 与 Kodak D-min 在 400–700 nm 最大差 0.005 D → 一致, 未替换不是问题。解混在 Kodak 曲线最低点留下 c = (0.026, 0.031, 0.011)
  (Kodak H-D 起点略高于 D-min), 影响可忽略。
- 单位: Kodak 染料谱按峰值归一 (1.0), spektrafilm 约按单位 Status M 归一 (峰值 1.20 / 1.42 / 1.28) → 层染料量的单位不同
  (同一密度下 Kodak 单位的绿层多约 19%)。化学模型的上限按曲线最大值换算、DIR 作用于归一化量。
- **化学模型与表示无关 (已验证)**: C-41 / ECN-2 的 Status M 反差倍数, spektrafilm 表示 1.089 / 1.134 / 1.147, Kodak 表示 1.102 / 1.140 / 1.164。
  → C-41 下的退步不是单位或化学兼容性造成的, 而是 ECN-2 起点的差异 (R/G 0.92 → 0.85, B/G 1.07 → 0.98) 被下游放大。

**退步的位置**: 输出前的逐帧两点灰平衡用通道斜率把各通道重新拉齐 (图卡: 两版输出都是 1.04 / 0.96, 真实 0.80 / 0.82),
底片层面的反差差异被抹掉; 印放密度矩阵 P 由 spektrafilm 的 Portra 染料谱拟合, 与 Kodak 原始谱的组合在图卡上色相略差。
这两处都是冲印店 / 扫描仪的经验部分, 现有数据无法确定它们与真实行为的差距。

**冻结**: next_k5219 保留为实验代际, 不并入 next; 不为追回成片分数调整经验常数。
解冻条件: 真实 800T (或 5219) 负片的密度读数 + 同一负片的冲印店扫描 —— 才能区分"底片数据"与"扫描定光模型"。

### 冷暖跟随检验 (wb_cast.py, 2026-10-18; 只用 RAW 配对, 无拟合)

问题: 冲印店是否基本不校色, 成片"遇冷则冷、遇暖则暖"; 模拟是否同样保留。输入 RAW 用固定日光白平衡 (不用相机自动白平衡)。
拍摄白平衡只能当粗坐标: 图卡、钨丝灯箱、灯泡帧共用同一预设, 灯管灯箱各自一个值, 只有夜景是逐帧自动 → 主要信息在按光源分组。

**3. 泛光的来源: 夜景的成片亮度与高光压缩** (tone_transfer.py, 8 个夜景, 只用传感器未饱和像素 —— 曝光是测量值):
- 中间调 (−1.5…+1 档) 模拟比真实亮, 逐场景 −0.5 … +3.2 档, 中位约 +0.6 档 (逐帧自动亮度 = 操作员变量);
- 中间调反差偏高 (−1.75 → +0.75 档: 模拟输出跨 4.9 档, 真实 4.5 档), 高光更早进入肩部 (+1.75 → +3.75 档: 模拟 0.51 档, 真实 0.76 档)。
→ 光源周围 +1…+3 档的被照亮区域被印得接近白, 与灯本身连成一片 = "黄白泛光"; 真实扫描在这一段仍有层次, 灯保持为亮点。
这是扫描定光 (亮度) 与相纸 / 扫描影调的问题, 不是输入错误, 也不是光晕。亮度偏差逐场景差异很大 (与此前"夜景亮度由冲印店逐帧决定"一致),
现有数据不能把肩部形状与逐帧亮度分开 → 记录, 不调参数。

**4. 不可辨识的真实高光信息**: 传感器饱和区内的亮度、形状与光谱 (只剩周围未饱和像素的颜色) 无法从 RAW 恢复; 现有重建是先验
(亮度对数均匀随机、穹顶形状)。因此光晕的"光源选择性"(钠灯 / 白炽灯红晕强, 白光 LED 弱) 在模型里只体现光谱类别
(halation_response 按每类光源光谱计算), 每盏灯的真实亮度不可辨识 —— 不能用固定倍数或人工光晕替代。

**5. 截断像素里的未饱和通道 —— 证实被丢弃, 但保留它们不改善光源外观 (实验开关, 不并入候选)**
传感器数据: 夜景"截断"像素中 22–62% 的蓝通道、17–55% 的红通道并未饱和 (是实测值); 三通道全饱和只占 26–76%。
旧重建把整像素换成"周围颜色 × 亮度先验", 覆盖了这些实测值。实验开关 `rawio.HIGHLIGHT_RECON = "per_channel"`
(`reconstruct_highlights_cam`, 相机原始通道; 未饱和通道保留, 饱和通道 = 实测通道 × 光源颜色比例且不低于截断值;
只有三通道全饱和时用亮度先验; 相机通道 → XYZ 用同图未饱和像素拟合的线性映射, 中位相对残差 2.5%)。
光源区域色差 (source_region_de.py, 8 个夜景 / 黄昏, 模拟 − 真实):

| | 灯芯 ΔE00 | 周围 0–300 µm ΔE00 | 周围 ΔL / Δb |
|---|---|---|---|
| next | 3.09 | 15.78 | +5.5 / +5.5 |
| 传感器判定 (next_sensor) | 3.06 | 15.96 | +5.7 / +5.7 |
| 传感器判定 + 逐通道 | 3.96 | 15.26 | +4.9 / +3.8 |

逐通道: 周围 6/8 场景略好, 灯芯在两个黄昏场景明显变差 (R1-03-4 4.2 → 7.4, R1-07-8 9.8 → 12.9), 目视中央路灯的橙色灯芯反而变白
→ 不满足"无新问题", 只保留为实验开关。原因: 截断区的颜色比例来自周围的光 (数码镜头眩光混合), 与灯本身的光谱不同;
真正决定胶片上灯色与红晕的是全饱和核心的亮度与光谱, **不可辨识**。

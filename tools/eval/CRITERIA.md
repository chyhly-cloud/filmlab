# 800T 模拟 "与真实成片差距不大" 的判定标准 (预先登记)

在拿到测试集 C 之前写下, 之后不再修改。

## 数据
- **测试集 C**: 全新收集的真实 CineStill 800T 冲印店扫描, 来源网页与参考集 (ref3) 不重叠,
  去掉作者声明调色的帧。C 不参与任何调参。
- **模拟**: 冻结在提交 85603a9 的渲染 (101 个场景, 按画面内容分为夜景 / 蓝调 / 室内 / 日光)。
- **对照**: 参考集 ref3 (94 张真实扫描, 曾用于调参) —— 代表 "另一组真实 800T"。

## 指标
每类 10 项: 最暗 1% / 中位亮度 (8 位), 暗部 / 中间调 / 高光的 Lab a、b, 中间调彩度, 亮度范围。
两侧都去掉大面积剪影 (L* < 5 的像素超过 30%) 的画面。

## 判定 (两条都满足才算通过)
1. **整体**: 综合误差 (各类各项 |中位差| / C 的四分位距, 求和)
   score(模拟, C) ≤ score(ref3, C)。即模拟与 C 的差距不大于另一组真实 800T 与 C 的差距。
2. **逐项**: 模拟中位数落在 C 的四分位区间之外的 (类别, 指标) 个数
   ≤ ref3 落在其外的个数。

## 结果 (测试集 C 只评估一次)
测试集 C: 130 张真实 800T 扫描, 54 个来源网页 (夜景 36 / 蓝调 27 / 室内 44 / 日光 23), 与 ref3 无重叠;
清单见 refC_manifest.tsv。模拟为提交 85603a9 的冻结渲染。

注: 首次运行时排除规则的正则把 "no editing mentioned" / "unedited" 也当成了调色声明, 只剩 33 张;
按登记的规则 (只排除作者声明调色的帧) 修正正则后运行。判定标准与阈值未改。

| 类别 | 模拟 误差 | ref3 误差 | 模拟 四分位外 | ref3 四分位外 |
|---|---|---|---|---|
| 夜景 | 6.30 | 7.40 | p50, 中b, 亮b, 中彩度 | 中a, 中b, 亮a, 亮b, 中彩度 |
| 蓝调 | 4.21 | 4.17 | 暗a, 暗b, 中b, 中彩度 | p1, 暗b, 中b, 中彩度 |
| 室内 | 3.73 | 6.46 | 暗b, 亮a | p1, 暗b, 中b, 亮a, 亮b |
| 日光 | 3.69 | 2.92 | p1, 中彩度 | 中b, 亮a |
| **合计** | **17.93** | **20.96** | **12** | **16** |

判定 1 (整体): 17.93 ≤ 20.96, 通过。判定 2 (逐项): 12 ≤ 16, 通过。
模拟与独立测试集的差距小于另一组真实 800T 扫描与它的差距。

## 色卡验证 (Vision3 500T, 3200K, 真实 Noritsu 扫描) — tools/eval/chart_500t.py

数据: Die Lichtfänger 500T 测试 (同场景 X100V RAW + 500T Noritsu 平坦扫描)。色调无关指标: 每通道用自身灰阶反查,
比较 18 个彩色块的 (r−g, b−g) 分离向量, 以"理想光谱曝光"(Ohta 色卡光谱 × 3200K × 500T 感光度) 为基准。

- 真实扫描 vs 理想: 分离比 1.04, 方向误差中位 8° → 胶片感光度数据与真实一致。
- 本系统: 曝光阶段 5° (绿 +16° 来自相机 RGB 本身, 输入限制); 染料阶段 9°。
- 参考印放的相纸染料串扰使黄绿 / 绿 / 黄额外偏红 10–20°, 真实 Noritsu 扫描没有这种偏转
  → Noritsu 型输出改为各通道独立 (print_crosstalk=False)。Frontier 保留 (Fuji 2001: 目标为复现相纸印放, 无反证数据)。
- 同时在 ref3 上 (CineStill 默认 Frontier, 不受此改动影响) 试过把 Frontier 也去掉串扰: A 21.3→25.5, B 24.0→22.2,
  全部 14.4→16.2 —— 证据不一致, 未采用。

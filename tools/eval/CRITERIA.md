# 800T 模拟 "与真实成片差距不大" 的判定标准 (预先登记)

在拿到测试集 C 之前写下, 之后不再修改。

## 数据
- **测试集 C**: 全新收集的真实 CineStill 800T 冲印店扫描, 来源网页与参考集 (ref3) 不重叠,
  去掉作者声明调色的帧。C 不参与任何调参。
- **模拟**: 冻结在提交 85603a9 的渲染 (101 个场景, 按画面内容分为夜景 / 蓝调 / 室内 / 日光)。
- **对照**: 参考集 ref3 (94 张真实扫描, 曾用于调参) —— 代表 "另一组真实 800T"。

## 指标
每类 10 项: 最暗 1% / 中位亮度 (8 位), 暗部 / 中间调 / 高光的 Lab a、b, 中间调彩度, 亮度范围。
两侧都去掉大面积剪影 (L* < 5 的像素超过 30%) 的画面。

## 判定 (两条都满足才算通过)
1. **整体**: 综合误差 (各类各项 |中位差| / C 的四分位距, 求和)
   score(模拟, C) ≤ score(ref3, C)。即模拟与 C 的差距不大于另一组真实 800T 与 C 的差距。
2. **逐项**: 模拟中位数落在 C 的四分位区间之外的 (类别, 指标) 个数
   ≤ ref3 落在其外的个数。

## 结果 (测试集 C 只评估一次)
测试集 C: 130 张真实 800T 扫描, 54 个来源网页 (夜景 36 / 蓝调 27 / 室内 44 / 日光 23), 与 ref3 无重叠;
清单见 refC_manifest.tsv。模拟为提交 85603a9 的冻结渲染。

注: 首次运行时排除规则的正则把 "no editing mentioned" / "unedited" 也当成了调色声明, 只剩 33 张;
按登记的规则 (只排除作者声明调色的帧) 修正正则后运行。判定标准与阈值未改。

| 类别 | 模拟 误差 | ref3 误差 | 模拟 四分位外 | ref3 四分位外 |
|---|---|---|---|---|
| 夜景 | 6.30 | 7.40 | p50, 中b, 亮b, 中彩度 | 中a, 中b, 亮a, 亮b, 中彩度 |
| 蓝调 | 4.21 | 4.17 | 暗a, 暗b, 中b, 中彩度 | p1, 暗b, 中b, 中彩度 |
| 室内 | 3.73 | 6.46 | 暗b, 亮a | p1, 暗b, 中b, 亮a, 亮b |
| 日光 | 3.69 | 2.92 | p1, 中彩度 | 中b, 亮a |
| **合计** | **17.93** | **20.96** | **12** | **16** |

判定 1 (整体): 17.93 ≤ 20.96, 通过。判定 2 (逐项): 12 ≤ 16, 通过。
模拟与独立测试集的差距小于另一组真实 800T 扫描与它的差距。

## 色卡验证 (Vision3 500T, 3200K, 真实 Noritsu 扫描) — tools/eval/chart_500t.py

数据: Die Lichtfänger 500T 测试 (同场景 X100V RAW + 500T Noritsu 平坦扫描)。色调无关指标: 每通道用自身灰阶反查,
比较 18 个彩色块的 (r−g, b−g) 分离向量, 以"理想光谱曝光"(Ohta 色卡光谱 × 3200K × 500T 感光度) 为基准。
曝光: 场记板 ISO 500 → 色卡 n5 落在胶片中灰 (底片 n5 密度 0.54, 标准中灰 0.536)。

| | 分离比 | 方向误差中位 |
|---|---|---|
| 真实 Noritsu 扫描 | 1.04 | 8° |
| 本系统 Frontier 输出 | 0.96 | 7° |
| 本系统 Noritsu 输出 | 0.97 | 13° |

- 真实扫描与理想光谱曝光一致 → 胶片感光度数据可信。
- 本系统各阶段: 曝光 5° (绿 +16° 来自相机 RGB 本身, 输入限制), 染料 7°, 扫描密度 7–11°。
- 相纸染料串扰 (参考印放) 开 / 关只差约 2°: 开时黄绿多偏 ~9°, 红少偏 ~11° → 无充分证据改动, 保留。
- 输出影调: 白 / n5 = 169 / 76 (8 位), 真实平坦扫描 L* 69 / 38, 接近。

更正: 上一版结论 ("Noritsu 去掉串扰") 来自测试脚本的错误 —— colour.sRGB_to_XYZ 默认先做 sRGB 解码,
把线性亮度算小了约 12 倍, 模拟过曝约 3.6 档, 高光压缩造成了虚假的色相偏转。已撤回该改动。

### 第二个场景: 5600K LED (灯光片不加滤镜, CineStill 的典型用法)

| | 分离比 | 方向误差中位 |
|---|---|---|
| 真实 Noritsu 扫描 | 1.01 | 10° |
| 本系统 Frontier 输出 | 0.84 | 12° |
| 本系统 Noritsu 输出 | 0.88 | 19° |

- 饱和度差距来自输入: 此场景 X100V 文件本身比色度学相机低饱和约 25% (理想 RGB 1.25 vs X100V 0.95);
  用理想 (CIE 观察者) RGB 作输入时, 曝光阶段方向误差 3–7°、不损失饱和度。
- 胶片 + 扫描链 (曝光 → 输出) 在两个场景中都基本保持色分离 (×0.94–1.0), 与真实一致。
- 黄绿在扫描阶段多偏 +10–15°: 来自通用档案 (Portra 800) 的印放换算用在 500T 上 —— 冲印店也只有通用档案,
  属于物理上真实的误差来源。试过二阶 (3D LUT 式) 换算: 无改善, 未采用。
- 结论: 在本数据可分辨的精度内 (真实扫描相对理想本身就有 8–10° 偏差), 胶片 / 冲洗 / 扫描链没有需要修正的系统误差。


## ASC 色块: Kodak 5219 (FotoKem ECN-2) vs 本系统 — tools/eval/asc_5219.py

参考为文章中的 Ideal 色块 (Alexa 35 经同一管线 vs Ideal: 分离比 1.05–1.06, 方向 2–3°, 管线接近中性)。

| | 3200K 分离比 / \|Δ方向\| | 5600K 分离比 / \|Δ方向\| |
|---|---|---|
| 真实 5219 | 0.92 / 4° | 0.96 / 3° |
| 模拟 500T ECN-2 (Frontier) | 0.95 / 3° | 0.92 / 4° |
| 模拟 500T C-41 (Frontier, CineStill 方式) | 1.00 / 3° | 1.03 / 3° |

- 整体饱和度与色相: 与真实 5219 一致。绿色的 +17° 偏转 (3200K) 也被复现。
- 不一致: 蓝天 (真实 0.67–0.72, −30°; 模拟 0.87–0.90, ±3°), 5600K 下绿色 (真实 +25°, 模拟 +7°)。
  但真实片经过的是电影管线 (印放密度扫描 → LogC4 → Rec709 LUT), 与冲印店扫描不同; 在 Die Lichtfänger 的
  Noritsu 扫描中蓝天与理想曝光一致 (1.16 / +5°)。无法归因于胶片 → 不据此改动模型。

## CineStill 800T 配对数据 (SillyStill: 同一三脚架, f/8, 数分钟内先后拍) — tools/eval/pair_compare.py

数据只有 1 对 RAW (咖啡店, 窗外直射阳光 + 阴影) 与 5 对数码 JPEG; 胶片侧为冲印店 JPEG (扫描仪未说明)。

| 场景 | 中间调 ΔL | 暗部彩度 模拟/真实 |
|---|---|---|
| 咖啡店 (RAW) | −24 | 1.4 / 9.9 |
| 夜景走廊 | −12 | 1.4 / 4.3 |
| 阴天建筑 | −10 | 1.9 / 6.4 |
| 阴影中的木墙 | −12 | 3.0 / 3.9 |
| 霓虹灯管 | −4 | 5.7 / 7.8 |

- 咖啡店: 测光补偿 +0.5 → +1.5 档时, 整条影调曲线在所有亮度档都与真实一致 → 胶片 + 扫描的影调形状正确,
  差的是整体亮度。ref3 同方向: 日光 p50 −35 (8 位), 室内 −13; 夜景正常。
- 扫描仪亮度依据由 LATD (积分透射, 光学印放机的测法) 改为平均密度 (数码冲印机的密度直方图):
  在 39 张正常曝光的日光 RAW 上离散更小 (σ 0.076 vs 0.097); 正常偏移重新标定为 −0.14。
  ref3: A 21.29→20.36, B 23.97→23.76, 全部 14.37→13.18 (室内 p50 −13→−3); C: 20.46→19.82 (判定仍通过)。
- 仍未解决: 日光逆光 / 高反差场景偏暗 (日光 p50 仍 −35)。试过但验证集 B 不支持、未采用:
  按比例校正 (斜率 0.5/0.7/0.85), "积分到灰" (正常偏移 0), 对数平均测光, 线性 / 对数平均各半测光 ——
  每一种都是修好日光就让夜景 / 黄昏过亮 (或相反)。现有数据无法区分"摄影师按场景补偿"与"冲印店按场景补偿",
  需要更多带 RAW 的配对数据。

### 扫描仪饱和度校正矩阵 (由 800T 配对拟合) 与剩余问题

- 加入 SATURATION_MATRIX (tools/eval/fit_scan_matrix.py): 留一验证 5 对全部改善; ref3 B 23.76→20.78, 全部 13.18→12.41,
  C 19.82→18.50 (判定通过)。天空色相 −120°→−102° (真实 −98°), 木墙 43–58°→62–74° (真实 72–87°)。
- 试过但未采用: 全强度颜色校正 (12.60)、斜率上限减半 (13.42, C 20.34)、换灰平衡锚点 (咖啡店不变)。
- 霓虹灯管 (pair 5): 数码 JPEG 中灯管 R 截断 (255), 亮度与颜色信息已丢失; 用 RAW 的截断重建处理 JPEG 会产生伪色,
  未采用 → 输入数据限制, 需 RAW。
- 咖啡店 (唯一的 RAW 对) 仍偏冷: 真实冲印店保留了阳光的暖色 (白卡 b +22, 模拟 +7), 与灰平衡参数无关;
  推测为冲印机的"颜色失败"(单一主色画面) 抑制 —— 需要更多日光 RAW 配对才能确定其规则。

## EPFL CineStill 800T 数据 (cs-413-cinestill/800t-emulation) — tools/eval/epfl_800t_manifest.csv

36 帧 Frontier 扫描 (TIFF: Fujifilm Digital Link; Photoshop 25.6 另存, XMP 无调整记录) × 47 张 Panasonic G81 RW2。
无日光场景。20 组可用于校准 (C-41 未书面确认), 14 组配对待确认, 2 组仅验证。

- 灰阶楔 (R1-17-18 ↔ P1480492, 14 级): 只拟合一个曝光偏移 (+0.53 档, 与拍摄者调查 +0.5 一致) 后,
  平均 |ΔL*| 1.4, 最大 2.6 → 胶片 + Frontier 的影调曲线正确。最亮 3 级模拟低约 2 L* (高光肩部略早), 未改。
- 夜景 (曝光 ≤ 4 s): ΔE 中位 4–12, 走廊 / 玻璃建筑与真实接近。
- 长曝光 (6 s、30 s) 的天空: 真实为深蓝, 模拟偏黄 18–28 (b)。已排除: 扫描仪灰平衡锚点 (4 种组合)、
  曝光 (−0.5…−2.5 档)、钠灯 589 nm (500T 红层仍有 32% 感光)。推测为倒易律失效的分层偏色 (CineStill 官方
  承认存在, 未公布分层数据) → 未建模。
- 灯箱色块 (对齐成功的 2 组): 暖光下颜色基本一致 (彩度比 1.02, 色相 +3°), 但模拟偏暗 11–21 L*
  (高调画面按平均密度定亮度被印暗, 与日光问题同源); 白光灯管下模拟偏黄 b +17。
- 试过但未采用: 取消 3200K 重平衡 —— EPFL 夜景略好、C 17.8, 但 ref3 B 20.8→23.1, 日光 / 室内更冷。
- 高调画面规则 (定亮度时密度在灰卡 + c 处封顶, 一个参数, 正常偏移按 39 张日光 RAW 重新标定): c = 0.1/0.2/0.3
  在调参集 A 上全部变差 (20.82 → 20.92–21.05), 按事先约定不采用。日光 p50 只从 −35 改善到 −30…−34:
  大多数日光帧的亮度校正已达上限, 估计方法的改变传不到输出 → 日光偏暗的主因不在亮度估计。
- 灯泡光晕测试 (R1-08…13, 真实): 红色光晕紧贴光源, 约 600 µm 外消失。光源在胶片上饱和、数码 RAW 中截断后重建、
  两台相机放大倍率不同 → 只能检验形状: 外侧尾部衰减 (折回曝光域约 ×0.5 / 100 µm) 与片基全反射模型
  (×0.5–0.6 / 100 µm) 一致; 强度无法检验。未改动。

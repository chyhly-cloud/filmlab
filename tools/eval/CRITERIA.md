# 800T 模拟 "与真实成片差距不大" 的判定标准 (预先登记)

在拿到测试集 C 之前写下, 之后不再修改。

## 数据
- **测试集 C**: 全新收集的真实 CineStill 800T 冲印店扫描, 来源网页与参考集 (ref3) 不重叠,
  去掉作者声明调色的帧。C 不参与任何调参。
- **模拟**: 冻结在提交 85603a9 的渲染 (101 个场景, 按画面内容分为夜景 / 蓝调 / 室内 / 日光)。
- **对照**: 参考集 ref3 (94 张真实扫描, 曾用于调参) —— 代表 "另一组真实 800T"。

## 指标
每类 10 项: 最暗 1% / 中位亮度 (8 位), 暗部 / 中间调 / 高光的 Lab a、b, 中间调彩度, 亮度范围。
两侧都去掉大面积剪影 (L* < 5 的像素超过 30%) 的画面。

## 判定 (两条都满足才算通过)
1. **整体**: 综合误差 (各类各项 |中位差| / C 的四分位距, 求和)
   score(模拟, C) ≤ score(ref3, C)。即模拟与 C 的差距不大于另一组真实 800T 与 C 的差距。
2. **逐项**: 模拟中位数落在 C 的四分位区间之外的 (类别, 指标) 个数
   ≤ ref3 落在其外的个数。

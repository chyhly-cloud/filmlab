# 800T 模拟 "与真实成片差距不大" 的判定标准 (预先登记)

在拿到测试集 C 之前写下, 之后不再修改。

## 数据
- **测试集 C**: 全新收集的真实 CineStill 800T 冲印店扫描, 来源网页与参考集 (ref3) 不重叠,
  去掉作者声明调色的帧。C 不参与任何调参。
- **模拟**: 冻结在提交 85603a9 的渲染 (101 个场景, 按画面内容分为夜景 / 蓝调 / 室内 / 日光)。
- **对照**: 参考集 ref3 (94 张真实扫描, 曾用于调参) —— 代表 "另一组真实 800T"。

## 指标
每类 10 项: 最暗 1% / 中位亮度 (8 位), 暗部 / 中间调 / 高光的 Lab a、b, 中间调彩度, 亮度范围。
两侧都去掉大面积剪影 (L* < 5 的像素超过 30%) 的画面。

## 判定 (两条都满足才算通过)
1. **整体**: 综合误差 (各类各项 |中位差| / C 的四分位距, 求和)
   score(模拟, C) ≤ score(ref3, C)。即模拟与 C 的差距不大于另一组真实 800T 与 C 的差距。
2. **逐项**: 模拟中位数落在 C 的四分位区间之外的 (类别, 指标) 个数
   ≤ ref3 落在其外的个数。

## 结果 (测试集 C 只评估一次)
测试集 C: 130 张真实 800T 扫描, 54 个来源网页 (夜景 36 / 蓝调 27 / 室内 44 / 日光 23), 与 ref3 无重叠;
清单见 refC_manifest.tsv。模拟为提交 85603a9 的冻结渲染。

注: 首次运行时排除规则的正则把 "no editing mentioned" / "unedited" 也当成了调色声明, 只剩 33 张;
按登记的规则 (只排除作者声明调色的帧) 修正正则后运行。判定标准与阈值未改。

| 类别 | 模拟 误差 | ref3 误差 | 模拟 四分位外 | ref3 四分位外 |
|---|---|---|---|---|
| 夜景 | 6.30 | 7.40 | p50, 中b, 亮b, 中彩度 | 中a, 中b, 亮a, 亮b, 中彩度 |
| 蓝调 | 4.21 | 4.17 | 暗a, 暗b, 中b, 中彩度 | p1, 暗b, 中b, 中彩度 |

## 色卡验证 (Vision3 500T, 3200K, 真实 Noritsu 扫描) — tools/eval/chart_500t.py

数据: Die Lichtfänger 500T 测试 (同场景 X100V RAW + 500T Noritsu 平坦扫描)。色调无关指标: 每通道用自身灰阶反查,
比较 18 个彩色块的 (r−g, b−g) 分离向量, 以"理想光谱曝光"(Ohta 色卡光谱 × 3200K × 500T 感光度) 为基准。
曝光: 场记板 ISO 500 → 色卡 n5 落在胶片中灰 (底片 n5 密度 0.54, 标准中灰 0.536)。

| | 分离比 | 方向误差中位 |
|---|---|---|
| 真实 Noritsu 扫描 | 1.04 | 8° |
| 本系统 Frontier 输出 | 0.96 | 7° |
| 本系统 Noritsu 输出 | 0.97 | 13° |

- 真实扫描与理想光谱曝光一致 → 胶片感光度数据可信。
- 本系统各阶段: 曝光 5° (绿 +16° 来自相机 RGB 本身, 输入限制), 染料 7°, 扫描密度 7–11°。
- 相纸染料串扰 (参考印放) 开 / 关只差约 2°: 开时黄绿多偏 ~9°, 红少偏 ~11° → 无充分证据改动, 保留。
- 输出影调: 白 / n5 = 169 / 76 (8 位), 真实平坦扫描 L* 69 / 38, 接近。

更正: 上一版结论 ("Noritsu 去掉串扰") 来自测试脚本的错误 —— colour.sRGB_to_XYZ 默认先做 sRGB 解码,
把线性亮度算小了约 12 倍, 模拟过曝约 3.6 档, 高光压缩造成了虚假的色相偏转。已撤回该改动。

### 第二个场景: 5600K LED (灯光片不加滤镜, CineStill 的典型用法)

| | 分离比 | 方向误差中位 |
|---|---|---|
| 真实 Noritsu 扫描 | 1.01 | 10° |
| 本系统 Frontier 输出 | 0.84 | 12° |
| 本系统 Noritsu 输出 | 0.88 | 19° |

- 饱和度差距来自输入: 此场景 X100V 文件本身比色度学相机低饱和约 25% (理想 RGB 1.25 vs X100V 0.95);
  用理想 (CIE 观察者) RGB 作输入时, 曝光阶段方向误差 3–7°、不损失饱和度。
- 胶片 + 扫描链 (曝光 → 输出) 在两个场景中都基本保持色分离 (×0.94–1.0), 与真实一致。
- 黄绿在扫描阶段多偏 +10–15°: 来自通用档案 (Portra 800) 的印放换算用在 500T 上 —— 冲印店也只有通用档案,
  属于物理上真实的误差来源。试过二阶 (3D LUT 式) 换算: 无改善, 未采用。
- 结论: 在本数据可分辨的精度内 (真实扫描相对理想本身就有 8–10° 偏差), 胶片 / 冲洗 / 扫描链没有需要修正的系统误差。

### 蓝色 / 天空偏淡的逐阶段追踪 (tools/eval/pair_stage_trace.py, pair_stage_stats.py)

- 蓝色偏淡集中在两帧: EPFL 黄昏 (dusk) Δb +34、远景 (skyline) +28; 其余场景 ≤ +11。
- 这两帧天空相对中性物: B−G 分离正常, 缺的是 R−G (真实 −0.48 / −0.51, 模拟 −0.10 / −0.14, 相机本身 −0.10 / −0.03)。
- 但对齐的整幅图显示, 真实扫描是**整张偏冷** (路面 / 墙 / 灯都偏蓝, 各亮度档 Δb +22…+37), 不只是天空。

### 有色成色剂遮罩 (带符号染料谱) 与 C-41 显影模型复核 (独立研究 2026-10-17)

**1. 负值的来源 (研究报告未查明)**
- Kodak H-1-5219 (2026) 染料谱图注明 "Process: ECN-2; D-mins subtracted", 纵轴到 −0.2; 原始数字化曲线 (spektrafilm 早期提交中的 csv)

**2. 自洽检验 (复现 + 去循环)**

截断 1.08 / 11°、0.91 / 14°; 带符号 1.14 / 10°、0.97 / 14° —— 差别小且方向不一, 不能区分。

**4. C-41 模型 (报告 B、C)**
- τ = (时间/C-41 标称) × 2^((温度−C-41 标称)/6) × activity(C-41)/activity(ECN-2) = 1/0.85: 时间 / 温度项相对 C-41 自身标称, 不与原生 ECN-2
  (3:00 @ 41.1°C) 比较 → 跨工艺差异全部落在一个估计值 activity=0.85 上; KIN_A / KIN_SHIFT 由 Portra 800 在 CD-4 内的推冲拟合。
  公开资料检索: 没有 5219 在 C-41 与 ECN-2 下的实测特性曲线 (只有主观扫描对比)。→ **τ 不可由公开数据标定**。
- 敏感性 (带符号谱, 扫描密度): τ 1.0 → 1.3 使 B 层 gamma 0.52 → 0.68、B−G 交叉 0.045 → 0.117, 色卡分离比 1.25 → 1.41; 染料谱平移开 / 关
  只改变 gamma ±0.03。τ 是 C-41 端最大的不确定量。
- 染料谱平移对带符号谱: 整体平移会把成色剂负瓣一起移动 (无物理依据); 只平移正部分 (signed_pos) 与整体平移的结果差 < 0.01 gamma。
- 可辨识性: EPFL 灰阶楔 (14 级) 各变体 |Δab| 6.6–8.0, τ 的影响 ≤ 0.7 —— 扫描仪逐帧两点灰平衡抹掉了交叉; 剩余误差以整体 Δb +5…+6

**结论 —— 冻结**

  并**引入了**绿色的暖偏 (Δa +2.7 → +13) 和青 / 蓝的欠饱和 (1.03 → 0.50, 0.63 → 0.21) —— 这些跨场景偏差来自输出端的经验部分, 不是输入。
- D65 白平衡在固定参考下去掉整体偏黄 (Δb +5.1 → +0.5), 暖色过饱和明显减轻 (橙 1.81 → 1.36, 黄 1.62 → 1.19, 钨丝灯箱 1.90 → 1.31)。
  剩余暖色过饱和与 §1 钨丝灯下黄 / 橙 B 层的重建极限方向一致。
- D65 白平衡放进现行完整链路 (只记录): RAW 配对 ΔE00 10.8 → 10.5, 9 对 12.08 → 12.09, ref3 A 20.82 → 21.24, B 20.78 → 21.68, C 18.50 → 17.79
  —— A、B 变差, 按规则不采用。下游的 SATURATION_MATRIX、LAB_TINT、LATD_NORMAL、光源先验都是在 D55 假设下标定的, 会抵消物理修正。

### 4. C-41 参数: 保持冻结 (τ ∈ [1.0, 1.3]), 不假设现有显影响应正确, 也不由冲印店扫描反推。

结论: 输入端有一个已证实的系统误差 (白平衡参考 D55 → 应为 D65); 光源识别与暖光下的光谱重建是信息极限, 只能界定;
最大的跨场景色相偏差 (绿暖偏、青 / 蓝欠饱和) 产生在冲印店扫描模型的经验部分。修正顺序应为: 先改输入白平衡参考 → 在固定参考输出下
确认物理核心 → 再只用 RAW 配对重新标定输出端经验部分。基线不变。

### 结论

1. **WB65 (已证实的输入错误)**: RAW 配对 10/12 改善, 图卡中性, C 一致改善, 但 B 在 3 个种子下一致变差 (约 +4%, 主要是 B 夜景 9.7 → 10.4)。
   按规则不作为默认; 已在正式代码中做成显式开关 `filmlab.lights.WB_REFERENCE` (默认 "D55", 与旧版逐位一致; "D65" 与沙箱逐位一致)。
   B 变差的最可能原因: SATURATION_MATRIX / LAB_TINT 是在 D55 输入下对 ref3 A 拟合的, 吸收了白平衡错误。
2. **两套验证目标在逐帧平衡上直接冲突**, 这是目前影响最大的单一因素: 关闭逐帧平衡使 RAW 配对 ΔE 10.90 → 7.83 (11/12 改善, 日光咖啡店 9.6 → 5.6),
   同时使 ref3 A +59%、B +30% (日光中 b +1.4–1.5 IQR, 偏暖)。即公开 800T 扫描总体上做了逐帧平衡, 而配对样本没有。
   12 个配对中 11 个来自同一卷 / 同一冲扫 (R1), 所以配对对"不平衡"的偏好不能推广为胶片物理; 逐帧平衡强度属于扫描操作员变量, 现有数据不可辨识。
   (此处两侧输入均为 RAW, 不存在之前的 RAW / JPEG 混杂。)
3. **物理核心 vs 经验输出**: 图卡支持 phys (无矩阵 / tint / P), 但 ref3 A/B 变差 40–45%。经验部分在统计上补偿了扫描操作与输入误差, 但在图卡上压缩了真实分离。
   不按经验重新拟合矩阵 (要求 1); 在有更多独立配对前, 保持现行基线。
